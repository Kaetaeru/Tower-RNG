# Tower RNG

Roblox의 RNG 성장 구조와 지속형 타워 디펜스 전투를 결합한 게임 프로젝트입니다.

플레이어는 전투와 동시에 타워를 계속 굴리고, 자동으로 싸우는 타워 편성을 이끌고 전장을 돌아다니며 몬스터가 떨어뜨린 코인을 직접 수집합니다. 코인으로 하나의 거대한 스탯 트리와 다음 스테이지 문을 열고, 짧고 반복적인 환생으로 영구 코인·행운 배율을 높입니다.

> 모든 굴림과 전투는 계정을 전진시킨다. 긴장감과 기대감은 있어도 불필요한 손실과 압박은 없어야 한다.

> 모든 입력과 명중은 강하게 반응해야 한다. UI 클릭부터 타워 공격까지 과장된 움직임과 타격감은 필수 품질 기준이다.

---

## 핵심 게임 루프

```text
자동 굴리기 + 자동 전투
→ 타워 획득·중복 축적
→ 몬스터 처치와 코인 드롭
→ 플레이어가 이동하며 코인 수집
→ 거대 스탯 트리 성장·자동 편성 갱신
→ 코인으로 다음 스테이지 문 개방
→ 높은 코인 효율과 스테이지 행운
→ 약 7~15분 중심의 반복 환생
→ 코인·스테이지 문 초기화
→ 영구 코인·행운 배율 상승
→ 더 빠르게 다시 진행
```

첫 환생은 신규 계정 기준 약 7~10분을 목표로 합니다.

---

## 월드와 지역

```text
로비
→ 지역 1 / 스테이지 1~3: 초원·숲
→ 지역 2 / 스테이지 4~6: 사막
→ 지역 3 / 스테이지 7~9: 정글
→ 지역 4 / 스테이지 10~12: 설원
→ 지역 5 / 스테이지 13~15: 용암지대
```

총 5개 지역과 15개 스테이지가 물리적으로 이어집니다. 각 스테이지 사이에는 벽과 잠긴 문이 있으며, 코인을 지불하면 현재 환생 주기 동안 다음 구역으로 이동할 수 있습니다.

지역 테마는 외형·환경·몬스터 구성의 차이를 만들지만 원소 저항과 강제 피해 상성은 만들지 않습니다.

---

## 빠른 5웨이브 전투

```text
웨이브 1
→ 웨이브 2
→ 웨이브 3
→ 웨이브 4
→ 웨이브 5 + 스테이지 보스
→ 웨이브 1부터 반복
```

- 일반 웨이브는 적정 전투력 기준 약 10초 목표
- 완료 즉시 다음 웨이브 시작
- 보스 웨이브는 약 15~20초 목표
- 한 주기는 약 55~70초 중심
- 각 웨이브는 `MinBudget`, `BaseBudget`, `MaxBudget` 사용
- 몬스터별 `BudgetRatio`, `SpawnCost`, `MinCount`, `MaxCount`로 구성
- 5웨이브의 보스는 `MinCount: 1`로 보장
- 보스 처치는 다음 스테이지 해금 조건이 아님
- 스테이지를 벗어나면 현재 웨이브와 보스 진행 초기화

베이스가 과부하되면 현재 전투를 정리하고 3초간 새 몬스터 생성을 중단한 뒤 같은 스테이지의 1웨이브부터 다시 시작합니다. 이미 바닥에 떨어진 코인과 영구 진행은 유지합니다.

---

## 타워 획득과 콘텐츠 규모

일반 타워는 전역 타워 풀을 사용합니다.

- 첫 스테이지에서도 모든 일반 타워가 이론적으로 등장 가능
- 높은 스테이지는 타워 종류가 아니라 행운 증가
- 지역 이동과 환생으로 일반 타워 풀 초기화 없음
- 첫 출시 일반 굴리기 타워 최소 50종 목표
- 여섯 역할마다 약 8~10종 목표
- 복합 역할은 한 종류로만 계산
- 변종·합체 전용 타워는 별도 추가

실제 획득 확률은 `1 / N`으로 표시합니다.

---

## 하나의 거대한 스탯 트리

스탯 트리는 여러 메뉴로 분리하지 않고 하나의 연결된 공간으로 만듭니다.

```text
                    특수 시스템
                         │
편성 ─── 전투 ─── 기본 기능 ─── 굴리기·행운
                         │
                    수집·오프라인
                         │
                    환생·후반 기능
```

중심에는 자동 굴리기, 자동 편성, 기본 자석과 기본 성능이 있습니다. 각 분야의 입구도 코인으로 해금하며, 같은 화면에서 잠긴 가지와 다음 목표를 확인할 수 있습니다.

---

## 변종

변종은 기본 타워의 모델과 행동 골격을 재사용하지만 단순 색칠 결과로 끝나지 않습니다.

초기 공통 계열:

- 인화성: 지속 피해·폭발·전파
- 독성: 중첩 독·지속·전염
- 공허: 연쇄·순간이동·처치 반응
- 거대: 크기·범위·대상 수·강한 단발 효과

변종은 별도 고정 타워 ID를 가지며 기본형보다 강하거나 더 넓은 활용 가치를 제공합니다.

---

## 오프라인 진행

오프라인에는 굴리기와 전투를 진행하지 않습니다. 스탯 트리에서 오프라인 코인을 해금하면 제한된 양의 코인을 축적합니다.

초기 밸런스 방향:

- 온라인 수익의 약 25%에서 시작
- 성장 후 최대 약 40%
- 기본 최대 8시간 저장
- 성장 후 12시간·24시간
- 접속 시 서버 자동 지급

---

## UI·전투 표현 철학

Tower RNG는 자동 시스템이 많기 때문에 화면이 정적으로 느껴져서는 안 됩니다.

반드시 강한 반응을 제공하는 영역:

- 버튼 클릭과 토글
- 스탯 노드 구매와 문 해금
- 편성 카드 교체와 합체
- 굴리기와 희귀 타워 획득
- 코인 흡입과 HUD 수치 증가
- 타워의 준비·공격·명중
- 몬스터 피격·처치
- 웨이브·보스 출현과 환생

과장된 움직임, 반동, 오버슈트, 음향과 명중 반응은 장식이 아니라 완료 기준입니다. 화면 흔들림·섬광·파티클·햅틱은 사용자가 강도를 조절할 수 있어야 합니다.

세부 기준은 `docs/design/PRESENTATION_FEEL.md`에서 관리합니다.

---

## UI 구조

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

현재 편성, 자동 편성 ON/OFF와 역할 성향을 조절하는 퀵 편성 HUD는 일반 플레이 화면에 항상 표시합니다.

로비에는 플레이어가 현재 보유한 가장 낮은 공식 확률의 타워를 `1 / N`으로 표시하는 희귀 타워 리더보드를 둡니다.

---

## 과금 방향

Roblox RNG 게임에서 흔한 영구 행운, VIP, 빠른 굴리기, 코인 배율, 자동 수집, 슬롯, 포션, 텔레포트와 서버 부스트를 참고하되 Tower RNG의 기본 기능을 유료로 되돌리지 않습니다.

출시 우선 방향:

```text
꾸미기
→ 관리·전시 편의
→ 게임에서도 얻을 수 있는 포션 묶음
→ VIP와 제한된 영구 가속
→ 서버 전체 부스트
```

자동 굴리기, 자동 편성, 일반 지역, 환생, 합체, 기본 변종 접근, 텔레포터와 오프라인 코인은 무료 진행으로 제공합니다. 유료 전용 핵심 타워, Robux 직접 타워 굴리기와 과부하 직후 결제 강요는 사용하지 않습니다.

정확한 상품, 가격과 배율은 무료 경제의 수직 슬라이스를 완성하고 측정한 뒤 확정합니다.

## 핵심 설계 철학

### 영구적인 손실을 주지 않는다
전투 실패와 베이스 과부하는 계정을 후퇴시키지 않습니다. 환생은 선택형 성장 행동입니다.

### 계정 전체를 성장시킨다
개별 타워 레벨과 무작위 능력치를 사용하지 않습니다. 새 타워는 기존 공통 성장을 즉시 적용받습니다.

### 운이 나빠도 진행된다
낮은 결과도 중복 수량, 합체 재료와 특수 주사위 진행에 기여합니다.

### 플레이어가 직접 움직일 이유를 만든다
타워는 자동 전투하지만 코인은 월드에 떨어집니다. 플레이어는 코인을 수집하고 잠긴 문을 열어 이동합니다.

### 모든 행동에 손맛을 준다
클릭, 구매, 굴림, 공격과 명중은 즉각적이고 과장된 반응을 가져야 합니다. 기능만 작동하고 체감이 없는 상태를 완성으로 보지 않습니다.

### 시간을 강요하지 않는다
강제 일일 숙제, 연속 출석 손실과 특정 시간에만 얻는 필수 전투력을 핵심 진행에 사용하지 않습니다.

## 문서 구조

프로젝트 작업 전에는 `AGENTS.md`를 먼저 읽습니다.

```text
AGENTS.md
→ docs/INDEX.md
→ docs/design/<SYSTEM>.md
→ docs/reference/<CATALOG>.md
→ docs/spec/<SYSTEM>.md
→ docs/technical/<SYSTEM>.md
→ docs/implementation/<SYSTEM>.md
→ 실제 코드
```

하위 계층의 규칙이나 코드가 변경되면 영향을 받는 상위 문서도 같은 작업에서 갱신합니다.
