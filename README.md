# Tower RNG

Roblox의 RNG 수집 성장과 지속형 타워 디펜스 전투를 결합한 게임 프로젝트입니다.

플레이어는 전투와 동시에 타워를 무료로 계속 굴리고, 추종형 타워 편성을 이끌며 몬스터가 떨어뜨린 코인을 직접 수집합니다. 코인은 영구 스탯과 스테이지 문에 사용하고, 전투로 쌓은 Defense XP를 환생 스탯 토큰으로 바꿉니다.

> 모든 굴림과 전투는 계정을 전진시킨다. 긴장감과 기대감은 있어도 불필요한 손실과 압박은 없어야 한다.

> 전투시간은 강제 대기시간이 아니라 성장의 척도다. 새 스테이지는 어렵게 진입하고, 성장한 플레이어는 같은 스테이지를 빠르게 압도한다.

> 환생은 진행을 지우지 않는다. 쌓은 전투 경험을 새로운 영구 선택으로 전환한다.

---

## 핵심 루프

```text
무료 자동 굴리기 + 자동 전투
→ 타워 획득·중복 축적
→ 코인 직접 수집 + Defense XP 자동 획득
→ 코인 스탯 구매
→ 코인으로 스테이지 문 영구 개방
→ 더 강한 적·보상·행운
→ Defense XP 요구량 충족
→ 환생
→ Defense XP 0 + 스탯 토큰 지급
→ 원하는 영구 스탯에 배분
→ 코인·문·현재 전투를 유지한 채 계속 진행
```

---

## V1 범위와 완주

```text
5개 지역
15개 스테이지
일반 굴리기 타워 50종 이상
6개 전투 역할
4개 공통 변종 계열
수동 합체
코인 스탯 트리
환생 스탯 토큰
```

플레이타임 목표:

```text
빠른 메인 완주: 8~10시간
중앙 메인 완주: 12~15시간
느린 메인 완주: 18~22시간
스테이지 15 안정 파밍·V1 숙련: 20~30시간
전체 수집: 완료 시간 없음
```

메인 완주는 스테이지 15 최초 클리어입니다. 특정 극희귀 타워는 필수가 아닙니다.

## 첫 수직 슬라이스

```text
기본 굴리기: 4.0초
굴리기 속도 I: 3.6초
Stage 1 StageCoinUnit: 1
보스 보상 보정: 1.15
스테이지 2 문: 750코인
스테이지 3 문: 3,200코인
첫 환생: 7,000 Defense XP
```

스테이지 1:

```text
일반 웨이브 약 10초
보스 평균 약 16초
5웨이브 평균 56.28초
주기 코인 가치 400
주기 Defense XP 400
```

첫 환생 도달:

```text
균형 소비 7.96~13.41분
문 우선 7.80~14.34분
트리 우선 9.63~12.70분
```

환생 후 코인, 열린 문, 현재 위치와 전투는 유지됩니다.

---

## 최초 계정 준비

```text
첫 수동 굴리기
→ 첫 타워 자동 배치
→ HP 5 초원 슬라임
→ 코인 10·Defense XP 10
→ 자동 굴리기 구매
→ 세 번 더 굴려 4슬롯 완성
→ 약 25초에 정규 웨이브 1
```

계정당 한 번만 실행합니다.

---

## 월드

```text
로비
→ 스테이지 1~3: 초원·숲
→ 스테이지 4~6: 사막
→ 스테이지 7~9: 정글
→ 스테이지 10~12: 설원
→ 스테이지 13~15: 용암지대
```

- 문은 코인으로 한 번 구매해 영구 개방
- 환생 후 재잠금 없음
- 재접속은 로비 시작
- 마지막 열린 활동 스테이지로 빠른 복귀
- 한 번에 하나의 스테이지만 활성
- 이동·재접속·과부하 시 웨이브 1부터 새 전투
- 환생은 현재 웨이브를 초기화하지 않음

---

## 전투 시간

각 스테이지는 진입과 안정 파밍의 목표 시간을 따로 가집니다.

```text
EntryTargetSeconds
FarmTargetSeconds
```

- 적을 모두 처리하면 즉시 다음 웨이브
- 플레이어 DPS에 맞춘 자동 적 강화 없음
- 후반 일반 웨이브 통상 상한 약 20초
- 후반 보스 통상 상한 약 40초
- 보스는 전체 주기의 약 25~35%

---

## 인플레이션

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
```

표준 일반 몬스터 HP:

```text
Stage 1: 5
Stage 4: 50
Stage 7: 500
Stage 10: 5,000
Stage 13: 50,000
Stage 15: 약 232,080
```

높은 스테이지는 코인과 Defense XP 보상도 증가합니다.

---

## 타워 확률과 성능

- 일반 타워 전역 풀
- 한 굴림 한 결과, 빈 결과 없음
- 공식 기본 확률 `1 / N`
- 현재 행운 적용 확률 미표시
- 공식 분모 합 정확히 100%
- 같은 역할에서 더 희귀하면 반드시 더 강함

```text
RawPowerBudget(N) = (N / 10)^0.20
```

V1 기준:

```text
최저 역할 기준: 각 1 / 10, 기여도 약 1
최고 일반 굴리기: 1 / 10^20
최고 순수 단일 화력 기여도: 약 6,309.57
```

---

## 행운 압축

```text
BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ 0.040 × AllocatedLuckTokens
+ TemporaryCompressionBonus
```

상한:

```text
일반 굴림 5.40
황금 굴림 5.65
다이아몬드 굴림 6.05
```

균형 행운 토큰 배분에서 최고 `1/10^20` 타워 누적 획득률:

```text
13.5시간 3.012%
15시간 4.661%
25시간 17.062%
30시간 22.705%
```

내부 유효 확률은 UI에 표시하지 않습니다.

---

## 환생

```text
Defense XP 요구량 충족
→ RebirthCount +1
→ 스탯 토큰 지급
→ Defense XP 0
```

유지:

- 코인
- 열린 문
- 현재 위치·스테이지·웨이브
- 타워·도감·스탯·합체·변종
- 굴림 카운터·포션·설정

스탯 토큰은 미사용분을 이월하고 플레이어가 직접 분배합니다. 환생당 지급량과 행운 외 스탯은 아직 미확정입니다.

---

## 인벤토리·합체·변종

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

- 수동 합체만 사용
- 실패 없음
- 자동 합체 없음
- 보호·편성 수량은 재료 제외
- 기본형과 변종 혼합 금지
- 플레이어 간 거래 없음

초기 변종:

- 인화성
- 독성
- 공허
- 거대

---

## 오프라인

오프라인에는 굴리기·전투·Defense XP·스탯 토큰·연금 정수가 진행되지 않습니다.

```text
온라인 수익의 약 25%에서 시작
성장 후 약 40%
8시간 → 12시간 → 24시간 저장
```

코인만 제한적으로 지급합니다.

---

## 과금 원칙

우선순위:

```text
꾸미기
→ 관리·전시 편의
→ 게임에서도 얻는 포션
→ 제한적 영구 가속
→ 서버 전체 부스트
```

사용하지 않음:

- 유료 전용 핵심 타워·변종·합체
- Robux 직접 타워 굴리기
- Defense XP·스탯 토큰 직접 판매
- 자동 굴리기·자동 편성 유료화
- 과부하 직후 구매 압박
