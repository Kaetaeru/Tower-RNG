# Tower RNG

Roblox의 RNG 수집 성장과 지속형 타워 디펜스 전투를 결합한 게임 프로젝트입니다.

플레이어는 전투와 동시에 타워를 무료로 계속 굴리고, 추종형 타워 편성을 이끌며 몬스터가 떨어뜨린 코인을 직접 수집합니다. 코인은 하나의 거대한 스탯 트리와 스테이지 문에 사용하고, 실제 전투로 쌓는 Defense XP를 충족해 환생합니다.

> 모든 굴림과 전투는 계정을 전진시킨다. 긴장감과 기대감은 있어도 불필요한 손실과 압박은 없어야 한다.

> 전투시간은 강제 대기시간이 아니라 성장의 척도다. 새 스테이지는 어렵게 진입하고, 성장한 플레이어는 같은 스테이지를 빠르게 압도한다.

> 모든 입력과 명중은 강하게 반응해야 한다. 타격감은 일반 화면 흔들림이 아니라 과장된 모델 움직임·반동·피격·음향에서 만든다.

---

## 핵심 루프

```text
무료 자동 굴리기 + 자동 전투
→ 타워 획득·중복 축적
→ 몬스터 처치
→ 코인 직접 수집 + Defense XP 자동 획득
→ 거대 스탯 트리 성장
→ 코인으로 다음 스테이지 문 개방
→ 더 강한 적·보상·행운
→ Defense XP 요구량 충족
→ 환생
→ 코인·문·Defense XP 초기화
→ 영구 코인·행운 성장
```

---

## 첫 수직 슬라이스 기준

현재 `Confirmed (Provisional Balance)` 값:

```text
기본 굴리기 간격: 4.0초
굴리기 속도 I: 3.6초
스테이지 1 StageCoinUnit: 1
보스 코인·Defense XP 보정: 1.15
스테이지 2 문: 750코인
스테이지 3 문: 3,200코인
첫 환생: 7,000 Defense XP
```

스테이지 1의 검증된 5웨이브 주기:

```text
평균 주기: 56.28초
생성 SpawnCost 합: 385
총 코인 가치: 400
총 Defense XP: 400
일반 웨이브: 약 10초
보스 웨이브: 평균 16초
보스 시간 비중: 약 28.4%
```

첫 환생 경제 시뮬레이션:

```text
균형 소비: 7.96~13.41분
문 우선: 7.80~14.34분
트리 우선: 9.63~12.70분
```

스테이지 1에 머물러도 15분 안에 환생할 수 있고, 강한 타워로 상위 스테이지를 실제 방어하면 약 8분대로 단축됩니다.

---

## 최초 계정 준비

정규 스테이지 1 웨이브는 4슬롯 기준으로 검증되어 있습니다. 첫 타워 한 개만 가진 계정에게 즉시 정규 웨이브를 시작하지 않습니다.

```text
첫 수동 굴리기
→ 첫 타워 자동 배치
→ HP 5 초원 슬라임 1마리
→ 정상 보상 코인 10·Defense XP 10
→ 자동 굴리기 10코인 구매
→ 세 번 더 굴려 빈 슬롯 채우기
→ 약 25초에 정규 웨이브 1 시작
```

- 튜토리얼용 적 약화 없음
- 추가 보너스 재화 없음
- 빈 슬롯 채움은 기존 타워를 교체하지 않음
- 계정당 한 번만 실행하고 환생·재접속으로 반복하지 않음

## 월드

```text
로비
→ 스테이지 1~3: 초원·숲
→ 스테이지 4~6: 사막
→ 스테이지 7~9: 정글
→ 스테이지 10~12: 설원
→ 스테이지 13~15: 용암지대
```

- 스테이지 사이의 물리적 문을 코인으로 개방
- 현재 환생의 열린 문은 재접속 후 유지
- 환생 시 모든 일반 문 재잠금
- 재접속은 로비에서 시작
- 마지막 활동 스테이지가 열려 있으면 빠른 복귀 버튼 제공
- 문은 전투력 검사가 아니며 높은 스테이지 행운만 받고 복귀하는 전략 허용
- 라이브 웨이브 입구는 로비

---

## 5웨이브 전투

```text
웨이브 1
→ 웨이브 2
→ 웨이브 3
→ 웨이브 4
→ 웨이브 5 + 보스
→ 웨이브 1
```

- 완료 즉시 다음 웨이브
- 목표 시간이 남아 있어도 기다리지 않음
- `MinBudget`, `BaseBudget`, `MaxBudget`
- `SpawnCost`, `BudgetRatio`, `MinCount`, `MaxCount`
- 보스 `MinCount: 1`
- 스테이지 이탈·재접속 시 1웨이브부터 재시작
- 과부하 시 3초 정지 후 같은 스테이지 1웨이브
- 이미 떨어진 코인은 과부하 중 유지

스테이지 1 기준 보스는 `우두머리 멧돼지`이며 HP 55, SpawnCost 100입니다.

### 웨이브 시간 철학

각 스테이지에는 두 시간 기준을 둡니다.

```text
EntryTargetSeconds
- 막 진입한 편성의 목표 처리시간

FarmTargetSeconds
- 해당 스테이지에서 성장한 편성의 목표 처리시간
```

- 새 스테이지 진입 시 범위 상단
- 성장하면 범위 하단
- 크게 성장하면 목표보다 훨씬 빠르게 종료 가능
- 플레이어 DPS에 맞춘 적 자동 강화 없음
- 후반의 통상 상한은 일반 웨이브 약 20초, 보스 약 40초
- 보스는 전체 주기 시간의 약 25~35% 목표

## 강한 수치 인플레이션

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
```

표준 일반 몬스터 HP:

```text
스테이지 1: 5
스테이지 4: 50
스테이지 7: 500
스테이지 10: 5,000
스테이지 13: 50,000
```

높은 스테이지는 체력뿐 아니라 코인과 Defense XP 보상도 크게 증가합니다. 플레이어 전투력에 맞춘 자동 난이도 조정은 사용하지 않습니다.

---

## 타워 확률과 전투력

- 일반 타워는 전역 풀
- 첫 출시 일반 굴리기 타워 최소 50종
- 여섯 역할마다 약 8~10종
- 공식 기본 확률은 `1 / N`
- 분모는 `999,999`에서 끝나지 않고 수십억·수조 이상 가능
- 공식 기본 확률만 표시
- 현재 행운 적용 확률은 표시하지 않음
- 한 굴림에 정확히 한 타워, 빈 결과 없음

희귀도 기반 전투 예산의 초기 기준:

```text
RawPowerBudget(N) = (N / 10) ^ 0.20
```

같은 역할에서는 `1 / 999` 타워가 `1 / 998` 타워보다 반드시 강합니다.

현재 역할별 최저급 `1 / 10` 기준 타워 6종과 스테이지 1 전체 주기 시뮬레이션이 작성되어 있습니다.

## 거대한 스탯 트리

첫 환생 전 중심 가격:

```text
자동 굴리기 10
자동 편성 30
자석 범위 I 50
핵심 성능 I 100
굴리기 속도 I 160
자석 속도 I 220
전투 분야 해금 450
핵심 성능 II 650
코인 획득 I 550
편성 슬롯 5 1,200
```

모든 노드는 한 좌표 공간에 연결되며 환생 후 유지합니다.

---

## 환생

첫 버전의 Defense XP:

```text
Defense XP
= 처치한 SpawnCost
× StageRewardScale
× BossModifier
```

- 일반 몬스터 BossModifier 1.00
- 보스 본체 BossModifier 1.15
- 별도 웨이브 완료 XP 보너스 없음

환생 시 초기화:

- 코인
- Defense XP
- 현재 환생의 모든 문
- 현재 전투와 바닥 코인

유지:

- 타워·보호·도감
- 스탯 트리
- 굴림 카운터
- 합체·변종
- 연금 정수·포션
- 오프라인 업그레이드
- 최초 튜토리얼 완료 상태
- 빈 슬롯 채움·자동 편성 설정
- 설정

환생 확인창에는 남은 코인과 구매 가능한 영구 노드를 표시합니다. 자동 소비하거나 환생을 막지는 않습니다.

---

## 인벤토리와 합체

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

- 합체는 플레이어가 원할 때 직접 실행
- 결과 고정·실패 없음
- 자동 합체 없음
- 보호·편성 중인 수량은 재료에서 제외
- 기본형과 변종 혼합 합체 없음
- 플레이어 간 타워·재화 거래 없음

퀵 편성 HUD는 일반 플레이 중 항상 보입니다.

## 변종

초기 공통 계열:

- 인화성
- 독성
- 공허
- 거대

변종은 기본형 자산을 재사용하지만 별도 TowerId와 강화 효과를 가집니다. 최종 공식 분모는 기본형보다 훨씬 커질 수 있습니다.

## UI·타격감·설정

반드시 강한 반응을 제공:

- 버튼·토글
- 스탯 구매·문 해금
- 편성·수동 합체
- 굴리기·희귀 획득
- 코인 흡입
- 공격 준비·판정·명중
- 피격·처치
- 보스·환생

일반 공격과 UI 클릭에는 화면 흔들림을 사용하지 않습니다. 보스 등장·처치 같은 제한된 사건에만 Low 강도로 허용하며 설정에서 끌 수 있습니다.

설정:

- 파티클
- 다른 플레이어 효과
- 피해 숫자
- 명중 섬광·Trail
- 희귀 연출
- UI 움직임·감소된 움직임
- 보스 카메라 흔들림
- 음향 채널
- 알림·자동 보호
- 성능

---

## 오프라인

오프라인에는 굴리기·전투·Defense XP·연금 정수를 진행하지 않습니다. 스탯 트리 해금 후 제한된 코인만 축적합니다.

- 온라인 수익 약 25%에서 시작
- 성장 후 약 40%
- 8시간 → 12시간 → 24시간 저장
- 접속 시 서버 자동 지급

---

## 과금 방향

우선순위:

```text
꾸미기
→ 관리·전시 편의
→ 게임에서도 얻는 포션 묶음
→ 제한적 VIP·영구 가속
→ 서버 전체 부스트
```

사용하지 않음:

- 유료 전용 핵심 타워·변종·합체
- Robux 직접 타워 굴리기
- Defense XP 직접 구매
- 자동 굴리기·자동 편성 유료화
- 현재 유효 확률 숨김을 악용한 결제 강요
- 과부하 직후 구매 팝업
