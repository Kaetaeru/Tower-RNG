# Tower RNG

Roblox의 RNG 성장 구조와 지속형 타워 디펜스 전투를 결합한 게임 프로젝트입니다.

플레이어는 전투와 동시에 타워를 계속 굴리고, 자동으로 싸우는 타워 편성을 이끌고 전장을 돌아다니며 몬스터가 떨어뜨린 코인을 직접 수집합니다. 코인으로 스탯 트리와 다음 스테이지 문을 열고, 짧고 반복적인 환생으로 영구 코인·행운 배율을 높입니다.

> 모든 굴림과 전투는 계정을 전진시킨다. 긴장감과 기대감은 있어도 불필요한 손실과 압박은 없어야 한다.

---

## 핵심 게임 루프

```text
자동 굴리기 + 자동 전투
        ↓
타워 획득·중복 축적
        +
몬스터 처치 후 코인 드롭
        ↓
플레이어가 전장을 이동하며 코인 수집
        ↓
스탯 트리 성장·자동 편성 갱신
        ↓
벽과 문으로 막힌 다음 스테이지를 코인으로 개방
        ↓
더 높은 코인 효율과 현재 스테이지 행운
        ↓
약 7~15분 중심의 반복 환생
        ↓
코인·지역·스테이지 문 초기화
        ↓
영구 코인 배율·행운 배율 상승
        ↓
더 빠르게 다시 진행
```

첫 환생은 신규 계정 기준 약 7~10분을 목표로 합니다. 환생은 드문 최종 초기화가 아니라 한 세션에서 여러 번 경험하는 핵심 성장 행동입니다.

---

## 월드 진행

첫 출시 구조:

```text
로비
→ 지역 1 / 스테이지 1~3
→ 지역 2 / 스테이지 4~6
→ 지역 3 / 스테이지 7~9
→ 지역 4 / 스테이지 10~12
→ 지역 5 / 스테이지 13~15
```

총 5개 지역과 15개 스테이지가 물리적으로 이어집니다. 각 스테이지 사이에는 벽과 잠긴 문이 있으며, 코인을 지불하면 현재 환생 주기 동안 다음 구역으로 이동할 수 있습니다.

일반 스테이지에는 클리어 조건이 없습니다. 현재 들어가 있는 하나의 스테이지만 개인 전투로 활성화되며, 다른 스테이지로 이동하면 타워는 이전 공격을 중단하고 현재 스테이지의 적을 다시 공격합니다.

중반 이후에는 스탯 트리에서 텔레포터를 영구 해금할 수 있습니다. 텔레포터는 로비와 현재 환생에서 이미 연 스테이지만 목적지로 제공합니다.

라이브 웨이브 입구는 로비에 배치합니다.

---

## 타워 획득

일반 타워는 전역 타워 풀을 사용합니다.

- 첫 스테이지에서도 모든 일반 타워가 이론적으로 등장 가능
- 높은 스테이지는 타워 종류보다 굴리기 행운을 증가
- 지역 이동과 환생으로 일반 타워 풀이 초기화되지 않음
- 변종, 한정, 합체 전용 타워는 각 시스템의 별도 규칙 사용

실제 획득 확률은 `1 / N`으로 표시합니다.

---

## 오프라인 진행

오프라인에는 굴리기와 전투를 진행하지 않습니다. 대신 스탯 트리에서 오프라인 코인 수집을 해금하면 제한된 양의 코인을 축적합니다.

초기 밸런스 방향:

- 온라인 기준 수익의 약 25%에서 시작
- 성장 후 최대 약 40%
- 기본 최대 8시간 저장
- 성장 후 12시간, 24시간
- 접속 시 서버가 코인을 자동 지급하고 요약 표시

현재 스테이지에 잠시 서 있는 행동이나 임시 포션으로 오프라인 수익을 비정상적으로 높일 수 없게 합니다.

---

## UI 구조

타워 관리는 하나의 인벤토리에서 처리합니다.

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

현재 편성 아이콘, 자동 편성 ON/OFF와 역할 성향을 빠르게 바꾸는 퀵 편성 HUD는 일반 플레이 화면에 항상 표시합니다.

## 핵심 설계 철학

### 영구적인 손실을 주지 않는다

전투 실패와 베이스 과부하는 계정을 후퇴시키지 않습니다. 환생은 플레이어가 선택하는 성장 행동이며 현재 코인과 문 진행만 초기화합니다.

### 계정 전체를 성장시킨다

개별 타워 레벨과 무작위 능력치를 사용하지 않습니다. 새 타워는 기존 스탯 트리와 환생 보너스를 즉시 적용받습니다.

### 운이 나빠도 진행된다

낮은 결과도 중복 수량, 합체 재료와 특수 주사위 진행에 기여합니다. 빈 굴림을 만들지 않습니다.

### 플레이어가 직접 움직일 이유를 만든다

타워는 자동 전투하지만 코인은 월드에 떨어집니다. 플레이어는 코인을 수집하고 잠긴 문을 열어 앞으로 이동합니다. 자석과 텔레포터는 영구 성장으로 점차 편의를 높입니다.

### 시간을 강요하지 않는다

강제 일일 숙제, 연속 출석 손실, 기간 한정 핵심 전투력과 특정 시간에만 얻을 수 있는 필수 보상을 핵심 진행에 사용하지 않습니다.

## 문서 구조

프로젝트 작업 전에는 반드시 `AGENTS.md`를 먼저 읽습니다.

```text
AGENTS.md
    ↓
docs/INDEX.md
    ↓
docs/design/<SYSTEM>.md
    ↓
docs/spec/<SYSTEM>.md
    ↓
docs/technical/<SYSTEM>.md
    ↓
docs/implementation/<SYSTEM>.md
    ↓
실제 코드
```

하위 계층의 규칙이나 코드가 변경되면 영향을 받는 상위 문서도 같은 작업에서 갱신해야 합니다.
