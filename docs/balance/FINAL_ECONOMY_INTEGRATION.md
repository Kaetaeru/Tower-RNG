# V1 후반 코인 경제 통합

- 계층: 계산·검증
- 상태: **Conditional Pass · 추가 숙련 싱크 정체성 미확정**
- 프로젝트 현황: `../PROJECT_STATUS.md`
- 최종 계산 배치: `FINAL_BALANCE_BATCH.md`
- 관련 계산: `V1_GATE_ECONOMY_BENCHMARK.md`, `V1_TOWER_VARIANT_BENCHMARK.md`, `V1_FUSION_BENCHMARK.md`, `OFFLINE_COIN_BENCHMARK.md`
- 재현 스크립트: `../../tools/balance/final_economy_integration.py`
- 마지막 정리: 2026-08-03

## 목적

기존 핵심 경제 이후 선택형 시스템을 같은 유연 예산에서 구매할 때 20~30시간의 코인 흐름을 검사합니다.

```text
핵심 경제
- 문
- 편성 슬롯
- 공통 전투 성장

선택 경제
- 변종
- 합체
- 오프라인 코인
```

합체 실행에는 코인 비용을 추가하지 않습니다. 합체 코인은 시스템과 계보의 영구 해금에만 사용합니다.

---

# 1. 입력 비용

## 핵심 경제

| 분야 | 누적 가격 |
|---|---:|
| 스테이지 4~15 문 | 1,302,495,000 |
| 편성 슬롯 5~12 | 2,790,686,200 |
| 전투 III~XI | 32,303,644,000 |
| **핵심 합계** | **36,396,825,200** |

## 선택 경제

| 분야 | 누적 가격 |
|---|---:|
| 변종 가지 | 25,018,500,000 |
| 합체 가지 | 2,750,250,000 |
| 오프라인 가지 | 3,120,100,000 |
| **선택 합계** | **30,888,850,000** |

```text
현재 계산된 전체 영구 코인 싱크
= 67,285,675,200
```

첫 15분 중심 노드와 스테이지 2·3 문은 이 합계 밖에 있습니다.

---

# 2. 선택 가지 배분

핵심 경제 모델이 보존한 유연 예산 안에서 다음 세 성향을 검사했습니다.

| 성향 | 변종 | 합체 | 오프라인 |
|---|---:|---:|---:|
| 균형 숙련 | 55% | 20% | 25% |
| 수집 중심 | 75% | 15% | 10% |
| 편의 중심 | 35% | 20% | 45% |

다만 핵심 기능을 지나치게 늦추지 않도록 다음 두 노드는 성향 분배보다 먼저 구매합니다.

```text
오프라인 해금 100,000
→ 합체 핵심 250,000
→ 이후 선택 가지 비중 적용
```

균형 핵심 경제에서 실제 해금:

```text
오프라인 해금 약 1.80h
합체 핵심 약 2.57h
```

# 4. 진행 전략별 30시간 결과

균형 숙련 성향을 기준으로 비교합니다.

| 핵심 소비 전략 | 30h 유연 예산 | 현재 선택 싱크 소비 | 잔여 코인 |
|---|---:|---:|---:|
| 문 우선 | 60.958B | 30.889B | **30.069B** |
| 균형형 | 50.922B | 30.889B | **20.033B** |
| 코인 실현 70% | 14.687B | 10.889B | **3.798B** |

70% 느린 계정은 30시간까지:

- 오프라인 가지 완료
- 합체 가지 완료
- 변종 노드 10/12 구매

상태이며 코인이 과도하게 남지 않습니다.

반대로 정상·빠른 계정은 현재 선택 가지를 모두 산 뒤 큰 잔여 코인이 발생합니다.

---

# 5. 추가 숙련 싱크 요구량

30시간 잔여를 5십억 이하로 제한하려면:

```text
균형형 추가 필요량
≈ 15.033B

문 우선 추가 필요량
≈ 25.069B
```

따라서 V1에는 다음 범위의 추가 선택 싱크가 필요합니다.

```text
권고 추가 숙련 코인 싱크
= 총 15B ~ 25B
```

이 계산에서는 싱크의 **정체성을 임의로 확정하지 않습니다.** 다음 조건만 잠급니다.

- 스테이지 15 최초 클리어에 필요하지 않음
- 일반 타워·변종·합체 결과의 확률을 직접 구매하지 않음
- Robux 대체 구매를 핵심으로 삼지 않음
- 무제한 전투 배율을 제공하지 않음
- 20~30시간 수집·편의·표현 목표와 연결
- 소비하지 않아도 메인 완주 가능

정확한 시스템은 별도 기획 결정을 거쳐야 합니다.

---

# 6. 메인 완주와의 분리

유연 예산은 핵심 문·슬롯·전투 예산 90%와 분리되어 있습니다.

따라서 변종·합체·오프라인 가지의 가격은 현재 계산에서 다음을 늦추지 않습니다.

- 스테이지 15 문
- 12슬롯
- 공통 전투 ×4.50
- 중앙 12~15시간 완주

플레이어가 선택 가지를 무시해도 핵심 예산이 해당 가지로 자동 유출되지 않으며, 핵심 가지 완료 뒤 남는 코인이 유연 예산으로 이동합니다.

---

# 7. 수용 판정

| 조건 | 결과 |
|---|---|
| 오프라인 1~2h 해금 | 통과, 1.80h |
| 합체 2~4h 해금 | 통과, 2.57h |
| 선택 가지가 중앙 완주 지연하지 않음 | 통과 |
| 현 선택 가지가 20~30h 목표 제공 | 통과, 21~26h 완료 |
| 느린 계정 코인 과잉 없음 | 통과 |
| 정상·빠른 계정 30h 코인 과잉 없음 | **미통과** |
| 필요한 추가 싱크 규모 산출 | 통과, 15~25B |

따라서 수학적 통합은 완료했지만, 후반 싱크의 실제 콘텐츠 정체성이 정해질 때까지 조건부 통과입니다.

---

# 8. 결론

```text
현재 영구 코인 싱크: 67.286B
현재 선택 가지: 30.889B
균형형 30h 잔여: 20.033B
필요한 추가 숙련 싱크: 15~25B
```

새 싱크를 선택한 뒤 이 문서의 배분 모델만 다시 실행하면 됩니다. 스테이지와 확률표를 다시 계산할 필요는 없습니다.
