- 계층: 계산·검증
- 상태: **Active Benchmark · Conditional Final Pass**
- 프로젝트 현황: `../PROJECT_STATUS.md`
- 최종 계산 배치: `FINAL_BALANCE_BATCH.md`
- 관련 계산: `V1_GATE_ECONOMY_BENCHMARK.md`, `SUPPORT_CONTROL_STACKING_BENCHMARK.md`, `RUNTIME_LOSS_BUDGET.md`, `V1_TOWER_VARIANT_BENCHMARK.md`, `V1_FUSION_BENCHMARK.md`
- 재현 스크립트: `../../tools/balance/final_account_paths.py`
- 마지막 정리: 2026-08-03

## 목적

지금까지 따로 검증한 확률, 슬롯, 환생, 문, 전투 성장, 지원·제어 규칙과 런타임 손실 예산을 한 계정 경로에서 다시 검사합니다.

검증 목표:

```text
빠른 메인 완주: 8~10시간
중앙 메인 완주: 12~15시간
느린 메인 완주: 18~22시간
안정 파밍과 V1 숙련: 20~30시간
```

10,000계정을 사용했으며, 결과는 활성 온라인 플레이시간입니다.

---

# 1. 완주 전력 기준

스테이지 15 행동형 계산의 120초 최초 클리어 경계는 이상적 모델에서 약 `9,550 EC`였습니다.

지원 출처 예산 규칙과 잔여 런타임 손실 예산을 적용하면:

```text
필요 입력 EC
≈ 9,550 / 0.953254
≈ 10,019
```

계산 안전 여유를 포함한 최종 기준:

```text
Stage15 FirstClearEC = 10,050
Stage15 StableFarmEC = 12,200
```

`StableFarmEC`는 약 100초 이하의 반복 주기를 위한 보수적 기준입니다.

---

# 2. 확률 시스템 입력

각 경로에서 실제로 반영한 요소:

- 전략별 영구 문 개방 시점
- 현재 입장 가능한 최고 스테이지의 행운
- 환생 횟수와 행운·성능·주사위 속도 포인트
- 황금·다이아몬드 굴림
- 실제 누적 굴림 수
- 타워 50종 보유 수량
- 현재 전체 슬롯
- 역할별 배치 상한
- 코인 전투 배율

완주 필수 전력에서 제외한 요소:

- 변종 전투력
- 합체 전투력
- 오프라인 코인
- 임시 포션
- 특정 극희귀 타워 확정 보유

따라서 변종이나 합체 결과가 없어도 표의 완주 시간이 성립합니다.

---

# 3. 빠른 경로

조건:

```text
문 우선 소비
정상 코인 실현
스테이지 15 문 약 9.02h
```

## 최초 클리어

| 보유 운 분위수 | 예상 시간 |
|---:|---:|
| P10 | 13.5h |
| P25 | 12.5h |
| P50 | 11.0h |
| P75 | **10.0h** |
| P90 | **9.5h** |

## 안정 파밍

| 보유 운 분위수 | 예상 시간 |
|---:|---:|
| P10 | 15.0h |
| P25 | 13.5h |
| P50 | 12.0h |
| P75 | 10.5h |
| P90 | 9.5h |

해석:

- 8~10시간 완주는 문 우선과 상위 약 25% 타워 운이 결합된 빠른 경로
- 문만 빨리 연 중앙·하위 계정은 전투력 성장을 기다려 11~13.5시간에 완주
- 문 우선 자체가 모든 계정의 9시간 완주를 보장하지 않음

# 4. 중앙 경로

| P25 | **14.0h** |

| P75 | 12.5h |
| P90 | 12.5h |

## 안정 파밍

| 보유 운 분위수 | 예상 시간 |

# 5. 느린 경로

단순히 낮은 타워 운만 적용하지 않고 실제 수집 누락, 비효율적 이동과 소비 지연을 합친 **코인 실현률**을 사용합니다.

## 기준 코인의 60% 실현

```text

```

| 분위수 | 최초 클리어 | 안정 파밍 |
|---:|---:|---:|
| P10 | **19.0h** | 19.5h |
| P25 | 18.0h | 18.5h |
| P50 | 18.0h | 18.0h |
| P75 | 18.0h | 18.0h |
| P90 | 18.0h | 18.0h |


| 분위수 | 최초 클리어 | 안정 파밍 |
|---:|---:|---:|

느린 경로에서는 타워 운보다 문·슬롯·전투 성장의 코인 병목이 더 크게 작용합니다.

# 6. 전체 목표 판정

| 목표 | 계산 결과 | 판정 |
|---|---|---|
| 빠른 8~10h | 문 우선 P75~P90 9.5~10h | 통과 |
| 중앙 12~15h | 균형 P10~P90 12.5~15h | 통과 |
| 느린 18~22h | 50~60% 코인 실현 18~21.5h | 통과 |
| 특정 극희귀 필수 아님 | P10도 확정 성장으로 통과 | 통과 |
| 변종 필수 아님 | 완주 전력에서 제외 | 통과 |
| 합체 필수 아님 | 완주 전력에서 제외 | 통과 |
| 빠른/느린 격차 과도하지 않음 | 약 9.5h 대 20.5h | 통과, 상한 근처 |

빠른 P90과 가장 느린 중앙 경로의 비율은 약 2.16배입니다. 목표의 상단에 가까우므로 실제 플레이테스트에서 느린 계정이 22시간을 반복적으로 넘는지 확인해야 합니다.

---

# 7. 오프라인 코인의 위치

이 표는 활성 온라인 플레이만 측정하므로 오프라인 코인을 포함하지 않습니다.

오프라인 코인은:

- 느린 계정의 문·슬롯 구매를 보조할 수 있음
- 활성 플레이 완주 목표를 강제로 단축하지 않음
- 타워 운·Defense XP·환생을 대신하지 않음

따라서 실제 달력 시간은 길어질 수 있지만 활성 플레이시간은 표의 목표를 유지합니다.

# 8. 남은 검증

수학 모델에서의 완주 시간은 통과했습니다. 실제 출시 전에는 다음을 Roblox에서 측정해야 합니다.

- 런타임 효율이 `RUNTIME_LOSS_BUDGET.md` 하한을 지키는지
- 플레이어가 실제로 코인의 50~100%를 어느 정도 수집하는지
- 메뉴·인벤토리·맵 이동 시간이 활성 플레이에 미치는 영향
- 자동 편성이 지원·제어 한계 기여를 올바르게 계산하는지
- 모바일 환경에서 물리 코인 수집이 느린 경로를 과도하게 만드는지
