# 4. 런타임 구현 예산

현재 값은 실제 측정이 아니라 구현 목표입니다.

```text
Stage1 RuntimeEfficiency >= 0.992
Stage9 RuntimeEfficiency >= 0.990
Stage12 RuntimeEfficiency >= 0.988
Stage15 RuntimeEfficiency >= 0.986
```

지원 규칙 교체까지 합친 예상 주기 증가:

```text
Stage9  +4.29%
Stage12 +4.81%
Stage15 +4.90%
```

Stage15 15h P10 예상:

```text
113.20초 → 118.75초
```

Roblox 실측이 이 예산을 지키는지 확인하기 전에는 런타임 항목을 완전 확정으로 취급하지 않습니다.

# 7. 아직 카탈로그에 넘기면 안 되는 항목

## 실제 런타임 효율

Roblox 프로파일링 전이므로 계산 목표일 뿐입니다.

## 50종 실제 타워 행동

확률 슬롯과 전력 예산만 있으며 대부분의 이름·행동·자산이 미작성입니다.

## 스테이지 2~15 최종 콘텐츠 정체성

계산용 몬스터 이름과 행동은 카탈로그 최종 채택 전입니다.

숙련 제어실의 계산용 NodeId·표시 이름도 카탈로그에서 최종 확정해야 합니다.

```text
확률·성장·스테이지·중첩·변종·합체·오프라인 계산
```
