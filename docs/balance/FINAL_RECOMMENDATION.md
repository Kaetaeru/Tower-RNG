# V1 최종 밸런스 권고값 묶음

- 계층: 계산·검증
- 상태: **Catalog Adopted · Runtime Measurement Pending**
- 프로젝트 현황: `../PROJECT_STATUS.md`
- 배치 체크리스트: `FINAL_BALANCE_BATCH.md`
- 채택 카탈로그: `../catalog/STAGE_GATE_CATALOG.md`, `../catalog/STAT_TREE_CATALOG.md`, `../catalog/TOWER_SYSTEM_CATALOG.md`
- 마지막 정리: 2026-08-03

## 책임

이 문서는 계산에서 도출된 최종 권고값과 카탈로그 채택 결과를 연결합니다.

```text
계산 완료
→ 사용자 승인
→ catalog 채택 완료
→ 기술 명세·Roblox 구현
→ 실제 런타임·플레이테스트
```

현재 가격·공식·공통 시스템 값은 카탈로그에 채택됐습니다. 이후 값 변경은 계산 문서만 수정해서는 효력이 없으며, 관련 검증 재실행과 카탈로그 갱신이 모두 필요합니다.



# 2. 변종 채택값

권위 문서:

- `../catalog/TOWER_SYSTEM_CATALOG.md`
- `../catalog/STAT_TREE_CATALOG.md`

| 계열 | 공식 티켓 | PowerBudget 배율 |
|---|---:|---:|
| 인화성 | `1 / 5,000` | `×5.4928` |
| 독성 | `1 / 10,000` | `×6.3096` |
| 공허 | `1 / 20,000` | `×7.2478` |
| 거대 | `1 / 50,000` | `×8.7055` |

```text
VariantBaseOddsN
= BaseTowerOddsN × FamilyOddsN
```

- 변종 티켓에는 일반 행운을 두 번째로 적용하지 않습니다.
- 잠긴 계열의 티켓 구간은 재분배하지 않습니다.
- 한 굴림에서 변종은 최대 하나입니다.
- 허용 범위는 각 계열별 `1~12 → 1~31 → 1~50`입니다.
- 변종 가지 총가격은 `25,018,500,000`입니다.

개별 변종 `TowerId`, 타워별 허용 계열과 행동은 아직 미작성입니다.

# 4. 오프라인 채택값

권위 문서: `../catalog/STAT_TREE_CATALOG.md`

```text
효율 25% → 30% → 35% → 40%

```

```text

```

- 현재 입장 스테이지가 아니라 실제 5웨이브를 완주한 진행을 사용합니다.
- 오프라인 타워·변종·굴림·Defense XP·환생·스테이지 진행은 없습니다.

# 5. 숙련 제어실 채택값

권위 문서: `../catalog/STAT_TREE_CATALOG.md`

```text
변종 가지 완료
AND 합체 가지 완료
AND 오프라인 가지 완료
→ 숙련 제어실 해금
```

기능:

- 텔레포터와 스테이지 즐겨찾기
- 역할별·개별 타워 타겟 명령
- 편성 프리셋과 타겟 프로필
- 퀵 HUD
- 코인 표시·병합 제어
- 도감·획득 연출 프리셋

```text
11노드
앞 10노드 20,000,000,000
전체 25,200,000,000
```

전투력·행운·확률·코인 수익·Defense XP를 증가시키지 않습니다.

# 8. 아직 채택하지 않은 값

## 실제 RuntimeEfficiency

아래는 카탈로그 수치가 아니라 구현 목표입니다.

```text
Stage1  RuntimeEfficiency >= 0.992
Stage9  RuntimeEfficiency >= 0.990
Stage12 RuntimeEfficiency >= 0.988
Stage15 RuntimeEfficiency >= 0.986
```

Roblox 수직 슬라이스에서 실제 측정하기 전까지 `Confirmed` 또는 `Implemented`로 승격하지 않습니다.

## 개별 콘텐츠

- 일반 타워 50종의 최종 이름·행동·자산
- 개별 변종과 합체 결과
- 스테이지 2~15 최종 `MonsterId`와 표시 이름
- 스탯 트리 좌표·아이콘·세부 연결선

# 9. 변경 관리

| 변경 | 재실행할 계산 | 갱신할 카탈로그 |
|---|---|---|
| 문·슬롯·전투 가격 | 통합 경제·전체 계정 경로 | Stage Gate·Stat Tree |
| 변종 티켓·가격 | 변종·합체·후반 경제·전체 경로 | Tower System·Stat Tree |
| 합체 재료·배율 | 합체·후반 경제·전체 경로 | Tower System·Stat Tree |
| 오프라인 효율·가격 | 오프라인·후반 경제·전체 경로 | Stat Tree |
| 숙련 제어실 가격 | 후반 경제 | Stat Tree |
| 일반 확률표 | 전체 밸런스 배치 | Tower·Tower System |

현재 수학 계산과 카탈로그 채택은 완료됐습니다. 다음 콘텐츠 작업은 스테이지 1~15 계산용 웨이브의 최종 `StageId`·`MonsterId` 채택입니다.
