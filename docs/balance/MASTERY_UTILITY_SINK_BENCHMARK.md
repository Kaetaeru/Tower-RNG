## 목적

기존 문·슬롯·전투·변종·합체·오프라인 가지를 완료한 정상·빠른 계정에 남는 30시간 코인을 흡수합니다.

새 전투 배율이나 확률 구매를 추가하지 않고, 이미 기획에 존재하는 다음 기능을 하나의 후반 **숙련 제어실** 가지로 묶습니다.

```text
월드 이동과 스테이지 즐겨찾기
편성 프리셋과 퀵 HUD
역할별·타워별 타겟 명령
코인 표시·병합 제어
도감·획득 연출 프리셋
```

이 가지는 메인 완주, 스테이지 15 최초 클리어, 타워 확률과 변종 확률에 영향을 주지 않습니다.

---

# 1. 해금 조건

숙련 제어실 가지는 다음 선택 가지가 모두 완료된 뒤 열립니다.

```text
변종 가지
합체 가지
오프라인 가지
```

목적:

- 기존 선택 시스템의 해금 시점을 늦추지 않음
- 메인 완주 전 코인이 편의 가지로 새는 문제 방지
- 20시간 후반부터 30시간 이후까지 이어지는 숙련 목표 제공
- 느린 계정에 추가 구매 압박을 주지 않음

환생, 접속 종료와 서버 이동으로 구매 상태가 초기화되지 않습니다.

# 3. 제공하지 않는 효과

숙련 제어실 노드는 다음 값을 증가시키지 않습니다.

- 타워 PowerBudget와 EquivalentContribution
- 공격력·공격속도·치명타
- 일반 행운과 Compression
- 굴리기 속도
- 변종 티켓 확률
- 합체 배율과 재료 효율
- 코인 드롭량과 오프라인 효율
- Defense XP와 환생 속도
- 편성 슬롯 12개 상한

`코인 표시·병합 제어`는 서버 부하와 화면 정리를 위한 표시·병합 방식만 바꿉니다. 획득 가능한 총 코인을 증가시키지 않습니다.

`숙련 제어실 완성`도 전투 보너스가 아니라 이미 해금한 편의 기능을 한 화면에서 관리하는 최종 노드입니다.

# 4. 균형형 도달 시점

| 4 | 26.49h |
| 5 | 26.79h |
| 6 | 27.20h |
| 7 | 27.70h |
| 8 | 28.30h |
| 9 | 29.10h |
| 10 | **29.99h** |

따라서 균형형은 30시간에 앞 10노드를 완료하고, 최종 통합 노드는 약 31시간에 완료합니다.

이 가지는 `20~30시간 숙련`의 마지막 부분과 30시간 이후 수집 플레이를 연결합니다.

# 5. 소비 전략별 30시간 결과

| 핵심 소비 전략 | 30시간 구매 | 숙련 소비 | 최종 잔여 |
|---|---:|---:|---:|
| 문 우선 | 11 / 11 | 25.2B | **4.870B** |
| 균형형 | 10 / 11 | 20.0B | **0.034B** |
| 전투 우선 | 6 / 11 | 6.0B | **0.648B** |
| 슬롯 우선 | 6 / 11 | 6.0B | **0.648B** |
| 코인 실현 70% | 0 / 11 | 0 | **3.798B** |

느린 계정은 30시간에도 기존 선택 가지를 완료하지 않았으므로 숙련 제어실이 열리지 않습니다. 기존 선택 가지의 미사용 예산만 남고 잔여는 5B 아래입니다.

문 우선 계정은 전체 숙련 제어실을 약 `29.03h`에 완료합니다.

전투·슬롯 우선 계정은 약 `28.68h`에 기존 선택 가지를 완료하고, 30시간까지 앞 6노드를 구매합니다.

# 6. 전체 코인 싱크

기존 계산:

```text
문·슬롯·전투 36.3968252B
변종          25.0185B
합체           2.75025B
오프라인       3.1201B
소계          67.2856752B
```

숙련 제어실 추가:

```text
25.2B
```

최종 영구 코인 싱크 권고 합계:

```text
92.4856752B
```

모든 계정이 30시간 안에 전체 금액을 구매해야 하는 것은 아닙니다. 균형형은 30시간에 10노드, 문 우선은 11노드, 느린 계정은 아직 기존 선택 가지를 진행합니다.

# 8. 남은 작업

계산은 완료됐지만 다음은 별도 단계입니다.

- 실제 NodeId·표시 이름·아이콘·좌표 카탈로그 채택

숙련 제어실 가격이나 노드 순서가 바뀌면 `FINAL_ECONOMY_INTEGRATION.md`와 이 벤치마크만 다시 실행하면 됩니다. 스테이지·확률·환생 계산은 다시 돌릴 필요가 없습니다.
