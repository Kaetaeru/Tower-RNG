## 목적

남은 계산을 하나의 거대한 식으로 섞지 않고 의존성 순서에 따라 한 배치로 처리했습니다.

```text
개별 공식·스크립트·문서 유지
→ 단계별 수용 조건 검사
→ 영향받는 하위 계산만 재실행
→ 최종 권고값 묶음 작성
→ 이후 카탈로그 채택
```

계산과 카탈로그는 계속 분리합니다.

---

# 고정 입력

- 일반 타워 50자리 확률표
- 시간대별 굴림 수와 보유 전력 분포
- 4→12슬롯과 역할 상한
- 지원·제어 중첩 계약
- 변종 계열 확률·PowerBudget·해금 가격
- 스테이지 1~15 검증 주기와 보상
- 문·슬롯·코인 전투 통합 경제
- 환생 XP와 네 분야 스탯
- 오프라인 코인 원칙

기준 변화가 없으면 이미 통과한 스테이지 1~15 웨이브를 반복 계산하지 않습니다.
