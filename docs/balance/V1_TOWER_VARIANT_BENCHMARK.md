## 목적

변종 타워가 다음 조건을 동시에 만족하도록 출현 방식, 전투력 예산과 코인 가지를 계산합니다.

- 게임 시작부터 나오지 않고 코인 스탯 트리 해금 뒤에만 등장
- 일반 타워 50종의 공식 기본 확률을 변경하지 않음
- 일반 행운으로 변종 판정까지 이중 압축하지 않음
- 기본형보다 확실히 강하지만 V1 완주에 필수적이지 않음
- 중후반 수집 목표와 20~30시간 코인 소비처 역할
- 한 굴림에서 변종이 둘 이상 동시에 선택되지 않음
- 최종 공식 `1 / N`을 정확히 계산 가능

이 문서는 계열 확률, 전투력 예산, 해금 범위와 가격을 권고합니다. 개별 변종의 이름, TowerId, 행동, 모델과 최종 채택값은 `docs/catalog`에서 별도로 작성합니다.

# 1. 판정 계약

굴림 순서:

```text
기존 일반 확률표와 행운으로 기본 타워 선택
→ 별도의 변종 티켓 판정
→ 선택된 계열이 해금·허용·범위 포함이면 변종 지급
→ 아니면 원래 기본형 지급
```

핵심 규칙:

- 변종 티켓은 일반 행운, 황금 주사위와 다이아몬드 주사위로 직접 압축하지 않음
- 행운은 먼저 선택되는 기본 타워 분포에만 정상 적용
- 네 계열은 하나의 고정 티켓 안에서 서로 겹치지 않는 구간 사용
- 잠긴 계열의 구간은 다른 계열로 재분배하지 않고 기본형 결과가 됨
- 한 굴림에서 변종 최대 1개
- 계열을 추가 해금해도 기존 계열의 공식 확률은 변하지 않음

따라서 특정 변종의 공식 기본 분모는 항상 다음과 같습니다.

```text
VariantBaseOddsN
= BaseTowerOddsN × FamilyOddsN
```

예를 들어 공식 `1 / 10` 타워의 인화성 변종은 `1 / 50,000`입니다.

---

# 2. 계열별 판정 확률과 전투력 예산

| 계열 | 계열 판정 | 기본형 대비 PowerBudget | `1 / 10` 기본형의 최종 확률 |
|---|---:|---:|---:|
| 인화성 | `1 / 5,000` | `×5.4928` | `1 / 50,000` |
| 독성 | `1 / 10,000` | `×6.3096` | `1 / 100,000` |
| 공허 | `1 / 20,000` | `×7.2478` | `1 / 200,000` |
| 거대 | `1 / 50,000` | `×8.7055` | `1 / 500,000` |

모든 계열과 타워가 해금·허용된 상태의 원시 변종 티켓 확률:

```text
1/5,000 + 1/10,000 + 1/20,000 + 1/50,000
= 0.00037
≈ 1 / 2,702.70
```

전투력 예산은 기존 희귀도 공식과 순서를 맞춥니다.

```text
VariantPowerMultiplier
= FamilyOddsN ^ 0.20

VariantPowerBudget
= BaseTowerPowerBudget × VariantPowerMultiplier
```

이는 최종 분모에 `RawPowerBudget(N)`을 적용한 값과 정확히 같습니다.

```text
RawPowerBudget(BaseN × FamilyN)
= RawPowerBudget(BaseN) × FamilyN^0.20
```

따라서 흔한 기본 타워의 변종이 같은 최종 분모의 일반 타워보다 강해지는 희귀도 역전은 만들지 않습니다.

계열 배율은 전부 직접 피해로 넣지 않습니다. 개별 변종은 다음 요소에 예산을 분배합니다.

- 기본 행동 강화
- 지속 피해·폭발·전염·연쇄
- 범위·대상 수·타겟 전환
- 역할 고유 지원·제어 기여
- 필요하면 느린 템포나 제한 조건

# 3. 타워 허용 범위 단계

한 계열을 해금했다고 즉시 50종 전체의 변종을 제작·판정하지 않습니다.

| 단계 | 허용 기본 타워 | 공식 기본 확률 질량 | 의도 |
|---|---:|---:|---|
| 계열 해금 | 확률표 1~12번 | 90% | `1/10`, `1/20` 기본군 |
| 확장 I | 확률표 1~31번 | 99.990625% | 반복 분모군과 `1/1000`까지 |
| 확장 II | 확률표 1~50번 | 100% | 모든 희귀 꼬리와 최고 타워 |

공식 확률 질량은 행운을 적용하지 않은 기본표 기준입니다. 실제 계산은 각 굴림의 현재 Compression을 적용한 뒤 허용 범위 안의 질량을 사용합니다.

이 구조의 목적:

- 최초 해금만으로 대부분의 굴림에서 변종 기회를 가짐
- 확장 I은 중간 희귀 타워의 변종 수집을 개방
- 확장 II는 극희귀 변종의 이론적 획득 가능성을 여는 선택형 숙련 싱크
- 전체 확장을 구매하지 않아도 메인 완주에 불이익 없음

# 4. 변종 코인 가지 권고안

균형형 통합 경제의 누적 유연 예산을 변종 가지에 순서대로 투자하는 모델입니다. 실제 구매 순서는 강제하지 않습니다.

| 노드 | 가격 | 누적 가격 | 균형형 도달 | 허용 범위 |
|---|---:|---:|---:|---:|
| 인화성 해금 | 3,500,000 | 3,500,000 | 5.00h | 1~12 |
| 독성 해금 | 15,000,000 | 18,500,000 | 6.80h | 1~12 |
| 공허 해금 | 50,000,000 | 68,500,000 | 9.12h | 1~12 |
| 거대 해금 | 150,000,000 | 218,500,000 | 10.90h | 1~12 |
| 인화성 확장 I | 100,000,000 | 318,500,000 | 11.65h | 1~31 |
| 독성 확장 I | 200,000,000 | 518,500,000 | 12.40h | 1~31 |
| 공허 확장 I | 500,000,000 | 1,018,500,000 | 13.65h | 1~31 |
| 거대 확장 I | 1,000,000,000 | 2,018,500,000 | 15.96h | 1~31 |
| 인화성 확장 II | 1,000,000,000 | 3,018,500,000 | 18.15h | 1~50 |
| 독성 확장 II | 2,000,000,000 | 5,018,500,000 | 20.25h | 1~50 |
| 공허 확장 II | 5,000,000,000 | 10,018,500,000 | 21.31h | 1~50 |
| 거대 확장 II | 15,000,000,000 | **25,018,500,000** | **24.50h** | 1~50 |

이 가지는 영구 해금이며 환생으로 초기화하지 않습니다.

30시간 균형형 유연 예산:

```text
50,921,671,000
```

변종 가지 전체 구매 뒤 남는 유연 예산:

```text
50,921,671,000 - 25,018,500,000
= 25,903,171,000
```

따라서 변종은 후반 잉여 코인의 약 절반을 흡수하지만, 합체·오프라인·편의 가지가 사용할 예산도 남깁니다.

# 5. 시간대별 획득량

조건:

- 균형 환생 배분
- 실제 스테이지·행운·황금·다이아몬드 Compression
- 위의 균형형 변종 노드 구매 순서
- 20,000계정
- 희귀 사건 수량은 Poisson 근사
- `P(1개 이상)`은 매 굴림의 실제 변종 확률을 곱해 정확 계산

| 활성 시간 | 누적 굴림 | 기대 변종 수 | 1개 이상 확률 | 수량 P10 / P50 / P90 / P99 |
|---:|---:|---:|---:|---|
| 5h | 5,209 | 0.000 | 0.0% | 0 / 0 / 0 / 0 |
| 8h | 8,498 | 0.448 | 36.1% | 0 / 0 / 1 / 3 |
| 10h | 10,759 | 0.843 | 56.9% | 0 / 1 / 2 / 4 |
| 12h | 13,079 | 1.317 | 73.2% | 0 / 1 / 3 / 5 |
| 13.5h | 14,858 | 1.876 | 84.7% | 0 / 2 / 4 / 6 |
| 15h | 16,671 | **2.503** | **91.8%** | **1 / 2 / 5 / 7** |
| 20h | 22,913 | 4.737 | 99.1% | 2 / 5 / 8 / 11 |
| 25h | 29,276 | 7.083 | 99.9% | 4 / 7 / 11 / 14 |
| 30h | 35,742 | **9.476** | **약 100%** | **6 / 9 / 13 / 17** |

해석:

- 첫 계열은 약 5시간에 열리지만 즉시 확정 변종을 지급하지 않음
- 중앙 계정은 약 10시간에 첫 변종을 경험하는 흐름
- V1 중앙 완주 시점인 13.5~15시간에는 변종 2개가 중앙값
- 20~30시간에는 여러 계열을 수집하지만 수백 개가 쌓이지 않음
- 변종이 메인 진행의 필수 보상이나 확정 지급으로 바뀌지 않음

# 6. 획득 변종 전투력 분포

획득한 변종의 최종 PowerBudget과 기본형 대비 증가량을 계산했습니다.

## 15시간

최고 보유 변종 PowerBudget:

```text
P10  5.49
P50  7.25
P90 13.80
P99 15.85
```

보유 변종을 편성에 모두 사용할 수 있다고 가정한 증가량 상한:

```text
P10  4.49
P50 14.15
P90 28.97
P99 44.37
```

15시간 기존 역할 상한 편성 중앙값과 비교한 중앙 증가 상한:

```text
약 0.50%
```

## 30시간

최고 보유 변종 PowerBudget:

```text
P10 10.00
P50 13.80
P90 32.99
P99 433.22
```

편성 증가량 상한:

```text
P10  39.49
P50  69.51
P90 106.03
P99 424.79
```

30시간 기존 역할 상한 편성 중앙값과 비교한 중앙 증가 상한:

```text
약 0.52%
```

이 수치는 변종의 실제 편성 증가량보다 높은 상한입니다. 변종의 기본형이 원래 상위 편성에 들어오지 않았다면 실제 증가는 더 작을 수 있습니다.

결론:

- 개별 변종은 같은 최종 분모의 일반 타워와 맞는 강한 결과
- 최초 획득 시점에는 중간 희귀 타워 수준의 의미 있는 전투력 상승 가능
- 장기 편성은 극희귀 일반 타워가 지배하므로 중앙 계정의 전체 전투력을 과도하게 올리지 않음
- P99의 희귀 기본형 변종은 매우 큰 수집·전투 보상이 될 수 있음
- 변종 없이도 기존 12~15시간 완주 계산 유지

# 7. 보호와 합체 연결

변종 획득은 다음 보호 규칙을 사용합니다.

- 모든 변종은 기본적으로 자동 보호 후보
- 공식 최종 분모가 보호 기준 이상이면 즉시 보호
- 수동 합체는 보호·편성 수량을 제외
- 같은 변종끼리만 합체 가능
- 기본형과 변종 혼합 금지
- 서로 다른 계열 혼합 금지
- 자동 합체 없음

정확한 자동 보호 분모와 변종 합체 계보는 합체 벤치마크와 카탈로그에서 결정합니다.

# 8. 수용 조건

재현 스크립트는 다음을 검사합니다.

- 네 계열 총 원시 티켓 확률이 정확히 `0.00037`
- 변종 가지 전체 가격이 정확히 `25,018,500,000`
- 전체 확장이 약 24~25시간에 완료
- 15시간 기대 변종 수 2~5개
- 15시간 1개 이상 확률 85~99%
- 30시간 기대 변종 수 8~15개
- 30시간 1개 이상 확률 99.9% 이상
- 15시간 중앙 편성 증가 상한 10% 이하
- 30시간 중앙 편성 증가 상한 15% 이하

현재 모든 조건을 통과합니다.

# 9. 결론

권고안:

```text
변종은 무료 굴림의 별도 고정 티켓
일반 행운은 기본 타워 선택에만 적용
계열 확률은 1/5,000 · 1/10,000 · 1/20,000 · 1/50,000
최종 분모 = 기본 타워 분모 × 계열 분모
전투력 배율 = 계열 분모^0.20
허용 범위는 12 → 31 → 50종
전체 변종 가지 비용 25.0185B
15시간 중앙 변종 수 2개
30시간 중앙 변종 수 9개
```

변종은 중후반 수집 목표와 코인 싱크가 되지만 메인 완주를 좌우하는 필수 성장축으로 사용하지 않습니다.

다음 계산은 변종과 기본형의 중복 수량을 실제로 소비하는 **수동 합체 비용·획득시간·전투력 벤치마크**입니다.
