## 목적

스테이지 15를 지역 5 용암지대와 V1의 최종 보스 스테이지로 완전 검증합니다.

기존 집계 EC 모델은 계정 전투력을 연속 피해량으로 변환했지만, 이 벤치마크는 다음 요소를 직접 실행합니다.

- 최저급 6역할의 개별 공격과 타겟 선정
- 12개 편성 슬롯
- 역할 하나당 최대 4개
- 최소 5개 역할을 사용하는 1,266개 역할 수량 조합
- 생성 간격과 타겟 전환
- 광역 공격, 감속, 마무리, 지원과 대형 사냥
- 용암 몬스터의 잔불·폭주·갑각 파괴·노출·분화 행동

몬스터 이름과 외형은 계산용 임시 정체성입니다. 최종 이름·모델·애니메이션·VFX·SFX와 실제 데이터 채택은 `docs/catalog`에서 별도로 수행합니다.

| 프로필 | 통합 전투력 EC | 행동 모델 변환값 |
|---|---:|---:|

| 30시간 P10 | 60,575 | ×19,918.16 |

행동 모델 변환값은 시간대별 실제 계정 전투력을 최저급 6역할 행동 문법에 적용하기 위한 내부 시뮬레이션 계수입니다. 플레이어에게 표시하는 능력치가 아닙니다.

편성 조건:

```text

```

## 잔불

불씨 정령을 처치하면 같은 경로 위치에 잔불 1개가 남습니다.

```text
잔불 보상: 없음
잔불 SpawnCost: 부모 5에 포함
추가 이동 거리: 없음
```

이는 작은 적을 처치한 뒤 즉시 타겟을 바꾸는 능력과 광역 화력의 가치를 검증합니다. 정글의 2개 분열과 달리 하나의 약한 잔여 개체만 남습니다.

## 용암 폭주

용암 사냥개는 HP가 45% 이하가 되면 이동속도가 30% 증가합니다.

```text
발동 횟수: 1회
무적: 없음
감속 효과: 계속 적용
```

## 갑각 파열

마그마 파수꾼은 최대 HP의 22% 보호막을 가집니다. 보호막이 처음 파괴될 때 모든 타워의 다음 공격을 최대 0.35초 늦춥니다.

```text
발동 횟수: 1회
반복 잠금: 없음
경로 전진: 없음
```

갑각을 여러 번 동시에 파괴해도 한 공격 처리 구간에서 가장 긴 지연만 적용하며 지연을 합산하지 않습니다.

## 용융 노출

흑요석 거상은 HP 50% 이하에서 내부 용융핵이 노출됩니다.

```text
받는 피해: ×1.15
이동속도: ×1.18
발동 횟수: 1회
```

후반부에 더 위험해지지만 집중 공격으로 빠르게 마무리할 수도 있는 양면 행동입니다.

## 칼데라의 심장

최종 보스는 다음 행동을 사용합니다.

```text
시작 보호막: 최대 HP 10%
HP 58% 이하: 추가 보호막 14% 1회
HP 70%와 35%: 분화 1회씩
```

분화 1회:

```text
모든 타워의 다음 공격 최대 0.45초 지연
경로 2% 전진
잔불 2개 생성
```

두 분화가 한 번의 강한 공격으로 동시에 통과되더라도 각 체력 구간은 한 번씩 처리합니다. 긴 무적시간은 사용하지 않습니다.

# 8. 경제와 기존 계산에 미치는 영향

기존 집계 모델과 동일한 보상 단위 `440`을 유지하고 15시간 P10 주기 차이가 1% 이내이므로 다음 계산을 다시 실행하지 않습니다.

- 환생 XP 곡선
- 행운 압축과 누적 굴림
- 문·슬롯·전투 통합 경제
- 시간대별 보유 전투력 분포
- 12~15시간 중앙 완주 목표

기존 집계 문서는 초기 역산의 기록으로 유지하지만, 스테이지 15 실제 전투 판단에서는 이 행동형 벤치마크를 우선합니다.
