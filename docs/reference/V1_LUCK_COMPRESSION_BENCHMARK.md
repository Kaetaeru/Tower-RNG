## 목적

50자리 공식 확률 사다리와 최고 일반 굴리기 타워 `1 / 10^20`을 기준으로, 스테이지 행운·실제 환생 시각·환생 행운 포인트·주사위 속도·황금·다이아몬드 굴림을 함께 검증합니다.

---

## 1. 잠정 행운 공식

```text
LuckCompressionBonus(L)
= 0.0340 × min(L, 25)
+ 0.0040 × max(L - 25, 0)

BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ LuckCompressionBonus(L)
+ TemporaryCompressionBonus
```

굴림 종류별 최종값:

```text
일반
Compression = clamp(BaseCompression, 1.00, 5.40)

황금
Compression = clamp(BaseCompression + 0.25, 1.00, 5.65)

다이아몬드
Compression = clamp(BaseCompression + 0.65, 1.00, 6.05)
```

확률표 적용:

```text
BaseLogOdds = log10(BaseOddsN)
AdjustedLogOdds = 1 + (BaseLogOdds - 1) / Compression
RawAdjustedWeight = 10 ^ (-AdjustedLogOdds)
FinalWeight = RawAdjustedWeight / Σ(RawAdjustedWeight)
```

현재 유효 확률은 서버 계산용이며 UI에는 표시하지 않습니다.

## 2. 스테이지 기본 압축값

행운 포인트와 포션이 없는 일반 굴림 기준입니다.

| 스테이지 | BaseCompression |
|---:|---:|
| 1 | 1.000 |
| 3 | 1.490 |
| 6 | 2.225 |
| 9 | 2.960 |
| 12 | 3.695 |
| 15 | 4.430 |

높은 스테이지는 적 처치 여부와 무관하게 현재 입장 스테이지 기준으로 적용합니다.

## 3. 행운 포인트 효과

| 행운 포인트 | Compression 보너스 |
|---:|---:|
| 0 | +0.000 |
| 1 | +0.034 |
| 4 | +0.136 |
| 10 | +0.340 |
| 25 | +0.850 |
| 50 | +0.950 |
| 100 | +1.150 |

첫 25포인트는 포인트당 `+0.0340`, 이후는 `+0.0040`입니다. 실제 환생 곡선에서 균형형이 완주·숙련 획득 목표를 통과하도록 재조정했습니다.

## 4. 주사위 속도

```text
RollRateMultiplier(S)
= 1
+ 0.010 × min(S, 25)
+ 0.0025 × max(S - 25, 0)

FinalRollInterval
= max(2.00초, BaseRollInterval / RollRateMultiplier(S))
```

현재 코인 속도 노드 이후 `BaseRollInterval = 3.6초`입니다.

| 속도 포인트 | 굴리기 간격 |
|---:|---:|
| 0 | 3.600초 |
| 10 | 3.273초 |
| 25 | 2.880초 |
| 50 | 2.743초 |
| 100 | 2.504초 |

## 8. 최고 타워 누적 획득률

`1 / 10^20` 최고 타워를 한 번 이상 획득할 확률입니다.

| 활성 플레이 | 미배분 | 균형 | 행운 혼합 | 행운 집중 | 속도 집중 |
|---:|---:|---:|---:|---:|---:|
| 5시간 | 0.004% | 0.011% | 0.026% | 0.083% | 0.005% |
| 13.5시간 | 0.823% | **3.005%** | 5.176% | 5.334% | 1.098% |
| 15시간 | 1.219% | **4.680%** | 7.398% | 7.315% | 1.639% |
| 25시간 | 3.817% | **18.146%** | 22.328% | 19.500% | 5.341% |
| 30시간 | 5.091% | **24.799%** | 29.093% | 24.976% | 7.251% |

균형 배분은 다음 목표를 통과합니다.

```text
중앙 V1 완주 13.5~15시간: 3~5%
V1 숙련 25~30시간: 15~25%
```

행운 집중은 초반에 강하지만 후반 소프트캡 때문에 행운과 속도를 섞는 빌드도 성립합니다.

---

## 9. 해석

- 스테이지 진행만으로도 행운이 증가하지만 최고 타워를 흔하게 만들지 않음
- 실제 환생 횟수를 사용해도 균형형이 기존 획득 목표를 통과
- 행운 몰입은 메인 완주 시점 약 7.3%이며 보장 타워가 아님
- 속도 몰입은 희귀 압축 없이 굴림 수와 합체 재료를 늘림
- 성능 투자로 환생이 빨라지므로 행운 혼합형은 장기 누적 확률이 높을 수 있음
- 공식 표시 확률은 계속 `1 / 10^20`
