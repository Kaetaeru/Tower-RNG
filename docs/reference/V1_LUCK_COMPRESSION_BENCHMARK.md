## 목적

50자리 공식 확률 사다리와 최고 일반 굴리기 타워 `1 / 10^20`을 기준으로, 스테이지 행운·환생 행운 포인트·주사위 속도·황금·다이아몬드 굴림을 함께 검증합니다.

환생 스탯은 네 분야입니다.

```text
행운
성능
재화
주사위 속도
```

행운만 계산하고 실제 굴림 횟수 증가를 무시하면 누적 획득률을 과소평가하므로 두 스탯을 같은 시뮬레이터에서 처리합니다.

---

## 1. 잠정 행운 공식

```text
LuckCompressionBonus(L)
= 0.0315 × min(L, 25)
+ 0.0090 × max(L - 25, 0)

BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ LuckCompressionBonus(L)
+ TemporaryCompressionBonus
```

굴림 종류별 최종값:

```text
일반
Compression = clamp(BaseCompression, 1.00, 5.40)

황금
Compression = clamp(BaseCompression + 0.25, 1.00, 5.65)

다이아몬드
Compression = clamp(BaseCompression + 0.65, 1.00, 6.05)
```

확률표 적용:

```text
BaseLogOdds = log10(BaseOddsN)
AdjustedLogOdds = 1 + (BaseLogOdds - 1) / Compression
RawAdjustedWeight = 10 ^ (-AdjustedLogOdds)
FinalWeight = RawAdjustedWeight / Σ(RawAdjustedWeight)
```

현재 유효 확률은 서버 계산용이며 UI에는 표시하지 않습니다.

## 2. 스테이지 기본 압축값

행운 포인트와 포션이 없는 일반 굴림 기준입니다.

| 스테이지 | BaseCompression |
|---:|---:|
| 1 | 1.000 |
| 3 | 1.490 |
| 6 | 2.225 |
| 9 | 2.960 |
| 12 | 3.695 |
| 15 | 4.430 |

스테이지 1의 `Compression = 1`은 공식 기본 확률표와 정확히 같습니다. 높은 스테이지는 적 처치 여부와 무관하게 현재 입장 스테이지 기준으로 적용합니다.

## 3. 행운 포인트 효과

| 행운 포인트 | Compression 보너스 |
|---:|---:|
| 0 | +0.0000 |
| 1 | +0.0315 |
| 4 | +0.1260 |
| 10 | +0.3150 |
| 25 | +0.7875 |
| 50 | +1.0125 |
| 100 | +1.4625 |

첫 25포인트는 포인트당 `+0.0315`, 이후는 `+0.0090`입니다. 한 분야에 계속 몰아도 증가하지만 다른 분야로 옮길 유인이 생깁니다.

## 4. 주사위 속도

```text
RollRateMultiplier(S)
= 1
+ 0.010 × min(S, 25)
+ 0.0025 × max(S - 25, 0)

FinalRollInterval
= max(2.00초, BaseRollInterval / RollRateMultiplier(S))
```

현재 코인 속도 노드 이후 `BaseRollInterval = 3.6초`입니다.

| 속도 포인트 | 굴리기 간격 |
|---:|---:|
| 0 | 3.600초 |
| 10 | 3.273초 |
| 25 | 2.880초 |
| 50 | 2.743초 |
| 100 | 2.504초 |

## 5. 토큰과 환생 계획 입력

확정:

```text
환생 1회당 스탯 토큰 4개
```

아직 두 번째 이후 Defense XP가 미검증이므로 다음 중앙 가정을 사용합니다.

```text
첫 환생: 10분
두 번째 환생: 30분
이후 평균 간격: 40분
```

| 활성 플레이 | 환생 | 누적 토큰 |
|---:|---:|---:|
| 15분 | 1 | 4 |
| 30분 | 2 | 8 |
| 2시간 | 4 | 16 |
| 5시간 | 8 | 32 |

| 13.5시간 | 21 | 84 |

## 6. 배분 시나리오

매 환생의 토큰 4개를 다음처럼 사용합니다.

```text
미배분
- 0 / 0 / 0 / 0

균형
- 행운 1 / 성능 1 / 재화 1 / 속도 1

행운 혼합
- 행운 2 / 성능 1 / 재화 0 / 속도 1

행운 집중
- 행운 4 / 나머지 0

속도 집중
- 속도 4 / 나머지 0
```

## 8. 최고 타워 누적 획득률

`1 / 10^20` 최고 타워를 한 번 이상 획득할 확률입니다.

| 활성 플레이 | 미배분 | 균형 | 행운 혼합 | 행운 집중 | 속도 집중 |
|---:|---:|---:|---:|---:|---:|
| 5시간 | 0.004% | 0.011% | 0.027% | 0.081% | 0.005% |
| 13.5시간 | 0.823% | **3.028%** | 5.253% | 6.254% | 1.122% |
| 15시간 | 1.219% | **4.683%** | 7.628% | 8.216% | 1.677% |
| 20시간 | 2.527% | 11.052% | 15.439% | 14.461% | 3.569% |
| 25시간 | 3.817% | **17.738%** | 22.699% | 20.282% | 5.519% |
| 30시간 | 5.091% | **24.618%** | 29.427% | 25.706% | 7.522% |

균형 배분은 다음 목표를 통과합니다.

```text
중앙 V1 완주 13.5~15시간: 3~5%
V1 숙련 25~30시간: 15~25%
```

행운 집중은 초반에 가장 강하지만 Compression 감소 효율 때문에 장기에는 행운과 속도를 섞는 배분이 더 높은 누적 확률을 만들 수 있습니다.

---

## 9. 해석

- 스테이지 진행만으로도 행운이 증가하지만 최고 타워를 흔하게 만들지 않음
- 균형형도 기존 최고 타워 획득 목표를 통과함
- 행운 몰입은 메인 완주 시점 확률을 약 8%까지 올리지만 필수·보장 타워가 되지 않음
- 속도 몰입은 희귀 압축 없이도 굴림 수와 합체 재료를 크게 늘림
- 행운 소프트캡과 주사위 속도의 상호작용으로 혼합 빌드가 성립
- 공식 표시 확률은 계속 `1 / 10^20`

---

## 10. 아직 미확정인 값

- 실제 두 번째 이후 환생 간격
- 포션·VIP·서버 부스트의 `TemporaryCompressionBonus`
- 후속 코인 굴리기 속도 노드
- 빠른·느린 실제 스테이지 도달 경로
- 전체 50종 보유·최적 편성 전투력 분포

환생 요구 XP나 굴리기 속도 노드가 바뀌면 `rebirth_stat_tokens.py`로 다시 검증합니다.
