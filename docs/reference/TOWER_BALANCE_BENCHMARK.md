## 목적

역할별 최저급 기준 타워 6종이 다음 조건을 만족하는지 검증합니다.

1. 첫 굴림으로 어느 역할이 나와도 스테이지 1 표준 적을 혼자 막을 수 있음
2. 역할별 기준 `EquivalentContribution`이 1.000 근처에 있음
3. 지원·제어·광역·마무리·대형 사냥의 비피해 가치를 같은 척도로 비교할 수 있음

이 문서는 실제 런타임 전투 시뮬레이터가 아니라 카탈로그 수치를 만들기 위한 **1차 결정론적 기준선**입니다.

---

## 1. 기준 조건

```text
스테이지: 1
표준 일반 몬스터 HP: 5
기본 베이스 도달시간: 10초
초기 편성 슬롯: 4
Formation 첫 판정 지연: 0.25초
Engage 최초 접근 지연: 0.50초
일반 웨이브 목표시간: 10초
보스 웨이브 대표시간: 17.5초
```

`17.5초`는 현재 목표 범위인 15~20초의 중앙값입니다.

### 허용 범위

```text
솔로 안전성
- 처치시간 < 베이스 도달시간

역할 기여도
- 0.970 <= EquivalentContribution <= 1.030
```

±3%는 애니메이션, 투사체 이동, 타겟 변경과 반올림이 아직 실제 엔진에서 검증되지 않은 1차 단계의 허용 오차입니다.

---

## 2. 역할별 환산 조건

### 단일 화력

```text
EquivalentContribution = 단일 대상 지속 DPS
```

견습 궁수의 DPS 1.000을 전체 역할의 시작 기준으로 사용합니다.

### 광역 화력

스테이지 1 기준 군집에서 평균 동시 명중 대상을 `1.67`로 둡니다.

```text
돌팔매꾼
= 대상당 DPS 0.60 × 평균 1.67대상
= 1.002
```

최대 3대상을 항상 맞힌다고 가정하지 않습니다.

### 제어

서리 견습생이 선두 적에게 15% 감속을 계속 유지하고, 나머지 세 슬롯이 각각 기여도 1.000을 제공한다고 가정합니다.

```text
직접 DPS 0.55
+ 아군 3슬롯 × 감속 15%
= 0.55 + 0.45
= 1.000
```

실제 구현에서는 감속 공백, 더 강한 감속과의 비중첩, 적이 죽기 직전에 적용된 무효 제어 시간을 제외해야 합니다.

### 마무리

골목 도적의 기준 조건:

```text
마무리 범위 공격 비중: 40%
Engage 유효 가동률: 90%
```

```text
0.80 × (1 + 0.40) × 0.90
= 1.008
```

실제 마무리 공격 비중은 웨이브 시뮬레이터에서 타겟 정책과 예약 피해를 포함해 다시 측정합니다.

### 지원

신참 북잡이는 자신을 제외한 기준 타워 3개를 15% 강화합니다.

```text
직접 DPS 0.55
+ 3슬롯 × 1.000 × 15%
= 1.000
```

같은 북잡이의 오라는 중첩하지 않는 현재 규칙을 사용합니다.

### 대형 사냥

대형 사냥은 웨이브 수가 아니라 실제 전투시간으로 가중합니다.

```text
일반 전투: 4 × 10초 = 40초
보스 전투: 17.5초
```

기존 `보스 피해 +125%`는 시간 가중 기여도 `1.104`로 기준보다 10.4% 높았습니다.

조정값:

```text
일반 투창 피해: 1.60 / 2초
정예·보스 피해: +80%
최종 대형 피해: 2.88 / 2초
시간 가중 EquivalentContribution: 0.995
```

## 3. 1차 결과

| 타워 | 솔로 처치시간 | 베이스 도달시간 | EquivalentContribution | 편차 | 결과 |

| 견습 궁수 | 4.25초 | 10.00초 | 1.000 | 0.0% | 통과 |

## 4. 확정된 1차 조정

### 멧돼지 사냥꾼

```text
이전
- 정예·보스 피해 +125%
- 최종 피해 3.60
- 시간 가중 기여도 1.104

조정
- 정예·보스 피해 +80%
- 최종 피해 2.88
- 시간 가중 기여도 0.995
```

다른 다섯 타워는 현재 임시 수치를 유지합니다.

## 5. 아직 검증하지 않은 요소

다음은 실제 웨이브·전투 시뮬레이터에서 다시 검증합니다.

- 투사체 이동시간과 빗나감 없는 명중 시점
- 타겟 변경 지연과 예약 피해
- 같은 공격 주기의 동시 판정 순서
- 오버킬과 피해 낭비
- 실제 적 생성 간격과 평균 군집도
- Engage 출발 위치와 재접근 횟수
- 감속이 이미 죽을 적에게 적용되는 낭비
- 지원 대상의 실제 역할별 성장값
- 보스 외 정예 몬스터의 등장 비중
- 치명타·공격속도·성능 강화 적용 후 순서 유지

이 항목들이 추가되어도 각 역할의 최저급 기준 기여도는 1.000 근처를 유지하도록 수치를 재조정합니다.
