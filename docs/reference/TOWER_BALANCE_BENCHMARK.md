## 목적

역할별 최저급 기준 타워 6종이 다음 조건을 만족하는지 검증합니다.

1. 첫 굴림으로 어느 역할이 나와도 스테이지 1 표준 적을 혼자 막을 수 있음
2. 역할별 기준 `EquivalentContribution`이 1.000 근처에 있음
3. 서로 다른 네 역할을 섞은 편성이 스테이지 1 일반 웨이브를 약 10초에 처리함
4. 대형 사냥 역할이 일반 웨이브의 약점을 보스 웨이브의 강점으로 보상함

이 문서는 실제 Roblox 런타임이 아니라 카탈로그 수치를 만들기 위한 결정론적 기준선입니다.

---

## 1. 기준 조건

```text
스테이지: 1
표준 일반 몬스터 HP: 5
표준 베이스 도달시간: 10초
초기 편성 슬롯: 4
Formation 첫 판정 지연: 0.25초
Engage 최초 접근 지연: 0.50초
일반 웨이브 목표: 약 10초
보스 웨이브 목표: 15~20초
전체 5웨이브 목표: 55~70초
```

1차 역할 기여도 허용 범위:

```text
0.970 <= EquivalentContribution <= 1.030
```

---

## 2. 역할별 환산 기준

### 단일 화력

```text
견습 궁수
1.00 피해 / 1초
EquivalentContribution = 1.000
```

### 광역 화력

```text
돌팔매꾼
0.60 피해 × 평균 1.67대상
EquivalentContribution = 1.002
```

### 제어

```text
서리 견습생
직접 DPS 0.55
+ 아군 3슬롯이 15% 감속으로 얻는 기대 기여 0.45
= 1.000
```

실제 구현에서는 감속 공백과 이미 죽을 적에게 적용된 제어 시간을 제외합니다.

### 마무리

```text
골목 도적
기본 DPS 0.80
마무리 공격 비중 40%
Engage 유효 가동률 90%
EquivalentContribution = 1.008
```

### 지원

```text
신참 북잡이
직접 DPS 0.55
+ 다른 기준 타워 3개의 15% 강화 0.45
= 1.000
```

같은 북잡이의 오라는 중첩하지 않습니다.

### 대형 사냥

```text
멧돼지 사냥꾼
일반 피해 1.60 / 2초
정예·보스 피해 +80%
대형 대상 피해 2.88 / 2초
```

처음 제안한 +125%는 시간 가중 기여도 1.104로 과도해 +80%로 낮췄습니다.

## 4. 일반 웨이브 혼합 편성 검증

서로 다른 네 역할로 이루어진 15개 편성을 웨이브 1~4에 적용했습니다.

| 웨이브 | 평균 | 최단 | 최장 | 누수 |
|---:|---:|---:|---:|---:|
| 1 | 9.98초 | 8.50초 | 10.50초 | 0 |
| 2 | 9.85초 | 7.75초 | 11.75초 | 0 |
| 3 | 9.97초 | 8.75초 | 11.25초 | 0 |
| 4 | 10.48초 | 9.00초 | 12.25초 | 0 |

일반 웨이브 전체 평균은 10.07초입니다.

## 5. 보스와 대형 사냥 검증

스테이지 1 보스 웨이브:

```text
우두머리 멧돼지 HP 55
들쥐 2마리
총 HP 59
BaseBudget 110
```

보스 웨이브 평균:

```text
멧돼지 사냥꾼 포함 편성: 14.82초
멧돼지 사냥꾼 미포함 편성: 18.35초
```

대형 사냥 역할은 보스 웨이브를 평균 약 3.53초, 약 19% 단축합니다.

전체 5웨이브 평균:

```text
멧돼지 사냥꾼 포함 편성: 56.30초
멧돼지 사냥꾼 미포함 편성: 56.25초
```

두 집단의 차이는 0.05초뿐입니다. 일반 웨이브의 낮은 기여와 보스 웨이브의 높은 기여가 전체 주기에서 거의 정확히 균형을 이룹니다.

따라서 멧돼지 사냥꾼의 현재 +80% 대형 피해는 `Confirmed (Provisional Balance)`로 유지합니다.

## 7. 아직 검증하지 않은 요소

- 실제 투사체 이동시간과 서버 판정 시점
- 애니메이션 판정 프레임
- 예약 피해와 오버킬 방지
- 실제 모델 크기와 Splash 반경
- Engage 출발 위치와 충돌 회피
- 동일 역할·동일 타워 중복 편성
- 역할별 최대 배치 제한
- 치명타·공격속도·스탯 트리 성장
- MinBudget·MaxBudget 변형 구성

이 항목이 추가되어도 희귀도 순서와 최저급 편성 안전성을 유지해야 합니다.
