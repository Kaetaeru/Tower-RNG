- 상태: **Active Template**
- 필수 참고: `../../AGENTS.md`
- 상위 문서: `../design/MONSTERS.md`, `../design/LEVEL_DESIGN.md`, `../design/STAGE_BOSSES.md`

## 목적

이 문서는 실제 몬스터와 스테이지 보스의 종류, 생성 비용과 전투 수치를 기록하는 카탈로그입니다. 몬스터의 공통 규칙은 기획 문서에서 관리하고, 개별 몬스터 데이터는 이 문서에서 관리합니다.

스테이지의 웨이브 구성은 몬스터를 마릿수로 직접 고정하기보다 생성 비용과 웨이브 예산을 사용합니다.
