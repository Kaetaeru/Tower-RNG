# 스테이지 1 웨이브 밸런스 벤치마크

- 계층: 참조 데이터
- 상태: **Active Benchmark**
- 필수 참고: `../../AGENTS.md`
- 상위 문서: `../design/BALANCE_MODEL.md`, `../design/LEVEL_DESIGN.md`
- 관련 문서: `TOWER_CATALOG.md`, `TOWER_BALANCE_BENCHMARK.md`, `MONSTER_CATALOG.md`, `STAGE_CATALOG.md`, `FIRST_REBIRTH_ECONOMY_BENCHMARK.md`
- 재현 스크립트: `../../tools/balance/stage1_wave_sim.py`
- 마지막 정리: 2026-08-02

## 목적

스테이지 1의 일반 웨이브 1~4가 약 10초, 보스 웨이브 5가 15~20초에 해소되고 전체 주기가 55~70초 범위에 들어오는지 검증합니다.

이번 단계는 실제 Roblox 런타임이 아니라 카탈로그 수치와 타겟 정책을 사용한 0.01초 단위 결정론적 모델입니다.

---

## 1. 검증 범위

사용 타워:

```text
견습 궁수
돌팔매꾼
서리 견습생
골목 도적
신참 북잡이
멧돼지 사냥꾼
```

검증 편성:

- 여섯 역할 중 서로 다른 네 역할을 선택하는 15개 조합
- 동일 타워 중복 배치는 이번 단계에서 제외
- 치명타·스탯 트리·공격속도 성장 미적용

통과 기준:

```text
모든 편성에서 베이스 누수 0
일반 웨이브 평균 9~11초
일반 웨이브 최장 12.5초 이하
보스 웨이브 평균 15~20초
보스 웨이브 최장 20초 이하
5웨이브 전체 평균 55~70초
```

## 10. 결론

스테이지 1의 기준 웨이브 1~5는 `Confirmed (Provisional Balance)`로 사용합니다.

```text
일반 웨이브 약 10초
보스 웨이브 평균 16초
전체 주기 평균 56.28초
15개 혼합 편성 누수 0
보스 보상 1.60배
대형 사냥 전체 주기 균형 통과
첫 환생 경제 입력 검증 완료
```

다음 전투 검증은 스테이지 1 `MinBudget`·`MaxBudget` 변형과 첫 40초 베이스 안전성입니다. 콘텐츠 확장은 역할별 `1 / 100` 기준 타워와 스테이지 2 순서로 진행합니다.
