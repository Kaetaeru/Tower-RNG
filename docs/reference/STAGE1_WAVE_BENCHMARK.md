- 계층: 참조 데이터

## 목적

스테이지 1의 일반 웨이브 1~4가 약 10초, 보스 웨이브 5가 15~20초에 해소되고 전체 주기가 55~70초 범위에 들어오는지 검증합니다.

웨이브 시간은 강제 지속시간이 아니라 적정 전투력 편성의 목표 처리시간입니다. 적이 모두 해소되면 즉시 다음 웨이브를 시작합니다.

이번 단계는 실제 Roblox 런타임이 아니라 카탈로그 수치와 타겟 정책을 사용한 0.01초 단위 결정론적 모델입니다.

---

## 1. 검증 범위

사용 타워:

```text
견습 궁수
돌팔매꾼
서리 견습생
골목 도적
신참 북잡이
멧돼지 사냥꾼
```

검증 편성:

- 여섯 역할 중 서로 다른 네 역할을 선택하는 15개 조합
- 동일 타워 중복 배치는 이번 단계에서 제외
- 치명타·스탯 트리·공격속도 성장 미적용
- 최초 계정의 튜토리얼 전투는 별도이며 정규 웨이브는 4슬롯 완성 후 시작

통과 기준:

```text
모든 편성에서 베이스 누수 0
일반 웨이브 평균 9~11초
일반 웨이브 최장 12.5초 이하
보스 웨이브 평균 15~20초
보스 웨이브 최장 20초 이하
5웨이브 전체 평균 55~70초
```

## 2. 임시 전투 가정

```text
Formation 첫 공격: 0.25초
골목 도적 첫 접근 포함 공격: 0.75초
멧돼지 사냥꾼 첫 투창: 0.50초
골목 도적 타겟 변경 접근 손실: 0.25초
서리 감속: 15%, 1.25초
신참 북잡이: 자신을 제외한 아군 핵심 출력 +15%
돌팔매꾼: 경로 진행도 차이 0.075 안의 최대 3대상 타격
```

모든 타워는 스테이지 전체 적을 타겟 후보로 사용할 수 있다는 현재 전투 기획을 따릅니다.

## 7. 대형 사냥 역할 검증

보스 웨이브 평균:

```text
멧돼지 사냥꾼 포함: 14.82초
멧돼지 사냥꾼 미포함: 18.35초
```

대형 사냥 타워를 넣으면 보스 웨이브가 평균 약 3.53초, 약 19% 빨라집니다.

전체 5웨이브 평균:

```text
멧돼지 사냥꾼 포함: 56.30초
멧돼지 사냥꾼 미포함: 56.25초
```

일반 웨이브의 낮은 기여와 보스 웨이브의 높은 기여가 거의 정확히 상쇄됩니다. 멧돼지 사냥꾼의 `정예·보스 +80%`는 현재 전체 주기 기준으로 유지합니다.

## 8. 시간 철학 검증

```text
보스 웨이브 시간 비중
= 16.00 / 56.28
≈ 28.4%
```

목표 범위인 25~35%에 들어옵니다.

현재 10초·16초는 강제 시간이 아니라 적정 전투력 기준입니다.

- 더 강한 편성은 더 빨리 종료
- 새 스테이지 진입 상태는 범위 상단에 가까움
- 해당 스테이지를 파밍하며 성장하면 범위 하단으로 감소
- 몬스터가 플레이어 DPS에 맞춰 자동 강화되지 않음

## 10. 최초 계정 예외

정규 웨이브는 4슬롯 기준이므로 최초 계정은 정규 웨이브 전에 슬라임 1마리를 상대합니다.

```text
튜토리얼 슬라임 가치: 코인 10, Defense XP 10
자동 굴리기 구매: 10코인
세 번의 추가 굴림: 12초
정규 웨이브 시작: 접속 후 약 25초
```

이 예외는 정규 웨이브 수치를 약화하지 않고 첫 선택 불가능 실패만 제거합니다.

## 12. 결론

스테이지 1의 기준 웨이브 1~5는 `Confirmed (Provisional Balance)`로 사용할 수 있습니다.

```text
일반 웨이브 약 10초
보스 웨이브 평균 16초
전체 주기 평균 56.28초
15개 혼합 편성 누수 0
보스 시간 비중 28.4%
한 주기 보상·Defense XP 400
대형 사냥 전체 주기 기여 균형 통과
```

다음 전투 검증은 스테이지 2의 실제 몬스터·웨이브를 작성해 진입 목표와 파밍 목표를 분리하는 것입니다.
