## 목적

스테이지 1의 일반 웨이브 1~4가 최저급 기준 타워 4슬롯 혼합 편성에서 평균 약 10초에 해소되는지 검증합니다.

이번 단계는 실제 Roblox 런타임 시뮬레이션이 아니라, 카탈로그 수치와 타겟 정책을 사용한 0.01초 단위 결정론적 모델입니다.

---

## 1. 검증 범위

사용 타워:

```text
견습 궁수
돌팔매꾼
서리 견습생
골목 도적
신참 북잡이
멧돼지 사냥꾼
```

검증 편성:

- 여섯 역할 중 서로 다른 네 역할을 선택하는 15개 조합
- 동일 타워 중복 배치는 이번 단계에서 제외
- 각 역할의 정확한 최대 배치 제한은 아직 적용하지 않음
- 일반 웨이브만 검증하며 스테이지 보스 웨이브는 제외

통과 기준:

```text
모든 편성에서 베이스 누수 0
웨이브별 전체 편성 평균 9~11초
웨이브별 최장 처리시간 12.5초 이하
```


## 6. 역할 차이 확인

가장 빠른 평균 편성:

```text
견습 궁수
돌팔매꾼
골목 도적
신참 북잡이
평균 8.75초
```

가장 느린 평균 편성:

```text
서리 견습생
골목 도적
신참 북잡이
멧돼지 사냥꾼
평균 11.44초
```

차이가 생기는 주된 이유:

- 돌팔매꾼은 웨이브 2의 군집형에 강함
- 멧돼지 사냥꾼은 보스가 없는 일반 웨이브에서는 일반 DPS만 사용함
- 제어와 지원을 함께 많이 넣으면 직접 처치 속도는 느려짐
- 그래도 최저급 혼합 편성이 베이스를 막지 못하는 상태는 발생하지 않음

이 차이는 역할의 개성을 보여 주는 허용 범위로 판단합니다. 일반 웨이브만으로 대형 사냥 타워의 전체 가치를 판단하지 않고, 보스 웨이브까지 추가한 뒤 다시 검증해야 합니다.

## 7. 아직 검증하지 않은 요소

- 실제 Roblox 투사체 이동과 서버 판정 순서
- 애니메이션 판정 프레임
- 예약 피해와 오버킬 방지
- 몬스터 모델 크기와 실제 Splash 반경
- Engage 위치와 충돌 회피
- 동일 역할·동일 타워 중복 편성
- 역할별 최대 배치 제한
- 치명타·공격속도·스탯 트리 성장
- 웨이브 5 보스와 대형 사냥 역할의 전체 주기 기여
- 코인 드롭 수집시간과 다음 웨이브 중 플레이어 동선
