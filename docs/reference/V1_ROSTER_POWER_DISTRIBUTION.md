## 목적

V1의 50자리 공식 확률 사다리, 실제 환생 XP 곡선, 행운·성능·주사위 속도를 함께 적용해 시간대별로 플레이어가 실제로 보유할 타워와 편성 전투력 분포를 검증합니다.

주요 질문:

- 15분·2시간·5시간·15시간·30시간에 가장 희귀한 보유 타워는 어느 정도인가
- 같은 시간에도 운에 따라 편성 전투력이 얼마나 벌어지는가
- 4~12슬롯에서 보유 타워만 사용한 전투력 상한은 얼마인가
- 행운 집중과 성능 집중이 실제 보유 전투력에 어떤 차이를 만드는가
- 스테이지 15을 극희귀 타워 없이 설계하려면 어느 분위수를 기준으로 해야 하는가

## 1. 시뮬레이션 입력

```text
계정 수: 시나리오당 20,000개
난수 시드: 20260802
타워: V1 일반 굴리기 50종
공식 최고 분모: 1 / 10^20
환생당 토큰: 4개
마일스톤: 15분, 30분, 2시간, 5시간, 15시간, 30시간
```

적용:

- 50종 공식 분모와 역할
- 로그 희귀도 압축
- 현재 스테이지 행운
- 실제 환생 시각
- 환생 행운 포인트
- 환생 성능 배율
- 환생 주사위 속도
- 매 10번째 황금 굴림
- 매 100번째 다이아몬드 굴림
- 중복 타워 보유 수량

제외:

- 변종
- 합체 결과
- 코인 스탯 트리의 전투 배율
- 임시 포션·서버 부스트
- 역할별 편성 상한
- 동일 효과 중첩 감소
- 실제 지원·제어 시너지
- 실제 스테이지 누수와 실패시간

## 2. 시뮬레이션 방식

동일한 최종 확률표를 사용하는 굴림은 하나의 그룹으로 묶고 정확한 다항분포로 표본화합니다.

```text
같은 Compression·특수 굴림 상태의 N회 굴림
→ Multinomial(N, FinalWeights)
→ 타워별 보유 수량 누적
```

확률이 다른 굴림을 하나의 평균 확률로 근사하지 않습니다. 스테이지 이동, 환생, 행운 포인트 변화와 황금·다이아몬드 굴림마다 별도 그룹을 사용합니다.

분위수 표기:

```text
P10: 하위 10% 경계
P50: 중앙값
P90: 상위 10% 경계
P99: 상위 1% 경계
```

## 3. 편성 전투력 정의

### 기본 기여도

```text
TowerPower
= RawPowerBudget
= (BaseOddsN / 10)^0.20
```

### Top-K 편성 상한선

```text
TopKBaseEC
= 보유한 모든 타워 복사본 중
  기여도가 높은 K개 합계
```

```text
TopKFinalEC
= TopKBaseEC
× RebirthPerformanceMultiplier
```

중복 타워는 보유 수량만큼 사용할 수 있습니다.

이 값은 **실제 최종 편성값이 아니라 전투력 상한선**입니다. 전체 슬롯 수만 적용하고 역할별 상한·지원 중첩·제어 상한을 적용하지 않았습니다.

4·6·8·10·12슬롯 값은 실제 해금 시각을 뜻하지 않습니다. 같은 보유 목록에서 슬롯이 그만큼 열렸을 때의 전투력 경계를 비교하기 위한 값입니다.

## 4. 배분 시나리오

환생당 토큰 4개를 다음처럼 사용합니다.

| 시나리오 | 행운 | 성능 | 재화 | 주사위 속도 |
|---|---:|---:|---:|---:|
| 미배분 | 0 | 0 | 0 | 0 |
| 균형 | 1 | 1 | 1 | 1 |
| 수집 혼합 | 2 | 1 | 0 | 1 |
| 행운 집중 | 4 | 0 | 0 | 0 |
| 성능 집중 | 0 | 4 | 0 | 0 |

재화 스탯은 코인 진행에 영향을 주지만 이 벤치마크의 고정 스테이지 도달 경로에는 반영하지 않습니다. 따라서 시나리오 비교표는 전체 진행 속도가 아니라 **해당 시간에 주어진 굴림·보유·성능만 비교한 격리 시험**입니다.

## 6. 균형형 슬롯별 전투력 상한

환생 성능 배율을 적용한 `TopKFinalEC`입니다.

| 슬롯 상한 | 15시간 P10 / P50 / P90 | 30시간 P10 / P50 / P90 |
|---:|---:|---:|
| 4 | `1,312 / 2,968 / 10,649` | `6,920 / 16,746 / 28,329` |
| 6 | `1,654 / 3,493 / 11,240` | `8,934 / 19,083 / 32,568` |
| 8 | `1,902 / 3,868 / 11,623` | `10,296 / 20,963 / 35,133` |
| 10 | `2,136 / 4,171 / 11,942` | `11,508 / 22,389 / 37,002` |
| 12 | `2,313 / 4,409 / 12,183` | `12,423 / 23,498 / 38,483` |

15시간에는 슬롯을 4개에서 12개로 늘려도 중앙 전투력이 약 `2,968 → 4,409`로 49% 증가합니다. 상위 계정은 한두 개의 극희귀 타워 비중이 커 슬롯 추가의 상대 효과가 더 작을 수 있습니다.

30시간에는 보유 상위 타워층이 두꺼워져 12슬롯 확장이 더 안정적인 누적 성장을 제공합니다.

## 9. 핵심 해석

### 9.1 V1 완주 시점의 운 편차는 크다

균형형 15시간 Top-12 전투력:

```text
P10  2,313
P50  4,409
P90 12,183
```

P90은 P10의 약 `5.27배`입니다. 극희귀 획득이 실제 전투력에 강한 대박 효과를 주면서도, 메인 진행을 그것에 맞추면 하위 계정이 막히는 구조입니다.

### 9.2 스테이지 15는 P90이나 최고 타워를 기준으로 만들면 안 된다

메인 완주 전투력의 확률적 기반은 다음 범위를 사용합니다.

```text
균형형 15시간
Top-8 P10 약 1,902
Top-10 P10 약 2,136
Top-12 P10 약 2,313
```

실제 스테이지 15 요구 전투력은 이 하위권 일반 타워 기반에 다음 확정 성장을 더해 맞춰야 합니다.

- 코인 전투 스탯
- 실제 해금된 편성 슬롯
- 수동 합체
- 변종
- 타겟·역할 조합

최고 `1/10^20` 타워나 P90 편성을 기본 완주 전력으로 사용하지 않습니다.

### 9.3 슬롯 수만으로 운 격차를 해결할 수 없다

15시간 P90 계정은 소수의 매우 강한 타워가 편성 전투력 대부분을 차지할 수 있습니다. 슬롯을 늘리면 하위·중앙 계정에는 꾸준한 성장 보상이 되지만, 극희귀를 얻은 계정과의 차이를 완전히 평준화하지 않습니다.

이는 의도된 RNG 보상이지만 메인 보스의 필수 DPS는 하위 분위수에 맞춰야 합니다.

### 9.4 네 환생 스탯의 전체 우열은 아직 확정하지 않는다

이 벤치마크는 스테이지 도달 시간을 고정했습니다.

- 재화 투자의 빠른 문·슬롯·코인 노드 진입
- 성능 투자의 빠른 스테이지 방어
- 실패·누수로 잃는 파밍 시간

을 아직 연결하지 않았습니다. 따라서 수집 혼합이 표에서 가장 강해도 전체 게임의 지배적 빌드라고 결론내리지 않습니다.

## 10. 검증 완료

- 50종·6역할 수량 검증
- 모든 계정의 보유 수량 합이 정확한 누적 굴림 수와 일치
- 동일 확률 상태의 정확한 다항분포 표본화
- 중복 타워를 포함한 Top-4~12 상한 계산
- 실제 환생 횟수와 성능 배율 적용
- 행운·속도에 따른 실제 굴림 수 적용
- 균형형 최고 타워 15시간 `3~6%` 목표 통과
- 균형형 최고 타워 30시간 `20~30%` 목표 통과

## 11. 아직 미확정인 값

- 실제 4→12슬롯 해금 시각과 가격
- 역할별 슬롯 상한
- 지원·제어·동일 효과 중첩을 반영한 실전 편성 평가
- 코인 전투 스탯의 15시간·30시간 배율
- 변종과 합체가 편성 전투력에 들어오는 시각
- 빌드별 실제 스테이지 도달 시간
- 스테이지 2~15 실제 웨이브와 누수율
- 최종 스테이지 15 권장 전투력

다음 검증에서는 실제 슬롯 해금 일정과 코인 전투 성장 배율을 정한 뒤, 이 분포의 해당 Top-K를 사용해 스테이지 15의 하위·중앙·상위 계정 목표 전투력을 역산합니다.
