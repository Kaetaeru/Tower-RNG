## 목적

이 문서는 5개 지역과 15개 스테이지의 실제 콘텐츠 구성을 기록합니다. 공통 웨이브·예산 규칙은 기획 문서에서 관리하고, 각 스테이지의 경로, 최소·기준·최대 예산, 몬스터 비율, 보스, 코인과 행운 데이터는 이 문서에 작성합니다.

스테이지 구성과 맵 디자인은 사용자가 아래 양식을 복제해 직접 제작합니다.

## 지역별 보스 제작 목표

각 지역은 두 개의 핵심 보스 계열을 가집니다.

```text
스테이지 1
- 초·중반 보스 기본형

스테이지 2
- 같은 계열의 강화형 또는 행동 변형

스테이지 3
- 지역 최종 보스
```

첫 출시 핵심 보스 계열 목표는 초·중반 5개와 최종 보스 5개로 총 10개입니다.

## 현재 작성 상태

15개 스테이지의 개별 구성은 아직 작성 전입니다. 각 지역의 세 스테이지는 기본 틀을 참고하되 사용자가 자유롭게 변형합니다.
