# 지역·스테이지 카탈로그

- 계층: 참조 데이터
- 상태: **Active Template**
- 필수 참고: `../../AGENTS.md`
- 상위 문서: `../design/LEVEL_DESIGN.md`, `../design/STAGE_BOSSES.md`, `../design/WORLD_NAVIGATION.md`
- 관련 문서: `TOWER_CATALOG.md`, `MONSTER_CATALOG.md`, `STAT_TREE_CATALOG.md`
- 마지막 정리: 2026-08-02

## 목적

이 문서는 5개 지역과 15개 스테이지의 실제 콘텐츠 구성을 기록합니다. 공통 웨이브·예산 규칙은 기획 문서에서 관리하고, 각 스테이지의 경로·웨이브 예산·몬스터 후보·보스·코인·행운 데이터는 이 문서에 작성합니다.

스테이지 구성과 맵 디자인은 사용자가 아래 양식을 복제해 직접 제작합니다.

## 현재 작성 상태

15개 스테이지의 개별 구성은 아직 작성 전입니다. 각 지역의 세 스테이지는 다음 기본 흐름을 참고하되 사용자가 자유롭게 변형합니다.

```text
지역 첫 스테이지
- 지역 기본 외형과 몬스터 소개

지역 두 번째 스테이지
- 군집·고속·고체력·특수 행동 중 둘 이상 혼합

지역 세 번째 스테이지
- 지역 대표 특성 강화
- 더 높은 웨이브 예산과 지역 대표 보스
```
