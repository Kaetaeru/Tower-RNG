## 목적

V1 일반 굴리기 타워 50자리의 공식 `1 / N` 골격을 정의합니다.

확정·검증된 내용:

- 일반 굴리기 타워 수 50
- 역할 분포 단일·광역 9종, 나머지 네 역할 각 8종
- 최저급 기준 타워 6종 각 `1 / 10`
- 최고 일반 굴리기 단일 화력 `1 / 10^20`
- 공식 단위분수 합 정확히 1
- 분모가 커질수록 RawPowerBudget 증가
- 실제 환생·행운·속도에서 최고 타워의 V1 완주·숙련 누적 획득 목표 통과
- 20,000계정 기준 시간대별 최고 보유와 Top-4~12 전투력 분포 검증

미확정:

- 7번 이후 실제 타워 이름·외형·행동
- 실제 4→12슬롯 해금 시각
- 역할별 슬롯 상한과 실전 시너지
- 변종·합체·코인 전투 성장까지 포함한 최종 편성 전투력

따라서 수학적 사다리와 V1 기본 보유 체감은 검증되었지만 실제 콘텐츠 정체성과 최종 스테이지 밸런스는 아직 확정본이 아닙니다.

## 1. 정확한 확률 합

```text
6 × 1/10    = 0.600
6 × 1/20    = 0.300
6 × 1/100   = 0.060
6 × 1/200   = 0.030
6 × 1/1000  = 0.006
상위 꼬리 20종 = 0.004 = 1/250
--------------------------------
전체          = 1.000
```

상위 꼬리 20종은 `1 / 256`에서 `1 / 10^20`까지이며 임의 정밀도 유리수 계산에서 정확히 `1 / 250`입니다.

```text
Σ(1 / BaseOddsN) = 1
```

부동소수점 반올림이나 숨은 빈 결과를 사용하지 않습니다.

실제 타워 정체성을 작성하며 역할 슬롯을 변경할 수 있지만, 역할 수량과 확률 합을 다시 검증해야 합니다.

## 3. 누적 공식 확률 구조

| 구간 | 포함 슬롯 | 구간 확률 | 누적 확률 |
|---|---:|---:|---:|
| `1 / 10` | 6 | 60% | 60% |
| `1 / 20` | 6 | 30% | 90% |
| `1 / 100` | 6 | 6% | 96% |
| `1 / 200` | 6 | 3% | 99% |
| `1 / 256` | 1 | 0.390625% | 99.390625% |
| `1 / 1,000` | 6 | 0.6% | 99.990625% |
| `1 / 12,500` 이상 | 19 | 0.009375% | 100% |

기본 확률에서 흔한 타워를 안정적으로 공급하고, 스테이지·환생 토큰 행운이 상위 꼬리를 끌어올릴 공간을 남깁니다.

기본 확률만 보면 `1 / 12,500` 이상 전체가 약 `1 / 10,666.67`입니다. 중후반 체감은 `V1_LUCK_COMPRESSION_BENCHMARK.md`의 로그 압축에 의존합니다.

## 5. 슬롯 상태

### 1~6번

```text
01 견습 궁수
02 돌팔매꾼
03 서리 견습생
04 골목 도적
05 신참 북잡이
06 멧돼지 사냥꾼
```

이름과 역할은 확정, 세부 수치는 잠정 밸런스입니다.

### 7~49번

- 실제 TowerId가 아닌 자리표시자
- 공식 분모와 역할은 시뮬레이션용 제안값
- 실제 타워 작성 시 한 자리씩 교체
- 임의 추가로 확률 합을 깨지 않음

### 50번

- V1 최고 일반 굴리기 단일 화력 자리
- 공식 분모 `1 / 10^20`
- 기본 EquivalentContribution 약 `6,309.57`
- 최종 이름·행동·외형 미정

## 6. 수학 검증 규칙

재현 스크립트 실패 조건:

- 슬롯 수가 50이 아님
- 공식 확률 합이 정확히 1이 아님
- 분모가 순위에 따라 비감소하지 않음
- 역할별 분모가 엄격히 증가하지 않음
- 역할 수량이 `9, 9, 8, 8, 8, 8`과 다름
- 최고 분모가 `10^20`이 아님
- 최고 슬롯 역할이 단일 화력이 아님
- 상위 꼬리 20종의 합이 `1 / 250`이 아님

## 7. 완료된 체감 검증

### 최고 타워 누적 확률

실제 환생 XP 곡선, 균형 배분, 행운과 주사위 속도를 함께 적용한 분석 결과:

```text
13.5시간 약 3.0%
15시간 약 4.7%
25시간 약 18%
30시간 약 25%
```

V1 완주 3~5%, 숙련 15~25% 목표를 통과했습니다.

### 전체 보유·편성 분포

`V1_ROSTER_POWER_DISTRIBUTION.md`에서 시나리오당 20,000계정을 표본화했습니다.

균형형 결과:

```text
15시간
- 최고 보유 분모 중앙값: 1 / 10^16
- Top-12 Final EC P10 / P50 / P90: 2,313 / 4,409 / 12,183
- 최고 1/10^20 타워 보유율: 4.720%

30시간
- 최고 보유 분모 중앙값: 1 / 2×10^19
- Top-12 Final EC P10 / P50 / P90: 12,423 / 23,498 / 38,483
- 최고 1/10^20 타워 보유율: 24.590%
```

15시간 P90 전투력은 P10의 약 5.27배입니다. 따라서 특정 극희귀 타워나 상위 분위수를 V1 메인 완주의 필수 조건으로 사용하지 않습니다.

## 8. 남은 검증

1. 7~50번의 실제 타워 이름·행동·외형 작성
2. 4→12슬롯 실제 해금 시각과 가격
3. 역할별 슬롯 상한과 지원·제어 중첩 규칙
4. 코인 전투 스탯·변종·합체를 포함한 실제 편성 전투력
5. 빠른·중앙·느린 빌드의 스테이지 도달 시간 연결
6. 결과가 과도하면 사다리·행운 곡선·획득 목표의 원인을 분리해 조정

특정 극희귀 타워는 V1 메인 완주의 필수 조건으로 사용하지 않습니다.
