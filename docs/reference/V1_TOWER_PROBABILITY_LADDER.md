## 목적

V1 일반 굴리기 타워 50자리의 공식 `1 / N` 골격을 정의합니다.

현재 확정된 내용:

- 일반 굴리기 타워 수: 50
- 역할 분포: 단일·광역 9종, 나머지 네 역할 각 8종
- 기존 최저급 기준 타워 6종: 각 `1 / 10`
- 최고 일반 굴리기 단일 화력 기준: `1 / 10^20`
- 공식 단위분수 합: 정확히 1
- 분모가 커질수록 `RawPowerBudget` 증가

현재 미확정인 내용:

- 7번 이후 실제 타워 이름·외형·행동
- 행운 적용 후 시간대별 획득 분포
- 이 사다리가 12~15시간 완주 곡선에 적합한지 여부

따라서 이 문서는 **수학적으로 유효한 첫 사다리**이지만 출시 확률표 확정본은 아닙니다.

## 1. 정확한 확률 합

사다리는 다음 묶음으로 구성합니다.

```text
6 × 1/10    = 0.600
6 × 1/20    = 0.300
6 × 1/100   = 0.060
6 × 1/200   = 0.030
6 × 1/1000  = 0.006
상위 꼬리 20종 = 0.004 = 1/250
--------------------------------
전체          = 1.000
```

상위 꼬리 20종은 `1 / 256`에서 `1 / 10^20`까지이며, 임의 정밀도 유리수 계산에서 정확히 `1 / 250`입니다.

```text
Σ(1 / BaseOddsN) = 1
```

부동소수점 반올림이나 숨은 빈 결과로 합을 맞추지 않습니다.

## 2. 역할 분포

| 역할 | V1 슬롯 수 |
|---|---:|
| 단일 화력 | 9 |
| 광역 화력 | 9 |
| 제어 | 8 |
| 마무리 | 8 |
| 지원 | 8 |
| 대형 사냥 | 8 |
| 합계 | **50** |

첫 다섯 공통 역할 단계에서는 역할별로 하나씩 배치합니다. 수학적 보정 슬롯과 최고점 때문에 단일 화력과 광역 화력이 각각 한 자리 더 많습니다.

역할 수량은 확정 출시 목표 범위인 역할별 8~10종을 지킵니다. 슬롯의 역할 배정은 실제 타워 정체성을 작성할 때 변경할 수 있지만, 변경 후에도 전체 확률 합과 역할 수량 검증을 다시 통과해야 합니다.

## 3. 누적 공식 확률 구조

| 구간 | 포함 슬롯 | 구간 확률 | 누적 확률 |
|---|---:|---:|---:|
| `1 / 10` | 6 | 60% | 60% |
| `1 / 20` | 6 | 30% | 90% |
| `1 / 100` | 6 | 6% | 96% |
| `1 / 200` | 6 | 3% | 99% |
| `1 / 256` | 1 | 0.390625% | 99.390625% |
| `1 / 1,000` | 6 | 0.6% | 99.990625% |
| `1 / 12,500` 이상 | 19 | 0.009375% | 100% |

이 분포는 기본 확률에서 흔한 타워를 안정적으로 공급하고, 스테이지·환생 행운이 상위 꼬리를 끌어올릴 공간을 크게 남깁니다.

다만 기본 확률만 보면 `1 / 12,500` 이상 전체가 약 `1 / 10,666.67`이므로, 실제 중후반 체감은 행운 압축 곡선에 매우 크게 의존합니다. 다음 시뮬레이션에서 반드시 검증합니다.

## 5. 슬롯 상태

### 1~6번

기존 실제 기준 타워와 연결됩니다.

```text
01 견습 궁수
02 돌팔매꾼
03 서리 견습생
04 골목 도적
05 신참 북잡이
06 멧돼지 사냥꾼
```

이름과 역할은 확정, 세부 수치는 잠정 밸런스입니다.

### 7~49번

- 실제 TowerId가 아닌 자리표시자
- 공식 분모와 역할은 시뮬레이션용 제안값
- 실제 타워를 작성할 때 한 자리씩 교체
- 중간 희귀도 타워를 임의로 추가해 확률 합을 깨지 않음

### 50번

- V1 최고 일반 굴리기 단일 화력 자리
- 공식 분모 `1 / 10^20`
- 기본 `EquivalentContribution` 약 `6,309.57`
- 최종 이름·행동·외형은 미정

## 6. 검증 규칙

재현 스크립트가 다음을 모두 실패 조건으로 검사합니다.

- 슬롯 수가 50이 아님
- 공식 확률 합이 정확히 1이 아님
- 분모가 순위에 따라 비감소하지 않음
- 역할별 분모가 엄격히 증가하지 않음
- 역할 수량이 `9, 9, 8, 8, 8, 8`과 다름
- 최고 분모가 `10^20`이 아님
- 최고 슬롯의 역할이 단일 화력이 아님
- 상위 꼬리 20종의 합이 정확히 `1 / 250`이 아님

## 7. 다음 시뮬레이션

이 사다리를 바로 출시 확률로 확정하지 않습니다. 다음 순서로 체감을 검증합니다.

1. 15분·30분·2시간·5시간·12~15시간·20~30시간의 누적 굴림 수 계산
2. 행운 없음 상태의 최고 보유 타워와 편성 전투력 분포 계산
3. 스테이지·환생·포션·특수 주사위의 행운 압축 후보 적용
4. 최고 타워 누적 획득률 목표 검증
   - 12~15시간: 3~5%
   - 20~30시간: 15~25%
5. 하위 10%·중앙·상위 10% 계정의 역할별 편성 기여도 비교
6. 결과가 과도하면 분모 사다리·행운 곡선·획득 목표 중 원인을 분리해 조정

특정 극희귀 타워는 V1 메인 완주의 필수 조건으로 사용하지 않습니다.
