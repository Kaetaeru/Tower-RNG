## 목적

하나의 거대한 스탯 트리의 실제 노드 이름, 좌표, 연결, 가격, 단계와 환생 조건을 기록합니다.

코인은 노드 구매에 사용하고 환생 조건은 Defense XP로 별도 진행합니다. 아래 첫 주기 노드는 첫 환생 경제 벤치마크를 통과한 `Confirmed (Provisional Balance)` 데이터입니다.

```text
                         굴리기 속도 I (0, 2)
                                  │
자동 편성 (-2, 0) ─ 자동 굴리기 (0, 0) ─ 핵심 성능 I (2, 0) ─ 전투 분야 (4, 0) ─ 핵심 성능 II (6, 0)

편성 슬롯 5 (-4, 0)       자석 범위 I (0, -2)
                                  │
                           자석 속도 I (0, -4) ─ 코인 획득 I (2, -4)
```
