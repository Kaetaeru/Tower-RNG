## 목적

이 문서는 실제 스탯 트리 노드의 이름, 연결 관계, 가격, 단계와 해금 조건을 기록합니다. 스탯 트리의 성장 철학과 허용 범위는 기획 문서에서 관리하고, 개별 노드 데이터는 이 문서에서 관리합니다.

## 확정된 노드 계열

정확한 가격과 단계 수는 미확정이지만 다음 계열은 상위 기획에서 사용하기로 확정했습니다.

### 극초반

- 자동 굴리기
- 자동 편성
- 기본 자석 범위
- 기본 자석 흡입 속도

### 전투 성장

- 성능 강화
- 공격속도
- 치명타 확률
- 치명타 피해
- 베이스 최대 체력
- 베이스 회복

### 굴리기·파밍

- 영구 행운
- 굴리기 속도
- 코인 획득량
- 오프라인 코인 해금
- 오프라인 효율
- 오프라인 저장 시간

### 편성과 시스템

- 전체 편성 슬롯
- 역할별 편성 슬롯
- 타겟 설정 확장
- 변종 계열 해금
- 합체
- 자동 합체
- 개인 스테이지 보스 관련 확장
- 텔레포터
- 중후반 강한 자석
