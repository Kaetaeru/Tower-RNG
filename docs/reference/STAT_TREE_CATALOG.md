# 스탯 트리 카탈로그

- 계층: 참조 데이터
- 상태: **Active Template**
- 필수 참고: `../../AGENTS.md`
- 상위 문서: `../design/STAT_TREE.md`, `../design/PROGRESSION.md`, `../design/ECONOMY_PACING.md`, `../design/REBIRTH.md`
- 관련 문서: `TOWER_CATALOG.md`, `MONSTER_CATALOG.md`, `STAGE_CATALOG.md`
- 마지막 정리: 2026-08-02

## 목적

하나의 거대한 스탯 트리의 실제 노드 이름, 좌표, 연결, 가격, 단계와 환생 조건을 기록합니다.

코인은 노드 구매에 사용하고 환생 조건은 Defense XP로 별도 진행합니다.

---

## 트리 분야

- 중심 기본 기능
- 전투
- 굴리기·행운
- 편성·타겟
- 수집·오프라인
- 베이스
- 특수 시스템
- 환생 조건·후반 편의

모든 분야는 하나의 좌표 공간에서 연결됩니다.

---

## 중심부

- 자동 굴리기
- 자동 편성
- 기본 자석 범위
- 기본 자석 속도
- 기본 성능 강화

첫 1~2분에 주요 기능을 경험하도록 배치합니다.

---

## 분야별 계열

### 전투

- 성능 강화
- 공격속도
- 치명타 확률
- 치명타 피해

### 굴리기·행운

- 영구 행운
- 굴리기 속도
- 특수 주사위 확장 후보

현재 타워별 유효 확률을 보여 주는 노드는 만들지 않습니다.

### 편성·타겟

- 전체 편성 슬롯
- 역할별 슬롯
- 역할별·타워별 타겟 확장
- 편성 프리셋 편의 후보

### 수집·오프라인

- 코인 획득량
- 자석
- 오프라인 코인 해금
- 효율
- 8·12·24시간 저장

### 베이스

- 최대 체력
- 지속 회복

### 특수 시스템

- 변종 계열 해금
- 수동 합체
- 텔레포터
- 보스 변종·도감 편의

자동 합체 노드는 만들지 않습니다.

### 환생 조건·후반

- 최소 환생 횟수 구간
- 강한 자석
- 고급 타겟·편성 편의
- 오프라인 후반 확장

Defense XP를 코인으로 직접 구매하는 노드는 만들지 않습니다.

## 분야 입구 양식

```markdown
## 분야 이름 해금

- NodeId:
- NodeType: BranchGate
- 좌표:
- 선행 중심 노드:
- 가격:
- 최소 환생 횟수:
- 해금 노드:
- 대표 보상 미리보기:
- 해금 연출:
```

해금 전에도 분야 이름과 대표 기능을 볼 수 있게 합니다.

---

## 첫 15분 배치 목표

```text
0~1분: 자동 굴리기
1~2분: 자동 편성·기본 자석
2~5분: 기본 전투·굴리기 노드
5~10분: 첫 분야 입구 또는 추가 영구 노드
7~15분: 첫 Defense XP 환생 가능
```

---

## 제작 점검

- [ ] 하나의 연결 트리인가
- [ ] 구매 불가 이유 표시 가능
- [ ] 다음 목표가 보이는가
- [ ] 분야 해금 직후 저가 노드가 있는가
- [ ] 상호 배타적 영구 함정이 없는가
- [ ] 환생 후 유지되는가
- [ ] 구매 피드백이 정의되어 있는가
- [ ] 자동 합체 노드가 없는가
- [ ] Defense XP 구매 노드가 없는가
- [ ] 목표 시간과 가격이 일치하는가

---

## 현재 작성 상태

개별 노드 좌표, 가격과 단계는 작성 전입니다. 중심부와 첫 환생 전 노드부터 작성합니다.
