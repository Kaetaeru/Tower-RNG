## 목적

스테이지 6을 지역 2 사막의 최종 보스 스테이지이자 두 번째 완전 검증 기준점으로 사용합니다.

검증 목표:

- 기존 장기 경제 계산의 스테이지 6 `400 보상 단위 / 75초` 프록시를 실제 전투 구성으로 검증
- 1.5~2시간대의 6슬롯 진입 계정이 완전히 막히지 않음
- 7슬롯 안정 파밍 계정은 역할 상한을 지키는 모든 대표 조합에서 누수 없이 약 75초 주기를 달성
- 보호막과 체력 구간 보호막을 재사용하면서, 보스의 짧은 잠복 행동을 직접 검증

현재 표시 이름과 외형은 계산용 임시 정체성입니다. HP, 이동시간, SpawnCost, 보호막·잠복 골격, 웨이브 구성과 처리시간을 우선 권위값으로 사용합니다.

## 1. 스테이지 기준

```text
Stage: 6
StageScale: 46.41588834
StageRewardScale: 68.20016794
StageCoinUnit: 1
표준 일반 몬스터 HP: 약 232.08
```

검증 프로필:

```text
진입 전체 검사
- 6슬롯
- 역할당 최대 2개
- 최소 4개 역할 사용
- 계정 출력 ×8.00
- 가능한 121개 역할 수량 조합

진입 정상 편성 부분집합
- 6슬롯
- 역할당 최대 2개
- 최소 5개 역할 사용
- 계정 출력 ×8.00
- 가능한 31개 조합

안정 파밍
- 7슬롯
- 역할당 최대 3개
- 최소 5개 역할 사용
- 계정 출력 ×9.50
- 가능한 96개 조합
```

`×8.00`과 `×9.50`은 최저급 역할 행동 모델을 해당 시간대 계정 전투력으로 옮기기 위한 시뮬레이션 변환값입니다. 플레이어에게 표시되는 별도 능력치가 아닙니다.

## 2. 계산용 몬스터

| 표시 이름 | MonsterId | HP | 추가 유효 체력 | 이동시간 | SpawnCost | 베이스 피해 | 역할 |
|---|---|---:|---:|---:|---:|---:|---|

| 유리갑 전갈 | `BOSS_GLASS_SCORPION` | 1,011.87 | 시작 보호막 12% + HP 60%에서 보호막 18% | 50초 | 100 | 10 | 보스·정예·대형 |

보스 본체:

```text
CoinRewardModifier: 1.15
DefenseXPModifier: 1.15
```

### 잠복 행동

유리갑 전갈은 HP가 35% 이하가 될 때 한 번 잠복합니다.

```text
지속시간: 1.25초
잠복 중: 타겟 불가
경로 진행: 즉시 +6%
재발동: 없음
```

잠복은 긴 무적 구간이 아니라 보스 전투의 짧은 박자 변화와 이동 압박입니다. 플레이어 공격을 장시간 무효화하지 않습니다.

### 최소 5역할 정상 편성

실제 자동 편성이 우선할 31개 최소 5역할 조합:

```text

최장: 116.34초
모든 웨이브 누수: 0
보스 평균: 33.81초
```

따라서 지역 2 최종전에 막 진입한 정상 편성은 특별 주기 상한 120초 안에서 클리어할 수 있습니다. 역할 구성이 지나치게 편중된 계정은 소량의 베이스 피해를 받을 수 있지만 보스에서 완전히 막히지는 않습니다.

## 6. 경제 검증

```text
보상 단위 400
× StageRewardScale 68.20016794
÷ 실제 파밍 주기 75.00초
× 60
= 분당 Defense XP 약 21,824.96
```

기존 계획 프록시도 정확히 `400 / 75초`였으므로 실질 차이가 없습니다.

따라서 다음 기존 계산을 다시 조정하지 않습니다.

- 두 번째 이후 환생 XP 기준
- 행운 압축 계수
- 장기 환생 횟수
- 시간대별 보유 타워 분포
- 편성 슬롯과 코인 전투 성장 시각

## 7. 수용 조건

재현 스크립트 실패 조건:

- 웨이브 예산이 `60/60/65/75/125`와 다름
- 전체 보상 단위가 정확히 400이 아님
- 6슬롯 최소 4역할 진입 검사에서 전체 누수가 4회를 초과
- 진입 프로필 웨이브 1 또는 보스에서 누수 발생
- 진입 평균 주기가 98~110초 밖
- 진입 최장 조합이 130초 초과
- 6슬롯 최소 5역할 부분집합에서 누수 발생
- 6슬롯 최소 5역할 부분집합 최장 주기가 118초 초과
- 7슬롯 파밍 프로필에서 누수 발생
- 파밍 일반 웨이브 평균이 8~16초 밖
- 파밍 보스 평균이 22~26초 밖
- 파밍 평균 주기가 72~78초 밖
- 파밍 최장 조합이 92초 초과
- 파밍 보스 시간 비중이 30~35% 밖

현재 모든 단언을 통과합니다.

실제 행동과 모델이 확정되면 같은 보상·주기 골격을 유지하며 다시 검증합니다.
