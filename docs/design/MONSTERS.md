## 요약

몬스터는 플레이어별 일반 스테이지 전장에 생성되어 지정된 경로를 따라 베이스로 이동합니다. 체력·속도·생성 비용·특수 행동을 조합해 타워 역할의 효율 차이를 만들되 강제 피해 상성은 사용하지 않습니다.

각 스테이지는 5개의 웨이브를 반복하며, 웨이브별 생성값 예산과 몬스터 후보 가중치로 실제 구성을 만듭니다. 5웨이브에는 해당 스테이지 보스가 등장합니다.

---

## 1. 기본 규칙

### MON-001: 경로 이동

- 생성 지점에서 스테이지 웨이포인트를 따라 베이스로 이동
- 플레이어를 직접 공격하지 않음
- 타워를 공격하거나 파괴하지 않음
- 몬스터끼리 물리적으로 밀어내지 않음
- 경로 끝에 도달하면 베이스 피해를 주고 제거

### MON-002: 개인 전장 소유

- 다른 플레이어가 내 몬스터를 공격하지 않음
- 다른 플레이어의 개인 몬스터를 내 화면에 표시하지 않음
- 체력·처치 보상·코인 드롭을 공유하지 않음
- 라이브 웨이브만 공동 전투의 예외

---

## 2. 몬스터 데이터

### MON-003: 기본 정의

각 몬스터는 최소한 다음 개념을 가집니다.

- 고유 ID와 표시 이름
- 등장 지역과 유형
- 최대 체력
- 목표 이동 시간 보정
- 기본 베이스 피해
- 생성 비용
- 코인 가치
- 정수 게이지 기여량
- 변종 가능 여부
- 특수 행동과 태그
- 모델 키트와 모션 참조

실제 개별 값은 `docs/reference/MONSTER_CATALOG.md`에서 관리합니다.

### MON-004: 런타임 상태

- 현재·최대 체력
- 경로 진행도와 월드 위치
- 현재 경로 구간
- 이동속도
- 예약 피해
- 상태 효과
- 변종·정예·보스 태그
- 행동 상태
- 현재 스테이지와 웨이브 귀속

스테이지가 바뀌거나 웨이브 전투가 정리되면 이전 귀속 몬스터는 제거됩니다.

---

## 3. 기본 몬스터 유형

몬스터 유형은 강제 상성 클래스가 아니라 웨이브 구성을 위한 행동 특성입니다.

### 일반형
기준 체력과 속도를 가진 기본 몬스터입니다.

### 군집형
낮은 생성 비용과 체력으로 많은 수가 등장하며 광역 화력의 효율을 높입니다.

### 고체력형
높은 체력과 생성 비용을 가지며 단일 화력과 대형 사냥의 효율을 높입니다.

### 고속형
빠르게 이동하여 제어와 선두 타겟의 가치를 높입니다.

### 부상 가속형
체력이 낮아지거나 특정 경로 구간에서 이동 특성이 변합니다.

### 지원형
주변 몬스터에게 속도, 회복 또는 제한된 지원을 제공합니다.

### 분열·생성형
사망 또는 조건 충족 시 작은 몬스터를 추가합니다. 생성된 몬스터의 예산과 보상 관계를 데이터에 명시합니다.

### 보호형
주변 몬스터에게 보호막이나 피해 감소를 제공합니다. 특정 공격 유형 완전 면역은 기본으로 사용하지 않습니다.

---

## 4. 생성 비용과 웨이브 예산

### MON-005: 생성 비용

각 일반 몬스터는 자신의 생성 비용을 가집니다.

```text
웨이브 예산 100
비용 5 몬스터 20마리
비용 20 몬스터 5마리
비용 5·10·20 몬스터 혼합
```

생성 비용은 다음의 기본 기준으로 사용합니다.

- 웨이브 총 몬스터 양
- 코인 가치
- 연금 정수 기여량
- 군집과 강한 소수 사이의 비교

### MON-006: 웨이브 후보와 가중치

각 웨이브는 몬스터 종류를 직접 한 줄로 고정하거나, 후보와 가중치로 예산을 채울 수 있습니다.

지정 가능한 정보:

- 등장 후보
- 후보별 가중치
- 최소·최대 등장 수
- 필수 등장 몬스터
- 생성 순서와 간격
- 예산을 초과하지 않는 조합 규칙

웨이브별 실제 데이터는 `STAGE_CATALOG.md`에 기록합니다.

### MON-007: 5웨이브 보스

5웨이브에는 해당 스테이지의 보스가 등장합니다.

- 보스 단독 또는 일반 몬스터와 혼합 가능
- 보스의 예산 소비 여부는 스테이지 데이터에 명시
- 보스 데이터는 `MONSTER_CATALOG.md`에 기록
- 보스 처치가 다음 스테이지 해금 조건은 아님

---

## 5. 능력치와 상성 원칙

### MON-008: 스테이지 기반 능력치

몬스터 능력치는 다음으로 결정합니다.

- 지역과 스테이지
- 웨이브
- 몬스터 종류
- 변종 여부
- 보스 여부
- 라이브 웨이브 단계

플레이어의 스탯 트리가 몬스터 체력·속도·피해를 자동으로 증가시키지 않습니다.

### MON-009: 유형별 면역 미사용

기본 규칙으로 사용하지 않음:

- 물리·마법 방어 분리
- 원소별 저항과 면역
- 특정 역할만 공격 가능한 적
- 특정 타워가 없으면 처치 불가능한 적
- 명중률과 회피율

지역 테마는 외형과 행동 차이를 만들지만 강제 원소 상성을 만들지 않습니다.

### MON-010: 역할 비중의 의미

- 군집 비중이 높으면 광역 중심이 유리
- 강적과 보스가 많으면 단일·대형 사냥 중심이 유리
- 빠른 적이 많으면 제어 중심이 안정적
- 혼합 구성에서는 균형형이 유리

어떤 편성 성향도 모든 스테이지의 강제 정답이 되지 않게 합니다.

---

## 6. 처치와 보상

### MON-011: 처치 판정

체력이 0 이하가 되면 즉시 전투 대상에서 제외됩니다.

### MON-012: 코인 드롭

처치 위치 주변에 코인을 떨어뜨립니다.

- 계정에 즉시 지급하지 않음
- 플레이어가 직접 수집
- 가까운 드롭끼리 묶음 병합 가능
- 환생 코인 배율과 스테이지 단가 반영

### MON-013: 연금 정수

처치 시 생성 비용을 기준으로 연금 정수 게이지가 자동 증가합니다. 코인을 줍지 못해도 유효한 처치의 정수 기여는 적용됩니다.

### MON-014: 베이스 도달

- 남은 체력 비율에 따른 베이스 피해
- 처치 코인과 정수 없음
- 이미 획득한 재화 차감 없음
- 웨이브에서는 해소된 몬스터로 계산

---

## 7. 상태 효과와 특수 행동

몬스터는 감속, 기절, 지속 피해와 표식의 대상이 될 수 있습니다.

특수 행동 예:

- 이동속도 변화
- 주변 몬스터 지원
- 체력 조건에 따른 형태 변화
- 일시적 보호막
- 분열 또는 추가 생성
- 제한된 상태 효과 사용

보스와 특수 적은 완전 면역보다 효과 감소와 지속시간 감소를 우선합니다.

---

## 8. 변종 몬스터

스탯 트리에서 기능을 해금한 뒤 일반 몬스터를 낮은 확률로 대체할 수 있습니다.

후보 방향:

- 황금
- 수정
- 정예
- 공허

변종은 고유 외형·모션, 더 높은 능력치, 추가 행동과 높은 보상을 가질 수 있습니다. 위험 증가보다 보상 가치가 충분해야 합니다.

---

## 9. 모델과 애니메이션

```text
MonsterKit
├─ Basic
├─ 자유 이름 모션 견본
└─ MonsterModule
```

공유 규칙:

- `Basic`이 실제 런타임 모델
- 다른 모델은 모션 상태 참조
- 이름과 상대 경로로 구성요소 대응
- 위치·회전·크기·색상·투명도·조명·파티클 처리

몬스터는 생성·경로 이동·특수 행동·사망·베이스 도달을 위한 별도 행동 모듈을 사용합니다.

---

## 10. 사용하지 않는 구조

- 몬스터가 플레이어를 직접 공격
- 몬스터가 타워를 파괴
- 특정 피해 유형 면역과 강제 상성
- 몬스터끼리 물리 충돌로 경로 차단
- 처치 보상의 자동 코인 지급
- 생성 비용과 무관한 임의 마릿수만으로 모든 웨이브 구성
- 보상 없이 난이도만 증가하는 변종
- 타워와 완전히 별개의 중복 애니메이션 엔진

---

## 11. 미확정 사항

- 지역별 실제 몬스터 목록
- 몬스터별 생성 비용과 능력치
- 웨이브 후보 선택 알고리즘의 정확한 계약
- 특수 행동의 수치와 빈도
- 변종 명칭·확률·보상 배율
- 15개 스테이지 보스 목록
