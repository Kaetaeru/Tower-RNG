## 요약

몬스터는 플레이어별 일반 스테이지 전장에 생성되어 지정된 경로를 따라 베이스로 이동합니다. 체력·속도·수량·생성 비용·특수 행동을 조합해 타워 역할의 효율 차이를 만들되, 특정 역할이나 피해 유형이 없으면 절대 처리할 수 없는 강제 상성은 사용하지 않습니다.

처치된 몬스터는 코인을 월드에 떨어뜨리고 연금 정수 게이지를 자동으로 채웁니다. 모델과 모션은 타워와 같은 `Basic + 자유 이름 모션 견본` 방식을 사용합니다.

---

## 1. 기본 규칙

### MON-001: 경로 이동

일반 몬스터는 생성 지점에서 나타나 스테이지 웨이포인트를 따라 베이스로 이동합니다.

- 플레이어를 직접 공격하지 않음
- 타워를 공격하거나 파괴하지 않음
- 몬스터끼리 물리적으로 밀어내지 않음
- 경로 끝에 도달하면 베이스 피해를 주고 제거

### MON-002: 개인 전장 소유

일반 스테이지 몬스터는 플레이어별로 독립합니다.

- 다른 플레이어가 내 몬스터를 공격하지 않음
- 다른 플레이어의 개인 몬스터를 내 화면에 표시하지 않음
- 체력, 처치 보상과 코인 드롭을 공유하지 않음

라이브 웨이브만 공동 전투의 예외입니다.

---

## 2. 몬스터 데이터

### MON-003: 기본 정의

각 몬스터는 최소한 다음 개념을 가집니다.

- 고유 ID와 표시 이름
- 최대 체력
- 이동 특성 또는 목표 이동 시간 보정
- 기본 베이스 피해
- 생성 비용
- 코인 가치
- 정수 게이지 기여량
- 변종 가능 여부
- 특수 행동과 태그
- 모델 키트와 모션 참조

### MON-004: 런타임 상태

전투 중 몬스터는 다음 상태를 가질 수 있습니다.

- 현재·최대 체력
- 경로 진행도와 월드 위치
- 현재 경로 구간
- 이동속도
- 예약 피해
- 상태 효과
- 변종·정예·보스 태그
- 행동 상태

---

## 3. 기본 몬스터 유형

몬스터 유형은 강제 상성 클래스가 아니라 스테이지 구성을 위한 행동 특성입니다.

### 일반형

기준 체력과 속도를 가진 기본 몬스터입니다.

### 군집형

- 낮은 생성 비용
- 낮은 개별 체력
- 많은 수량
- 광역 화력의 효율을 높임

### 고체력형

- 높은 체력과 생성 비용
- 적은 수량
- 단일 화력과 대형 사냥의 효율을 높임

### 고속형

- 빠른 이동
- 상대적으로 낮거나 중간 체력
- 제어와 선두 타겟의 가치를 높임

### 부상 가속형

체력이 낮아지거나 특정 경로 구간에 들어가면 이동 방식이 변합니다.

### 지원형

주변 몬스터에게 속도, 회복 또는 다른 제한된 지원을 제공합니다.

### 분열·생성형

사망 또는 특정 조건에서 작은 몬스터를 추가할 수 있습니다. 생성된 몬스터의 보상과 생성 비용 관계는 개별 데이터에 명시합니다.

### 보호형

주변 몬스터에게 보호막이나 피해 감소를 제공할 수 있습니다. 특정 공격 유형을 완전히 무효화하는 면역은 기본으로 사용하지 않습니다.

이 목록은 최초 카탈로그의 후보이며, 실제 출시 몬스터 수와 조합은 지역 설계에서 정합니다.

---

## 4. 능력치와 생성 비용

### MON-005: 스테이지 기반 능력치

몬스터 능력치는 다음으로 결정됩니다.

- 지역과 스테이지
- 몬스터 종류
- 변종 여부
- 보스 여부
- 라이브 웨이브 단계

플레이어의 스탯 트리가 몬스터 체력·속도·피해를 자동으로 증가시키지 않습니다.

### MON-006: 생성 예산

각 몬스터는 자신의 생성 비용만큼 스테이지 생성값 예산을 소비합니다.

같은 예산에서 약한 다수, 강한 소수와 혼합 구성을 만들 수 있습니다. 생성 비용은 코인 가치와 정수 게이지 기여량의 기본 기준으로도 사용합니다.

---

## 5. 상성 원칙

### MON-007: 유형별 면역 미사용

기본 규칙으로 다음을 사용하지 않습니다.

- 물리·마법 방어 분리
- 원소별 저항과 면역
- 특정 역할만 공격 가능한 적
- 특정 타워가 없으면 처치 불가능한 적
- 명중률과 회피율

역할 적합성은 처리 속도와 파밍 효율을 바꾸지만 진행 가능 여부를 절대적으로 잠그지 않습니다.

### MON-008: 역할 비중의 의미

몬스터 구성은 자동 편성의 역할 성향을 시험합니다.

- 군집이 많으면 광역 중심 편성이 유리
- 강적이 많으면 단일·대형 사냥 중심이 유리
- 빠른 적이 많으면 제어 중심이 안정적
- 혼합 구성에서는 균형형 편성이 유리

어떤 프리셋도 모든 스테이지에서 강제 정답이 되지 않도록 합니다.

---

## 6. 처치와 보상

### MON-009: 처치 판정

현재 체력이 0 이하가 되면 즉시 전투 대상에서 제외됩니다. 예약 피해는 여러 타워의 과도한 오버킬을 줄이는 데 사용할 수 있습니다.

### MON-010: 코인 드롭

처치된 몬스터는 사망 위치 주변에 코인을 떨어뜨립니다.

- 계정에 즉시 지급하지 않음
- 플레이어가 획득 범위 안으로 이동해야 획득
- 가까운 코인 드롭끼리 묶음으로 합쳐질 수 있음
- 환생 코인 배율과 스테이지 단가를 반영

### MON-011: 연금 정수 게이지

처치 시 생성 비용을 기준으로 연금 정수 게이지가 자동으로 증가합니다. 코인을 줍지 못하더라도 유효한 처치의 정수 게이지는 적용됩니다.

### MON-012: 베이스 도달

베이스에 도달한 몬스터는 남은 체력 비율에 따라 피해를 주고 제거됩니다.

- 처치 보상 없음
- 코인 드롭 없음
- 정수 게이지 증가 없음
- 이미 획득한 재화 차감 없음

---

## 7. 상태 효과와 특수 행동

몬스터는 감속, 기절, 지속 피해와 표식의 대상이 될 수 있습니다.

일부 몬스터는 다음과 같은 특수 행동을 가질 수 있습니다.

- 이동속도 변화
- 주변 몬스터 지원
- 체력 조건에 따른 형태 변화
- 일시적 보호막
- 분열 또는 추가 생성
- 제한된 상태 효과 사용

보스와 특수 적은 완전 면역보다 효과 감소와 지속시간 감소를 우선합니다.

---

## 8. 변종 몬스터

변종 몬스터는 스탯 트리에서 기능을 해금한 뒤 일반 몬스터를 낮은 확률로 대체할 수 있습니다.

후보 방향:

- 황금
- 수정
- 정예
- 공허

변종은 다음을 가질 수 있습니다.

- 고유 외형과 모션
- 더 높은 능력치
- 추가 특수 행동
- 더 높은 코인 가치
- 정수 게이지 또는 정수 보너스

위험 증가보다 보상 가치가 충분히 높아야 합니다.

---

## 9. 모델과 애니메이션

몬스터는 타워와 같은 시각 상태 모션 엔진을 사용합니다.

```text
MonsterKit
├─ Basic
├─ 자유 이름 모션 견본
└─ MonsterModule
```

공유 규칙:

- `Basic`이 실제 런타임 모델
- 다른 모델은 모션 상태 참조
- 이름과 상대 경로로 구성요소 대응
- 위치·회전·크기·색상·투명도·조명·파티클 처리

타워의 공격 행동 모듈을 그대로 사용하는 것은 아니며, 몬스터는 생성·경로 이동·특수 행동·사망·베이스 도달을 위한 별도 행동 모듈을 사용합니다.

자세한 제작 규약은 `docs/technical/MONSTER_MODELING.md`에서 관리합니다.

---

## 10. 사용하지 않는 구조

- 몬스터가 플레이어를 직접 공격하는 일반 스테이지
- 몬스터가 타워를 파괴
- 특정 피해 유형 면역과 강제 상성
- 몬스터끼리 물리 충돌로 경로 차단
- 베이스 도달 시 보유 코인 차감
- 처치 보상의 자동 코인 지급
- 보상 없이 난이도만 증가하는 변종
- 타워와 완전히 별개의 중복 애니메이션 엔진

---

## 11. 미확정 사항

- 최초 5개 지역의 몬스터 목록
- 체력·속도·베이스 피해 곡선
- 각 특수 행동의 실제 수치와 빈도
- 변종 계열의 최종 명칭과 확률
- 변종별 보상 배율
- 몬스터 카탈로그 데이터 형식
