## 요약

전투와 굴리기는 메뉴 사용 중에도 계속되므로, UI는 자주 확인하는 정보와 복잡한 관리 기능을 분리합니다.

타워 보유, 상세 편성과 합체는 하나의 `인벤토리` 안에서 탭으로 관리합니다. 현재 편성과 자동 편성 상태를 빠르게 조절하는 `퀵 편성 HUD`는 일반 플레이 화면에 항상 표시합니다.

---

## 1. 기본 원칙

### UIF-001: 플레이를 멈추지 않는 메뉴

- 인벤토리와 스탯 트리를 열어도 자동 전투와 자동 굴리기 계속 진행
- 희귀 획득 연출이 메뉴 조작과 코인 수집을 장시간 막지 않음
- 주요 상태는 메뉴를 닫지 않아도 확인 가능
- 모바일·게임패드·키보드에서 같은 핵심 기능에 접근 가능

메뉴를 보는 동안 캐릭터 이동 조작이 제한될 수는 있지만, 전투와 굴리기 시스템 자체를 정지하지 않습니다.

---

## 2. 항상 보이는 기본 HUD

### UIF-002: 핵심 진행 정보

일반 플레이 화면에서 다음을 항상 확인할 수 있어야 합니다.

- 현재 코인
- 연금 정수
- 현재 지역과 스테이지
- 현재 스테이지 행운
- 굴리기 남은 시간 또는 진행 상태
- 황금 주사위까지 남은 굴림
- 다이아몬드 주사위까지 남은 굴림
- 자동 굴리기 ON/OFF
- 환생 가능 알림

텔레포터를 해금한 뒤에는 빠른 이동 버튼도 기본 HUD 또는 가까운 상위 메뉴에 표시합니다.

---

## 3. 퀵 편성 HUD

### UIF-003: 항상 보이는 간편 편성

퀵 편성은 상세 인벤토리를 열지 않고 현재 편성을 확인하고 기본 설정을 바꾸는 HUD입니다.

기본 구성:

- 현재 편성된 타워 아이콘 또는 축약 카드
- 현재 편성 수 / 전체 슬롯 수
- 자동 편성 ON/OFF
- 현재 역할 성향 프리셋
- 프리셋 빠른 변경
- 상세 인벤토리·편성 탭 열기

### UIF-004: 퀵 편성의 책임 제한

퀵 편성 HUD에서는 자주 사용하는 간단한 조작만 제공합니다.

허용:

- 자동 편성 토글
- 역할 성향 프리셋 전환
- 현재 편성 확인
- 특정 슬롯의 간단한 제거 또는 최근 추천 교체
- 상세 편성 화면 열기

상세 화면으로 넘길 기능:

- 전체 보유 타워 검색과 정렬
- 여러 수량의 세부 편성
- 복합 역할 슬롯 선택
- 타워 보호
- 합체 재료 선택
- 도감과 계보 확인

HUD가 복잡한 전체 인벤토리를 그대로 복제하지 않게 합니다.

---

## 4. 인벤토리

### UIF-005: 통합 인벤토리

`인벤토리`는 타워 관리의 상위 메뉴입니다.

초기 탭 구조:

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

합체가 해금되기 전에는 합체 탭을 잠긴 상태로 표시하거나 해금 시점에 추가할 수 있습니다. 정확한 노출 방식은 튜토리얼 흐름에서 정합니다.

### UIF-006: 타워 보유 탭

필수 기능:

- 타워 종류별 보유 수량
- 실제 획득 확률과 보조 등급
- 역할과 행동 요약
- 보호 상태
- 도감 등록 여부
- 검색·역할·희귀도·변종 필터
- 현재 편성 수량
- 합체 가능 여부

같은 타워는 개별 무작위 능력치 목록이 아니라 종류별 수량으로 표시합니다.

### UIF-007: 편성 탭

필수 기능:

- 전체 편성 슬롯
- 역할별 슬롯
- 현재 편성 타워와 수량
- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 자동 편성 평가 결과 또는 변경 요약
- 수동 추가·제거·교체
- 복합 역할 타워의 슬롯 선택

퀵 편성 HUD에서 할 수 없는 세부 조정은 이 탭에서 수행합니다.

### UIF-008: 합체 탭

중후반 합체 해금 후 다음을 제공합니다.

- 합체 가능한 타워 목록
- 필요한 중복 수량
- 보호된 수량 제외 표시
- 소비될 타워와 고정 결과 미리보기
- 합체 계보
- 합체 누적 진행
- 자동 합체 설정

합체는 실패하지 않으며 결과를 숨기지 않습니다.

---

## 5. 주요 별도 메뉴

### UIF-009: 인벤토리 밖의 시스템

다음은 타워 수량 관리와 책임이 다르므로 인벤토리의 탭으로 강제 합치지 않습니다.

- 스탯 트리
- 지역·스테이지 및 텔레포터
- 포션
- 환생
- 라이브 웨이브
- 설정과 접근성

HUD에서 빠른 버튼을 제공할 수 있지만 각 시스템은 독립된 화면과 흐름을 가집니다.

---

## 6. 스테이지와 텔레포터 UI

### UIF-010: 물리적 진행 우선

초기에는 플레이어가 월드의 문과 가격 표시를 직접 보고 다음 스테이지를 구매합니다.

문 UI 필수 정보:

- 다음 지역·스테이지 이름
- 해금 코인 가격
- 현재 보유 코인
- 구매 가능 여부
- 해당 스테이지의 코인·행운 방향

### UIF-011: 텔레포터 화면

텔레포터 해금 후 다음 목적지를 표시합니다.

- 로비
- 현재 환생 주기에서 해금한 스테이지

잠긴 스테이지는 이동할 수 없습니다. 현재 위치와 선택 목적지를 명확하게 구분합니다.

---

## 7. 환생과 오프라인 요약

### UIF-012: 환생 확인

환생 전 다음을 한 화면에서 확인합니다.

초기화:

- 코인
- 지역·스테이지 문
- 현재 전투와 미획득 코인

유지:

- 타워
- 스탯 트리
- 자동 기능
- 합체·변종·도감
- 연금 정수와 포션

보상:

- 다음 코인 배율
- 다음 행운 배율
- 새로 충족하는 스탯 트리 조건

### UIF-013: 오프라인 보상 요약

접속 시 오프라인 코인을 자동 지급한 뒤 다음을 짧게 표시합니다.

- 오프라인 시간
- 적용된 시간과 상한
- 효율
- 지급 코인
- 관련 스탯 트리 업그레이드

요약은 즉시 닫을 수 있으며 다른 진행을 막지 않습니다.

---

## 8. 사용하지 않는 구조

- 타워 보유·편성·합체가 서로 완전히 분리된 여러 최상위 메뉴
- 상세 인벤토리를 항상 HUD에 펼쳐 두기
- 퀵 편성에서 모든 세부 기능을 처리하려는 복잡한 UI
- 메뉴 사용 중 자동 전투와 굴리기 정지
- 환생의 초기화 항목을 숨김
- 오프라인 보상을 수령 버튼을 놓치면 잃는 구조
- 잠긴 스테이지로 텔레포트 가능하게 표시

---

## 9. 미확정 사항

- HUD의 정확한 화면 위치와 크기
- 퀵 편성에 표시할 최대 타워 아이콘 수
- 모바일에서 전체 편성 아이콘을 축약하는 방식
- 합체 탭의 잠금 전 표시 여부
- 인벤토리 카드의 최종 정보 밀도
- 편성 변경 애니메이션과 알림 방식
- 메뉴를 열었을 때 캐릭터 이동 입력 처리
