## 요약

전투와 굴리기는 메뉴 중에도 계속됩니다. 자주 확인하는 정보는 HUD에, 복잡한 관리는 인벤토리·코인 스탯 트리·환생 스탯 배분 화면에 둡니다.

타워 보유·편성·수동 합체는 하나의 인벤토리에서 관리하고 퀵 편성은 상시 표시합니다. 일반 클릭에는 화면 흔들림을 사용하지 않습니다.

---

## 1. 기본 원칙

- 메뉴 중 자동 전투·굴리기 계속
- 입력 직후 눌림 피드백
- 서버 승인 뒤 성공 연출
- 모바일·게임패드·키보드 핵심 기능 동등 접근
- 반복 연출 짧게·축약 가능
- 주요 행동을 숫자만 조용히 바꾸지 않음

---

## 2. 최초 계정 흐름

```text
첫 굴리기 점등
→ 첫 타워 카드가 슬롯 1로 이동
→ 초원 슬라임 전투
→ 코인 10 수집 강조
→ 코인 스탯 트리 중심 점등
→ 자동 굴리기 구매
→ 새 타워가 빈 슬롯 2~4를 채움
→ 4슬롯 완성
→ 정규 웨이브 HUD
```

- 현재 단계 하나만 강조
- 닫을 수 없는 전체 화면 설명 없음
- 재접속 시 다음 미완료 단계부터 재개
- 빈 슬롯 채움은 기존 타워를 교체하지 않음

---

## 3. 상시 HUD

필수 정보:

- 코인
- 연금 정수
- Defense XP / 다음 환생 요구량
- 미사용 환생 스탯 토큰
- 현재 지역·스테이지
- 현재 웨이브·보스 진행
- 현재 행운과 출처
- 굴리기 진행
- 황금·다이아몬드 진행
- 자동 굴리기 ON/OFF
- 환생 가능 알림
- 퀵 편성

표시하지 않음:

- 현재 행운 적용 타워별 `1 / N`
- 실시간 확률표와 내부 Compression

표시 가능:

- 공식 기본 `1 / N`
- 현재 스테이지 행운
- 행운에 배분한 토큰 수
- 활성 포션·부스트

---

## 4. 퀵 편성과 인벤토리

퀵 편성:

- 현재 편성 카드
- 편성 수 / 슬롯 수
- 빈 슬롯 채움 ON/OFF
- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 상세 편성 열기

인벤토리:

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

타워 보유:

- Owned·Protected·Equipped 수량
- 공식 `1 / N`
- 역할·행동·도감
- 검색·희귀도·역할·변종 필터

편성:

- 전체·역할 슬롯
- 수동 추가·제거
- 자동 편성·역할 성향
- 편성 불가 이유

합체:

- 사용 가능 수량
- 필요한 재료와 고정 결과
- 보호·편성 수량 제외
- 자동 합체 설정 없음

---

## 5. 성장 메뉴 분리

### 코인 스탯 트리

- 하나의 거대한 연결 트리
- 코인 가격
- 기능·전투·편성·수집·오프라인 성장
- 구매 뒤 영구 유지

### 환생 스탯 배분

- 미사용 토큰
- 스탯별 배분량
- 다음 토큰의 실제 효과
- 소프트캡·상한
- 서버 승인 뒤 수치 갱신

두 화면은 자원과 목적이 다르므로 명확히 분리합니다. 토큰을 코인 트리 노드처럼 보이게 하지 않습니다.

---

## 6. 문·텔레포터·복귀

문 표시:

- 다음 스테이지 이름
- 코인 가격·현재 코인
- 구매 가능 여부
- 더 높은 보상·행운 방향
- 전투력 보장을 뜻하지 않는다는 안내

구매 성공:

- 실제 장벽 진동·광원·파편
- 카메라 강제 흔들림 없음
- 계정에 영구 개방

텔레포터:

- 로비
- 영구적으로 열린 스테이지
- 잠긴 스테이지 불가

재접속 빠른 복귀:

- 로비에서 시작
- 마지막 활동 스테이지가 열려 있을 때 표시
- 해금 재검증 뒤 새 1웨이브 시작

## 7. 환생 UI

조건:

```text
현재 Defense XP / 요구 Defense XP
```

첫 환생:

```text
7,000 Defense XP
```

확인창 표시:

- 이번 환생에서 받을 스탯 토큰
- Defense XP가 0이 됨
- 초과 Defense XP가 기본 이월되지 않음
- 코인 유지
- 열린 문 유지
- 현재 위치·웨이브·전투 유지
- 타워·코인 스탯·포션 유지

버튼:

```text
환생
스탯 배분 보기
취소
```

표시하지 않음:

- 남은 코인을 쓰라는 경고
- 문 재잠금 경고
- 로비 이동 경고
- 전투 초기화 경고

환생 직후:

```text
토큰 획득 연출
→ 미사용 토큰 갱신
→ 스탯 배분 진입 선택
→ 현재 전투·굴리기 계속
```

연출은 전투를 장시간 가리지 않습니다.

---

## 8. 행운 배분 UI

행운 스탯에는 다음을 표시합니다.

```text
현재 투자 토큰
다음 토큰: Compression +0.040
현재 일반 굴림 상한: 5.40
현재 스테이지 기여
황금·다이아몬드 추가 보정
```

타워별 유효 확률은 표시하지 않습니다. 공식 분모와 행운이 강화되었다는 사실만 제공합니다.

재분배 규칙은 미확정이므로 현재 UI 계약에 초기화·환불 버튼을 넣지 않습니다.

---

## 9. 오프라인 요약

- 실제·적용 오프라인 시간
- 효율·상한
- 지급 코인
- 다음 업그레이드
- 굴리기·Defense XP·정수·스탯 토큰이 진행되지 않았다는 안내

즉시 닫을 수 있습니다.

---

## 10. 설정

```text
설정
├─ 화면·효과
├─ 카메라
├─ 음향
├─ UI·접근성
├─ 알림·자동 보호
└─ 성능
```

- 파티클 Full / Reduced / Minimal
- 다른 플레이어 효과
- 피해 숫자·명중 섬광·Trail
- 희귀 연출 길이
- 감소된 움직임
- 보스 흔들림 Off / Low / Normal
- 음향 채널
- UI 크기
- 공식 분모 기준 자동 보호
- 자동 성능 조절

---

## 11. 표현 원칙

- 일반 클릭: 눌림·오버슈트·음향, 화면 흔들림 없음
- 코인 노드: 코인 이동·노드 점등
- 토큰 배분: 토큰 이동·스탯 게이지 상승
- 편성: 카드 이동
- 합체: 재료 수렴·결과 등장
- 코인: 곡선 흡입·HUD 반동
- 환생: 초기화보다 토큰 획득 강조
- 보스: 제한된 카메라 연출

---

## 12. 사용하지 않는 구조

- 서버 응답 전 무반응 버튼
- 현재 유효 확률 표시
- 자동 합체 설정
- 메뉴 중 전투·굴리기 정지
- 환생 시 코인·문·전투 초기화 표시
- 환생 직전 코인 소비 압박
- 잠긴 스테이지 텔레포트
- 일반 클릭 화면 흔들림
- 반복 Robux 팝업
- 튜토리얼 보상 재지급

---

- HUD 위치·크기
- 모바일 축약
- 인벤토리 카드 밀도
- 환생당 토큰 지급량 표시 방식
- 행운 외 스탯 카드
- 토큰 재분배 UI
