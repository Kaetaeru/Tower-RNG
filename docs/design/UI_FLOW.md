## 요약

전투와 굴리기는 메뉴 사용 중에도 계속되므로, UI는 자주 확인하는 정보와 복잡한 관리 기능을 분리합니다.

타워 보유, 상세 편성과 합체는 하나의 `인벤토리` 안에서 탭으로 관리합니다. 현재 편성과 자동 편성 상태를 빠르게 조절하는 `퀵 편성 HUD`는 일반 플레이 화면에 항상 표시합니다.

UI는 단순 정보판이 아닙니다. 클릭, 구매, 해금, 토글과 카드 이동에 즉각적이고 과장된 움직임·음향·반동을 제공해야 하며, 입력이 밋밋하게 느껴지는 상태를 완료로 보지 않습니다.

---

## 1. 기본 원칙

### UIF-001: 플레이를 멈추지 않는 메뉴

- 인벤토리와 스탯 트리를 열어도 자동 전투와 자동 굴리기 계속 진행
- 희귀 획득 연출이 메뉴 조작과 코인 수집을 장시간 막지 않음
- 주요 상태는 메뉴를 닫지 않아도 확인 가능
- 모바일·게임패드·키보드에서 같은 핵심 기능에 접근 가능

메뉴를 보는 동안 캐릭터 이동 조작이 제한될 수는 있지만, 전투와 굴리기 시스템 자체를 정지하지 않습니다.

### UIF-002: 즉각적인 입력 반응

모든 주요 UI 입력은 서버 결과를 기다리기 전에 눌렸다는 반응을 즉시 보여 줍니다.

기본 방향:

- 눌림 축소와 빠른 복원
- 끝에서 짧게 튕기는 오버슈트
- 색상·테두리·광택 변화
- 명확한 클릭음
- 지원 기기의 선택적 햅틱

구매나 해금처럼 서버 승인이 필요한 결과 연출은 승인 후 재생하지만, 입력 반응 자체를 지연시키지 않습니다.

### UIF-003: 과장된 상태 변화

다음 상태는 텍스트만 바꾸지 않습니다.

- 토글 ON/OFF
- 노드 구매
- 문 해금
- 편성 교체
- 합체 완료
- 환생
- 희귀 타워 획득

예:

- 토글이 끝점에서 반동
- 구매한 노드에서 연결선으로 빛이 퍼짐
- 카드가 빠지고 새 카드가 자리로 튕겨 들어옴
- 문이 진동·광원·파편과 함께 열림

세부 철학은 `PRESENTATION_FEEL.md`를 따릅니다.

## 2. 항상 보이는 기본 HUD

### UIF-004: 핵심 진행 정보

일반 플레이 화면에서 다음을 항상 확인할 수 있어야 합니다.

- 현재 코인
- 연금 정수
- 현재 지역과 스테이지
- 현재 웨이브와 보스 웨이브 진행
- 현재 스테이지 행운
- 굴리기 남은 시간 또는 진행 상태
- 황금 주사위까지 남은 굴림
- 다이아몬드 주사위까지 남은 굴림
- 자동 굴리기 ON/OFF
- 환생 가능 알림

텔레포터를 해금한 뒤에는 빠른 이동 버튼도 기본 HUD 또는 가까운 상위 메뉴에 표시합니다.

HUD 값이 증가할 때는 짧은 확대·반동·음향으로 변화가 느껴져야 합니다. 단, 숫자를 읽기 어려울 정도로 오래 흔들지 않습니다.

---

## 3. 퀵 편성 HUD

### UIF-005: 항상 보이는 간편 편성

퀵 편성은 상세 인벤토리를 열지 않고 현재 편성을 확인하고 기본 설정을 바꾸는 HUD입니다.

기본 구성:

- 현재 편성된 타워 아이콘 또는 축약 카드
- 현재 편성 수 / 전체 슬롯 수
- 자동 편성 ON/OFF
- 현재 역할 성향 프리셋
- 프리셋 빠른 변경
- 상세 인벤토리·편성 탭 열기

### UIF-006: 퀵 편성의 책임 제한

허용:

- 자동 편성 토글
- 역할 성향 프리셋 전환
- 현재 편성 확인
- 특정 슬롯의 간단한 제거 또는 최근 추천 교체
- 상세 편성 화면 열기

상세 화면으로 넘길 기능:

- 전체 보유 타워 검색과 정렬
- 여러 수량의 세부 편성
- 복합 역할 슬롯 선택
- 타워 보호
- 합체 재료 선택
- 도감과 계보 확인

자동 편성으로 카드가 바뀌면 새 카드가 위치로 들어오는 움직임과 짧은 강조를 제공합니다. HUD가 복잡한 전체 인벤토리를 그대로 복제하지 않게 합니다.

## 4. 인벤토리

### UIF-007: 통합 인벤토리

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

합체가 해금되기 전에는 합체 탭을 잠긴 상태로 표시하거나 해금 시점에 추가할 수 있습니다.

### UIF-008: 타워 보유 탭

필수 기능:

- 타워 종류별 보유 수량
- 실제 획득 확률과 보조 등급
- 역할과 행동 요약
- 보호 상태
- 도감 등록 여부
- 검색·역할·희귀도·변종 필터
- 현재 편성 수량
- 합체 가능 여부

같은 타워는 개별 무작위 능력치 목록이 아니라 종류별 수량으로 표시합니다.

카드 선택, 보호 전환과 필터 변경은 즉시 움직임과 음향으로 반응합니다.

### UIF-009: 편성 탭

필수 기능:

- 전체 편성 슬롯
- 역할별 슬롯
- 현재 편성 타워와 수량
- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 자동 편성 평가 결과 또는 변경 요약
- 수동 추가·제거·교체
- 복합 역할 타워의 슬롯 선택

### UIF-010: 합체 탭

중후반 합체 해금 후 다음을 제공합니다.

- 합체 가능한 타워 목록
- 필요한 중복 수량
- 보호된 수량 제외 표시
- 소비될 타워와 고정 결과 미리보기
- 합체 계보
- 합체 누적 진행
- 자동 합체 설정

합체는 실패하지 않으며 결과를 숨기지 않습니다. 실행 시 재료 카드가 중심으로 모이고 결과 카드가 강하게 등장하는 짧은 연출을 제공합니다.

## 5. 주요 별도 메뉴

### UIF-011: 인벤토리 밖의 시스템

- 스탯 트리
- 지역·스테이지 및 텔레포터
- 포션
- 환생
- 라이브 웨이브
- 상점
- 설정과 접근성

상점은 독립 메뉴로 제공하며 전투 HUD에 큰 구매 버튼을 반복 노출하지 않습니다. 구체적인 원칙은 `MONETIZATION.md`를 따릅니다.

---

## 6. 스테이지와 텔레포터 UI

### UIF-012: 물리적 진행 우선

문 UI 필수 정보:

- 다음 지역·스테이지 이름
- 해금 코인 가격
- 현재 보유 코인
- 구매 가능 여부
- 해당 스테이지의 코인·행운 방향

문을 구매하면 가격 숫자만 사라지는 것이 아니라 실제 월드 장벽이 강한 반응과 함께 열립니다.

### UIF-013: 텔레포터 화면

목적지:

- 로비
- 현재 환생 주기에서 해금한 스테이지

잠긴 스테이지는 이동할 수 없습니다. 목적지 선택과 실제 이동 성공을 서로 다른 피드백으로 구분합니다.

---

## 7. 환생과 오프라인 요약

### UIF-014: 환생 확인

초기화:

- 코인
- 지역·스테이지 문
- 현재 전투와 미획득 코인

유지:

- 타워
- 스탯 트리
- 자동 기능
- 합체·변종·도감
- 연금 정수와 포션

보상:

- 다음 코인 배율
- 다음 행운 배율
- 새로 충족하는 스탯 트리 조건

환생 연출은 잃는 항목보다 영구 배율이 상승하는 감각을 중심으로 구성합니다.

### UIF-015: 오프라인 보상 요약

- 오프라인 시간
- 적용된 시간과 상한
- 효율
- 지급 코인
- 관련 스탯 트리 업그레이드

요약은 즉시 닫을 수 있으며 다른 진행을 막지 않습니다.

---

## 8. 접근성과 효과 강도

### UIF-016: 사용자 조절

설정에서 다음을 조절할 수 있게 설계합니다.

- UI 움직임 강도
- 화면 흔들림
- 섬광 강도
- 파티클 밀도
- 햅틱
- 피해 숫자
- 희귀 연출 길이

효과를 낮춰도 클릭, 성공, 실패, 잠금과 명중 여부는 명확하게 전달해야 합니다.

---

## 9. 사용하지 않는 구조

- 입력했는데 서버 응답 전까지 아무 반응도 없는 버튼
- 숫자와 텍스트만 바뀌는 주요 구매·해금
- 타워 보유·편성·합체가 서로 완전히 분리된 여러 최상위 메뉴
- 상세 인벤토리를 항상 HUD에 펼쳐 두기
- 퀵 편성에서 모든 세부 기능을 처리하는 복잡한 UI
- 메뉴 사용 중 자동 전투와 굴리기 정지
- 환생의 초기화 항목 숨김
- 오프라인 보상을 수령 버튼을 놓치면 잃는 구조
- 잠긴 스테이지로 텔레포트 가능하게 표시
- 전투 중 반복적인 Robux 구매 팝업

---

## 10. 미확정 사항

- HUD의 정확한 화면 위치와 크기
- 공통 버튼 애니메이션 시간값
- 퀵 편성에 표시할 최대 타워 아이콘 수
- 모바일 편성 아이콘 축약 방식
- 합체 탭의 잠금 전 표시 여부
- 인벤토리 카드 정보 밀도
- 메뉴를 열었을 때 캐릭터 이동 입력 처리
- UI 효과 강도 설정의 최종 단계
