## 요약

전투와 굴리기는 메뉴 중에도 계속됩니다. 자주 확인하는 정보는 HUD, 복잡한 관리는 인벤토리와 별도 메뉴로 분리합니다.

타워 보유·편성·수동 합체는 하나의 인벤토리 안에서 관리하고 퀵 편성은 항상 보입니다. UI 입력은 즉시 강하게 반응하지만 일반 클릭에 화면 흔들림을 사용하지 않습니다.

---

## 1. 기본 원칙

- 메뉴 중 자동 전투·굴리기 계속
- 서버 응답 전 눌림 피드백 즉시 표시
- 성공 연출은 서버 승인 후
- 모바일·게임패드·키보드 핵심 기능 동등 접근
- 반복 작업 연출은 짧고 축약 가능
- 숫자·텍스트만 조용히 바뀌는 주요 행동 금지

기본 입력 피드백:

```text
눌림 압축
→ 색·테두리·광택
→ 클릭음 또는 햅틱
→ 짧은 오버슈트
→ 결과 표시
```

---

## 2. 상시 HUD

필수 정보:

- 코인
- 연금 정수
- Defense XP / 다음 환생 요구량
- 현재 지역·스테이지
- 현재 웨이브·보스 진행
- 현재 스테이지 행운
- 굴리기 진행
- 황금·다이아몬드 주사위 진행
- 자동 굴리기 ON/OFF
- 환생 가능 알림
- 퀵 편성

표시하지 않음:

- 현재 행운 적용 타워별 `1 / N`
- 실시간 확률표

표시 가능:

- 공식 기본 `1 / N`
- 현재 행운 수치·출처

재접속 로비에서는 유효할 때 `마지막 스테이지로 복귀` 버튼을 표시합니다.

---

## 3. 퀵 편성 HUD

- 현재 편성 아이콘·축약 카드
- 편성 수 / 전체 슬롯
- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 프리셋 빠른 변경
- 상세 편성 탭 열기

상세 기능은 인벤토리로 넘깁니다.

- 전체 검색·정렬
- 수량 관리
- 복합 역할 슬롯
- 보호 수량
- 합체
- 도감·계보

동일 타워를 여러 개 편성할 수 있으며 역할별 슬롯이 상한을 담당합니다.

---

## 4. 인벤토리

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

### 타워 보유

- ID별 OwnedCount
- ProtectedCount
- EquippedCount
- 공식 기본 `1 / N`
- 역할·행동 요약
- 도감
- 검색·희귀도·역할·변종 필터
- 수동 합체 가능 여부

현재 행운 적용 확률은 카드에 표시하지 않습니다.

### 편성

- 전체·역할 슬롯
- 타워별 편성 수량
- 자동 편성·역할 성향
- 수동 추가·제거
- 복합 역할 선택
- 편성 불가 이유

### 수동 합체

- 합체 가능한 타워
- Owned·Protected·Equipped·Available 수량
- 필요한 재료
- 고정 결과
- 계보와 누적
- 확인 버튼

자동 합체 설정은 존재하지 않습니다.

## 5. 주요 메뉴

- 거대 스탯 트리
- 인벤토리
- 포션
- 환생
- 텔레포터
- 라이브 웨이브
- 상점
- 설정
- 도감·프로필

상점은 독립 메뉴이며 전투 중 반복 구매 팝업을 사용하지 않습니다.

---

## 6. 문과 이동 UI

문:

- 다음 스테이지 이름
- 코인 가격
- 현재 코인
- 구매 가능 여부
- 예상 코인·행운 방향

구매 성공 시 실제 장벽이 진동·광원·파편과 함께 열립니다. 카메라를 강제로 흔들지는 않습니다.

텔레포터:

- 로비
- 현재 환생에서 열린 스테이지
- 잠긴 스테이지 이동 불가

빠른 복귀:

- 재접속은 로비
- 마지막 활동 스테이지가 열려 있을 때만 표시
- 누르면 해금 재검증 후 새 1웨이브 시작

---

## 7. 환생 UI

조건:

```text
현재 Defense XP / 요구 Defense XP
```

초기화 표시:

- 코인
- Defense XP
- 현재 환생의 모든 문
- 전투·미획득 코인

유지 표시:

- 타워·보호
- 스탯 트리
- 굴림 카운터
- 합체·변종·도감
- 연금 정수·포션
- 오프라인 업그레이드
- 설정

보상 표시:

- 다음 영구 코인 성장
- 다음 영구 행운 성장
- 새 환생 조건 노드

초과 Defense XP는 기본적으로 이월되지 않는다고 명시합니다.

---

## 8. 오프라인 요약

- 실제 오프라인 시간
- 적용 시간과 상한
- 효율
- 지급 코인
- 다음 오프라인 업그레이드

Defense XP·굴림·정수는 오프라인에 진행되지 않음을 표시합니다. 요약은 즉시 닫을 수 있습니다.

---

## 9. 설정 탭

```text
설정
├─ 화면·효과
├─ 카메라
├─ 음향
├─ UI·접근성
├─ 알림·자동 보호
└─ 성능
```

핵심 설정:

- 파티클 Full / Reduced / Minimal
- 다른 플레이어 효과
- 피해 숫자
- 명중 섬광·Trail
- 희귀 연출 길이
- UI 움직임
- 감소된 움직임 모드
- 보스 화면 흔들림 Off / Low / Normal
- FOV·보스 프레이밍
- 음향 채널
- UI 크기
- 굴리기 알림
- 공식 분모 기준 자동 보호
- 자동 성능 조절

세부값은 `SETTINGS.md`를 따릅니다.

---

## 10. 표현 원칙

- 일반 UI 클릭: 눌림·오버슈트·음향, 화면 흔들림 없음
- 노드 구매: 코인 이동·노드 팽창·연결선 점등
- 편성: 카드 교체 이동
- 합체: 재료 수렴·결과 등장
- 코인: 곡선 흡입·HUD 반동
- 환생: 초기화보다 영구 성장 강조
- 보스: 제한된 카메라 연출 허용

효과를 줄여도 성공·실패·명중·보상은 명확해야 합니다.

---

## 11. 사용하지 않는 구조

- 서버 응답 전 무반응 버튼
- 숫자만 바뀌는 주요 행동
- 현재 유효 확률 표시
- 자동 합체 설정
- 메뉴 중 전투·굴리기 정지
- 환생 초기화 숨김
- 오프라인 수령 실패
- 잠긴 스테이지 텔레포트
- 일반 UI 클릭 화면 흔들림
- 반복 Robux 팝업

- HUD 위치·크기
- 공통 애니메이션 시간

- 인벤토리 카드 정보 밀도
