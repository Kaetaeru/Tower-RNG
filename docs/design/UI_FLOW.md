## 요약

전투와 굴리기는 메뉴 중에도 계속됩니다. 자주 확인하는 정보는 HUD에, 복잡한 관리는 인벤토리·코인 스탯 트리·환생 스탯 배분 화면에 둡니다.

환생 화면은 Defense XP 기준 스테이지와 진행률을 보여 주고, 스탯 화면은 행운·성능·재화·주사위 속도의 네 카드로 구성합니다.

---

## 1. 기본 원칙

- 메뉴 중 자동 전투·굴리기 계속
- 입력 직후 눌림 피드백
- 서버 승인 뒤 성공 연출
- 모바일·게임패드·키보드 핵심 기능 동등 접근
- 반복 연출 짧게·축약 가능
- 주요 행동을 숫자만 조용히 바꾸지 않음

---

## 2. 최초 계정 흐름

```text
첫 굴리기 점등
→ 첫 타워 카드가 슬롯 1로 이동
→ 초원 슬라임 전투
→ 코인 10 수집 강조
→ 코인 스탯 트리 중심 점등
→ 자동 굴리기 구매
→ 새 타워가 빈 슬롯 2~4를 채움
→ 4슬롯 완성
→ 정규 웨이브 HUD
```

- 현재 단계 하나만 강조
- 닫을 수 없는 전체 화면 설명 없음
- 재접속 시 다음 미완료 단계부터 재개
- 빈 슬롯 채움은 기존 타워를 교체하지 않음

---

## 3. 상시 HUD

필수 정보:

- 코인
- 연금 정수
- Defense XP / 다음 환생 요구량
- 환생 XP 기준 스테이지
- 미사용 환생 스탯 토큰
- 현재 지역·스테이지
- 현재 웨이브·보스 진행
- 현재 행운과 출처
- 굴리기 진행
- 황금·다이아몬드 진행
- 자동 굴리기 ON/OFF
- 환생 가능 알림
- 퀵 편성

표시하지 않음:

- 현재 행운 적용 타워별 `1 / N`
- 실시간 확률표와 내부 Compression

표시 가능:

- 공식 기본 `1 / N`
- 현재 스테이지 행운
- 행운 투자 포인트
- 활성 포션·부스트

---

## 4. 퀵 편성과 인벤토리

퀵 편성:

- 현재 편성 카드
- 편성 수 / 슬롯 수
- 빈 슬롯 채움 ON/OFF
- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 상세 편성 열기

인벤토리:

```text
인벤토리
├─ 타워 보유
├─ 편성
└─ 합체
```

- Owned·Protected·Equipped 수량
- 공식 `1 / N`
- 역할·행동·도감
- 검색·희귀도·역할·변종 필터
- 수동 편성·자동 편성
- 합체 재료와 고정 결과
- 자동 합체 설정 없음

---

## 5. 성장 메뉴 분리

### 코인 스탯 트리

- 하나의 거대한 연결 트리
- 코인 가격
- 기능·전투·편성·수집·오프라인 성장
- 구매 뒤 영구 유지

### 환생 스탯 배분

```text
행운
성능
재화
주사위 속도
```

- 미사용 토큰
- 스탯별 투자량
- 다음 포인트의 실제 효과
- 25포인트 감소 효율 경계
- 현재 배율·굴리기 간격
- 환생 직후 재분배 가능 여부
- 서버 승인 뒤 수치 갱신

두 화면은 자원과 목적이 다르므로 명확히 분리합니다.

---

## 6. 문·텔레포터·복귀

문 표시:

- 다음 스테이지 이름
- 코인 가격·현재 코인
- 구매 가능 여부
- 더 높은 보상·행운 방향
- 전투력 보장을 뜻하지 않는다는 안내

문은 계정에 영구 개방되며 환생으로 닫히지 않습니다.

텔레포터:

- 로비
- 영구적으로 열린 스테이지
- 잠긴 스테이지 불가

재접속은 로비에서 시작하고 마지막 열린 스테이지로 빠른 복귀를 제공합니다.

---

## 7. 환생 HUD와 기준 스테이지

첫 환생:

```text
7,000 Defense XP
보상: 스탯 토큰 4개
```

두 번째 이후에는 다음을 표시합니다.

```text
현재 Defense XP / 요구량
현재 진행률
XP 기준 스테이지
예상 토큰 보상 4개
```

높은 스테이지에서 첫 유효 XP를 얻어 기준이 상승하면:

```text
기존 진행률 계산
→ 새 요구량과 현재 XP로 함께 변환
→ 막대 퍼센트 유지
→ `XP 기준: 스테이지 N` 짧은 갱신 연출
```

숫자가 커졌다는 이유로 손해를 봤다고 느끼지 않도록 `진행률 유지` 문구를 짧게 표시합니다. 모달 창이나 전투 중단은 사용하지 않습니다.

---

## 8. 환생 확인창

표시:

- 이번 환생에서 받을 토큰 4개
- Defense XP가 0이 됨
- 초과 Defense XP 기본 미이월
- 코인 유지
- 열린 문 유지
- 현재 위치·웨이브·전투 유지
- 타워·코인 스탯·포션 유지
- 현재 네 분야 배분 요약

버튼:

```text
기존 배분 유지하고 환생
환생 후 전체 재분배
스탯 배분 보기
취소
```

표시하지 않음:

- 남은 코인을 쓰라는 경고
- 문 재잠금 경고
- 로비 이동 경고
- 전투 초기화 경고

환생 직후:

```text
토큰 4개 획득 연출
→ 미사용 토큰 갱신
→ 선택했다면 전체 재분배 화면
→ 현재 전투·굴리기 계속
```

---

## 9. 환생 스탯 카드

### 행운

```text
현재 포인트
현재 Compression 보너스
다음 포인트 증가량
현재 스테이지 기여
일반·황금·다이아몬드 상한
```

타워별 유효 확률은 표시하지 않습니다.

### 성능

```text
현재 PerformanceMultiplier
다음 포인트 뒤 배율
모든 역할 기여도에 적용
전투 단축으로 환생도 간접 가속
```

### 재화

```text
현재 코인 배율
다음 포인트 뒤 배율
접속 중·오프라인 코인 적용
Defense XP·정수 미적용
```

### 주사위 속도

```text
현재 BaseRollInterval
현재 최종 굴리기 간격
다음 포인트 뒤 간격
V1 최소 2.0초
```

황금·다이아몬드도 실제 굴림 수만큼 빨라진다고 설명합니다.

---

## 10. 배분과 재분배

새 토큰 배분:

- `+1`, `+5`, `최대`
- 적용 전 예상값 미리보기
- 서버 승인 후 토큰 이동·수치 갱신

전체 재분배:

- 환생 직후 기회가 있을 때만 표시
- 기존 네 분야 포인트를 미사용 토큰으로 반환
- 새 배분 확정 전 취소 가능
- 확정 뒤 다음 환생까지 다시 재분배 불가
- 비용 없음

상시 초기화 버튼은 제공하지 않습니다.

---

## 11. 오프라인 요약

- 실제·적용 오프라인 시간
- 효율·상한
- 지급 코인
- 재화 스탯 적용 배율
- 다음 업그레이드
- 굴리기·Defense XP·정수·스탯 토큰이 진행되지 않았다는 안내

즉시 닫을 수 있습니다.

---

## 12. 설정

```text
설정
├─ 화면·효과
├─ 카메라
├─ 음향
├─ UI·접근성
├─ 알림·자동 보호
└─ 성능
```

- 파티클 Full / Reduced / Minimal
- 다른 플레이어 효과
- 피해 숫자·명중 섬광·Trail
- 희귀 연출 길이
- 감소된 움직임
- 보스 흔들림 Off / Low / Normal
- 음향 채널
- UI 크기
- 공식 분모 기준 자동 보호
- 자동 성능 조절

---

## 13. 표현 원칙

- 일반 클릭: 눌림·오버슈트·음향, 화면 흔들림 없음
- 코인 노드: 코인 이동·노드 점등
- 토큰 배분: 토큰 이동·스탯 게이지 상승
- 전체 재분배: 네 게이지 회수 뒤 새 배분 강조
- XP 기준 상승: 막대 퍼센트 고정·숫자 롤링
- 편성: 카드 이동
- 합체: 재료 수렴·결과 등장
- 코인: 곡선 흡입·HUD 반동
- 환생: 초기화보다 토큰 획득 강조
- 보스: 제한된 카메라 연출

---

## 14. 사용하지 않는 구조

- 서버 응답 전 무반응 버튼
- 현재 유효 확률 표시
- 자동 합체 설정
- 메뉴 중 전투·굴리기 정지
- 환생 시 코인·문·전투 초기화 표시
- 환생 직전 코인 소비 압박
- 상시 무료 재분배 버튼
- XP 기준 상승 시 진행률 감소
- 잠긴 스테이지 텔레포트
- 일반 클릭 화면 흔들림
- 반복 Robux 팝업
- 튜토리얼 보상 재지급

---
