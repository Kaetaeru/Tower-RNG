## 요약

편성은 보유 타워 중 실제 전투에 참여할 타워를 정하는 시스템입니다.

```text
시작 전체 슬롯: 4
V1 최대 슬롯: 12
동일 타워 전용 상한: 없음
역할별 상한: 전체 슬롯 수에서 자동 계산
```

첫 계정은 새 타워로 빈 시작 슬롯을 자동으로 채웁니다. 자동 편성은 별도 코인 노드로 해금합니다.

---

## 1. 추종 편대

### FOR-001: 플레이어 추종

- 타워끼리 물리 충돌하지 않음
- 플레이어 이동을 막지 않음
- 지형에 걸리거나 멀어지면 편대 위치로 복귀
- 이동 중에도 전투 기능 유지
- Engage 타워는 실제 대상에게 이동하며 이동 시간이 효율에 영향

### FOR-002: 스테이지 전환

스테이지가 바뀌면 이전 전투와의 연결을 끊습니다.

- 이전 타겟과 행동 취소
- Engage 교전 슬롯 해제
- 이전 소환체·설치물 정리
- 새 스테이지 편대로 재귀속
- 현재 스테이지 적 재탐색

Engage 타워는 새 적에게 이동하며 이동 불가 또는 과도한 이탈 시 플레이어 근처로 복귀한 뒤 재교전합니다.

---

## 2. 전체 편성 슬롯

### FOR-003: 4→12슬롯

전체 슬롯은 코인 스탯 트리에서 한 칸씩 순차 구매합니다.

| 전체 슬롯 | NodeId | 코인 가격 | 균형형 목표 해금 |
|---:|---|---:|---:|
| 4 | 시작값 | 0 | 시작 |
| 5 | `NODE_FORMATION_SLOT_5` | 1,200 | 약 11분 |
| 6 | `NODE_FORMATION_SLOT_6` | 15,000 | 약 32분 |
| 7 | `NODE_FORMATION_SLOT_7` | 170,000 | 약 1시간 32분 |
| 8 | `NODE_FORMATION_SLOT_8` | 1,500,000 | 약 3시간 |
| 9 | `NODE_FORMATION_SLOT_9` | 9,000,000 | 약 5시간 |
| 10 | `NODE_FORMATION_SLOT_10` | 80,000,000 | 약 8시간 |
| 11 | `NODE_FORMATION_SLOT_11` | 400,000,000 | 약 10시간 39분 |
| 12 | `NODE_FORMATION_SLOT_12` | 2,300,000,000 | 약 13시간 31분 |

규칙:

- 이전 슬롯 노드 구매가 선행 조건
- 별도 스테이지·환생 횟수 조건 없음
- 구매 뒤 영구 유지
- 환생 후 초기화 없음
- 한 번에 한 칸 증가
- V1에서 12개를 초과하지 않음

가격과 시간 검증은 `V1_FORMATION_SLOT_BENCHMARK.md`를 따릅니다.

## 3. 역할별 최대 배치 수

### FOR-004: 자동 역할 상한

V1에서는 역할별 슬롯을 따로 구매하지 않습니다.

```text
RoleCap(TotalSlots)
= max(2, ceil(TotalSlots / 3))
```

| 전체 슬롯 | 역할 하나의 최대 배치 수 |
|---:|---:|
| 4~6 | 2 |
| 7~9 | 3 |
| 10~12 | 4 |

초기 역할:

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

여섯 역할 모두 같은 상한을 사용합니다.

의도:

- 4슬롯부터 최소 두 역할 사용
- 특정 역할 중심 편성 허용
- 12슬롯 전체를 단일 역할로 채우는 구조 방지
- 일반적인 보유 전투력은 거의 훼손하지 않음

20,000계정 시뮬레이션에서 역할 상한 적용 뒤 15시간 균형형 중앙 편성 전투력은 무제한 Top-12의 약 99%를 유지했습니다.

### FOR-005: 동일 타워 제한 없음

편성 가능 수량은 다음 세 값의 최소입니다.

```text
보유 수량
전체 남은 슬롯
선택 역할의 남은 상한
```

같은 타워를 여러 번 획득했다면 역할 상한 안에서 그대로 여러 개 사용할 수 있습니다. 동일 타워 전용 패널티나 별도 중복 상한은 사용하지 않습니다.

## 4. 첫 계정 빈 슬롯 자동 채움

### FOR-006: EmptySlotFill

자동 편성이 없어도 편성에 빈 슬롯이 있고 새 타워를 획득하면 해당 타워를 빈 슬롯에 넣습니다.

```text
새 타워 획득
→ 현재 편성에 빈 슬롯 존재
→ 역할 상한 사용 가능
→ 가장 앞의 빈 슬롯에 1개 자동 배치
```

- 첫 수동 굴리기 결과는 슬롯 1에 배치
- 자동 굴리기 이후 세 결과가 남은 시작 슬롯을 채움
- 역할 상한이 막혀 있으면 다음 사용 가능한 역할·빈 슬롯 선택
- 이미 찬 슬롯의 타워는 교체하지 않음
- 더 강한 타워를 얻어도 자동 편성 해금 전에는 기존 타워를 밀어내지 않음
- 자동 편성 OFF에서도 설정이 켜져 있으면 빈 슬롯만 채울 수 있음
- 플레이어가 의도적으로 슬롯을 비울 때 EmptySlotFill을 끌 수 있음

이는 최초 계정이 약 25초 안에 4슬롯을 구성하도록 하는 안전장치입니다.

---

## 5. 복합 역할 타워

### FOR-007: 역할 슬롯 선택

둘 이상의 역할을 가진 타워는 편성 시 사용할 역할 하나를 선택합니다.

- 빈 슬롯 자동 채움: 현재 사용량이 가장 낮은 사용 가능 역할 우선
- 자동 편성: 역할 성향과 전체 조합을 고려해 재선택 가능
- 수동 편성: 플레이어가 역할 슬롯 직접 선택

한 타워가 동시에 둘 이상의 역할 상한을 소비하지 않습니다.

---

## 6. 자동 편성

### FOR-008: 극초반 해금

```text
가격: 30코인
균형 소비 목표: 접속 후 약 31초
```

- 자동 굴리기 직후 해금
- 환생 후 유지
- 추가 사용료 없음
- 보유 수량·전체 슬롯·역할 상한 준수

### FOR-009: ON/OFF

#### ON

- 새 타워 획득 또는 조건 변화 시 조합 재평가
- 역할 성향 프리셋 반영
- 현재 조합보다 의미 있게 좋아질 때 갱신
- 역할 상한과 동일 효과 중첩 효율 반영

#### OFF

- 새 타워를 얻어도 현재 편성 유지
- 플레이어가 직접 추가·제거·교체
- EmptySlotFill이 켜져 있으면 완전히 빈 슬롯만 채움

### FOR-010: 역할 성향 프리셋

초기 방향:

- 균형형
- 단일 화력 중심
- 광역 화력 중심
- 안정·제어 중심
- 대형 사냥 중심

정확한 이름과 평가 가중치는 후속 편성 평가 벤치마크에서 정합니다.

### FOR-011: 편성 평가

단순 표시 공격력만 합산하지 않습니다.

고려 요소:

- 타워 기본 EquivalentContribution
- 계정 공통 성장
- 지원·제어의 조합 기여
- 역할 성향
- 전체 슬롯과 역할 상한
- 동일 효과 중첩 효율
- 현재 웨이브의 일반·대형 적 비중

지원·제어 타워가 직접 피해가 낮다는 이유만으로 항상 제외되어서는 안 됩니다.

---

## 7. 수동 편성

### FOR-012: 전투 중 무료 변경

- 전투 중 추가·제거·교체 가능
- 편성 변경 비용 없음
- 변경 즉시 편대와 전투에 반영
- 자동 편성 OFF에서는 새 획득이 현재 편성을 강제로 교체하지 않음

### FOR-013: 교체 악용 방지

- 교체로 공격·능력 재사용 주기를 무조건 초기화하지 않음
- 제거된 타워의 지원 효과와 생성물 정리
- 반복 교체로 즉시 능력을 사용하는 악용 방지
- 타겟 설정과 역할 성향 유지

---

## 8. 퀵 편성 HUD

### FOR-014: 상시 간편 조작

일반 플레이 화면에 다음을 표시합니다.

- 현재 편성 아이콘 또는 축약 카드
- 현재 편성 수 / 전체 슬롯 수
- 역할별 사용 수 / 상한
- 자동 편성 ON/OFF
- EmptySlotFill ON/OFF
- 현재 역할 성향 프리셋
- 프리셋 빠른 변경
- 상세 편성 열기

상세 보유 목록·보호·합체 관리는 인벤토리에서 수행합니다.

---

## 9. 인벤토리 편성 탭

필수 정보와 조작:

- 전체·역할 편성 수와 상한
- 타워별 보유·편성 수량
- 편성 불가 이유
- 자동 편성 상태와 역할 성향
- 빈 슬롯 자동 채움 설정
- 이름·역할 검색과 필터
- 수동 추가·제거·교체
- 복합 역할 슬롯 선택
- 자동 편성 변경 요약

타워 보유와 합체는 같은 인벤토리의 별도 탭에서 관리합니다.

---

## 10. 효과 중첩

역할 상한과 별도로 동일 효과의 과도한 중첩을 효과 규칙으로 조절합니다.

- 동일 지원 효과의 최강값 또는 효율 감소
- 감속 상한
- 기절 연속 저항
- 자동 편성 평가에 실제 중첩 효율 반영

역할 상한을 지원·제어의 효과 상한 대체물로 사용하지 않습니다.

---

## 11. 환생과 저장

환생 후에도 유지:

- 전체 슬롯 구매
- 자동 계산되는 역할 상한
- 자동 편성 해금과 ON/OFF
- EmptySlotFill 설정
- 역할 성향
- 저장된 수동 편성
- 퀵 HUD 설정

환생은 현재 전투를 초기화하지 않습니다. 슬롯 구매는 계정 영구 상태입니다.

---

## 12. 사용하지 않는 구조

- 동일 타워 전용 편성 상한
- 동일 타워 중복 성능 패널티
- 역할별 슬롯을 여섯 갈래로 별도 구매
- 편성 변경 비용
- 전투 중 편성 변경 금지
- 자동 편성을 중후반까지 잠금
- 자동 편성을 강제로 항상 켜기
- 자동 편성 OFF에서 가득 찬 슬롯 강제 교체
- 환생 시 슬롯 초기화
- 12슬롯을 단일 역할로 채우는 편성

---

## 13. 미확정 사항

- 편대의 최종 3D 배열과 12개 모델 가독성
- 복합 역할 자동 선택의 세부 동률 규칙
- 자동 편성 평가 공식과 프리셋 가중치
- 자동 편성 ON에서 수동 수정 시 잠금 방식
- 편성 프리셋 저장 수
- 지원·제어 효과별 중첩 곡선
- Roblox 런타임에서의 실제 오버킬·타겟 전환 손실
