## 요약

편성은 보유 타워 중 실제 전투에 참여할 타워를 정하는 시스템입니다. 전체 최대 배치 수와 역할별 최대 배치 수를 사용하며, 동일 타워 전용 제한은 두지 않습니다.

자동 편성은 극초반 스탯 트리에서 해금합니다. 플레이어는 자동 편성을 켜 두고 전투력이 더 높은 조합으로 자동 갱신하거나, 끄고 직접 편성을 유지할 수 있습니다.

---

## 1. 추종 편대

### FOR-001: 플레이어를 따라다니는 편대

편성된 타워는 플레이어 주변과 뒤에 편대 형태로 배치됩니다.

기본 원칙:

- 타워끼리 물리적으로 충돌하지 않음
- 플레이어의 이동을 막지 않음
- 지형에 걸리거나 멀어지면 편대 위치로 복귀
- 일반 스테이지의 공격 후보는 플레이어 위치로 제한하지 않음
- 이동 중에도 전투 기능 유지
- Engage 타워는 공격 대상에게 실제로 이동하며 그 시간이 공격 효율에 영향을 줄 수 있음

편대의 시각 배열과 이동 보간은 기술 설계에서 정합니다.

---

## 2. 편성 제한

### FOR-002: 전체 최대 배치 수

초기 기준:

- 시작 전체 편성: 4개
- 최종 목표 상한: 12개

전체 편성 슬롯은 스탯 트리에서 영구 구매합니다. 환생해도 구매한 슬롯을 유지합니다.

초반 4개에서 6개까지는 빠르게 늘리고, 이후 슬롯은 장기 성장 목표가 됩니다. 정확한 해금 시점은 지역·스테이지와 환생 밸런스에 맞춰 조정합니다.

### FOR-003: 역할별 최대 배치 수

초기 역할:

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

각 역할은 초반부터 최소 한 자리를 사용할 수 있습니다. 전체 편성 수가 역할 수보다 적다면 플레이어가 어떤 역할을 사용할지 선택합니다.

역할별 슬롯 확장은 스탯 트리에서 영구 구매하며, 최종적으로 주요 역할에 모두 접근할 수 있어야 합니다.

### FOR-004: 동일 타워 제한 없음

동일 타워 전용 편성 상한을 사용하지 않습니다.

편성 가능 수량은 다음으로 결정됩니다.

```text
보유 수량
전체 남은 편성 슬롯
선택한 역할의 남은 슬롯
```

---

## 3. 복합 역할 타워

### FOR-005: 역할 슬롯 선택

둘 이상의 역할에 들어갈 수 있는 타워는 편성할 때 사용할 역할 슬롯 하나를 선택합니다.

```text
서리폭풍 대마법사
- 광역 화력
- 제어
```

자동 편성은 선택한 편성 성향과 현재 역할 슬롯 상황을 고려해 사용할 역할을 결정할 수 있습니다. 정확한 평가 규칙은 시스템 명세에서 정합니다.

---

## 4. 자동 편성

### FOR-006: 극초반 해금

자동 편성은 자동 굴리기 직후의 극초반 스탯 트리 구간에서 매우 저렴하게 해금합니다.

- 환생 후에도 해금 유지
- 추가 사용료 없음
- 보유하지 않은 타워를 편성하지 않음
- 전체 슬롯과 역할별 슬롯 준수
- 보호 상태와 무관하게 보유 수량 안에서 편성 가능

### FOR-007: 자동 편성 토글

자동 편성은 ON/OFF 토글로 작동합니다.

#### ON

- 새로운 타워 획득 또는 편성 조건 변화 시 조합 재평가
- 현재 설정된 역할 성향에 따라 가장 높은 평가 조합으로 갱신
- 더 낮은 평가의 조합으로 불필요하게 교체하지 않음

#### OFF

- 새로운 타워를 얻어도 현재 편성 유지
- 플레이어가 직접 추가·제거·교체

수동 편집을 시작했을 때 자동 편성을 자동으로 끌지, 편집 내용을 새 기준으로 사용할지는 시스템 명세에서 정합니다.

### FOR-008: 역할 성향 프리셋

자동 편성의 역할 비중은 정확한 숫자를 직접 입력하는 방식보다 편성 성향 프리셋으로 조절합니다.

프리셋 예시 방향:

- 균형형
- 단일 화력 중심
- 광역 화력 중심
- 안정·제어 중심
- 대형 사냥 중심

정확한 프리셋 명칭과 역할 가중치는 밸런스 단계에서 정합니다.

### FOR-009: 편성 평가

자동 편성은 표시 공격력만 단순 합산하지 않습니다.

평가에 포함할 수 있는 요소:

- 타워의 기본 전투 성능
- 현재 계정의 공통 성장
- 지원·제어가 조합 전체에 주는 기여
- 역할 성향 프리셋
- 전체·역할 슬롯
- 동일 효과 중첩 효율

정확한 전투력 공식은 아직 확정하지 않지만, 지원·제어 타워가 직접 피해가 낮다는 이유만으로 항상 제외되어서는 안 됩니다.

---

## 5. 수동 편성 변경

### FOR-010: 전투 중 무료 변경

- 전투 중 편성 추가·제거·교체 가능
- 편성 변경 비용 없음
- 변경 즉시 추종 편대와 전투에 반영
- 자동 편성 OFF에서는 새 타워 획득이 기존 편성을 바꾸지 않음
- 자동 편성 ON에서는 평가가 높아질 때 자동 갱신 가능

### FOR-011: 교체 악용 방지

- 편성 교체로 공격·능력 재사용 대기시간을 무조건 초기화하지 않음
- 제거된 타워의 지원 효과와 생성물을 안전하게 정리
- 반복 교체로 즉시 능력을 사용하는 악용 방지
- 저장한 타겟 우선순위와 편성 성향 유지

## 6. 편성 UI

필수 정보:

- 전체 편성 수와 상한
- 역할별 편성 수와 상한
- 타워별 보유 수량과 현재 편성 수량
- 편성할 수 없는 구체적인 이유
- 자동 편성 ON/OFF
- 현재 역할 성향 프리셋
- 자동 편성으로 변경될 후보 조합 또는 변경 요약

필수 조작:

- `+`와 `-`로 수량 조절
- 카드 드래그로 추가·교체
- 역할 필터와 이름 검색
- 현재 편성 우선 정렬
- 자동 편성 실행·토글
- 편성 성향 선택

---

## 7. 효과 중첩과 편성 자유

지원과 제어 타워의 과도한 중첩은 동일 타워 제한이 아니라 효과 규칙으로 조절합니다.

- 동일 지원 효과의 최강값 적용 또는 효율 감소
- 감속 상한
- 기절 연속 저항 또는 내부 제한
- 자동 편성 평가에 중첩 효율 반영

---

## 8. 환생

환생해도 다음을 유지합니다.

- 자동 편성 해금
- 자동 편성 ON/OFF 설정
- 역할 성향 프리셋
- 전체·역할별 편성 슬롯
- 저장된 수동 편성 정보

환생 후 현재 보유 타워를 기준으로 편성을 다시 생성하거나 기존 편성을 그대로 복구할 수 있습니다. 정확한 재생성 순서는 명세에서 정합니다.

---

## 9. 사용하지 않는 구조

- 동일 타워 전용 편성 상한
- 편성 변경 비용
- 전투 중 편성 변경 금지
- 자동 편성을 중후반까지 잠금
- 자동 편성이 항상 강제로 켜지는 구조
- 역할별 정확한 숫자를 필수로 입력해야 하는 복잡한 초기 UI
- 새 타워 획득 시 자동 편성 OFF 상태에서도 강제 교체
- 최종적으로 되돌릴 수 없는 역할 슬롯 선택

---

## 10. 미확정 사항

- 전체·역할 슬롯 노드의 가격과 최종 해금 속도
- 편대의 최종 시각 배열
- 복합 역할 타워의 역할 선택 UI
- 자동 편성 평가 공식
- 편성 성향 프리셋의 최종 종류와 가중치
- 자동 편성 ON 상태에서 수동 수정했을 때의 처리
- 편성 프리셋 저장 수
