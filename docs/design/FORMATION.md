## 요약

편성은 보유 타워 중 실제 전투에 참여할 타워를 정하는 시스템입니다. 전체 최대 배치 수와 역할별 최대 배치 수를 사용하며 동일 타워 전용 제한은 두지 않습니다.

첫 계정은 타워를 얻을 때 비어 있는 시작 슬롯을 자동으로 채웁니다. 이는 자동 편성 최적화가 아니라 전투 가능한 최소 편대를 만드는 빈자리 보충 규칙입니다. 자동 편성은 이후 별도 노드로 해금합니다.

---

## 1. 추종 편대

### FOR-001: 플레이어를 따라다니는 편대

- 타워끼리 물리 충돌하지 않음
- 플레이어 이동을 막지 않음
- 지형에 걸리거나 멀어지면 편대 위치로 복귀
- 일반 스테이지의 공격 후보는 플레이어 위치로 제한하지 않음
- 이동 중에도 전투 기능 유지
- Engage 타워는 실제 대상에게 이동하며 이동 시간이 효율에 영향

### FOR-002: 스테이지 전환

스테이지가 변경되면 모든 타워는 이전 전투와의 연결을 끊습니다.

- 이전 타겟과 행동 취소
- Engage 교전 슬롯 해제
- 이전 소환체·설치물 정리
- 새 스테이지 편대로 재귀속
- 현재 스테이지 적 재탐색

Engage 타워는 새 적에게 이동하며, 이동이 불가능하거나 지나치게 멀면 추종 보정으로 플레이어 근처에 합류한 뒤 재교전합니다.

---

## 2. 편성 제한

### FOR-003: 전체 최대 배치 수

- 시작 전체 편성: 4개
- 첫 확장 슬롯 가격: 1,200코인
- 장기 목표 상한: 12개

전체 슬롯은 영구 스탯 트리에서 구매하며 환생 후에도 유지합니다.

### FOR-004: 역할별 최대 배치 수

초기 역할:

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

각 역할은 초반부터 최소 한 자리를 사용할 수 있어야 합니다. 역할별 슬롯은 최종적으로 모두 접근 가능합니다.

### FOR-005: 동일 타워 제한 없음

편성 가능 수량:

```text
보유 수량
전체 남은 슬롯
선택 역할의 남은 슬롯
```

동일 타워 전용 상한은 사용하지 않습니다. 같은 타워를 여러 번 획득했다면 역할별 슬롯 한도 안에서 그대로 여러 개 사용할 수 있습니다.

---

## 3. 첫 계정 빈 슬롯 자동 채움

### FOR-006: EmptySlotFill

자동 편성이 없어도 편성에 빈 슬롯이 있고 새 타워를 획득하면 해당 타워를 빈 슬롯에 넣습니다.

```text
새 타워 획득
→ 현재 편성에 빈 슬롯 존재
→ 역할 슬롯 사용 가능
→ 가장 앞의 빈 슬롯에 1개 자동 배치
```

- 첫 수동 굴리기 결과는 슬롯 1에 배치
- 자동 굴리기 이후 세 결과가 남은 시작 슬롯을 채움
- 역할 슬롯이 막혀 있으면 다음 사용 가능한 빈 슬롯·역할을 선택
- 이미 찬 슬롯의 타워는 교체하지 않음
- 더 강한 타워를 얻어도 자동 편성 해금 전에는 기존 타워를 밀어내지 않음
- 자동 편성 OFF에서도 완전히 비어 있는 슬롯만 채울 수 있음
- 플레이어가 의도적으로 슬롯을 비운 이후 자동 채움을 끄는 설정은 편성 UI에서 제공 가능

이는 첫 계정이 약 25초 안에 4슬롯을 구성하도록 하는 안전장치입니다.

---

## 4. 복합 역할 타워

### FOR-007: 역할 슬롯 선택

둘 이상의 역할에 들어갈 수 있는 타워는 편성 시 사용할 역할 슬롯 하나를 선택합니다.

빈 슬롯 자동 채움은 사용 가능한 역할 중 가장 여유가 큰 슬롯을 사용하고, 자동 편성은 역할 성향과 현재 슬롯 상황을 고려해 역할을 재선택할 수 있습니다.

---

## 5. 자동 편성

### FOR-008: 극초반 해금

```text
가격: 30코인
균형 소비 목표: 접속 후 약 31초
```

- 자동 굴리기 직후 매우 저렴하게 해금
- 환생 후 유지
- 추가 사용료 없음
- 보유 수량과 전체·역할 슬롯 준수

### FOR-009: ON/OFF 토글

#### ON

- 새 타워 획득 또는 조건 변화 시 조합 재평가
- 역할 성향 프리셋을 반영한 높은 평가 조합으로 갱신
- 더 낮은 평가 조합으로 불필요하게 교체하지 않음

#### OFF

- 새 타워를 얻어도 현재 편성 유지
- 플레이어가 직접 추가·제거·교체
- 단, 설정이 켜져 있으면 완전히 빈 슬롯은 `EmptySlotFill`이 채울 수 있음

### FOR-010: 역할 성향 프리셋

초기 방향:

- 균형형
- 단일 화력 중심
- 광역 화력 중심
- 안정·제어 중심
- 대형 사냥 중심

정확한 명칭과 가중치는 밸런스 단계에서 정합니다.

### FOR-011: 편성 평가

단순 표시 공격력만 합산하지 않습니다.

고려 요소:

- 타워 기본 전투 성능
- 계정 공통 성장
- 지원·제어의 조합 기여
- 역할 성향
- 전체·역할 슬롯
- 동일 효과 중첩 효율

지원·제어 타워가 직접 피해가 낮다는 이유만으로 항상 제외되어서는 안 됩니다.

---

## 6. 수동 편성

### FOR-012: 전투 중 무료 변경

- 전투 중 추가·제거·교체 가능
- 편성 변경 비용 없음
- 변경 즉시 편대와 전투에 반영
- 자동 편성 OFF에서는 새 획득이 현재 편성을 강제로 교체하지 않음

### FOR-013: 교체 악용 방지

- 교체로 공격·능력 재사용 주기를 무조건 초기화하지 않음
- 제거된 타워의 지원 효과와 생성물 정리
- 반복 교체로 즉시 능력 사용하는 악용 방지
- 타겟 설정과 역할 성향 유지

---

## 7. 퀵 편성 HUD

### FOR-014: 항상 보이는 간편 조작

일반 플레이 화면에 다음을 표시합니다.

- 현재 편성 아이콘 또는 축약 카드
- 현재 편성 수 / 전체 슬롯 수
- 자동 편성 ON/OFF
- 현재 역할 성향 프리셋
- 프리셋 빠른 변경
- 인벤토리 편성 탭 열기

퀵 편성은 자주 사용하는 설정을 담당하며 전체 보유 목록·보호·합체 같은 상세 관리는 인벤토리에서 수행합니다.

---

## 8. 인벤토리 편성 탭

필수 정보와 조작:

- 전체·역할 편성 수와 상한
- 타워별 보유·편성 수량
- 편성 불가 이유
- 자동 편성 상태와 역할 성향
- 빈 슬롯 자동 채움 ON/OFF
- 이름·역할 검색과 필터
- 수동 추가·제거·교체
- 복합 역할 슬롯 선택
- 자동 편성 변경 요약

타워 보유와 합체는 같은 인벤토리의 별도 탭에서 관리합니다.

---

## 9. 효과 중첩

지원과 제어의 과도한 중첩은 동일 타워 제한보다 효과 규칙으로 조절합니다.

- 동일 지원 효과의 최강값 또는 효율 감소
- 감속 상한
- 기절 연속 저항
- 자동 편성 평가에 중첩 효율 반영

---

## 10. 환생

환생 후에도 유지:

- 자동 편성 해금과 설정
- 빈 슬롯 자동 채움 설정
- 역할 성향
- 전체·역할 슬롯
- 저장된 수동 편성
- 퀵 편성 HUD 설정

환생 직후 보유 타워를 기준으로 기존 편성을 복구하며, 자동 편성 ON이면 다시 평가할 수 있습니다.

---

## 11. 사용하지 않는 구조

- 동일 타워 전용 편성 상한
- 편성 변경 비용
- 전투 중 편성 변경 금지
- 자동 편성을 중후반까지 잠금
- 자동 편성을 강제로 항상 켜기
- 역할 숫자 직접 입력을 필수로 요구
- 자동 편성 OFF에서 가득 찬 슬롯의 타워 강제 교체
- 상세 인벤토리를 항상 HUD에 펼쳐 두기
- 스테이지 변경 후 이전 전투 편성 상태 유지

---

## 12. 미확정 사항

- 역할별 슬롯의 정확한 초기 수량
- 편대 최종 배열
- 복합 역할 자동 선택 우선순위
- 자동 편성 평가 공식
- 역할 성향 최종 종류와 가중치
- 자동 편성 ON에서 수동 수정 시 처리
- 편성 프리셋 저장 수
- 퀵 편성 아이콘 표시 방식
