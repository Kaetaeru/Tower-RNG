## 요약

일반 스테이지는 몬스터가 계속 생성되는 개인 파밍 전장입니다. 첫 출시는 5개 지역, 지역당 3개 스테이지로 총 15개 스테이지를 사용합니다.

각 스테이지의 전투는 5개의 웨이브를 한 주기로 반복합니다. 웨이브마다 생성값 예산을 사용하며, 5번째 웨이브에는 해당 스테이지의 보스가 등장합니다. 스테이지를 벗어나면 진행 중인 웨이브 주기는 초기화됩니다.

---

## 1. 출시 지역

### LVL-001: 5개 지역과 15개 스테이지

```text
로비
→ 지역 1 / 스테이지 1~3: 초원·숲
→ 지역 2 / 스테이지 4~6: 사막
→ 지역 3 / 스테이지 7~9: 정글
→ 지역 4 / 스테이지 10~12: 설원
→ 지역 5 / 스테이지 13~15: 용암지대
```

지역은 다음을 공유하는 콘텐츠 묶음입니다.

- 시각적 테마와 맵 분위기
- 몬스터 세력과 외형 방향
- 대표 몬스터 행동
- 경로 형태
- 코인·행운 구간
- 배경음과 환경 연출

지역 테마는 특정 원소 저항이나 피해 유형 면역을 만들지 않습니다.

### LVL-002: 지역 내부 세 단계

기본 제작 틀:

```text
지역 첫 스테이지
- 지역 기본 몬스터와 경로 소개

지역 두 번째 스테이지
- 군집·고속·고체력·특수 행동 혼합

지역 세 번째 스테이지
- 지역 대표 특성 강화
- 높은 웨이브 예산
- 지역 대표 보스 사용 가능
```

각 스테이지의 실제 구성과 맵 디자인은 `docs/reference/STAGE_CATALOG.md`의 양식을 복제해 사용자가 직접 작성합니다.

## 2. 물리적인 진행

### LVL-003: 선형 연결

- 각 스테이지 사이에 벽·문·장벽 배치
- 코인을 지불하면 현재 환생 주기 동안 다음 구역 개방
- 열린 구역은 걸어서 앞뒤로 이동 가능
- 환생하면 모든 일반 스테이지 문 재잠금
- 플레이어별 해금 상태 사용

정확한 스테이지 전환과 텔레포터 규칙은 `WORLD_NAVIGATION.md`에서 관리합니다.

### LVL-004: 하나의 활성 스테이지

현재 들어가 있는 하나의 스테이지만 개인 전투로 활성화합니다.

스테이지 전환 시:

- 이전 스테이지 몬스터 제거
- 이전 미획득 코인 제거
- 진행 중인 웨이브 주기 초기화
- 타워의 이전 공격·타겟·생성물 종료
- 새 스테이지의 행운·코인 단가·웨이브 구성 적용
- 새 스테이지의 1웨이브부터 시작

두 스테이지를 동시에 파밍할 수 없습니다.

---

## 3. 지속형 5웨이브 주기

### LVL-005: 클리어 없는 반복 파밍

다음 스테이지 문은 코인으로 구매하며, 웨이브나 보스 처치가 해금 조건이 아닙니다.

```text
웨이브 1
→ 웨이브 2
→ 웨이브 3
→ 웨이브 4
→ 웨이브 5 + 스테이지 보스
→ 웨이브 1부터 새 주기 시작
```

- 스테이지에 머무는 동안 5웨이브 주기가 반복됨
- 보스를 잡아도 스테이지가 종료되지 않음
- 보스를 놓치거나 베이스에 도달시켜도 영구 손실 없음
- 웨이브 완료 여부와 무관하게 다음 문 구매 가능
- 원하는 만큼 현재 스테이지에서 반복 파밍 가능

### LVL-006: 웨이브 완료

웨이브는 해당 웨이브에 배정된 몬스터 생성이 끝나고, 생성된 몬스터가 모두 다음 중 하나로 해소되면 완료됩니다.

- 타워에게 처치됨
- 베이스에 도달함
- 스테이지 전환이나 과부하로 정리됨

일반적인 웨이브 전환에는 짧은 준비 시간을 둘 수 있지만 정확한 시간은 밸런스 단계에서 정합니다.

### LVL-007: 스테이지 이탈 초기화

스테이지 경계를 벗어나 로비 또는 다른 스테이지로 이동하면 현재 주기의 웨이브 진행은 저장하지 않습니다.

재입장 시:

```text
웨이브 진행도 1로 초기화
→ 새 1웨이브 생성 시작
```

- 이전 웨이브의 몬스터와 보스 제거
- 이전 스테이지의 보상과 코인 드롭 정리
- 이전 웨이브를 여러 스테이지에 동시에 유지하지 않음
- 텔레포터 이동도 같은 초기화 규칙 적용

---

## 4. 웨이브 예산과 몬스터 생성

### LVL-008: 웨이브별 생성값 예산

각 웨이브는 총 생성값 예산을 가집니다.

```text
웨이브 예산 100
비용 5 몬스터 → 최대 20마리
비용 20 몬스터 → 최대 5마리
비용 5·10·20 몬스터 → 혼합 구성
```

몬스터 마릿수를 직접 고정하기보다 개별 몬스터의 생성 비용과 웨이브 예산으로 총량을 결정합니다.

### LVL-009: 예산 기반 구성

각 웨이브 데이터는 다음을 지정할 수 있습니다.

- 총 예산
- 등장 가능한 몬스터 후보
- 후보별 선택 가중치
- 최소·최대 등장 수
- 필수 포함 몬스터
- 생성 간격과 분산 방식
- 웨이브 전용 특별 규칙

같은 총예산이라도 군집, 강한 소수 또는 혼합 구성을 만들 수 있습니다.

### LVL-010: 웨이브 진행 방향

기본적인 한 주기의 변화:

```text
1웨이브
- 스테이지의 기본 구성

2웨이브
- 예산 또는 조합 증가

3웨이브
- 지역 특성과 역할 압박 강화

4웨이브
- 보스 전 준비 구성

5웨이브
- 스테이지 보스 포함
- 일반 몬스터를 함께 포함할 수 있음
```

각 웨이브의 정확한 예산과 몬스터 배치는 스테이지 카탈로그에서 작성합니다.

### LVL-011: 분산 생성

웨이브 예산을 한 프레임에 모두 생성하지 않습니다.

- 웨이브 시간 안에서 몬스터를 분산 생성
- 군집형도 서버와 화면을 과도하게 순간 압박하지 않게 배치
- 다음 웨이브는 현재 웨이브가 완료된 뒤 시작

정확한 웨이브 길이와 생성 간격은 추후 밸런싱합니다.

---

## 5. 5웨이브 스테이지 보스

### LVL-012: 고정 보스 웨이브

각 스테이지의 5웨이브에는 해당 스테이지에 지정된 보스가 등장합니다.

- 보스는 개인 전장에 생성
- 일반 타워 타겟팅과 전투 규칙 사용
- 대형 사냥 역할의 가치 제공
- 코인 묶음과 연금 정수 보너스 제공 가능
- 보스 처치가 다음 스테이지 해금 조건은 아님
- 5웨이브가 끝나면 다시 1웨이브부터 반복

보스가 웨이브 예산 안에서 비용을 소비할지 별도 보스 슬롯을 사용할지는 스테이지별 데이터에 명시합니다.

자세한 공통 규칙은 `STAGE_BOSSES.md`에서 관리합니다.

---

## 6. 높은 스테이지의 가치

### LVL-013: 코인 효율 증가

높은 스테이지는 이전보다 좋은 이론적 코인 효율을 제공합니다. 처치하지 못한 몬스터가 많으면 실제 수익은 낮아집니다.

### LVL-014: 현재 스테이지 행운

- 높은 스테이지일수록 높은 굴리기 행운
- 최고 해금 기록이 아니라 현재 위치 기준
- 스테이지 전환 시 즉시 변경
- 처치율과 웨이브 진행도와 무관하게 적용
- 어려운 높은 스테이지에 머물러 행운만 얻는 전략 허용

---

## 7. 경로 디자인

### LVL-015: 자유로운 단일 경로

초기 버전은 스테이지마다 하나의 몬스터 경로를 사용합니다.

예:

- S자 경로
- 성벽이나 숲을 도는 경로
- 다리와 협곡
- 모래 언덕과 폐허
- 정글 유적
- 빙하 협곡
- 용암 강 주변의 굽은 길

맵 제작자가 경로와 웨이포인트를 직접 지정합니다. 초기 갈림길과 복수 경로는 제외합니다.

### LVL-016: 경로와 타워 역할

경로 진행도는 선두·후미 판정에 사용하고 실제 월드 거리는 광역·연쇄 공격에 사용합니다. 경로의 굴곡과 근접 구간은 역할별 효율 차이를 만들 수 있습니다.

### LVL-017: 목표 이동 시간

맵 길이와 전투 시간을 분리합니다.

```text
실제 이동속도
= 전체 경로 길이 ÷ 목표 이동 시간
```

보스와 특수 몬스터는 별도 목표 시간을 가질 수 있습니다.

---

## 8. 베이스와 과부하

### LVL-018: 체력과 회복

베이스는 최대 체력과 지속 회복을 가집니다.

### LVL-019: 도착 피해

```text
실제 베이스 피해
= 몬스터 기본 베이스 피해
× 도착 시 현재 체력 / 최대 체력
```

### LVL-020: 과부하

베이스 체력이 0이 되면:

```text
현재 몬스터와 웨이브 정리
→ 짧은 생성 중단
→ 베이스 완전 회복
→ 같은 스테이지의 1웨이브부터 재개
```

타워, 획득한 코인, 굴리기, 스탯과 문 해금을 잃지 않습니다.

---

## 9. 스테이지 데이터

각 스테이지는 최소한 다음 개념을 가집니다.

- 지역과 순번
- 테마와 맵 설명
- 월드 경계와 문
- 경로와 웨이포인트
- 생성 지점과 베이스
- 목표 이동 시간
- 1~5웨이브 예산
- 웨이브별 몬스터 후보와 가중치
- 5웨이브 보스
- 코인 단가
- 스테이지 행운
- 문 해금 가격
- 핵심 전투 특징

개별 데이터는 `docs/reference/STAGE_CATALOG.md`에서 관리합니다.

---

## 10. 사용하지 않는 구조

- 보스 처치나 웨이브 완료를 다음 스테이지 해금 조건으로 사용
- 스테이지 입장권과 반복 입장료
- 이탈 후 이전 웨이브 진행 유지
- 여러 스테이지의 웨이브를 동시에 파밍
- 높은 스테이지일수록 몬스터 수만 증가
- 특정 피해 유형 면역을 지역 테마로 강제
- 베이스 파괴에 따른 영구 자산 손실
- 초기 복수 경로

---

## 11. 미확정 사항

- 15개 스테이지의 이름과 실제 맵 디자인
- 웨이브별 예산·생성 시간·준비 시간
- 몬스터별 생성 비용과 가중치
- 각 스테이지 보스의 종류와 수치
- 문 가격·코인 단가·행운 곡선
- 보스가 예산을 소비하는 기본 방식
