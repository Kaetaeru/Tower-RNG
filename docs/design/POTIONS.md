## 요약

포션은 영구 스탯을 대체하지 않고 일정 시간 동안 선택한 활동을 가속하는 소비품입니다.

- 구매 재화: 연금 정수
- 초기 기준 지속시간: 10분
- 같은 포션 재사용: 효과 중첩 없이 시간 연장
- 서로 다른 포션: 동시에 사용 가능
- 오프라인 중 시간 정지
- 환생해도 보유량과 활성 효과의 남은 시간 유지

---

## 1. 포션 상점

포션 상점은 고정된 상품을 항상 판매합니다.

- 상점 갱신 대기 없음
- 구매 횟수 제한 없음
- 가격 변동 없음
- 무작위 포션 상자 없음
- 필요한 포션 직접 선택
- 코인과 연금 정수의 혼합 가격 없음

---

## 2. 초기 포션

| 분류 | 포션 | 효과 |
|---|---|---|
| 굴리기 | 행운의 포션 | 일반 굴리기 행운 증가 |
| 굴리기 | 신속한 굴리기 포션 | 굴리기 간격 감소 |
| 전투 | 성능의 포션 | 타워 핵심 성능 증가 |
| 전투 | 전투 속도의 포션 | 공격과 능력 발동 속도 증가 |
| 전투 | 집중의 포션 | 치명타 확률과 피해 증가 |
| 파밍 | 풍요의 포션 | 획득하는 코인 가치 증가 |
| 방어 | 수호의 포션 | 베이스 최대 체력과 회복 증가 |

초기에는 역할별·원소별·특정 타워 전용 포션을 사용하지 않습니다.

---

## 3. 굴리기 포션

### 행운의 포션

영구 행운, 환생 행운, 현재 스테이지 행운과 특수 주사위에 추가로 적용됩니다. 정확한 배율 순서는 굴리기 명세에서 정합니다.

### 신속한 굴리기 포션

굴리기 간격을 줄여 다음을 가속합니다.

- 총 굴리기 횟수
- 황금·다이아몬드 주사위 도달
- 중복 타워와 합체 재료 축적

---

## 4. 전투 포션

### 성능의 포션

스탯 트리의 성능 강화와 같은 적용 규칙을 사용합니다.

### 전투 속도의 포션

일반 공격, 주기적 지원, 소환과 특수 능력의 발동 간격을 줄일 수 있습니다. Engage 이동속도를 자동으로 증가시키지는 않습니다.

### 집중의 포션

피해 판정의 치명타 확률과 치명타 피해를 증가시킵니다. 비피해 지원·제어 수치에는 일반 치명타를 적용하지 않습니다.

---

## 5. 파밍과 방어 포션

### 풍요의 포션

몬스터가 떨어뜨리는 코인 가치에 적용됩니다.

- 일반 몬스터 코인
- 변종 몬스터 코인
- 개인 보스 코인 묶음

연금 정수 게이지에는 적용하지 않습니다. 포션으로 정수 수급을 다시 늘리는 순환 구조를 만들지 않습니다.

### 수호의 포션

베이스 최대 체력과 회복량을 증가시킵니다. 종료 시 현재 체력이 원래 최대치를 초과하면 원래 최대치로 조정하며 피해로 표시하지 않습니다.

---

## 6. 지속시간과 중첩

### 같은 포션

효과 수치는 중첩하지 않고 남은 시간만 연장합니다.

```text
성능의 포션 6분 남음
+ 같은 포션 사용
→ 효과 수치 유지
→ 남은 시간 16분
```

### 서로 다른 포션

서로 다른 종류는 동시에 사용할 수 있습니다. 모든 포션을 항상 함께 사용해야만 정상 효율이 나오는 구조는 피합니다.

---

## 7. 시간 보존과 환생

포션 시간은 접속 중 활성 시간에만 감소합니다.

- 서버 이동 후 유지
- 스테이지·지역 이동 후 유지
- 베이스 과부하 중에도 감소
- 접속 종료 중 정지
- 재접속 시 남은 시간부터 재개
- 환생 후에도 보유량과 활성 효과 유지

환생 확인 화면에는 활성 포션이 사라지지 않는다는 점을 표시합니다.

---

## 8. 초기 테스트 값

| 포션 | 초기 효과 예시 |
|---|---:|
| 행운의 포션 | 행운 ×1.5 |
| 신속한 굴리기 포션 | 굴리기 속도 +25% |
| 성능의 포션 | 성능 강화 +25% |
| 전투 속도의 포션 | 공격속도 +20% |
| 집중의 포션 | 치명타 확률 +10%p, 치명타 피해 +25%p |
| 풍요의 포션 | 코인 가치 +25% |
| 수호의 포션 | 최대 체력·회복 +50% |

위 수치는 첫 테스트용이며 확정값이 아닙니다.

---

## 9. 사용하지 않는 구조

- 특정 역할·원소·타워 전용 포션
- 변종 확률 전용 포션
- 보스 출현 확률 포션
- 모든 효과를 합친 필수 최상급 포션
- 무작위 결과 포션
- 사용 실패
- 환생 시 포션 소실
- 풍요의 포션으로 연금 정수 획득 증가

---

## 10. 미확정 사항

- 포션 정식 명칭
- 최종 효과와 지속시간
- 연금 정수 가격
- 라이브 웨이브 적용 범위
- 최대 저장 가능 지속시간
