# 포션 기획

- 계층: 게임 기획
- 상태: Confirmed with provisional balance values
- 관련 문서: `docs/design/CURRENCY.md`, `docs/design/COMBAT.md`, `docs/design/LEVEL_DESIGN.md`
- 하위 문서 예정: `docs/spec/POTIONS.md`
- 마지막 정리: 2026-08-02

## 요약

포션은 영구 스탯을 대체하지 않고 일정 시간 동안 플레이어가 선택한 활동을 가속하는 소비품입니다.

- 구매 재화: 연금 정수
- 기본 지속시간: 10분
- 같은 포션 재사용: 효과 중첩 없이 남은 시간 연장
- 서로 다른 포션: 동시에 사용 가능
- 오프라인 중에는 지속시간이 감소하지 않음

연금 정수의 획득 구조는 `docs/design/CURRENCY.md`에서 관리합니다.

---

## 1. 포션 상점

포션 상점은 고정된 상품을 항상 판매합니다.

기본 원칙:

- 상점 갱신 대기 없음
- 구매 횟수 제한 없음
- 가격 변동 없음
- 무작위 포션 상자 없음
- 필요한 포션을 직접 선택해 구매
- 일반 성장 재화와 연금 정수를 동시에 요구하지 않음

포션은 특정 시간에 접속하거나 상점 갱신을 기다리게 만드는 시스템이 아닙니다.

---

## 2. 초기 포션 목록

| 분류 | 포션 | 효과 |
|---|---|---|
| 굴리기 | 행운의 포션 | 굴리기 행운 증가 |
| 굴리기 | 신속한 굴리기 포션 | 굴리기 간격 감소 |
| 전투 | 성능의 포션 | 모든 타워의 핵심 성능 증가 |
| 전투 | 전투 속도의 포션 | 공격과 능력 발동 속도 증가 |
| 전투 | 집중의 포션 | 치명타 확률과 치명타 피해 증가 |
| 파밍 | 풍요의 포션 | 일반 성장 재화 획득량 증가 |
| 방어 | 수호의 포션 | 베이스 최대 체력과 회복 증가 |

초기에는 역할별, 원소별, 특정 타워 전용 포션을 만들지 않습니다.

---

## 3. 굴리기 포션

### 행운의 포션

일정 시간 동안 모든 일반 굴리기의 행운 배율을 증가시킵니다.

특수 주사위와 함께 적용됩니다.

```text
최종 행운
= 영구 행운 × 포션 배율 × 특수 주사위 배율
```

황금 및 다이아몬드 주사위와 조합할 수 있지만, 충분한 지속시간을 제공해 특정 한 번의 굴림에 지나치게 집착할 필요가 없게 합니다.

### 신속한 굴리기 포션

굴리기 간격을 줄입니다.

영향을 받는 항목:

- 지속시간 동안의 전체 굴리기 횟수
- 황금 및 다이아몬드 주사위 도달 속도
- 중복 타워 축적 속도
- 합체 재료 축적 속도

굴리기 횟수와 여러 장기 진행값을 동시에 가속하므로 행운 포션과 함께 높은 가치의 포션으로 취급합니다.

---

## 4. 전투 포션

### 성능의 포션

영구 스탯의 `성능 강화`와 같은 규칙으로 모든 편성 타워를 강화합니다.

적용 예시:

- 공격 타워: 피해량 증가
- 지속 피해 타워: 지속 피해량 증가
- 제어 타워: 지정된 감속·기절 성능 증가
- 지원 타워: 지원 수치 증가
- 소환 타워: 소환체 전투 성능 증가
- 마무리 및 대형 사냥 타워: 기본 기능과 특화 기능 강화

각 타워는 성능 강화가 적용되는 수치를 자신의 데이터에 명시합니다.

### 전투 속도의 포션

타워의 공격과 능력 발동 주기를 빠르게 합니다.

적용 대상:

- 일반 공격 간격
- 주기적 지원 능력
- 소환 능력 주기
- 특수 능력 재사용 대기시간

상태 효과의 지속시간 자체는 변경하지 않습니다.

### 집중의 포션

치명타 확률과 치명타 피해를 함께 증가시킵니다.

치명타 적용 대상:

- 직접 공격
- 광역 피해
- 연쇄 피해
- 지속 피해
- 소환체 피해
- 타워의 고유 추가 피해

지원 효과, 감속 수치와 같은 비피해 수치에는 일반 치명타를 적용하지 않습니다. 특별한 확률 강화 효과는 해당 타워의 고유 능력으로 별도 처리합니다.

---

## 5. 파밍·방어 포션

### 풍요의 포션

몬스터 처치로 얻는 일반 성장 재화를 증가시킵니다.

적용 대상:

- 일반 몬스터 성장 재화
- 변종 몬스터 성장 재화
- 개인 스테이지 보스 성장 재화

적용하지 않는 대상:

- 연금 정수와 정수 게이지
- 포션 구매 비용
- 초기 기준의 라이브 웨이브 최종 보상

연금 정수로 포션을 산 뒤 해당 포션으로 정수 수급량을 다시 늘리는 순환 구조는 만들지 않습니다.

### 수호의 포션

베이스 최대 체력과 체력 회복량을 증가시킵니다.

용도:

- 다음 스테이지 시험 진입
- 베이스 과부하 위험 완화
- 안정적인 장기 파밍

포션 종료 시 현재 베이스 체력이 원래 최대 체력보다 높다면 원래 최대치로 조정합니다. 이 과정은 피해로 표시하지 않습니다.

---

## 6. 지속시간과 중첩 규칙

### 기본 지속시간

모든 초기 포션의 기본 지속시간은 10분으로 통일합니다.

포션마다 시간이 달라 관리가 복잡해지는 것을 피하고 가격과 효과를 쉽게 비교할 수 있게 합니다.

### 같은 포션 재사용

같은 포션의 효과 수치는 중첩하지 않고 지속시간만 연장합니다.

```text
성능의 포션 6분 남음
+ 성능의 포션 1개 사용
→ 성능 수치는 그대로
→ 남은 시간 16분
```

### 서로 다른 포션

서로 다른 종류의 포션은 동시에 사용할 수 있습니다.

예시:

```text
행운의 포션
+ 신속한 굴리기 포션
+ 성능의 포션
```

각 포션은 서로 다른 활동이나 목적을 가속해야 하며, 모든 포션을 항상 동시에 사용해야만 효율적인 구조는 피합니다.

---

## 7. 포션 시간 보존

포션 시간은 접속 중인 활성 시간에만 감소합니다.

- 서버 이동 후 유지
- 스테이지 변경 후 유지
- 베이스 과부하 중에도 유지
- 접속 종료 중에는 시간 정지
- 재접속 시 남은 시간부터 재개

연결 종료나 서버 이동으로 포션 시간을 잃지 않게 합니다.

---

## 8. 초기 테스트 수치

다음 수치는 확정 밸런스가 아니라 첫 테스트를 위한 기준입니다.

| 포션 | 초기 효과 예시 |
|---|---:|
| 행운의 포션 | 행운 ×1.5 |
| 신속한 굴리기 포션 | 굴리기 속도 +25% |
| 성능의 포션 | 성능 강화 +25% |
| 전투 속도의 포션 | 공격속도 +20% |
| 집중의 포션 | 치명타 확률 +10%p, 치명타 피해 +25%p |
| 풍요의 포션 | 일반 성장 재화 +25% |
| 수호의 포션 | 최대 체력 +50%, 체력 회복 +50% |

---

## 9. 초기 가격 방향

가격은 두 단계 정도로 단순하게 구성합니다.

| 포션 | 가격 예시 |
|---|---:|
| 성능의 포션 | 연금 정수 10 |
| 전투 속도의 포션 | 연금 정수 10 |
| 집중의 포션 | 연금 정수 10 |
| 수호의 포션 | 연금 정수 10 |
| 행운의 포션 | 연금 정수 15 |
| 신속한 굴리기 포션 | 연금 정수 15 |
| 풍요의 포션 | 연금 정수 15 |

굴리기와 재화 포션은 여러 장기 진행값에 영향을 주므로 더 높은 가격군으로 시작합니다.

---

## 10. 만들지 않는 포션

초기에는 다음 포션을 사용하지 않습니다.

- 특정 역할만 강화하는 포션
- 특정 원소나 피해 유형 강화 포션
- 특정 타워 전용 포션
- 변종 타워 확률 전용 포션
- 보스 등장 확률 포션
- 모든 효과를 합친 최상급 포션
- 결과가 무작위인 포션
- 사용에 실패할 수 있는 포션

새로운 좋은 타워를 얻었을 때 기존 소비품과 맞지 않아 실망하는 상황을 피합니다.

---

## 11. 설계 원칙

- 포션 없이도 모든 일반 진행 가능
- 포션은 일시적인 가속이며 영구 성장의 필수 조건이 아님
- 선택한 활동에 맞는 명확한 효과 제공
- 구매 상품과 가격은 항상 확인 가능
- 포션 사용으로 영구적인 손실이나 실패가 발생하지 않음
- 특정 빌드나 타워 유형에 플레이어를 고정하지 않음

---

## 12. 미확정 사항

- 포션의 정식 명칭
- 각 포션의 최종 수치
- 최종 지속시간
- 최종 연금 정수 가격
- 라이브 웨이브 보상에 풍요의 포션을 적용할지 여부
- 최대 저장 가능 지속시간을 둘지 여부
