## 요약

Roblox RNG 게임에서 흔한 VIP, 영구 행운, 굴리기 속도, 코인 배율, 포션, 슬롯과 서버 부스트를 참고하되 Tower RNG의 핵심 루프를 유료로 되돌리지 않습니다.

우선순위:

```text
꾸미기
→ 관리·전시 편의
→ 게임에서도 얻는 시간제 포션
→ 제한적인 VIP·영구 가속
→ 서버 전체 부스트
```

Defense XP 직접 판매, Robux 직접 타워 굴리기, 유료 전용 핵심 타워와 자동 합체 상품은 사용하지 않습니다.

---

## 1. 무료 핵심 기능

무료 진행으로 제공:

- 자동 굴리기·자동 편성
- 모든 일반 지역·스테이지
- Defense XP 환생
- 기본 인벤토리·퀵 편성
- 거대 스탯 트리
- 수동 합체
- 기본 변종 접근
- 오프라인 코인
- 텔레포터
- 설정·접근성

상품을 판매하기 위해 무료 코인·행운·굴리기 속도·Defense XP 획득을 의도적으로 낮추지 않습니다.

---

## 2. 유료 전용 전투력 금지

사용하지 않음:

- 유료 전용 핵심 타워
- 유료 전용 변종·합체 계보
- Robux 확정 극희귀 타워
- Robux 직접 반복 굴리기
- Defense XP 직접 구매·포션·배율
- 특정 상품 없이는 처리 불가능한 몬스터
- 유료 자동 합체
- 유료만 가능한 접근성 설정

외형 타워는 무료 타워와 전투 성능이 같은 스킨으로 취급합니다.

---

## 3. 상품 정보 투명성

구매 전에 표시:

- 정확한 상품 효과
- 행운·코인·속도 수치
- 지속시간
- 중첩 방식
- 적용 대상
- 실제 런타임 가격

행운 상품도 `LuckScore` 또는 압축 계수에 더하는 보너스를 명확히 표시합니다. 다만 게임 전체 원칙에 따라 **행운 적용 후 타워별 현재 `1 / N`은 표시하지 않습니다.**

공식 기본 확률은 계속 표시합니다.

---

## 4. 출시 후보

### 꾸미기

- 주사위·굴리기 연출 스킨
- 플레이어 오라·이동 흔적
- 코인 흡입 효과
- 타워 편대 궤적
- UI 테마·클릭음
- 이름표·프로필·리더보드 장식

### 관리·전시 편의

- 추가 편성 프리셋
- 추가 인벤토리 필터 프리셋
- 추가 전시 슬롯
- 추가 프로필 꾸미기 슬롯

기본 편성·보호·수동 합체 기능은 무료입니다. 자동 합체는 무료·유료 모두 존재하지 않습니다.

### VIP

후보:

- VIP 태그와 프로필 외형
- 전용 획득 연출
- 추가 프리셋·전시 슬롯
- 작은 행운 보너스
- 제한된 포션 지속시간 보너스

VIP가 정상 진행의 필수 배율 묶음이 되지 않게 합니다.

### 시간제 상품

- 행운 포션
- 굴리기 속도 포션
- 코인 포션
- 전투 포션
- 1회 스타터 팩

동일한 포션은 연금 정수와 일반 플레이로도 획득할 수 있어야 합니다.

### 서버 전체 부스트

- 제한 시간 행운 또는 코인 보너스
- 효과와 남은 시간 표시
- 무한 중첩 금지
- 다른 플레이어 보상 감소 없음
- 필수 접속 시간으로 만들지 않음
- Defense XP 서버 부스트는 출시 후보에서 제외

---

## 5. 신중히 검토할 영구 가속

### 코인 배율

문·스탯 진행을 줄이는 효과가 크므로 제한합니다. Defense XP 요구량을 직접 줄이지는 않습니다.

### 영구 행운

희귀 수집 가치에 직접 영향을 주므로 작은 보너스만 검토합니다.

- 유료 행운을 전제로 공식 기본 확률 악화 금지
- 기존 희귀 타워 `BaseOddsN` 변경 금지
- 유료 보너스 수치 공개
- 현재 결과별 유효 확률은 비공개

### 굴리기 속도

무료 스탯 트리와 포션이 이미 존재합니다. 판매한다면 작은 상한만 허용합니다.

연출 건너뛰기·축약은 무료 설정입니다.

### 자석 편의

제한적 반경 보너스는 검토 가능하지만 즉시 무제한 자동 수집으로 플레이어 이동을 제거하지 않습니다.

## 6. 상점 UX

- 독립 메뉴
- 전투 중 반복 팝업 금지
- 과부하 직후 구매 강요 금지
- 환생 조건 부족 시 결제 유도 금지
- 가짜 시간 제한·허위 할인 금지
- 상품 효과·가격 카드에서 확인
- 입력 즉시 반응, 서버 승인 후 성공 연출
- 구매 연출이 전투·굴리기를 오래 막지 않음
- 일반 상점 클릭에 화면 흔들림 없음

## 7. 출시 방향

첫 출시 후보:

```text
꾸미기
관리·전시 편의 패스
VIP
포션 묶음
1회 스타터 팩
서버 전체 행운·코인 부스트
```

첫 출시 제외:

- 구독
- 유료 전용 전투 타워
- Robux 직접 굴리기
- Defense XP 상품
- 자동 합체 상품
- 복잡한 회전형 유료 상점

정확한 가격과 배율은 무료 수직 슬라이스의 첫 환생·문·스탯 경제를 측정한 뒤 확정합니다.
