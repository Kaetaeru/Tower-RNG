## 요약

여러 Roblox RNG 게임을 비교하면 영구 행운, VIP, 빠른 굴리기, 코인 배율, 자동 수집, 추가 슬롯, 포션 지속시간, 텔레포트, 스타터 팩과 서버 전체 부스트가 반복적으로 사용됩니다.

반면 자동 굴리기, 빠른 굴리기와 무제한 인벤토리를 무료로 제공하는 RNG 게임도 있습니다. Tower RNG는 장르의 과금 사례를 참고하되, 자동 굴리기와 핵심 진행을 유료로 되돌리지 않습니다.

과금의 우선순위는 **꾸미기 → 관리 편의 → 게임 안에서도 얻을 수 있는 시간제 가속 → 제한된 영구 가속**입니다.

---

## 1. 조사에서 확인한 상품군

공통적으로 발견되는 상품:

- VIP 태그와 최종 행운 보너스
- 영구 행운 배율
- 빠른 굴리기 또는 굴리기 연출 생략
- 코인 배율
- 자동 수집 또는 자동 전리품
- 인벤토리·캐릭터·장비 슬롯
- 포션 지속시간 증가
- 상인·지역 텔레포트
- 포션과 스타터 묶음
- 서버 전체 행운 부스트
- 오라·이름표·전시 슬롯 같은 꾸미기

Tower RNG에 그대로 적용하지 않을 항목도 있으며, 무료 스탯 트리와 직접 코인 수집의 의미를 먼저 보호합니다.

## 2. 핵심 원칙

### MON-001: 기본 게임 무료 완성

다음은 무료 진행으로 제공합니다.

- 극초반 자동 굴리기와 자동 편성
- 모든 일반 지역과 스테이지
- 환생
- 기본 인벤토리와 퀵 편성
- 스탯 트리의 전투·굴리기·수집 성장
- 합체와 변종의 기본 접근
- 오프라인 코인
- 스탯 트리 텔레포터

### MON-002: 유료 전용 핵심 전투력 금지

- 유료 전용 핵심 타워 없음
- 유료 전용 변종과 합체 계보 없음
- Robux로 확정 극희귀 타워 지급 없음
- Robux를 직접 소비하는 반복 타워 굴리기 없음
- 특정 상품이 없으면 처리할 수 없는 몬스터 없음

유료 외형 타워를 판매한다면 무료 타워와 동등한 스킨으로 취급합니다.

### MON-003: 무료 경제를 먼저 완성

무료 플레이의 첫 환생과 성장 시간을 먼저 맞춘 뒤 유료 가속을 추가합니다. 상품 판매를 위해 무료 코인·행운·굴리기 속도를 의도적으로 낮추지 않습니다.

### MON-004: 투명한 표시

- 정확한 효과와 지속시간
- 행운·코인·속도 배율
- 중첩 방식
- 적용 대상
- 실제 런타임 가격

구매 전에 모두 확인할 수 있어야 합니다.

## 3. 출시 우선 상품 후보

### 꾸미기

- 주사위와 굴리기 연출 스킨
- 플레이어 오라와 이동 흔적
- 코인 흡입 효과
- 타워 편대 궤적
- UI 테마와 클릭음
- 이름표·프로필·리더보드 장식

### 관리 편의

- 추가 편성 프리셋
- 추가 자동 합체 규칙 저장
- 추가 인벤토리 필터
- 추가 전시 슬롯

기본 편성, 보호와 자동 합체 기능 자체를 유료 전용으로 만들지 않습니다.

### VIP

후보 구성:

- VIP 태그와 프로필 외형
- 전용 획득 연출
- 추가 프리셋·전시 슬롯
- 작은 최종 행운 보너스
- 제한된 포션 지속시간 보너스

정확한 혜택과 배율은 미확정입니다. VIP가 필수 배율 묶음이 되지 않게 합니다.

### 시간제 상품

- 행운 포션 묶음
- 굴리기 속도 포션 묶음
- 코인 포션 묶음
- 전투 포션 묶음
- 스타터 팩

같은 포션은 연금 정수와 일반 플레이로도 획득할 수 있어야 합니다.

### 서버 전체 부스트

한 플레이어의 구매가 서버 전체에 제한 시간 행운 또는 코인 보너스를 줄 수 있습니다.

- 다른 플레이어의 보상을 감소시키지 않음
- 효과 배율 무한 중첩 금지
- 구매자와 남은 시간 표시
- 필수 접속 시간으로 만들지 않음

## 4. 신중하게 검토할 영구 가속

### 코인 배율

RNG 게임에서 흔하지만 환생 시간을 직접 줄입니다. 채택한다면 무료 성장과 선택을 무의미하게 만들지 않는 범위로 제한합니다.

### 영구 행운

희귀 수집 가치에 가장 큰 영향을 주므로 작은 최종 배율만 검토합니다. 유료 행운을 전제로 기본 확률을 악화시키지 않습니다.

### 실제 굴리기 속도

빠른 굴리기는 흔한 상품이지만 Tower RNG에는 무료 굴리기 속도 스탯이 있습니다. 판매한다면 작은 상한만 허용하며 연출 건너뛰기와 접근성 설정은 무료로 제공합니다.

### 수집 편의

자석 반경의 제한된 추가 보너스는 검토할 수 있지만, 즉시 무제한 자동 수집을 제공해 플레이어 이동을 제거하지 않습니다.

## 5. 상점 UX

- 상점은 독립 메뉴에서 접근
- 전투 중 반복 구매 팝업 금지
- 과부하 직후 구매 강요 금지
- 가짜 시간 제한과 허위 할인 금지
- 상품 효과와 가격을 카드에서 즉시 확인
- 구매 입력과 성공 결과에 강한 피드백 제공
- 구매 연출이 전투와 굴리기를 오래 막지 않음

세부 감각 기준은 `PRESENTATION_FEEL.md`를 따릅니다.

## 6. 출시 방향

첫 출시 후보:

```text
- 꾸미기 상품
- 관리·전시 편의 패스
- VIP
- 포션 묶음
- 1회 스타터 팩
- 서버 전체 부스트
```

첫 출시에서 제외:

- 구독
- 유료 전용 전투 타워
- Robux 직접 타워 굴리기
- 복잡한 회전형 유료 상점

정확한 상품 수, 가격과 배율은 무료 경제의 수직 슬라이스를 측정한 뒤 결정합니다.

## 7. 측정

- 무료·유료 첫 환생 시간
- 무료·유료 시간당 굴림 격차
- 상품별 구매율과 재구매율
- 유료 행운이 희귀 획득 분포에 미치는 영향
- 구매 후 이탈률
- 유료 배율이 스탯 트리를 무의미하게 만드는지

## 8. 사용하지 않는 구조

- 자동 굴리기 유료 전용화
- 유료 전용 핵심 타워와 변종
- Robux 직접 타워 뽑기
- 무한 중첩 행운·코인 부스트
- 과부하 직후 부활 판매
- 전투를 가리는 결제 팝업
- 확률과 배율을 숨긴 상품
- 유료 상품을 전제로 느리게 만든 무료 진행
