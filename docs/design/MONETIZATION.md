## 조사 상태

다른 Roblox RNG 게임의 현재 상품과 가격을 웹에서 검증하려 했으나 이번 작업에서는 검색 서비스가 응답하지 않았습니다. 따라서 특정 게임의 상품을 사실로 인용하거나 그대로 확정하지 않습니다.

이 문서는 RNG 게임을 조사할 때 비교할 항목, Tower RNG가 허용할 수 있는 상품 방향과 금지선을 기록한 잠정 기획입니다. 실제 상품·가격·배율은 벤치마크 재조사와 경제 시뮬레이션 뒤 확정합니다.

---

## 1. 벤치마크 조사 기준

각 RNG 게임에서 다음을 동일한 표로 조사합니다.

- 영구 게임패스
- 반복 구매 Developer Product
- 유료 재화
- 구독 또는 월간 혜택
- 행운 배율
- 굴리기 속도·쿨다운 감소
- 자동 굴리기·자동 삭제·자동 잠금
- 인벤토리·저장 공간
- 오프라인 보상 시간·효율
- 포션·부스트 묶음
- 한정 외형과 효과
- 유료 전용 캐릭터·타워·오라
- 서버 전체 부스트
- 선물 기능
- 가격대와 중첩 방식
- 무료 플레이로 같은 기능을 얻을 수 있는지
- 실제 확률 공개 여부

특정 사례를 반영할 때는 조사 날짜와 출처를 함께 기록합니다.

## 2. Tower RNG 과금 원칙

### MON-001: 핵심 루프 무료 접근

다음 기능을 유료 구매에만 묶지 않습니다.

- 자동 굴리기
- 자동 편성
- 모든 일반 지역과 스테이지
- 환생
- 합체
- 변종 계열의 기본 접근
- 텔레포터
- 오프라인 코인 수익
- 전투 역할과 타겟 설정

게임패스는 기본 게임을 완성시키는 필수 부품이 아니라 편의·표현·가속을 제공합니다.

### MON-002: 유료 전용 필수 전투력 금지

- 일반 진행에 필수인 유료 전용 타워를 만들지 않음
- 유료 타워가 무료 타워의 완전한 영구 상위호환이 되지 않음
- 특정 유료 상품이 없으면 스테이지를 정상 진행할 수 없는 구조 금지
- 유료 구매가 실제 확률을 숨기거나 다른 확률로 표시하지 않음

### MON-003: 실제 효과 공개

행운·속도·코인 상품은 다음을 구매 전에 표시합니다.

- 정확한 효과 또는 배율
- 지속시간
- 중첩 방식
- 적용 대상
- 무료 성장과의 관계
- 구매 후 실제 최종 수치 확인 경로

## 3. 우선 상품군

### 꾸미기

가장 안전한 우선 상품입니다.

후보:

- 주사위 외형과 굴리기 연출
- 플레이어 오라와 이동 흔적
- 코인 흡입·획득 효과
- 타워 편대 발판·궤적
- 피해 숫자 스킨
- 프로필·이름표·리더보드 장식
- 로비 감정표현
- UI 테마와 클릭음 세트

꾸미기는 전투 판정과 공식 획득 확률을 변경하지 않습니다.

### 편의 게임패스

후보:

- 추가 편성 프리셋 저장칸
- 추가 자동 합체 규칙 저장
- 추가 인벤토리 필터 프리셋
- 희귀 획득 연출 세부 설정
- 더 많은 타워 보호·즐겨찾기 그룹
- 빠른 메뉴·단축키 확장

기본 편성·보호·자동 합체 자체는 무료 성장으로 제공하고, 유료 상품은 저장 가능한 설정 수를 늘리는 방향을 우선합니다.

### 시간제 가속 상품

후보:

- 행운 포션 묶음
- 굴리기 속도 포션 묶음
- 코인 가치 포션 묶음
- 전투 성능 포션 묶음
- 여러 포션을 포함한 스타터 묶음

게임 안의 연금 정수로도 같은 종류의 포션을 획득할 수 있어야 합니다. 유료 구매는 즉시 확보와 묶음 편의에 가깝게 둡니다.

## 4. 신중하게 검토할 상품

### 영구 행운 게임패스

RNG 게임에서 매력적인 상품이지만 전체 수집 가치와 공정성 체감에 가장 큰 영향을 줍니다.

허용을 검토한다면:

- 실제 배율 공개
- 스탯 트리·환생·포션과의 중첩 방식 공개
- 무한 구매 불가
- 무료 진행으로도 충분한 행운 성장 가능
- 유료 효과를 전제로 기본 확률을 악화시키지 않음

최종 채택 여부와 배율은 벤치마크 조사 뒤 확정합니다.

### 영구 굴리기 속도 게임패스

행운보다 결과 품질을 직접 바꾸지는 않지만 시간당 시도 수와 특수 주사위 도달 속도를 크게 높입니다.

검토 조건:

- 무료 스탯 트리의 굴리기 속도를 무의미하게 만들지 않음
- 서버 성능과 저장 부하를 감당할 상한 사용
- 포션과의 중첩 방식 공개

### 오프라인 보상 확장

후보:

- 최대 저장 시간 증가
- 오프라인 효율 소폭 증가

기본 8시간과 스탯 트리 확장은 무료로 유지합니다. 유료 상품이 없는 플레이어가 매일 불리한 접속 압박을 느끼지 않도록 차이를 제한합니다.

### 서버 부스트

한 플레이어가 서버 전체에 제한된 시간 동안 행운·코인 부스트를 제공하는 상품은 소셜 효과가 있지만, 다음 문제가 있습니다.

- 서버 이동 악용
- 다른 플레이어 의존성
- 효과 중첩과 표시
- 구매 압박과 채팅 홍보

첫 출시 필수 상품으로 두지 않고 후속 검토합니다.

## 5. 기본적으로 사용하지 않는 방향

- 굴리기 1회마다 Robux 요구
- 실제 확률을 숨기는 유료 상자
- 유료 구매 실패 또는 무작위 수량
- 영구적으로 다시 얻을 수 없는 핵심 전투력 판매
- 결제 전용 환생·지역·웨이브
- 유료 상품을 구매해야 자동 굴리기 사용 가능
- 유료 상품을 전제로 불편하게 만든 기본 인벤토리
- 강제 팝업과 전투 중 반복 구매 유도
- 보스 직전 결제를 요구하는 실패 압박
- 유료 부스트 없이는 사실상 불가능한 확률 설계

---

## 6. 상품 배치 UX

- 상점은 독립 메뉴에서 명확하게 접근
- 전투 HUD에 상시 큰 구매 버튼을 여러 개 배치하지 않음
- 부족한 재화나 실패 순간마다 Robux 팝업을 자동 표시하지 않음
- 상품 카드는 효과·기간·중첩을 구매 전에 표시
- 이미 보유한 영구 상품은 다시 구매할 수 없게 표시
- 시간제 효과의 남은 시간은 HUD에서 확인 가능
- 결제 성공 피드백은 강하게 제공하되 전투를 오래 중단하지 않음

---

## 7. 출시 전 조사 과제

다음 유형에서 최소 5개 이상의 활성 Roblox RNG 게임을 선정해 비교합니다.

- 순수 오라·캐릭터 굴리기 RNG
- 전투가 결합된 RNG
- 방치형·펫 성장 게임
- 확률 수집과 환생을 함께 사용하는 게임

조사 결과로 다음을 결정합니다.

- 첫 출시 게임패스 수
- 가격대
- 영구 행운·속도 사용 여부
- 포션 묶음 구성
- 스타터 팩 구성
- 오프라인 확장 사용 여부
- 꾸미기 상품 우선순위
- 상품별 매출과 이탈을 확인할 텔레메트리

## 8. 잠정 출시 방향

현재 가장 안전한 순서:

```text
1. 꾸미기 상품
2. 추가 설정·프리셋 편의
3. 게임 안에서도 얻는 포션 묶음
4. 제한적인 스타터 팩
5. 조사 후 영구 행운·속도 판단
6. 서버 부스트와 한정 판매는 후속 검토
```

정확한 상품, 가격과 수치는 아직 확정하지 않습니다.
