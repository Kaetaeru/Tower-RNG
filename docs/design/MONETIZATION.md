## 요약

Roblox RNG 게임에서 흔한 VIP, 영구 행운, 굴리기 속도, 코인 배율, 포션, 슬롯과 서버 부스트를 참고하되 Tower RNG의 핵심 진행을 유료로 대체하지 않습니다.

우선순위:

```text
꾸미기
→ 관리·전시 편의
→ 게임에서도 얻는 시간제 포션
→ 제한적 VIP·영구 가속
→ 서버 전체 부스트
```

Defense XP와 환생 스탯 토큰의 직접 판매, Robux 직접 타워 굴리기, 유료 전용 핵심 타워와 자동 합체 상품은 사용하지 않습니다.

---

## 1. 무료 핵심 기능

무료 제공:

- 자동 굴리기·자동 편성
- 모든 일반 지역·스테이지
- Defense XP 환생과 스탯 토큰 배분
- 인벤토리·퀵 편성
- 코인 스탯 트리
- 수동 합체
- 기본 변종 접근
- 오프라인 코인
- 텔레포터
- 설정·접근성

상품 판매를 위해 무료 코인·행운·굴리기·Defense XP 획득을 의도적으로 낮추지 않습니다.

---

## 2. 유료 전용 전투력 금지

사용하지 않음:

- 유료 전용 핵심 타워
- 유료 전용 변종·합체 계보
- Robux 확정 극희귀 타워
- Robux 직접 반복 굴리기
- Defense XP 직접 구매·포션·배율
- 환생 스탯 토큰 직접 구매·묶음·배율
- 유료 전용 환생 스탯
- 특정 상품 없이는 처리 불가능한 몬스터
- 유료 자동 합체
- 유료만 가능한 접근성 설정

외형 타워는 무료 타워와 성능이 같은 스킨입니다.

---

## 3. 상품 정보 투명성

구매 전 표시:

- 정확한 효과
- 행운·코인·속도 수치
- 지속시간
- 중첩 방식과 상한
- 적용 대상
- 실제 가격

행운 상품은 `TemporaryCompressionBonus`처럼 실제 입력 계수를 표시합니다. 게임 원칙에 따라 행운 적용 후 타워별 현재 `1 / N`은 표시하지 않습니다.

공식 기본 확률은 계속 표시합니다.

---

## 4. 출시 후보

### 꾸미기

- 주사위·굴리기 연출 스킨
- 플레이어 오라·이동 흔적
- 코인 흡입 효과
- 타워 편대 궤적
- UI 테마·클릭음
- 프로필·리더보드 장식

### 관리·전시 편의

- 추가 편성 프리셋
- 추가 인벤토리 필터 프리셋
- 추가 전시·프로필 꾸미기 슬롯

기본 편성·보호·수동 합체·스탯 배분 기능은 무료입니다.

### VIP

후보:

- VIP 태그·프로필 외형
- 전용 획득 연출
- 추가 프리셋·전시 슬롯
- 작은 TemporaryCompressionBonus
- 제한된 포션 지속시간 보너스

VIP가 정상 진행의 필수 배율 묶음이 되지 않게 합니다.

### 시간제 상품

- 행운 포션
- 굴리기 속도 포션
- 코인 포션
- 전투 포션
- 1회 스타터 팩

동일한 포션은 연금 정수와 일반 플레이로도 획득할 수 있어야 합니다.

### 서버 전체 부스트

- 제한 시간 행운 또는 코인 보너스
- 효과와 남은 시간 표시
- 무한 중첩 금지
- 다른 플레이어 보상 감소 없음
- Defense XP·스탯 토큰 부스트 제외

---

## 5. 신중히 검토할 영구 가속

### 코인 배율

영구 문·코인 스탯 진행을 줄이는 효과가 크므로 제한합니다. Defense XP 요구량이나 토큰 지급량을 직접 바꾸지 않습니다.

### 영구 행운

환생 행운 토큰이 핵심 확정 성장축이므로 유료 영구 행운은 특히 작아야 합니다.

- 유료 행운 전제로 공식 확률 악화 금지
- 기존 `BaseOddsN` 변경 금지
- 보너스 수치·상한 공개
- 환생 토큰 한 개의 가치를 대체하지 않도록 검증
- 결과별 유효 확률은 비공개

### 굴리기 속도

무료 코인 스탯과 포션이 이미 존재합니다. 판매한다면 작은 상한만 허용합니다.

연출 건너뛰기·축약은 무료 설정입니다.

### 자석 편의

제한적 반경 보너스는 검토할 수 있지만 무제한 자동 수집으로 이동을 제거하지 않습니다.

---

## 6. 상점 UX

- 독립 메뉴
- 전투 중 반복 팝업 금지
- 과부하 직후 구매 강요 금지
- 환생·토큰 부족 시 결제 유도 금지
- 가짜 시간 제한·허위 할인 금지
- 효과·가격 카드 표시
- 입력 즉시 반응, 서버 승인 후 성공 연출
- 구매 연출이 전투·굴리기를 오래 막지 않음
- 일반 클릭 화면 흔들림 없음

---

## 7. 출시 방향

후보:

```text
꾸미기
관리·전시 편의 패스
VIP
포션 묶음
1회 스타터 팩
서버 전체 행운·코인 부스트
```

제외:

```text
구독
유료 전용 전투 타워
Robux 직접 굴리기
Defense XP 상품
환생 스탯 토큰 상품
자동 합체 상품
복잡한 회전형 유료 상점
```

정확한 가격과 배율은 무료 수직 슬라이스와 행운 압축 곡선을 측정한 뒤 확정합니다.

## 8. 측정

- 무료·유료 굴림 수 격차
- 무료·유료 문·코인 스탯 진행 시간
- 유료 행운의 희귀 획득 분포
- 환생 행운 토큰 대비 유료 행운의 상대 효과
- 상품별 구매·재구매와 구매 후 이탈
- 유료 배율이 코인 트리·토큰 배분을 무의미하게 만드는지
- 공식 분모와 유료 행운 설명 오해

## 9. 사용하지 않는 구조

- 자동 굴리기·자동 편성 유료화
- 유료 전용 핵심 타워·변종·합체
- Robux 직접 타워 뽑기
- Defense XP 직접 판매·배율
- 환생 스탯 토큰 직접 판매·배율
- 자동 합체 판매
- 무한 중첩 행운·코인 부스트
- 과부하·환생 직전 결제 강요
- 전투를 가리는 팝업
- 상품 효과 숨김
- 유료 상품을 전제로 느린 무료 진행
- 현재 행운 적용 타워별 확률 표시
