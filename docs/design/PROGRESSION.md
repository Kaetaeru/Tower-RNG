## 요약

Tower RNG의 진행은 무료 굴리기, 자동 전투, 직접 코인 수집, 영구 스테이지 문, 코인 스탯 트리와 Defense XP 환생 스탯 토큰으로 구성합니다.

V1 메인 콘텐츠 완주는 스테이지 15 최초 클리어이며 활성 플레이 중앙값 `12~15시간`을 목표로 합니다.

```text
빠른 완주: 8~10시간
중앙 완주: 12~15시간
느린 완주: 18~22시간
V1 숙련·스테이지 15 안정 파밍: 20~30시간
전체 수집: 완료 시간 없음
```

환생은 코인과 월드 진행을 초기화하지 않습니다. Defense XP만 0으로 만들고 영구 스탯 토큰을 지급합니다.

---

## 1. 기본 진행 흐름

```text
첫 수동 굴리기
→ 최초 슬라임과 첫 코인
→ 자동 굴리기
→ 4슬롯 완성
→ 반복 5웨이브 전투
→ 코인 수집·코인 스탯 구매
→ 코인으로 문 영구 개방
→ 높은 스테이지의 수치·보상·행운
→ Defense XP 축적
→ 환생
→ Defense XP 0 + 스탯 토큰 획득
→ 토큰을 원하는 영구 스탯에 배분
→ 같은 월드 진행에서 계속 전투
```

코인, 열린 문, 현재 스테이지와 현재 전투는 환생 뒤에도 유지됩니다.

---

## 2. 전역 타워 풀과 확률

- 첫 스테이지에서도 모든 일반 타워 등장 가능
- 공식 기본 확률은 `1 / N`
- 일반 V1 최고 기준은 `1 / 10^20`
- 공식 기본 확률만 표시
- 현재 행운 적용 확률은 표시하지 않음
- 높은 스테이지는 타워 종류가 아니라 행운을 증가
- 기존 중·고희귀 공식 분모를 신규 콘텐츠 때문에 몰래 낮추지 않음

예외:

- 해금 전 변종
- 이벤트·한정 풀
- 합체 전용 타워

50자리 공식 분모 골격은 `../reference/V1_TOWER_PROBABILITY_LADDER.md`를 따릅니다.

---

## 3. 최초 25초

정규 스테이지 1 웨이브는 4슬롯 기준이므로 최초 계정에서 한 번만 다음 준비를 사용합니다.

```text
첫 타워 획득·자동 배치
→ HP 5 초원 슬라임 1마리
→ 정상 보상 코인 10·Defense XP 10
→ 자동 굴리기 10코인 구매
→ 4초 간격으로 세 번 더 굴림
→ 빈 시작 슬롯 자동 채움
→ 약 25초에 정규 웨이브 1 시작
```

튜토리얼용 약화 적과 보너스 재화를 사용하지 않습니다. 재접속·환생으로 반복하지 않습니다.

## 4. 첫 15분

균형 소비 기준:

| 목표 | 기준 시간 |
|---|---:|
| 자동 굴리기 | 0:08 |
| 4슬롯·정규 웨이브 | 약 0:25 |
| 자동 편성 | 0:31 |
| 자석 범위 I | 0:40 |
| 핵심 성능 I | 0:56 |
| 굴리기 속도 I | 1:19 |
| 스테이지 2 문 | 3:05 |
| 자석 속도 I | 3:33 |
| 전투 분야 해금 | 4:02 |
| 핵심 성능 II | 4:45 |
| 스테이지 3 문 | 7:50 |
| 코인 획득 I | 8:21 |
| 첫 환생 | 약 8:30 |

소비·전투 준비 조합별 첫 환생 범위:

```text
균형 소비: 7.96~13.41분
문 우선: 7.80~14.34분
트리 우선: 9.63~12.70분
```

첫 환생까지의 계산은 유지됩니다. 환생 후 코인과 문이 남으므로 이후 진행은 더 이상 동일한 경제 주기를 반복하지 않습니다.

## 5. 초기 코인 가격

```text
자동 굴리기 10
자동 편성 30
자석 범위 I 50
핵심 성능 I 100
굴리기 속도 I 160
자석 속도 I 220
전투 분야 해금 450
코인 획득 I 550
핵심 성능 II 650
편성 슬롯 5 1,200

스테이지 2 문 750
스테이지 3 문 3,200
```

문 가격은 계정당 한 번 지불합니다. 세부 좌표·연결은 `../reference/STAT_TREE_CATALOG.md`를 따릅니다.

---

## 6. 웨이브 템포

- 스테이지 1 일반 웨이브 약 10초
- 스테이지 1 보스 평균 약 16초
- 5웨이브 전체 약 56초
- 적이 모두 해소되면 즉시 다음 웨이브
- 새 스테이지 진입 시 목표 범위 상단
- 파밍 성장 뒤 목표 범위 하단
- 크게 성장하면 이전 스테이지를 몇 초 만에 압도 가능
- 플레이어 DPS에 맞춘 적 자동 강화 없음
- 후반 일반 웨이브 통상 상한 약 20초
- 후반 보스 통상 상한 약 40초

환생은 웨이브를 초기화하거나 전투를 멈추지 않습니다.

---

## 7. 스테이지 인플레이션과 문

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
```

표준 일반 몬스터:

```text
스테이지 1: HP 5
스테이지 4: HP 50
스테이지 7: HP 500
스테이지 10: HP 5,000
스테이지 13: HP 50,000
스테이지 15: HP 약 232,080
```

문 규칙:

- 코인으로 영구 개방
- 전투력 검사 없음
- 부족한 전투력으로 높은 스테이지 행운만 받고 복귀하는 전략 허용
- 낮은 스테이지 파밍 가능
- 환생 후 재잠금 없음

## 8. 환생과 스탯 토큰

### 첫 환생

```text
요구량: 7,000 Defense XP
```

### 실행

```text
Defense XP 요구량 충족
→ RebirthCount +1
→ 스탯 토큰 지급
→ Defense XP 0
→ 현재 전투 계속
```

유지:

- 코인
- 열린 문·텔레포터 목적지
- 현재 위치·스테이지·웨이브
- 타워·스탯·도감·합체·변종
- 굴림 카운터·포션·설정

### 토큰

- 영구 보유
- 미사용분 이월
- 플레이어가 원하는 스탯에 배분
- 환생 횟수만으로 자동 배율 지급 없음
- 환생당 지급량과 재분배 규칙은 미확정

행운 배분의 첫 잠정 계수:

```text
행운 토큰 1개
→ Compression +0.040
```

---

## 9. 행운 진행

잠정 공식:

```text
BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ 0.040 × AllocatedLuckTokens
+ TemporaryCompressionBonus
```

상한:

```text
일반 5.40
황금 5.65
다이아몬드 6.05
```

균형적인 행운 토큰 배분 시뮬레이션:

```text
13.5시간 최고 타워 누적 획득률: 약 3.01%
15시간: 약 4.66%
25시간: 약 17.06%
30시간: 약 22.71%
```

최고 타워는 메인 완주에 필요하지 않습니다.

## 10. 기능 등장 순서

```text
0~30분
- 자동 굴리기·자동 편성·자석·첫 환생

1~2시간
- 오프라인 코인·기초 타겟 설정

2~4시간
- 첫 변종·수동 합체

4~6시간
- 텔레포터·세부 편성·추가 변종

5~7시간
- V1 핵심 시스템 전체 해금

7~15시간
- 해금한 시스템을 조합해 후반 지역 공략
```

자동 합체는 만들지 않습니다.

---

## 11. 재접속

유지:

- 코인·Defense XP·환생 토큰
- 영구적으로 열린 문
- 마지막 활동 스테이지
- 타워·편성·스탯·설정

폐기:

- 현재 웨이브·몬스터·보스 체력
- 바닥 코인

재접속은 로비에서 시작하고 마지막 열린 스테이지로 빠른 복귀 버튼을 제공합니다.

---

## 12. 출시 범위

- 일반 굴리기 타워 최소 50종
- 역할별 약 8~10종
- 5개 지역·15개 스테이지
- 지역별 보스 계열과 최종 보스
- 변종 4개 공통 계열
- 수동 합체
- 코인 스탯 트리
- 환생 스탯 토큰 배분
- 오프라인 코인
- 희귀 타워 리더보드
- 설정·접근성

라이브 웨이브는 후속 콘텐츠입니다.

---

## 13. 핵심 원칙

- 공식 분모가 큰 타워는 반드시 더 강함
- 모든 굴림은 진행 가치를 가짐
- 높은 스테이지는 강한 인플레이션과 큰 보상
- 코인·문 진행은 영구 누적
- 환생은 XP를 토큰으로 바꾸는 선택
- 특정 극희귀 없이 V1 완주 가능
- 전투시간은 대기시간이 아니라 성장의 척도
- 자동 합체와 거래 없음
- 현재 행운 적용 확률 미표시

---

## 14. 남은 검증

- 환생당 토큰 지급량과 토큰 스탯 목록
- 두 번째 이후 환생 요구량
- 50종 확률표의 시간대별 최고 보유·편성 전투력 분포
- 지역별 문 가격과 실제 전투 데이터
- 후속 굴리기 속도 노드
- 빠른·중앙·느린 스테이지 15 도달 시뮬레이션
