## 요약

Tower RNG의 진행은 무료 굴리기, 자동 전투, 직접 코인 수집, 물리적 스테이지 문, 하나의 거대한 스탯 트리와 방어 경험치 환생으로 구성합니다.

스테이지 수치는 강하게 인플레이션합니다. 스테이지 1 표준 일반 몬스터의 체력은 5이며 스테이지 4에서는 50입니다. 높은 스테이지는 더 강한 적과 더 큰 코인·방어 경험치·행운을 제공합니다.

첫 환생은 약 7~15분을 목표로 하지만 이후 환생 요구량은 점차 증가합니다. 같은 시간 간격으로 계속 환생하는 구조가 아닙니다.

---

## 1. 기본 진행 흐름

```text
첫 수동 굴리기
→ 자동 전투와 코인 수집
→ 자동 굴리기·자동 편성
→ 5웨이브와 스테이지 보스
→ 거대 스탯 트리 성장
→ 코인으로 다음 문 개방
→ 높은 스테이지의 수치·보상·행운
→ 전투로 Defense XP 축적
→ 환생
→ 영구 코인·행운 성장
→ 다시 진행
```

코인은 문과 스탯에 사용합니다. 환생에는 코인을 요구하지 않습니다.

---

## 2. 전역 타워 풀과 확률

- 첫 스테이지에서도 모든 일반 타워 등장 가능
- 공식 기본 확률은 `1 / N`
- 분모는 수조 이상으로 확장 가능
- 공식 기본 확률만 표시
- 현재 행운 적용 확률은 표시하지 않음
- 높은 스테이지는 타워 종류가 아니라 행운을 증가
- 기존 희귀 타워 공식 확률은 신규 콘텐츠 때문에 몰래 낮추지 않음

예외:

- 해금 전 변종
- 이벤트·한정 풀
- 합체 전용 타워

세부 계약은 `RNG_PROBABILITY.md`를 따릅니다.

## 3. 첫 15분

### PRG-001: 초기 시간표

```text
0~1분
- 첫 굴리기
- 첫 전투
- 첫 코인
- 자동 굴리기

1~2분
- 자동 편성
- 기본 자석

2~5분
- 기본 전투·굴리기 노드
- 스테이지 2 문

5~10분
- 스테이지 3 또는 추가 영구 노드
- 여러 보스 주기
- Defense XP 진행 확인

7~15분
- 첫 환생 가능
```

강제 타이머가 아니라 정상 플레이 목표입니다.

### PRG-002: 목표 시간층

- 수 초: 다음 공격·굴림·코인
- 약 10초 이상: 다음 웨이브
- 약 1분: 보스와 가까운 구매
- 수 분: 문·분야 해금·Defense XP 진행
- 장기: 극희귀 타워·변종·합체·환생·리더보드

---

## 4. 스테이지 인플레이션

### PRG-003: 기하급수 성장

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
```

표준 일반 몬스터 예:

```text
스테이지 1: HP 5
스테이지 4: HP 50
스테이지 7: HP 500
스테이지 10: HP 5,000
스테이지 13: HP 50,000
```

보상도 함께 증가하며 높은 스테이지가 성공적인 파밍에서 더 효율적이어야 합니다.

### PRG-004: 성장감 보호

- 플레이어 전투력에 맞춰 적이 자동 강화되지 않음
- 강한 희귀 타워를 얻으면 이전 스테이지를 압도할 수 있음
- 약하면 이전 스테이지에서 스탯과 타워를 성장
- 난이도와 보상은 다음 스테이지로 이동해 선택

---

## 5. 환생 주기

### PRG-005: 첫 환생

약 7~15분 목표. 첫 환생 전 자동 시스템, 문, 보스, 스탯과 Defense XP를 경험합니다.

### PRG-006: 이후 환생

- Defense XP 요구량 증가
- 두 번째 환생은 약 15~25분 목표
- 초기 여러 회는 약 20~40분 중심
- 중기 이후 점진적으로 증가
- 고정 대기시간·일일 제한 없음
- 초과 Defense XP는 기본 이월 없음

### PRG-007: 환생 보상

- 영구 코인 성장
- 영구 행운 성장
- 일부 트리 구역 조건

코인·문·Defense XP는 초기화하지만 타워·스탯·도감·합체·변종·포션·설정은 유지합니다.

## 6. 기능 등장 순서

### 극초반

- 첫 굴리기
- 직접 코인 수집
- 자동 굴리기
- 자동 편성
- 기본 자석
- 첫 보스
- 첫 문

### 초반

- 전투·굴리기·편성 노드
- 오프라인 코인
- Defense XP와 첫 환생
- 분야 입구 해금

### 중반

- 역할·타워별 타겟 설정
- 변종 계열
- 수동 합체
- 텔레포터
- 마지막 활동 스테이지 빠른 복귀

### 후반

- 강한 자석과 수집 편의
- 세밀한 편성·타겟 기능
- 보스 후속 확장
- 라이브 웨이브

자동 합체는 만들지 않습니다.

## 7. 재접속 진행

- 현재 환생의 열린 문 유지
- 코인·Defense XP 유지
- 마지막 활동 스테이지 ID 저장
- 웨이브·몬스터·보스 체력·바닥 코인 폐기
- 재접속 위치는 로비
- 열린 마지막 스테이지로 빠른 복귀 버튼 제공

세부 계약은 `../technical/STATE_LIFECYCLE.md`를 따릅니다.

## 8. 출시 범위

- 일반 굴리기 타워 최소 50종
- 역할별 약 8~10종
- 5개 지역·15개 스테이지
- 지역별 초·중반 보스 계열과 최종 보스
- 변종 4개 공통 계열
- 수동 합체
- 거대 스탯 트리
- 오프라인 코인
- 희귀 타워 리더보드
- 설정·접근성

라이브 웨이브는 후속 콘텐츠로 유지합니다.

---

## 9. 핵심 원칙

- 공식 분모가 큰 타워는 반드시 더 강함
- 모든 굴림은 결과와 진행 가치를 가짐
- 높은 스테이지는 강한 인플레이션과 큰 보상
- 환생은 실제 전투 진행으로 획득
- 코인 소비와 환생 진행을 분리
- 자동 합체와 거래 없음
- 현재 행운 적용 확률 미표시
- UI·공격·피격은 강하게 반응하되 일반 화면 흔들림은 사용하지 않음

- 문·스탯 가격
