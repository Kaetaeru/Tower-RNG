## 요약

Tower RNG의 진행은 무료 굴리기, 자동 전투, 직접 코인 수집, 물리적 스테이지 문, 하나의 거대한 스탯 트리와 방어 경험치 환생으로 구성합니다.

첫 수직 슬라이스의 경제 기준:

```text
스테이지 1 StageCoinUnit: 1
보스 코인·Defense XP 보정: 1.15
스테이지 2 문: 750코인
스테이지 3 문: 3,200코인
첫 환생: 7,000 Defense XP
```

첫 환생은 소비 성향과 전투 준비에 따라 약 `7.80~14.34분`으로 검증되었습니다. 이후 환생 요구량은 점차 증가합니다.

---

## 1. 기본 진행 흐름

```text
첫 수동 굴리기
→ 최초 슬라임 전투와 첫 코인
→ 자동 굴리기
→ 세 번 더 굴려 4슬롯 완성
→ 정규 5웨이브 시작
→ 자동 편성·자석·전투 성장
→ 코인으로 다음 문 개방
→ 높은 스테이지의 수치·보상·행운
→ 전투로 Defense XP 축적
→ 환생
→ 영구 코인·행운 성장
→ 다시 진행
```

코인은 문과 스탯에 사용합니다. 환생에는 코인을 요구하지 않습니다.

---

## 2. 전역 타워 풀과 확률

- 첫 스테이지에서도 모든 일반 타워 등장 가능
- 공식 기본 확률은 `1 / N`
- 분모는 수조 이상으로 확장 가능
- 공식 기본 확률만 표시
- 현재 행운 적용 확률은 표시하지 않음
- 높은 스테이지는 타워 종류가 아니라 행운을 증가
- 기존 희귀 타워 공식 확률은 신규 콘텐츠 때문에 몰래 낮추지 않음

예외:

- 해금 전 변종
- 이벤트·한정 풀
- 합체 전용 타워

## 3. 최초 25초

### PRG-001: 첫 전투 안전성

정규 스테이지 1 웨이브는 4슬롯 기준이므로 최초 계정에서 한 번만 다음 준비를 사용합니다.

```text
첫 타워 획득·자동 배치
→ HP 5 초원 슬라임 1마리
→ 정상 보상 코인 10·Defense XP 10
→ 자동 굴리기 10코인 구매
→ 기본 4초 간격으로 세 번 더 굴림
→ 빈 시작 슬롯 자동 채움
→ 약 25초에 정규 웨이브 1 시작
```

튜토리얼용 적 약화와 보너스 재화는 사용하지 않습니다. 환생·재접속 시 반복하지 않습니다.

## 4. 첫 15분

### PRG-002: 균형 소비 기준 경로

| 목표 | 기준 시간 |
|---|---:|
| 자동 굴리기 | 0:08 |
| 4슬롯 완성·정규 웨이브 시작 | 약 0:25 |
| 자동 편성 | 0:31 |
| 자석 범위 I | 0:40 |
| 핵심 성능 I | 0:56 |
| 굴리기 속도 I | 1:19 |
| 스테이지 2 문 | 3:05 |
| 자석 속도 I | 3:33 |
| 전투 분야 해금 | 4:02 |
| 핵심 성능 II | 4:45 |
| 스테이지 3 문 | 7:50 |
| 코인 획득 I | 8:21 |
| 첫 환생 | 약 8:30 |

강제 타이머가 아니라 정상 플레이 목표입니다.

### PRG-003: 소비 성향별 범위

```text
균형 소비: 7.96~13.41분
문 우선: 7.80~14.34분
트리 우선: 9.63~12.70분
```

스테이지 1만 파밍해도 첫 환생이 가능하며, 강한 타워를 얻어 상위 스테이지를 실제로 방어할 수 있으면 더 빨라집니다.

### PRG-004: 목표 시간층

- 수 초: 다음 공격·굴림·코인
- 10~30초: 다음 초기 구매
- 약 1분: 보스 주기와 굴리기 속도 성장
- 수 분: 문·분야 해금·Defense XP 진행
- 장기: 극희귀 타워·변종·합체·환생·리더보드

## 5. 첫 주기 가격

중심 스탯 트리:

```text
자동 굴리기 10
자동 편성 30
자석 범위 I 50
핵심 성능 I 100
굴리기 속도 I 160
자석 속도 I 220
전투 분야 해금 450
핵심 성능 II 650
코인 획득 I 550
편성 슬롯 5 1,200
```

문:

```text
스테이지 2 750
스테이지 3 3,200
```

세부 좌표·연결·효과는 `../reference/STAT_TREE_CATALOG.md`를 따릅니다.

## 6. 웨이브 템포와 성장감

웨이브 시간은 고정 타이머가 아니라 적정 편성의 목표 처리시간입니다.

- 스테이지 1 일반 웨이브 약 10초
- 스테이지 1 보스 웨이브 평균 16초
- 전체 5웨이브 평균 약 56초
- 적이 모두 해소되면 즉시 다음 웨이브
- 새 스테이지 진입 상태에서는 목표 범위 상단
- 해당 스테이지를 파밍하며 성장하면 목표 범위 하단
- 크게 성장하면 이전 스테이지를 몇 초 만에 압도 가능
- 플레이어 DPS에 맞춘 자동 적 강화 없음

후반의 통상 상한은 일반 웨이브 약 20초, 보스 약 40초를 기준으로 합니다. 세부 철학은 `WAVE_PACING.md`를 따릅니다.

## 7. 스테이지 인플레이션

### PRG-005: 기하급수 성장

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
```

표준 일반 몬스터:

```text
스테이지 1: HP 5
스테이지 4: HP 50
스테이지 7: HP 500
스테이지 10: HP 5,000
스테이지 13: HP 50,000
```

보상도 함께 증가하며 높은 스테이지가 성공적인 파밍에서 더 효율적이어야 합니다.

### PRG-006: 문과 전투 준비 분리

- 문은 전투력 검사 없이 코인으로 개방
- 전투력이 부족해도 높은 스테이지 행운을 받을 수 있음
- 낮은 스테이지로 돌아와 파밍 가능
- 강한 희귀 타워를 얻으면 이전 스테이지를 압도 가능
- 플레이어 전투력에 맞춰 적이 자동 강화되지 않음

---

## 8. 환생 주기

### PRG-007: 첫 환생

```text
요구량: 7,000 Defense XP
```

첫 경제 버전 공식:

```text
Defense XP
= 처치 SpawnCost
× StageRewardScale
× BossModifier
```

보스 본체의 BossModifier는 1.15이며 별도 웨이브 완료 XP 보너스는 없습니다.

### PRG-008: 이후 환생

- 두 번째 환생 약 15~25분 목표
- 초기 여러 회 약 20~40분 중심
- 중기 이후 점진적으로 증가
- 고정 대기시간·일일 제한 없음
- 초과 Defense XP 기본 이월 없음

초기 공식 후보:

```text
RequiredDefenseXP(r) = 7,000 × (r + 1)^1.65
```

첫 항만 검증 완료이며 지수는 두 번째 주기 시뮬레이션 전까지 Proposed입니다.

### PRG-009: 환생 보상

- 영구 코인 성장
- 영구 행운 성장
- 일부 트리 구역 조건

코인·문·Defense XP는 초기화하지만 타워·스탯·도감·합체·변종·포션·설정·최초 튜토리얼 완료 상태는 유지합니다.

## 9. 기능 등장 순서

### 극초반

- 첫 굴리기와 최초 슬라임
- 직접 코인 수집
- 자동 굴리기
- 빈 슬롯 자동 채움
- 자동 편성
- 기본 자석
- 첫 보스
- 첫 문

### 초반

- 전투·굴리기·편성 노드
- 첫 분야 입구
- 오프라인 코인
- Defense XP와 첫 환생

### 중반

- 역할·타워별 타겟 설정
- 변종 계열
- 수동 합체
- 텔레포터
- 마지막 활동 스테이지 빠른 복귀

### 후반

- 강한 자석과 수집 편의
- 세밀한 편성·타겟 기능
- 보스 후속 확장
- 라이브 웨이브

자동 합체는 만들지 않습니다.

## 10. 재접속 진행

- 현재 환생의 열린 문 유지
- 코인·Defense XP 유지
- 최초 튜토리얼 완료 상태 유지
- 빈 슬롯 자동 채움 설정 유지
- 마지막 활동 스테이지 ID 저장
- 웨이브·몬스터·보스 체력·바닥 코인 폐기
- 재접속 위치는 로비
- 열린 마지막 스테이지로 빠른 복귀 버튼 제공

## 11. 출시 범위

- 일반 굴리기 타워 최소 50종
- 역할별 약 8~10종
- 5개 지역·15개 스테이지
- 지역별 초·중반 보스 계열과 최종 보스
- 변종 4개 공통 계열
- 수동 합체
- 거대 스탯 트리
- 오프라인 코인
- 희귀 타워 리더보드
- 설정·접근성

라이브 웨이브는 후속 콘텐츠로 유지합니다.

---

## 12. 핵심 원칙

- 공식 분모가 큰 타워는 반드시 더 강함
- 모든 굴림은 결과와 진행 가치를 가짐
- 높은 스테이지는 강한 인플레이션과 큰 보상
- 환생은 실제 전투 진행으로 획득
- 코인 소비와 환생 진행을 분리
- 약한 운에서도 15분 안에 첫 환생 가능
- 전투시간은 대기시간이 아니라 성장의 척도
- 자동 합체와 거래 없음
- 현재 행운 적용 확률 미표시
- UI·공격·피격은 강하게 반응하되 일반 화면 흔들림은 사용하지 않음

- 두 번째 환생 요구량
