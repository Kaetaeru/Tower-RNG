## 요약

Tower RNG의 진행은 무료 자동 굴리기, 빠른 5웨이브 자동 전투, 코인 직접 수집, 하나의 거대한 영구 스탯 트리와 짧고 반복적인 환생을 중심으로 구성합니다.

첫 환생은 신규 계정 기준 약 7~10분을 목표로 합니다. 일반 웨이브는 권장 전투력 기준 약 10초, 보스가 포함된 한 주기는 약 55~70초를 목표로 해 항상 가까운 목표가 보이게 합니다.

---

## 1. 기본 진행 흐름

```text
첫 수동 굴리기
→ 자동 전투와 코인 수집
→ 자동 굴리기·자동 편성 해금
→ 10초 웨이브와 5웨이브 보스 주기
→ 거대 스탯 트리 성장
→ 물리적인 스테이지 문 구매
→ 더 높은 코인 효율과 행운
→ 환생
→ 영구 코인·행운 배율 증가
→ 이전 구간을 더 빠르게 재진행
```

굴리기와 전투는 별도 모드가 아닙니다. 플레이어는 월드를 이동하고 코인을 수집하며 성장 결정을 내립니다.

---

## 2. 전역 타워 풀

### PRG-001: 기본 타워의 전역 풀

- 첫 스테이지에서도 모든 일반 타워가 이론적으로 등장 가능
- 높은 지역과 스테이지는 타워 종류보다 굴리기 행운을 높임
- 지역 이동과 환생으로 일반 타워 풀 초기화 없음
- 실제 확률은 `1 / N`으로 표시

예외:

- 스탯 트리로 해금하는 변종 계열
- 이벤트·한정 별도 풀
- 합체 전용 상위 타워
- 기타 명시된 비굴리기 획득 타워

---

## 3. 첫 10분

### PRG-002: 극초반 목표 시간표

```text
0~1분
- 첫 굴리기
- 첫 타워 전투
- 첫 코인 수집
- 자동 굴리기

1~2분
- 자동 편성
- 기본 자석

2~4분
- 기본 전투·굴리기 노드
- 스테이지 2 문

4~7분
- 스테이지 3 또는 추가 영구 노드
- 여러 번의 보스 주기

7~10분
- 첫 환생 가능
```

이는 정상 플레이 기준 목표이며 강제 시간 제한이 아닙니다.

### PRG-003: 여러 시간층의 목표

- 수 초: 다음 굴림, 공격, 코인
- 약 10초: 다음 웨이브
- 약 1분: 보스, 가까운 스탯
- 수 분: 문, 분야 해금, 환생
- 장기: 극희귀 타워, 변종, 합체, 리더보드

다음 목표가 보이지 않는 긴 무반응 구간을 만들지 않습니다.

---

## 4. 환생 주기

### PRG-004: 첫 환생 목표

신규 계정의 첫 환생은 약 7~10분을 목표로 합니다.

첫 환생 전 최소 경험:

- 수동·자동 굴리기
- 자동 전투와 코인 수집
- 자동 편성
- 기본 스탯 트리 구매
- 잠긴 스테이지 문
- 5웨이브와 보스
- 환생 유지·초기화 확인

합체와 변종은 첫 환생 전에 강제하지 않습니다.

### PRG-005: 반복 환생 빈도

- 한 세션에서 여러 번 환생 가능
- 일반 환생은 약 7~15분 범위를 중심으로 조정
- 영구 노드나 높은 스테이지를 위해 환생을 미룰 수 있음
- 한 번의 수 시간 환생 주기를 핵심 진행으로 강요하지 않음

---

## 5. 무한 환생

### PRG-006: 완만한 성장

- 코인 배율은 계속 증가하지만 추가 증가량이 점차 완만해짐
- 행운 배율은 코인보다 더 느리게 증가
- 주요 기능 해금은 유한한 환생 구간에 집중
- 이후 환생은 장기 배율과 기록 성장

### PRG-007: 비용과 보상 조정

환생 요구 코인은 영구 성장으로 빨라지는 진행을 상쇄하되, 일반 환생 주기가 지나치게 짧거나 길어지지 않게 조정합니다.

정확한 경제 기준은 `ECONOMY_PACING.md`에서 관리합니다.

## 6. 기능 등장 순서

### 극초반

- 첫 굴리기
- 코인 직접 수집
- 자동 굴리기
- 자동 편성
- 기본 자석
- 첫 보스 주기
- 첫 스테이지 문

### 초반 반복 진행

- 거대 트리 분야 해금
- 전체·역할 편성 슬롯
- 성능·공격속도·치명타
- 영구 행운과 굴리기 속도
- 오프라인 코인
- 첫 환생

### 중반

- 역할별·타워별 타겟 설정
- 변종 계열
- 합체
- 텔레포터

### 후반

- 자동 합체
- 강한 자석과 수집 자동화
- 세밀한 편성·타겟 기능
- 라이브 웨이브

스테이지 보스는 별도 해금 기능이 아니라 모든 스테이지의 기본 웨이브 구조입니다.

## 7. 출시 콘텐츠 범위

- 일반 굴리기 타워 최소 50종
- 여섯 역할마다 약 8~10종
- 변종과 합체 전용 타워는 추가 콘텐츠
- 지역별 초·중반 보스 계열과 최종 보스
- 5개 지역, 15개 스테이지

실제 타워·몬스터·노드는 reference 카탈로그에서 작성합니다.

---

## 8. 밸런스 원칙

- 현재 스테이지 행운과 코인 효율 사이의 선택 허용
- 어려운 높은 스테이지에서 행운만 받는 행동도 허용
- 오프라인 코인은 접속 플레이를 대체하지 않는 보조 수익
- 환생 직후 이전 구간을 눈에 띄게 빠르게 통과
- 새 타워는 기존 영구 성장 즉시 적용
- 지역 진행 때문에 일반 타워가 잠기지 않음
- 보스 보상은 가치 있지만 일반 웨이브를 무의미하게 만들지 않음
- 과금 상품을 전제로 무료 경제를 늦추지 않음
- 모든 입력·공격·피격·성장에는 명확한 감각 피드백 제공

---

## 9. 미확정 사항

- 환생 요구 코인과 배율 공식
- 일반 환생 주기의 최종 시간
- 시스템별 정확한 환생 요구 횟수
- 일반 50종의 실제 확률 분포
- 스테이지별 예산과 코인 곡선
- 이벤트·한정 풀 운영 방식
