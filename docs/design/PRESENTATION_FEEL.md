## 요약

Tower RNG는 자동 전투와 반복 굴리기가 중심이므로 정적으로 느껴져서는 안 됩니다. UI 클릭, 굴리기, 코인 획득, 타워 공격, 몬스터 피격, 보스와 환생까지 모든 핵심 행동에 즉각적이고 과장된 반응을 제공합니다.

타격감은 카메라 흔들림이 아니라 모델의 큰 움직임, 준비 동작, 반동, 피격 반응, 방향성 있는 파티클과 음향을 중심으로 만듭니다. 일반 공격과 UI 클릭에는 화면 흔들림을 사용하지 않으며 보스급 사건에만 제한적으로 허용합니다.

---

## 1. 필수 원칙

### PRS-001: 모든 핵심 행동은 반응

다음은 시각·움직임·음향 중 둘 이상을 가집니다.

- 버튼·토글
- 스탯 구매
- 문·텔레포트
- 굴리기·희귀 획득
- 편성·수동 합체
- 코인 드롭·흡입
- 공격 준비·판정·명중
- 피격·처치
- 웨이브·보스
- 환생

숫자나 텍스트만 바뀌는 것으로 완료 처리하지 않습니다.

### PRS-002: 과장된 모델 움직임

- 버튼 압축과 오버슈트
- 카드 확대·기울기·광택
- 공격 전 큰 역동작
- 발사·타격 시 무기·몸체 반동
- 피격 순간 압축·튕김·형태 변화
- 코인의 곡선 흡입
- 희귀 결과의 큰 화면 공간 사용

현실적 미세 움직임보다 읽기 쉬운 실루엣 변화를 우선합니다.

### PRS-003: 강약 계층

```text
Micro
- 빠른 반복 입력·연속 공격

Standard
- 일반 구매·일반 공격

Heavy
- 강공격·치명타·큰 합체

Heroic
- 보스 등장·처치·극희귀·환생
```

모든 순간을 최대 강도로 표현하지 않습니다.

## 2. UI 타격감

### PRS-004: 클릭

- 즉시 눌림 축소
- 색·외곽선·광택 변화
- 짧은 클릭음
- 빠른 복원과 오버슈트
- 지원 기기의 선택적 햅틱
- 화면 흔들림 없음

서버 승인 전 입력 반응은 즉시 보여 주고, 성공·실패는 응답 후 별도로 표현합니다.

### PRS-005: 상태 변화

- 토글 손잡이 이동과 반동
- 구매 노드 팽창·연결선 점등
- 문 진동·파편·광원
- 편성 카드 교체
- 합체 재료 수렴·결과 등장
- HUD 수치의 짧은 반동

### PRS-006: 반복 피로

- 일반 반응은 짧게
- 희귀·보스·환생만 크게
- 반복 연출 축약 가능
- 정보 확인을 늦추지 않음

---

## 3. 전투 타격감

### PRS-007: 세 단계

```text
준비
- 압축·충전·조준·역동작

판정
- 접촉·발사·광선·폭발·충격파

명중
- 피격 포즈·반동·섬광·음향·피해 숫자
```

명중 시점을 분명히 읽을 수 있어야 합니다.

### PRS-008: 일반 카메라 흔들림 금지

다음에는 화면 흔들림을 사용하지 않습니다.

- 일반 공격
- 연속 공격
- 일반 치명타
- 일반 몬스터 처치
- 코인 획득
- UI 입력

타격감은 공격자와 피격 대상의 움직임으로 전달합니다.

### PRS-009: 제한된 보스 카메라

허용 가능:

- 보스 등장
- 지역 최종 보스 처치
- 일부 보스 핵심 행동
- 환생·극희귀의 선택적 대형 연출

- 기본 강도 Low
- 설정에서 Off 가능
- 긴 강제 컷신 없음
- 조작을 빼앗는 카메라 고정 없음

### PRS-010: 피격·처치

- 짧은 Overlay·압축·흔들림
- 진행 방향을 잃지 않는 반응
- 상태 효과별 외형
- 처치 시 붕괴·분해·튕김·폭발
- 보스 처치 강화 마무리

서버 경로·판정을 방해하지 않습니다.

---

## 4. 굴리기·보상

### PRS-011: 일반 굴리기

- 빠른 결과 카드
- 공식 기본 희귀도에 따른 색·음향·움직임
- 중복 수량 증가 체감
- 자동 굴리기 중 화면을 가리지 않음

### PRS-012: 희귀 결과

- 다른 예고와 모델 강조
- 공식 기본 `1 / N` 표시
- 현재 행운 적용 확률은 표시하지 않음
- 건너뛰기·축약 설정
- 전투 완전 정지 없음

### PRS-013: 코인

```text
사망
→ 코인 분출
→ 병합
→ 자석 가속·곡선 흡입
→ HUD 반동·음향
```

연속 획득은 음높이·리듬으로 상승감을 줄 수 있습니다.

---

## 5. 웨이브·보스·환생

### PRS-014: 웨이브 연결

- 완료 짧은 강조
- 다음 번호 빠른 진입
- 즉시 생성
- 5웨이브 보스 예고 강화

### PRS-015: 보스

- 짧은 경고
- 이름·체력 HUD 강한 진입
- 환경·음향 반응
- 일반 몬스터보다 큰 실루엣·피격·처치
- 카메라 연출은 설정 준수

### PRS-016: 환생

- 초기화보다 영구 성장 강조
- Defense XP 충족과 영구 배율 상승 표시
- 다음 진행이 빨라질 것을 수치·움직임으로 전달

---

## 6. 가독성·성능·접근성

### PRS-017: 동시성 우선순위

```text
1. 내 UI 성공·실패
2. 내 타워 강공격·명중
3. 보스 경고·상태
4. 일반 공격 장식
5. 다른 플레이어 장식
```

- 같은 대상의 빠른 피해 숫자·음향 병합
- 화면 밖 효과 축약
- 다른 플레이어 효과 축약
- 보스 연출 중 일반 장식 강도 감소 가능

### PRS-018: 설정

사용자가 줄일 수 있는 항목:

- 파티클
- 다른 플레이어 효과
- 피해 숫자
- 명중 섬광
- Trail·잔상
- 희귀 연출
- UI 움직임
- 보스 화면 흔들림
- FOV·프레이밍
- 햅틱·진동

세부값은 `SETTINGS.md`를 따릅니다.

### PRS-019: 저사양

- 파티클·잔상·조명 축소
- 다른 플레이어 표시 축소
- 핵심 명중 프레임·음향·UI 반응 유지
- 자동 성능 조절 지원

타격감은 파티클 수가 아니라 타이밍과 형태 변화의 조합으로 만듭니다.

---

## 7. 완료 기준

- 입력 즉시 반응하는가
- 준비·판정·명중이 구분되는가
- 더 강한 행동이 더 강하게 느껴지는가
- 일반 공격이 카메라 흔들림에 의존하지 않는가
- 반복 흐름을 막지 않는가
- 설정을 낮춰도 핵심 정보가 남는가
- 저사양에서 핵심 피드백이 유지되는가

조건을 충족하지 못하면 기능만 작동해도 표현 측면에서 완료가 아닙니다.

---

## 8. 미확정 사항

- 공통 UI 애니메이션 시간 토큰
- Micro·Standard·Heavy·Heroic 데이터 형식
- 보스 흔들림 정확한 강도·지속
- 피해 숫자·음향 병합 시간창
- 모바일 햅틱 범위
- 단계별 효과 예산
