## 요약

Tower RNG는 자동 전투와 반복 굴리기가 중심이므로 화면이 정적으로 느껴져서는 안 됩니다. UI 클릭, 굴리기, 코인 획득, 타워 공격, 몬스터 피격과 보스 출현까지 모든 핵심 행동에 즉각적이고 과장된 반응을 제공합니다.

타격감과 반응성은 장식이 아니라 핵심 게임 경험입니다. 기능이 정상 작동하더라도 입력과 결과가 밋밋하게 표현되면 완성된 기능으로 보지 않습니다.

---

## 1. 핵심 철학

### PRS-001: 모든 핵심 행동은 반응한다

다음 행동은 반드시 시각·음향·움직임 중 둘 이상의 피드백을 가집니다.

- 버튼 클릭과 토글 변경
- 스탯 노드 구매
- 문 해금과 텔레포트
- 굴리기와 희귀 타워 획득
- 자동 편성 변경
- 코인 드롭·흡입·획득
- 타워의 공격 준비·발사·명중
- 몬스터 피격·처치
- 웨이브 시작과 보스 출현
- 환생 실행

단순히 숫자나 텍스트만 바뀌는 것으로 완료 처리하지 않습니다.

### PRS-002: 과장된 움직임

현실적인 미세 움직임보다 읽기 쉽고 만족감 있는 과장된 움직임을 우선합니다.

허용되는 표현:

- 버튼 눌림 시 축소 후 튕겨 오르는 반동
- 카드 선택 시 짧은 확대·기울기·광택 이동
- 공격 준비 시 큰 실루엣 변화와 역동작
- 명중 순간의 순간 정지, 반동, 흔들림과 확대
- 코인이 플레이어에게 곡선을 그리며 빠르게 흡입
- 희귀 획득 시 화면 공간을 크게 사용하는 연출

과장은 판정 정보를 가리거나 조작을 방해하지 않는 범위에서 사용합니다.

### PRS-003: 결과보다 먼저 준비를 읽게 한다

강한 행동은 준비 동작에서도 강함이 느껴져야 합니다.

```text
예고
→ 준비와 힘 축적
→ 판정
→ 강한 명중 반응
→ 짧은 마무리 반동
```

모든 공격을 같은 크기의 번쩍임으로 처리하지 않습니다. 타워의 역할·희귀도·행동 루틴에 따라 리듬과 무게를 구분합니다.

## 2. UI 타격감

### PRS-004: 클릭 피드백

모든 주요 버튼은 입력 즉시 반응합니다.

기본 피드백 조합:

- 눌림 축소
- 빠른 복원 또는 오버슈트
- 테두리·광택·색상 변화
- 짧은 클릭음
- 진동 지원 기기에서는 선택적 햅틱

서버 응답을 기다려야 하는 구매도 입력 반응 자체는 즉시 보여 줍니다. 다만 성공 연출은 서버 승인 뒤 재생합니다.

### PRS-005: 상태 변화의 물리적 표현

ON/OFF, 구매, 잠금 해제와 편성 교체는 텍스트만 바꾸지 않습니다.

예:

- 토글 손잡이가 힘 있게 이동하고 끝에서 짧게 반동
- 구매한 노드가 중심에서 빛나며 연결선으로 에너지가 전달
- 잠긴 문이 진동·파편·광원과 함께 열림
- 편성 카드가 기존 위치에서 빠지고 새 카드가 자리로 튕겨 들어옴

### PRS-006: 반복 피로 방지

반복 클릭이 많은 화면은 피드백을 유지하되 지나치게 긴 연출을 강제하지 않습니다.

- 짧고 빠른 기본 반응
- 중요한 구매와 희귀 결과만 큰 연출
- 반복 작업은 애니메이션 속도 증가 또는 축약 가능
- 핵심 정보 확인을 늦추지 않음

## 3. 전투 타격감

### PRS-007: 공격의 세 단계

각 공격은 가능한 범위에서 다음을 구분합니다.

```text
준비 반응
- 역동작, 압축, 충전, 조준

판정 반응
- 섬광, 검기, 탄환, 충격파, 화면·모델 반동

명중 반응
- 몬스터 피격 포즈, 순간 강조, 피해 숫자, 효과음
```

피해 판정 시점과 시각 연출은 행동 문법에 맞추되, 명중 순간을 플레이어가 명확히 인식할 수 있어야 합니다.

### PRS-008: 무게 등급

공격은 최소한 가벼움·보통·강함·결정타 수준의 표현 강도를 가질 수 있습니다.

영향 요소:

- 타워 행동 루틴과 공격 주기
- 단일 타격 피해 비중
- 치명타
- 보스 대상 특화
- 희귀도와 고유 확장

빠른 연속 공격은 작은 반응을 자주 제공하고, 느린 강공격은 큰 준비와 큰 명중 반응을 제공합니다.

### PRS-009: 피격과 처치

몬스터는 피해 숫자만 띄우고 그대로 이동하지 않습니다.

가능한 피드백:

- 짧은 피격 Overlay
- 진행 방향을 유지하는 범위의 흔들림·압축
- 상태 효과별 명확한 외형
- 처치 시 형태 붕괴·튕김·분해·폭발
- 보스 처치 시 일반 몬스터보다 큰 마무리

피격 반응이 경로 이동과 서버 판정을 방해해서는 안 됩니다.

---

## 4. 굴리기와 보상

### PRS-010: 굴리기 리듬

일반 굴리기는 짧고 반복 가능한 만족감을 제공합니다.

- 결과 카드의 빠른 등장
- 확률에 따른 색·음향·움직임 단계
- 중복도 수량 증가와 진행 기여가 느껴지는 반응
- 자동 굴리기 중 화면을 과도하게 가리지 않음

### PRS-011: 희귀 결과

희귀 결과는 확실히 크게 표현합니다.

- 일반 굴림과 다른 예고
- 강한 화면·음향 변화
- 타워 실루엣 또는 모델 강조
- 실제 `1 / N` 확률 표시
- 건너뛰기와 자동 축약 설정 지원

희귀 연출은 전투와 코인 수집을 완전히 정지시키지 않습니다.

### PRS-012: 코인 수집

코인은 단순 접촉 삭제가 아니라 수집 행동 자체가 만족스럽게 보여야 합니다.

- 획득 범위 진입 시 빠른 가속
- 플레이어 방향으로 곡선 이동
- 연속 획득 시 음높이 또는 리듬 상승
- 큰 묶음은 더 큰 수치·효과
- HUD 코인 값이 증가할 때 짧은 반동

---

## 5. 웨이브·보스·환생

### PRS-013: 빠른 웨이브 연결

웨이브 완료 후 긴 정적 시간을 만들지 않습니다.

- 완료 순간 짧은 강조
- 다음 웨이브 번호가 빠르게 진입
- 즉시 다음 생성 시작
- 5웨이브에는 보스 예고를 강화

### PRS-014: 보스 출현

보스는 일반 몬스터 한 마리가 커진 것처럼 등장하지 않습니다.

- 출현 전 짧은 경고
- 스테이지 환경·UI·음향 변화
- 이름과 체력 표시의 강한 진입
- 모델 등장 동작 또는 환경 반응

### PRS-015: 환생

환생은 초기화보다 영구 성장 획득이 중심으로 느껴져야 합니다.

- 사라지는 코인·문보다 상승하는 영구 배율을 강조
- 중심 스탯 트리 또는 계정에 힘이 축적되는 연출
- 다음 진행이 빨라질 것이라는 명확한 수치·동작 피드백

---

## 6. 가독성·접근성·성능

### PRS-016: 과장과 가독성의 균형

- 판정 범위와 대상이 보이지 않을 정도로 화면을 덮지 않음
- 중요한 UI 숫자를 흔들어 읽기 어렵게 만들지 않음
- 같은 순간 여러 효과가 겹치면 중요도에 따라 축약
- 다른 플레이어 효과는 기본적으로 간소화 가능

### PRS-017: 강도 설정

사용자가 다음을 줄일 수 있게 설계합니다.

- 화면 흔들림
- 섬광 강도
- 파티클 밀도
- 피해 숫자
- 진동·햅틱
- 희귀 연출 길이

설정을 낮춰도 입력·명중·보상 발생 여부는 명확히 전달해야 합니다.

### PRS-018: 성능 단계

타격감은 많은 파티클 수 자체가 아니라 타이밍·형태 변화·음향·반동의 조합으로 만듭니다.

저사양에서는:

- 파티클 수 축소
- 잔상 길이 축소
- 다른 플레이어 효과 축소
- 핵심 명중 프레임과 UI 반응 유지

---

## 7. 완료 기준

다음 조건을 만족하지 못하면 UI 또는 전투 기능을 표현 측면에서 완료로 보지 않습니다.

- 입력 즉시 반응하는가
- 행동 준비와 결과가 구분되는가
- 명중 순간을 알아볼 수 있는가
- 강한 행동이 더 강하게 느껴지는가
- 반복 사용해도 흐름을 막지 않는가
- 저사양·접근성 설정에서도 핵심 피드백이 남는가

---

## 8. 미확정 사항

- 공통 UI 애니메이션 토큰과 시간값
- 전투 무게 등급의 정확한 데이터 형식
- 카메라 흔들림과 순간 정지의 기본 강도
- 모바일 햅틱 지원 범위
- 접근성 설정의 최종 단계
- 저사양 효과 예산
