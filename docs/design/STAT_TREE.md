## 요약

계정 성장에는 서로 다른 두 배분 체계가 있습니다.

```text
코인 스탯 트리
- 코인으로 노드 구매
- 기능·편의·전투·수집 성장
- 하나의 거대한 연결 트리

환생 스탯 배분
- 환생으로 받은 스탯 토큰 사용
- 플레이어가 영구 스탯에 직접 배분
- 코인 트리와 별도 자원·화면
```

두 체계 모두 환생 뒤 유지됩니다. 환생은 Defense XP만 초기화합니다.

---

## 1. 공통 성장 철학

- 구매·배분 결과 영구 유지
- 실패 확률·유지비 없음
- 개별 타워 레벨과 무작위 옵션 없음
- 신규 타워가 공통 성장 즉시 적용
- Defense XP 직접 구매 없음
- 상호 배타적 영구 함정은 피함
- 자동 합체 없음

---

# A. 코인 스탯 트리

## 2. 거대한 연결 트리

```text
                    특수 시스템
                         │
편성 ─── 전투 ─── 중심 기본 기능 ─── 굴리기
                         │
                    수집·오프라인
                         │
                        베이스
```

- 여러 독립 페이지가 아니라 한 좌표 공간
- 드래그·확대·축소·중심 복귀
- 선행 연결선과 구매 가능 상태
- 잠긴 가지 대표 보상 미리보기
- 분야 입구도 코인으로 구매

환생 스탯 토큰은 이 연결 트리의 코인 가격을 대신하지 않습니다.

## 3. 첫 15분 중심 노드

| 노드 | 가격 | 효과 |
|---|---:|---|
| 자동 굴리기 | 10 | 자동 굴리기 |
| 자동 편성 | 30 | 자동 편성 |
| 자석 범위 I | 50 | 반경 +4 studs |
| 핵심 성능 I | 100 | 역할 기여도 +25% |
| 굴리기 속도 I | 160 | 4.0초 → 3.6초 |
| 자석 속도 I | 220 | 흡입 속도 +35% |
| 전투 분야 해금 | 450 | 전투 가지 공개 |
| 코인 획득 I | 550 | 코인 +15% |
| 핵심 성능 II | 650 | 추가 +25% |
| 편성 슬롯 5 | 1,200 | 4 → 5슬롯 |

정확한 NodeId·좌표·연결은 `../reference/STAT_TREE_CATALOG.md`를 따릅니다.

균형 소비 목표:

```text
0:08 자동 굴리기
0:31 자동 편성
0:40 자석 범위 I
0:56 핵심 성능 I
1:19 굴리기 속도 I
3:33 자석 속도 I
4:02 전투 분야
4:45 핵심 성능 II
```

강제 순서가 아니며 문을 먼저 구매할 수 있습니다.

## 4. 코인 트리 분야

### 전투

- 핵심 성능
- 공격속도
- 치명타 확률·피해
- 역할별 기여 계산에 맞는 공통 강화

### 편성·타겟

- 전체 슬롯 4 → 장기 상한 12
- 역할 슬롯
- 전체·역할·타워별 타겟 확장
- 편성 프리셋과 퀵 HUD

### 굴리기

- 굴리기 속도
- 특수 주사위 관련 편의 후보

영구 행운의 주 성장축은 환생 스탯 배분으로 이동합니다. 코인 트리에 추가 행운 노드를 넣을지는 미확정입니다. 중복 행운원을 무분별하게 늘리지 않습니다.

### 수집·오프라인

- 자석 범위·속도
- 코인 획득
- 오프라인 코인 해금·효율·저장시간

### 베이스

- 최대 체력
- 지속 회복

### 특수 시스템

- 변종 계열
- 수동 합체
- 텔레포터
- 세부 타겟
- 보스 후속 편의

텔레포터는 영구적으로 열린 문 목적지에 접근합니다. 환생 뒤 목적지가 사라지지 않습니다.

---

## 5. 환생 조건

일부 코인 노드는 최소 환생 횟수 또는 특정 환생 스탯 배분을 요구할 수 있습니다.

적합한 대상:

- 강한 자석
- 수동 합체
- 변종 확장
- 세부 타겟
- 텔레포터
- 오프라인 확장

첫 환생 전 중심 노드에는 환생 조건이 없습니다.

문과 기존 구매 노드는 환생으로 초기화하지 않습니다.

---

# B. 환생 스탯 배분

## 6. 토큰 획득

```text
환생 성공
→ Defense XP 0
→ RebirthCount +1
→ 스탯 토큰 지급
```

- 토큰 영구 보유
- 미사용분 이월
- 코인과 교환 불가
- 자동 균등 배분 없음
- 환생당 지급량은 미확정

---

## 7. 배분 데이터

```text
RebirthStatTokensEarned
UnspentRebirthStatTokens
RebirthStatAllocations[StatId]
```

불변조건:

```text
배분 합 + 미사용 토큰 = 누적 획득 토큰
```

토큰 배분은 서버 승인 후 원자적으로 처리합니다.

---

## 8. 확정된 첫 환생 스탯

현재 계수가 계산된 항목은 행운뿐입니다.

```text
행운 토큰 1개
→ BaseCompression +0.040
```

잠정 공식:

```text
BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ 0.040 × AllocatedLuckTokens
+ TemporaryCompressionBonus
```

상한:

```text
일반 5.40
황금 5.65
다이아몬드 6.05
```

행운 외 토큰 스탯은 아직 확정하지 않습니다.

---

## 9. 배분 UI

필수 정보:

- 미사용 토큰
- 각 StatId의 현재 투자량
- 다음 토큰의 실제 효과
- 소프트캡·하드캡
- 서버 승인 결과

환생 직후 배분 화면으로 이동할 수 있지만 강제하지 않습니다. 현재 전투와 굴리기는 계속됩니다.

재분배 가능 여부와 비용은 미확정입니다.

---

## 10. 저장과 피드백

코인 노드 구매:

```text
선행 조건·코인 검증
→ 코인 차감
→ 노드 단계 증가
```

환생 토큰 배분:

```text
미사용 토큰·상한 검증
→ 토큰 차감
→ 배분 단계 증가
→ 파생 능력치·행운 캐시 재계산
```

피드백:

- 입력 즉시 눌림 반응
- 서버 승인 후 점등·수치 갱신
- 구매 불가 이유 표시
- 감소된 움직임 설정 지원
- 일반 구매에 카메라 흔들림 없음

---

## 11. 사용하지 않는 구조

- 환생 시 코인 트리 초기화
- 환생 시 토큰 배분 초기화
- 코인으로 환생 토큰 구매
- Defense XP 구매
- 개별 타워 레벨
- 무작위 토큰 스탯
- 자동 토큰 배분
- 자동 합체
- 텔레포터로 잠긴 문 우회
- 환생 뒤 문 목적지 삭제

- 역할 슬롯 성장 속도
- 베이스 초기 체력
