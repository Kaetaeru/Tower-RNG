## 요약

튜토리얼은 실제 지속형 전투와 선형 월드 안에서 핵심 기능을 하나씩 사용하게 합니다. 별도의 긴 연습 모드로 플레이를 멈추지 않으며, 첫 굴리기·첫 코인 획득·첫 스탯 구매까지만 짧게 강제합니다.

자동 굴리기와 자동 편성은 극초반에 해금합니다. 합체, 텔레포터와 개인 보스는 실제 해금 시점에 안내합니다.

---

## 1. 필수 초반 단계

### TUT-001: 짧은 필수 구간

```text
1. 로비에서 스테이지 1로 이동
2. 첫 수동 굴리기
3. 획득 타워의 자동 전투 확인
4. 몬스터가 떨어뜨린 코인 직접 획득
5. 스탯 트리 열기
6. 매우 저렴한 자동 굴리기 노드 구매
```

필수 단계 이후 주요 메뉴와 이동을 자유롭게 사용할 수 있습니다.

### TUT-002: 실제 플레이 안에서 진행

- 별도 튜토리얼 맵을 기본으로 사용하지 않음
- 튜토리얼 중에도 몬스터 생성과 자동 전투 계속
- 설명창이 코인 수집과 이동을 가리지 않음
- 경험한 플레이어가 불필요하게 오래 기다리지 않음

---

## 2. 극초반 기능 안내

### TUT-003: 자동 굴리기

첫 코인과 스탯 트리 사용법을 가르치기 위한 첫 저가 노드입니다.

- 수동 굴리기 몇 회 후 안내
- 구매 후 자동 굴리기 ON/OFF 가능
- 전투·이동·메뉴 중에도 진행
- 환생 후 유지

### TUT-004: 자동 편성과 퀵 HUD

자동 굴리기 직후 극초반 구역에서 해금합니다.

- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 퀵 편성 HUD에서 상태 확인과 빠른 변경
- 상세 관리는 인벤토리 편성 탭

### TUT-005: 첫 잠긴 문

충분한 코인을 모으면 스테이지 2로 이어지는 문 구매를 안내합니다.

- 클리어 조건이 아니라 코인으로 개방
- 문 너머로 직접 이동
- 새 스테이지에 들어가면 이전 전투 종료
- 타워가 새 적을 자동 탐색
- 이전 스테이지로 돌아갈 수 있음

### TUT-006: 첫 환생

신규 계정 기준 약 7~10분 부근에 첫 환생 조건을 경험하도록 조정합니다.

실행 전 반드시 표시:

- 코인과 모든 스테이지 문 초기화
- 타워·스탯 트리·자동 기능 유지
- 영구 코인·행운 배율 증가
- 이전 구간을 더 빠르게 통과하게 됨

---

## 3. 지연 안내 기능

### TUT-007: 오프라인 진행

오프라인 코인 노드를 처음 구매할 때 다음을 안내합니다.

- 오프라인에는 굴리기와 전투가 진행되지 않음
- 제한된 코인만 축적
- 효율과 최대 시간이 스탯 트리로 증가
- 접속 시 자동 지급

### TUT-008: 합체는 중후반에 안내

- 실제 합체 노드 해금 시 안내
- 충분한 중복 타워가 쌓인 시점과 가깝게 배치
- 결과 고정, 실패 없음, 추가 코인 비용 없음 강조

### TUT-009: 텔레포터

텔레포터 노드 해금 시 안내합니다.

- 로비와 현재 환생에서 연 스테이지로 이동
- 잠긴 문 우회 불가
- 반복 사용료 없음
- 텔레포트도 일반 스테이지 전환과 같은 전투 정리 적용

### TUT-010: 상황형 안내

처음 사용할 수 있게 되었을 때 짧게 안내:

- 역할 성향 프리셋
- 타겟 우선순위
- 포션
- 변종 타워
- 개인 보스
- 라이브 웨이브
- 수동 조작형 타워

---

## 4. 강제 수준

### TUT-011: 필수와 선택 안내 구분

필수:

- 첫 굴리기
- 첫 코인 획득
- 첫 스탯 트리 구매

필수 이후:

- 짧은 강조와 안내
- 닫거나 나중에 다시 확인 가능
- 기능 사용을 장시간 강제하지 않음

---

## 5. 사용하지 않는 구조

- 모든 시스템을 시작 직후 한꺼번에 설명
- 합체·텔레포터·라이브 웨이브를 사용 시점보다 훨씬 일찍 설명
- 긴 대화 동안 전투와 굴리기 정지
- 튜토리얼 실패로 진행 손실
- 자동 기능을 중후반까지 잠금
- 첫 문을 전투 클리어 조건으로 잠금

---

## 6. 미확정 사항

- 필수 구간 정확한 시간
- 자동 기능의 정확한 가격
- 역할 성향 프리셋 종류
- 첫 문과 첫 환생의 실제 가격 곡선
- 튜토리얼 다시 보기 위치
