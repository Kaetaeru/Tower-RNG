## 요약

튜토리얼은 실제 월드에서 진행합니다. 정규 5웨이브 전에 최초 슬라임 한 마리로 자동 굴리기와 4슬롯 편성을 준비합니다.

첫 환생은 약 `7.80~14.34분`에 도달합니다. 환생은 코인·문·현재 전투를 지우지 않고 Defense XP를 스탯 토큰으로 바꾼다는 점을 명확히 안내합니다.

---

## 1. 필수 초반 단계

```text
1. 로비에서 스테이지 1 진입
2. 첫 수동 굴리기
3. 첫 타워 슬롯 1 자동 배치
4. 초원 슬라임 한 마리 전투
5. 코인 10 직접 수집
6. 코인 스탯 트리 열기
7. 자동 굴리기 10코인 구매
8. 세 번의 자동 굴리기로 빈 슬롯 채우기
9. 4슬롯 완성 뒤 정규 웨이브 1
```

- 별도 튜토리얼 맵 없음
- 정규 슬라임과 같은 HP 5·보상 사용
- 공격력 보정·적 자동 약화 없음
- 추가 보너스 코인 없음
- 최초 계정에서 한 번만 실행
- 재접속·환생으로 반복하지 않음

첫 타워 역할과 무관하게 슬라임을 혼자 처치할 수 있다는 기준 타워 검증을 사용합니다.

## 2. 첫 90초 안내

| 시간 | 사건 | 안내 |
|---:|---|---|
| 약 0:08 | 자동 굴리기 | ON과 다음 굴림 타이머 |
| 약 0:25 | 4슬롯·웨이브 1 | 빈 슬롯 채움과 5웨이브 시작 |
| 약 0:31 | 자동 편성 | 퀵 편성·ON/OFF |
| 약 0:40 | 자석 범위 I | 흡입 반경 링 |
| 약 0:56 | 핵심 성능 I | 역할별 공통 기여 강화 |
| 약 1:19 | 굴리기 속도 I | 4.0초 → 3.6초 |

자동 굴리기 이후 구매는 강제하지 않습니다.

## 3. 기본 시스템

### 공식 확률과 행운

- 카드의 `1 / N`은 공식 기본 확률
- 큰 분모일수록 희귀하고 강함
- 현재 행운 적용 유효 확률은 표시하지 않음
- 높은 스테이지와 행운 토큰은 희귀 결과 가능성을 높임

### 빈 슬롯과 자동 편성

- 자동 편성 전에도 새 타워가 빈 시작 슬롯을 채움
- 이미 배치된 타워를 교체하지 않음
- 4슬롯 이후 최적화는 자동 편성
- 동일 타워 여러 개 사용 가능
- 역할별 슬롯 제한 준수

### 5웨이브

```text
1~4 일반 웨이브
→ 5 보스
→ 다시 1
```

- 완료 즉시 다음 웨이브
- 스테이지 이탈 시 새 1웨이브
- 보스 처치는 문 조건이 아님

### 첫 문

```text
스테이지 2 문: 750코인
```

- 균형 소비 약 3분
- 더 강한 적·보상·행운
- 전투력 검사 아님
- 어려우면 행운만 받고 이전 스테이지로 복귀 가능
- 한 번 열면 계정 영구 유지
- 환생 후 재잠금 없음

### 첫 분야

```text
전투 분야 해금: 450코인
```

약 4분에 코인 스탯 트리의 첫 큰 가지를 공개합니다.

## 4. Defense XP와 환생

### TUT-001: Defense XP

최초 슬라임 뒤 HUD 막대를 강조합니다.

- 처치 위협도와 스테이지 배율로 자동 증가
- 코인과 별도
- 코인을 놓쳐도 획득
- 베이스 도달 적은 XP 없음
- 오프라인 증가 없음
- 보스 본체 1.15배

### TUT-002: 첫 환생

```text
요구량: 7,000 Defense XP
목표: 7~15분
검증: 7.80~14.34분
```

80%에서 메뉴를 한 번 강조하고 100%에서 실행 가능 알림을 표시합니다. 자동 실행하지 않습니다.

환생 확인창의 핵심 문장:

> Defense XP를 스탯 토큰으로 바꿉니다. 코인, 열린 문과 현재 전투는 그대로 유지됩니다.

변경:

- Defense XP 0
- 환생 횟수 증가
- 스탯 토큰 지급

유지:

- 코인
- 열린 문·현재 스테이지
- 현재 웨이브·몬스터·바닥 코인
- 타워·도감·코인 스탯 트리
- 굴림·합체·변종·포션·설정

초과 Defense XP는 기본 이월되지 않는다고 알립니다.

### TUT-003: 첫 토큰 배분

환생 뒤 현재 전투를 멈추지 않고 다음을 짧게 안내합니다.

```text
토큰 획득
→ 미사용 토큰 확인
→ 스탯 배분 화면 열기 선택
```

첫 계산 완료 스탯:

```text
행운 토큰 1개
→ Compression +0.040
```

현재 타워별 유효 확률은 보여 주지 않습니다. 다음 토큰의 효과와 상한만 표시합니다.

토큰 배분을 강제하지 않으며 미사용분은 이월됩니다.

## 5. 지연 안내

### 오프라인 코인

- 제한된 코인만 축적
- 굴리기·Defense XP·정수·토큰 진행 없음
- 접속 시 자동 지급

### 수동 합체

- 같은 타워 중복 사용
- 결과 고정·실패 없음
- 보호·편성 수량 제외
- 기본형·변종 혼합 불가
- 자동 합체 없음

### 변종

- 별도 TowerId
- 공식 최종 `1 / N`
- 해금 계열만 판정

### 텔레포터

- 로비와 영구적으로 열린 스테이지
- 잠긴 문 우회 불가
- 이동하면 새 1웨이브

### 재접속

- 로비 시작
- 코인·문·Defense XP·토큰 유지
- 이전 전투 상태는 저장하지 않음
- 마지막 열린 활동 스테이지로 빠른 복귀

## 6. 강제 수준

필수:

- 첫 굴리기
- 최초 슬라임
- 첫 코인
- 자동 굴리기 구매
- 4슬롯 준비

선택 안내:

- 자동 편성
- 코인 스탯 구매
- 문
- 환생
- 토큰 배분
- 합체·변종·텔레포터

긴 대화로 전투를 멈추지 않습니다.

---

## 7. 사용하지 않는 구조

- 타워 하나로 정규 5웨이브 즉시 시작
- 선택 불가능한 첫 과부하
- 모든 시스템 시작 직후 설명
- 현재 유효 확률 표시
- 긴 대화로 전투 정지
- 튜토리얼 실패 손실
- 보스 처치 문 잠금
- 환생 코인 비용
- 환생 시 코인·문·전투 초기화 안내
- 자동 토큰 배분
- 자동 합체 안내

---

## 8. 남은 검증

- 최초 슬라임 코인 동선
- 실제 UI의 25초 편차
- 복합 역할의 빈 슬롯 선택
- 환생당 토큰 지급량에 맞춘 첫 배분 안내
- 도움말·모바일 입력 크기
