## 요약

튜토리얼은 실제 지속 전투와 선형 월드 안에서 진행합니다. 첫 굴리기·코인 획득·첫 스탯 구매까지만 짧게 강제하고, 나머지는 실제 해금 시 안내합니다.

공식 기본 `1 / N`은 설명하지만 현재 행운 적용 확률은 보여 주지 않습니다. 첫 환생은 Defense XP를 통해 약 7~15분에 경험하도록 조정합니다.

---

## 1. 필수 초반 단계

```text
1. 로비에서 스테이지 1 진입
2. 첫 수동 굴리기
3. 타워 자동 전투 확인
4. 코인 직접 수집
5. 거대 스탯 트리 열기
6. 자동 굴리기 구매
```

필수 이후 자유롭게 이동·메뉴 사용이 가능합니다.

- 별도 튜토리얼 맵 없음
- 설명 중 전투·굴리기 계속
- 이동·코인 수집을 가리지 않음
- 재방문 플레이어를 오래 묶지 않음

---

## 2. 극초반 안내

### 공식 확률

- 타워 카드의 `1 / N`은 공식 기본 확률
- 높은 분모일수록 더 희귀하고 더 강함
- 현재 행운이 반영된 실제 분모는 표시하지 않음
- 행운은 희귀 결과 가능성을 높임

### 자동 편성

- ON/OFF
- 역할 성향
- 퀵 편성 HUD
- 상세 관리는 인벤토리

### 5웨이브

```text
1~4웨이브
→ 5웨이브 보스
→ 다시 1웨이브
```

- 완료 즉시 다음 웨이브
- 스테이지 이탈 시 초기화
- 보스 처치가 다음 문 조건은 아님

### 첫 문

- 코인으로 개방
- 새 스테이지는 더 강한 적·보상·행운
- 새 스테이지 진입 시 1웨이브 시작
- 문은 재접속 후 유지, 환생 시 초기화

---

## 3. Defense XP와 첫 환생

### TUT-001: Defense XP

처음 몬스터를 처치한 뒤 HUD의 Defense XP 막대를 짧게 강조합니다.

설명:

- 처치한 위협도에 따라 자동 증가
- 높은 스테이지에서 더 크게 증가
- 코인과 별도
- 베이스에 도달한 적은 XP 없음
- 오프라인에는 증가하지 않음

### TUT-002: 첫 환생

약 7~15분에 첫 요구량을 채우도록 조정합니다.

표시:

초기화:

- 코인
- Defense XP
- 모든 스테이지 문
- 현재 전투·바닥 코인

유지:

- 타워·도감
- 스탯 트리
- 굴림 카운터
- 자동 기능
- 연금 정수·포션
- 합체·변종 진행
- 설정

보상:

- 영구 코인 성장
- 영구 행운 성장

초과 Defense XP는 기본 이월되지 않는다고 알립니다.

---

## 4. 지연 안내

### 오프라인 코인

- 굴리기·전투·Defense XP 진행 없음
- 제한된 코인만 축적
- 접속 시 자동 지급

### 수동 합체

실제 해금 시:

- 같은 타워 중복 사용
- 결과 고정·실패 없음
- 보호·편성 수량 제외
- 기본형·변종 혼합 불가
- 자동 합체 없음

### 변종

- 기본형보다 강한 별도 TowerId
- 공식 최종 `1 / N` 표시
- 해금한 계열만 판정

### 텔레포터

- 로비와 현재 환생에서 연 스테이지
- 잠긴 문 우회 불가
- 이동 시 웨이브 초기화

### 재접속 빠른 복귀

첫 재접속 때:

- 로비에서 시작
- 열린 문은 유지
- 이전 웨이브는 저장되지 않음
- 마지막 활동 스테이지가 열려 있으면 빠른 복귀 가능

### 설정

- 파티클·피해 숫자·UI 움직임
- 보스 화면 흔들림
- 희귀 연출
- 자동 보호
- 일반 공격은 화면 흔들림 없음

---

## 5. 상황형 안내

처음 사용할 수 있을 때만 안내:

- 역할 성향
- 타겟 우선순위
- 포션
- 변종 몬스터
- 보스 변종
- 라이브 웨이브
- 수동 조작형 타워

기본 스테이지 보스는 중후반 해금 기능처럼 안내하지 않습니다.

---

## 6. 강제 수준

필수:

- 첫 굴리기
- 첫 코인
- 첫 스탯 구매

나머지:

- 짧은 강조
- 닫기 가능
- 도움말에서 다시 보기
- 기능 사용 장시간 강제 없음

---

## 7. 사용하지 않는 구조

- 모든 시스템 시작 직후 설명
- 현재 행운 적용 확률 표시
- 합체·텔레포터를 너무 일찍 설명
- 자동 합체 안내
- 긴 대화로 전투 정지
- 튜토리얼 실패 손실
- 보스 처치 문 잠금
- 환생 코인 비용 안내
