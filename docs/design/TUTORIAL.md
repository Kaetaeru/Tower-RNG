## 요약

튜토리얼은 실제 지속형 전투 안에서 핵심 기능을 하나씩 사용하게 합니다. 별도의 긴 연습 모드로 플레이를 멈추지 않으며, 첫 굴리기·첫 코인 획득·첫 스탯 구매까지만 짧게 강제합니다.

자동 굴리기와 자동 편성은 극초반에 해금합니다. 합체는 중후반 시스템이므로 시작 직후 설명하지 않고 실제 해금 시점에 안내합니다.

---

## 1. 필수 초반 단계

### TUT-001: 짧은 필수 구간

다음 단계까지만 필수로 진행합니다.

```text
1. 첫 수동 굴리기
2. 획득한 타워가 자동으로 전투하는 모습 확인
3. 몬스터가 떨어뜨린 코인 직접 획득
4. 스탯 트리 열기
5. 매우 저렴한 자동 굴리기 노드 구매
```

필수 단계가 끝나면 주요 메뉴와 이동을 자유롭게 사용할 수 있습니다.

### TUT-002: 실제 플레이 안에서 진행

- 굴리기와 전투를 중단하는 별도 튜토리얼 맵을 기본으로 사용하지 않습니다.
- 튜토리얼 중에도 몬스터 생성과 자동 전투가 계속됩니다.
- 설명창은 필요한 행동을 가리지 않아야 합니다.
- 이미 규칙을 아는 플레이어가 불필요하게 오래 기다리게 하지 않습니다.

---

## 2. 극초반 기능 안내

### TUT-003: 자동 굴리기

첫 코인과 스탯 트리 사용법을 가르치기 위해 자동 굴리기는 매우 저렴한 첫 성장 노드로 구매합니다.

- 수동 굴리기 몇 회 후 안내
- 구매 후 플레이 내내 굴리기와 전투를 동시에 진행
- 자동 굴리기 ON/OFF 가능
- 자동 굴리기는 수동 굴리기와 같은 확률과 특수 주사위 규칙 사용

### TUT-004: 자동 편성

자동 편성은 자동 굴리기 직후의 극초반 스탯 트리 구간에서 해금합니다.

- 자동 편성 ON/OFF 가능
- ON 상태에서는 더 높은 평가 조합이 생기면 자동 갱신
- OFF 상태에서는 현재 편성 유지
- 역할별 편성 성향 프리셋을 선택 가능
- 정확한 프리셋 종류와 평가 가중치는 추후 밸런스 단계에서 정함

### TUT-005: 다음 스테이지

플레이어가 충분한 코인을 모으면 다음 스테이지 구매를 안내합니다.

- 스테이지는 클리어 조건이 아니라 코인으로 해금
- 높은 스테이지는 더 높은 코인 효율과 행운 제공
- 너무 어려우면 이전 스테이지로 돌아갈 수 있음

---

## 3. 지연 안내 기능

### TUT-006: 합체는 중후반에 안내

합체는 극초반 튜토리얼에 포함하지 않습니다.

- 스탯 트리에서 합체가 실제로 해금될 때 안내
- 충분한 중복 타워가 쌓인 시점과 가깝게 배치
- 합체 결과 고정, 실패 없음, 추가 코인 비용 없음이라는 핵심만 우선 설명

### TUT-007: 환생 안내

환생은 첫 환생 요구량에 가까워졌을 때 안내합니다.

- 초기화되는 항목과 유지되는 항목을 실행 전에 명확히 표시
- 코인과 지역·스테이지 진행은 초기화
- 타워, 스탯 트리, 자동 기능과 영구 진행은 유지
- 환생 보상인 코인·행운 배율을 미리 표시

### TUT-008: 상황형 안내

다음 기능은 실제로 처음 사용할 수 있게 되었을 때 짧게 안내합니다.

- 역할 성향 프리셋
- 타겟 우선순위
- 포션
- 변종 타워
- 개인 보스
- 라이브 웨이브
- 수동 조작형 고유 타워

---

## 4. 강제 수준

### TUT-009: 필수와 선택 안내 구분

필수:

- 첫 굴리기
- 첫 코인 획득
- 첫 스탯 트리 구매

필수 이후:

- 짧은 강조와 안내 제공
- 안내를 닫거나 나중에 다시 볼 수 있음
- 기능 사용 자체를 장시간 강제하지 않음

---

## 5. 사용하지 않는 구조

- 모든 시스템을 시작 직후 한꺼번에 설명
- 합체와 환생을 실제 사용 시점보다 훨씬 일찍 설명
- 긴 대화가 끝날 때까지 전투와 굴리기 정지
- 튜토리얼 실패로 보상이나 진행 손실
- 자동 굴리기와 자동 편성을 중후반까지 잠금
- 기본 기능을 배우기 위해 별도 입장권이나 비용 요구

---

## 6. 미확정 사항

- 필수 구간의 정확한 시간
- 자동 굴리기와 자동 편성 노드의 정확한 가격
- 편성 성향 프리셋의 종류와 명칭
- 안내 UI의 형태
- 튜토리얼 다시 보기 위치
