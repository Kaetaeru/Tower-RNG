## 요약

튜토리얼은 실제 지속형 전투와 선형 월드 안에서 핵심 기능을 하나씩 사용하게 합니다. 첫 굴리기·코인 획득·첫 스탯 구매까지만 짧게 강제합니다.

5웨이브 주기와 첫 스테이지 보스는 별도 해금 기능이 아니라 스테이지 1에서 자연스럽게 경험하고 설명합니다. 합체와 텔레포터는 실제 해금 시점에 안내합니다.

---

## 1. 필수 초반 단계

### TUT-001: 짧은 필수 구간

```text
1. 로비에서 스테이지 1로 이동
2. 첫 수동 굴리기
3. 획득 타워의 자동 전투 확인
4. 몬스터가 떨어뜨린 코인 직접 획득
5. 스탯 트리 열기
6. 매우 저렴한 자동 굴리기 노드 구매
```

필수 단계 이후 주요 메뉴와 이동을 자유롭게 사용할 수 있습니다.

### TUT-002: 실제 플레이 안에서 진행

- 별도 튜토리얼 맵을 기본으로 사용하지 않음
- 튜토리얼 중에도 웨이브와 자동 전투 계속
- 설명창이 이동과 코인 수집을 가리지 않음
- 경험한 플레이어가 오래 기다리지 않음

---

## 2. 극초반 기능 안내

### TUT-003: 자동 굴리기

첫 코인과 스탯 트리 사용법을 가르치는 첫 저가 노드입니다.

### TUT-004: 자동 편성과 퀵 HUD

- 자동 편성 ON/OFF
- 역할 성향 프리셋
- 퀵 편성 HUD에서 상태 확인과 빠른 변경
- 상세 관리는 인벤토리 편성 탭

### TUT-005: 5웨이브 주기

스테이지 1에서 처음 웨이브가 진행될 때 다음을 짧게 안내합니다.

```text
현재 스테이지는 5개의 웨이브를 반복합니다.
5웨이브에는 스테이지 보스가 등장합니다.
```

함께 설명할 내용:

- 웨이브 숫자와 현재 진행 상태
- 5웨이브 이후 다시 1웨이브부터 반복
- 웨이브·보스 처치가 다음 문 해금 조건은 아님
- 다른 스테이지나 로비로 이동하면 웨이브 진행 초기화

### TUT-006: 첫 스테이지 보스

첫 5웨이브 진입 시 보스 표시와 대형 사냥 역할을 간단히 안내할 수 있습니다.

- 보스를 잡으면 큰 코인 묶음과 정수 보너스를 얻을 수 있음
- 코인 묶음은 직접 주워야 함
- 보스를 놓쳐도 타워·문·스탯을 잃지 않음
- 보스는 매 5웨이브마다 다시 등장

### TUT-007: 첫 잠긴 문

충분한 코인을 모으면 스테이지 2 문 구매를 안내합니다.

- 클리어 조건이 아니라 코인으로 개방
- 새 스테이지에 들어가면 이전 웨이브와 전투 초기화
- 새 스테이지의 1웨이브부터 시작
- 타워가 새 적을 자동 탐색

### TUT-008: 첫 환생

신규 계정 기준 약 7~10분 부근에 첫 환생 조건을 경험하도록 조정합니다.

표시할 내용:

- 코인과 모든 스테이지 문 초기화
- 현재 웨이브와 미획득 코인 초기화
- 타워·스탯 트리·자동 기능 유지
- 영구 코인·행운 배율 증가

---

## 3. 지연 안내 기능

### TUT-009: 오프라인 진행

- 오프라인에는 굴리기와 전투가 진행되지 않음
- 제한된 코인만 축적
- 효율과 시간이 스탯 트리로 증가
- 접속 시 자동 지급

### TUT-010: 합체

- 실제 합체 노드 해금 시 안내
- 결과 고정, 실패 없음, 추가 코인 비용 없음
- 충분한 중복이 쌓인 중후반에 배치

### TUT-011: 텔레포터

- 로비와 현재 환생에서 연 스테이지로 이동
- 잠긴 문 우회 불가
- 텔레포트 시 이전 웨이브 초기화
- 목적지의 1웨이브부터 시작

### TUT-012: 상황형 안내

처음 사용할 수 있게 되었을 때 안내:

- 역할 성향 프리셋
- 타겟 우선순위
- 포션
- 변종 타워와 변종 몬스터
- 합체
- 라이브 웨이브
- 수동 조작형 타워

기본 스테이지 보스는 상황형 중후반 해금 목록에 포함하지 않습니다.

---

## 4. 강제 수준

### TUT-013: 필수와 선택 안내

필수:

- 첫 굴리기
- 첫 코인 획득
- 첫 스탯 트리 구매

필수 이후:

- 짧은 강조와 안내
- 닫거나 나중에 다시 확인 가능
- 기능 사용을 장시간 강제하지 않음

---

## 5. 사용하지 않는 구조

- 모든 시스템을 시작 직후 한꺼번에 설명
- 보스를 중후반 해금 기능처럼 안내
- 합체·텔레포터·라이브 웨이브를 지나치게 일찍 설명
- 긴 대화 동안 전투와 굴리기 정지
- 튜토리얼 실패로 진행 손실
- 첫 문을 보스 처치 조건으로 잠금

---

## 6. 미확정 사항

- 필수 구간 정확한 시간
- 자동 기능의 가격
- 역할 성향 프리셋 종류
- 첫 5웨이브의 실제 길이와 예산
- 첫 문과 첫 환생의 가격 곡선
- 튜토리얼 다시 보기 위치
