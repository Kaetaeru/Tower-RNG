## 요약

튜토리얼은 실제 지속 전투와 선형 월드 안에서 진행합니다. 첫 굴리기·코인 획득·첫 스탯 구매까지만 짧게 강제하고, 나머지는 실제 해금 시 안내합니다.

첫 필수 구매인 자동 굴리기는 10코인이며 경제 벤치마크에서 약 8초에 도달합니다. 첫 환생은 6,500 Defense XP로 약 7.67~13.86분에 도달합니다.

---

## 1. 필수 초반 단계

```text
1. 로비에서 스테이지 1 진입
2. 첫 수동 굴리기
3. 타워 자동 전투 확인
4. 코인 직접 수집
5. 거대 스탯 트리 열기
6. 자동 굴리기 10코인 구매
```

필수 이후 자유롭게 이동·메뉴 사용이 가능합니다.

- 별도 튜토리얼 맵 없음
- 설명 중 전투·굴리기 계속
- 이동·코인 수집을 가리지 않음
- 재방문 플레이어를 오래 묶지 않음

첫 웨이브에서 편성이 아직 차지 않아 일부 적이 베이스에 도달할 수 있으므로, 시작 베이스 체력은 첫 40초의 편성 충전 구간을 버틸 수 있어야 합니다. 튜토리얼용 적 자동 약화는 사용하지 않습니다.

---

## 2. 첫 90초 안내

균형 경로 기준:

| 시간 | 사건 | 안내 |
|---:|---|---|
| 약 0:08 | 자동 굴리기 구매 | ON 상태와 다음 굴림 타이머 강조 |
| 약 0:20 | 자동 편성 구매 가능 | 퀵 편성 HUD와 ON/OFF 설명 |
| 약 0:34 | 자석 범위 I | 코인 흡입 반경 링을 한 번 표시 |
| 약 0:52 | 핵심 성능 I | 모든 역할의 핵심 성능 강화 설명 |
| 약 1:16 | 굴리기 속도 I | 기본 4.0초가 3.6초가 되는 것을 표시 |

자동 편성 이후 구매는 강제하지 않습니다. 다음 구매가 가능해질 때 짧게 점등할 뿐입니다.

## 3. 기본 시스템 안내

### 공식 확률

- 타워 카드의 `1 / N`은 공식 기본 확률
- 높은 분모일수록 더 희귀하고 더 강함
- 현재 행운이 반영된 실제 분모는 표시하지 않음
- 행운은 희귀 결과 가능성을 높임

### 자동 편성

- ON/OFF
- 역할 성향
- 퀵 편성 HUD
- 상세 관리는 인벤토리

### 5웨이브

```text
1~4웨이브
→ 5웨이브 보스
→ 다시 1웨이브
```

- 완료 즉시 다음 웨이브
- 스테이지 이탈 시 초기화
- 보스 처치가 다음 문 조건은 아님

### 첫 문

```text
스테이지 2 문: 750코인
```

- 균형 소비 기준 약 3분
- 새 스테이지는 더 강한 적·보상·행운
- 문 개방은 전투력 검사 아님
- 어려우면 행운만 받고 스테이지 1로 돌아올 수 있음
- 새 스테이지 진입 시 1웨이브 시작
- 문은 재접속 후 유지, 환생 시 초기화

### 첫 분야 해금

```text
전투 분야 해금: 450코인
```

균형 소비 기준 약 4분에 첫 큰 가지가 열립니다. 연결선을 따라 빛이 퍼지고 후속 노드가 한 화면에서 공개되어야 합니다.

## 4. Defense XP와 첫 환생

### TUT-001: Defense XP

처음 몬스터를 처치한 뒤 HUD의 Defense XP 막대를 짧게 강조합니다.

설명:

- 처치한 위협도와 스테이지 보상 배율에 따라 자동 증가
- 코인과 별도
- 코인을 놓쳐도 획득
- 베이스에 도달한 적은 XP 없음
- 오프라인에는 증가하지 않음
- 첫 버전은 별도 웨이브 완료 XP 보너스 없음

### TUT-002: 첫 환생

```text
요구량: 6,500 Defense XP
목표 시간: 7~15분
검증 범위: 7.67~13.86분
```

요구량 80%에 도달하면 환생 메뉴를 한 번 강조하고, 100%에 도달하면 실행 가능 상태를 알립니다. 자동 실행하지 않습니다.

표시할 초기화:

- 코인
- Defense XP
- 모든 스테이지 문
- 현재 전투·바닥 코인

표시할 유지:

- 타워·도감
- 스탯 트리
- 굴림 카운터
- 자동 기능
- 연금 정수·포션
- 합체·변종 진행
- 설정

보상:

- 영구 코인 성장
- 영구 행운 성장

초과 Defense XP는 기본 이월되지 않는다고 알립니다.

## 5. 지연 안내

### 오프라인 코인

- 굴리기·전투·Defense XP 진행 없음
- 제한된 코인만 축적
- 접속 시 자동 지급

### 수동 합체

실제 해금 시:

- 같은 타워 중복 사용
- 결과 고정·실패 없음
- 보호·편성 수량 제외
- 기본형·변종 혼합 불가
- 자동 합체 없음

### 변종

- 기본형보다 강한 별도 TowerId
- 공식 최종 `1 / N` 표시
- 해금한 계열만 판정

### 텔레포터

- 로비와 현재 환생에서 연 스테이지
- 잠긴 문 우회 불가
- 이동 시 웨이브 초기화

### 재접속 빠른 복귀

첫 재접속 때:

- 로비에서 시작
- 열린 문은 유지
- 이전 웨이브는 저장되지 않음
- 마지막 활동 스테이지가 열려 있으면 빠른 복귀 가능

### 설정

- 파티클·피해 숫자·UI 움직임
- 보스 화면 흔들림
- 희귀 연출
- 자동 보호
- 일반 공격은 화면 흔들림 없음

---

## 6. 상황형 안내

처음 사용할 수 있을 때만 안내:

- 역할 성향
- 타겟 우선순위
- 포션
- 변종 몬스터
- 보스 변종
- 라이브 웨이브
- 수동 조작형 타워

기본 스테이지 보스는 중후반 해금 기능처럼 안내하지 않습니다.

## 7. 강제 수준

필수:

- 첫 굴리기
- 첫 코인
- 자동 굴리기 구매

나머지:

- 짧은 강조
- 닫기 가능
- 도움말에서 다시 보기
- 기능 사용 장시간 강제 없음

## 8. 사용하지 않는 구조

- 모든 시스템 시작 직후 설명
- 현재 행운 적용 확률 표시
- 합체·텔레포터를 너무 일찍 설명
- 자동 합체 안내
- 긴 대화로 전투 정지
- 튜토리얼 실패 손실
- 보스 처치 문 잠금
- 환생 코인 비용 안내
- 플레이어 전투력에 맞춘 튜토리얼 적 자동 스케일

## 9. 남은 검증

- 첫 웨이브 동안 필요한 베이스 체력
- 실제 UI 조작과 코인 수집으로 인한 시간 편차
- 도움말 위치
- 모바일 튜토리얼 입력 크기
