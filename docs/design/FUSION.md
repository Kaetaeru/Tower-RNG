## 요약

합체는 같은 `TowerId`의 중복 수량을 고정된 상위 타워로 압축하는 중후반 **수동 시스템**입니다.

```text
같은 기본형 3개
→ 1단계 합체 결과 1개

같은 1단계 결과 3개
→ 2단계 합체 결과 1개
```

- 성공률 100%
- 결과 고정
- V1 최대 2단계
- 실행 코인·정수 비용 없음
- 자동 합체 없음
- 보호·편성 중인 수량 자동 소비 없음
- 환생 후 해금·결과·기록 유지

합체는 재료 세 개의 전투력을 한 슬롯에 그대로 보존하는 시스템이 아닙니다. 슬롯 압축, 계보 수집과 고정된 상위 행동이 가치의 중심입니다.

---

# 1. 기본 합체 규칙

## FUS-001: 1단계

```text
재료: 같은 TowerId 기본형 3개
결과: 해당 계보의 1단계 TowerId 1개
PowerBudget: 기본형 ×1.45
```

## FUS-002: 2단계

```text
재료: 같은 1단계 TowerId 3개
기본형 환산 재료: 9개
결과: 해당 계보의 2단계 TowerId 1개
PowerBudget: 기본형 ×2.1025
```

```text
2.1025 = 1.45²
```

V1에서는 2단계가 최대입니다. 3단계 이상은 후속 버전에서 별도 확률·전투력·인벤토리 계산을 거칩니다.

---

# 2. 재료 전력과 희귀도

| 결과 | 재료 총 기본 전력 | 결과 전력 |
|---|---:|---:|
| 1단계 | ×3.00 | ×1.45 |
| 2단계 | ×9.00 | ×2.1025 |

기존 희귀도 공식과 비교한 등가 분모 증가:

```text
1단계: 1.45^5 ≈ ×6.4097
2단계: 2.1025^5 ≈ ×41.0847
```

예를 들어 `1/10` 기본형은:

```text
1단계 약 1/64 상당
2단계 약 1/411 상당
```

이 기준으로 흔한 합체 결과가 극희귀 일반 타워를 즉시 역전하지 않게 합니다.

PowerBudget 전체를 단순 피해 배율로 사용할 필요는 없습니다. 합체 결과는 다음에 예산을 나눌 수 있습니다.

- 기본 공격 강화
- 대상 수·범위·관통
- 행동 주기와 템포
- 역할 고유 지원·제어
- 계보 고유 능력
- 필요하면 추가 제약이나 준비시간

---

# 3. 해금과 코인 가지

합체 실행에는 코인 비용이 없지만 시스템과 계보 범위는 코인 스탯 트리에서 영구 해금합니다.

| 노드 | 가격 | 효과 |
|---|---:|---|
| 합체 핵심 | 250,000 | 확률표 1~31번 기본형의 1단계 계보 |
| 고급 합체 | 750,000,000 | 허용 계보의 2단계 |
| 희귀 계보 확장 | 2,000,000,000 | 확률표 32~50번 계보 허용 |

```text
합체 가지 총가격: 2,750,250,000
```

균형형 통합 경제 목표:

```text
합체 핵심: 약 2.57시간
고급 합체: 약 19.77시간
희귀 계보 확장: 약 22.38시간
```

첫 튜토리얼에는 합체를 넣지 않습니다. 합체 핵심을 구매한 뒤 중복 재료가 있을 때 지연 튜토리얼을 표시합니다.

---

# 4. 수동 실행

## FUS-003: 자동 합체 없음

사용하지 않음:

- 획득 직후 자동 소비
- 백그라운드 합체
- 오프라인 합체
- 희귀도 필터 기반 자동 합체
- 유료 자동 합체

플레이어가 합체 화면에서 재료와 결과를 확인한 뒤 직접 실행합니다.

여러 번 가능한 같은 계보에 대해 **실행 수량을 직접 지정하는 일괄 실행**은 허용할 수 있습니다. 이는 플레이어 승인 없이 작동하는 자동 합체가 아닙니다.

## FUS-004: 재료 가능 수량

```text
AvailableForFusion
= OwnedCount
- ProtectedCount
- EquippedCount
```

- 보호된 수량 제외
- 현재 편성에 필요한 수량 제외
- 부족 이유 표시
- 서버가 실행 순간 다시 검증
- 재료 부족 시 아무것도 차감하지 않음

# 5. 기본형과 변종

```text
같은 기본형 + 같은 기본형
→ 해당 기본 계보가 있으면 가능

같은 변종 + 같은 변종
→ 대응 계보가 있으면 가능

기본형 + 변종
→ 불가능

서로 다른 변종
→ 불가능
```

변종은 별도 `TowerId`입니다.

현재 변종 획득 계산에서 같은 변종 3개 이상을 보유한 계정 비율:

```text
15시간 약 0.25%
30시간 약 3.84%
```

따라서:

- 변종 1단계 합체는 대응 계보가 있을 때만 허용
- 변종 합체 전용 필수 해금 노드는 만들지 않음
- 변종 2단계는 V1 핵심 진행으로 계산하지 않음
- 변종 합체를 후반 코인 싱크의 중심으로 사용하지 않음

각 카탈로그 항목은 다음 중 하나를 명시합니다.

- 기본형 합체 계보
- 변종 대응 계보
- 변종 전용 계보
- 합체 불가

---

# 6. 전투와 완주의 관계

20,000계정 계산 결과:

```text
2.5시간 중앙 편성 증가 약 1.3%
15시간 중앙 편성 증가 0%
30시간 중앙 편성 증가 약 2.3%
```

합체는 특정 역할 공백과 슬롯 압축에 도움을 주지만 스테이지 15 완주의 필수 전력으로 사용하지 않습니다.

- 특정 합체 결과를 문 조건으로 사용하지 않음
- 합체 결과가 없어도 12~15시간 중앙 완주 가능
- 자동 편성은 실제 결과 타워의 기여도를 평가
- 자동 편성 OFF에서는 결과 획득이 현재 편성을 강제 교체하지 않음

---

# 7. 계보와 표시

합체 화면 필수 정보:

- 기본형→1단계→2단계 전체 계보
- Owned·Protected·Equipped·Available 수량
- 단계별 필요 재료
- 고정 결과 미리보기
- 결과 PowerBudget과 행동 차이
- 실행 가능 횟수
- 수동 실행 수량
- 합체 도감과 누적 기록

합체 전용 타워는 일반 굴림의 공식 `BaseOddsN`이 없을 수 있습니다. 비굴리기 결과를 일반 굴림 희귀도 리더보드에 같은 방식으로 섞지 않습니다.

---

# 8. 저장과 원자성

```text
TransactionId 검증
→ 계보·해금·재료 검증
→ 보호·편성 수량 검증
→ 재료 차감
→ 결과 지급
→ 도감·합체 누적 갱신
→ 중요 저장 예약
```

- 버튼 연타 중복 소비 금지
- 클라이언트가 결과 ID 결정 불가
- 실패 검증 시 재료 차감 없음
- 환생 뒤 해금·누적·결과·도감 유지
- 플레이어 간 재료 거래 없음

---

# 9. 사용하지 않는 구조

- 자동 합체
- 합체 실패 확률
- 무작위 결과
- 실행 코인·정수 비용
- 합체권과 대기시간
- 보호·편성 수량 자동 소비
- 기본형·변종 혼합
- 서로 다른 변종 혼합
- 환생 시 합체 진행 초기화
- 개별 결과의 무작위 능력치
