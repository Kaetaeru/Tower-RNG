## 요약

합체는 같은 타워의 중복 수량을 고정된 상위 타워로 변환하는 중후반 성장 시스템입니다. 합체는 실패하지 않고 결과가 무작위로 바뀌지 않으며, 타워 재료 외의 추가 코인 비용을 요구하지 않습니다.

합체는 극초반 튜토리얼에 포함하지 않습니다. 충분한 중복 타워와 환생 진행이 쌓인 뒤 스탯 트리에서 해금하며, 실제 해금 시점에 별도 안내합니다.

---

## 1. 해금 시점

### FUS-001: 중후반 시스템

합체는 게임 시작 직후 제공하지 않습니다.

- 자동 굴리기와 자동 편성보다 훨씬 뒤에 배치
- 중복 타워가 충분히 쌓인 시점과 가깝게 해금
- 스탯 트리 노드로 영구 해금
- 최소 환생 횟수를 요구할 수 있음
- 환생 후에도 해금 유지

정확한 환생 요구 횟수와 가격은 스탯 트리 밸런스에서 정합니다.

### FUS-002: 지연 튜토리얼

합체 설명은 극초반 튜토리얼에서 제외합니다.

실제 합체 해금 시 다음만 우선 안내합니다.

- 같은 타워 중복을 재료로 사용
- 결과는 미리 정해져 있음
- 실패 없음
- 추가 코인 비용 없음
- 보호된 타워는 소비하지 않음

---

## 2. 기본 합체

### FUS-003: 동일 타워 재료

초기 기준:

```text
동일 타워 3개
→ 고정된 상위 타워 1개
```

재료 수량은 초기 기준이며 단계마다 다르게 설정할 수 있습니다.

### FUS-004: 확정 결과

- 성공률 100%
- 결과 타워 고정
- 실패 없음
- 무작위 결과 없음
- 소비 재료와 결과를 실행 전에 표시

### FUS-005: 추가 비용 없음

합체는 타워 재료 외에 다음을 요구하지 않습니다.

- 코인
- 연금 정수
- 합체권
- 입장권
- 대기 시간 단축 비용

---

## 3. 보호와 수량

### FUS-006: 보호된 수량 제외

- 보호된 타워는 수동·자동 합체 재료에서 제외
- 보호 해제 전 소비 불가
- 재료 부족 이유를 UI에 표시

### FUS-007: 보유 수량 검증

서버가 실제 보유 수량을 확인하고 재료 차감과 결과 지급을 하나의 처리로 수행합니다. 동시에 여러 요청으로 같은 수량이 중복 소비되어서는 안 됩니다.

---

## 4. 합체 계보

### FUS-008: 고정 계보

각 합체 가능한 타워는 정해진 다음 결과를 가집니다.

```text
기본 타워
→ 상위 타워
→ 더 높은 상위 타워
```

계보는 사전에 확인할 수 있으며 같은 재료에서 무작위 결과가 나오지 않습니다.

변종은 기본형 대응 계보, 변종 전용 계보 또는 합체 불가 중 하나를 타워 데이터에 명시합니다.

---

## 5. 합체 누적

### FUS-009: 영구 누적 진행

합체를 수행하면 계정의 합체 누적 진행이 증가합니다.

```text
합체 수행
→ 합체 누적 증가
→ 이후 변종 타워 판정에 영구 보너스
```

- 환생해도 유지
- 합체 실패로 감소하지 않음
- 높은 단계 또는 희귀 타워 합체가 더 많이 기여할 수 있음

일반 희귀도와 변종 확률 중 어디에 어떻게 적용하는지는 시스템 명세에서 정합니다.

---

## 6. 자동 합체

### FUS-010: 후속 편의 기능

자동 합체는 합체 해금 이후 별도 스탯 트리 노드로 제공합니다.

- 수동 합체와 같은 재료·결과 규칙
- 보호된 수량 제외
- 추가 비용 없음
- 환생 후 유지
- 대상 필터와 최소 보존 수량 지원 가능

---

## 7. 자동 편성과의 관계

합체로 상위 타워를 획득하면 자동 편성 ON 상태에서 편성을 재평가할 수 있습니다.

- 전체·역할 슬롯 준수
- 현재 역할 성향 프리셋 반영
- 결과 타워가 더 높은 평가를 받을 때 교체 가능
- 자동 편성 OFF 상태에서는 편성을 강제로 바꾸지 않음

---

## 8. 환생

환생해도 다음을 유지합니다.

- 합체 시스템 해금
- 자동 합체 해금과 설정
- 합체 누적 진행
- 합체로 획득한 상위 타워
- 합체 계보 도감

---

## 9. 사용하지 않는 구조

- 극초반 합체 강제 안내
- 합체 실패 확률
- 재료만 파괴되는 결과
- 무작위 상위 타워
- 합체 실행 코인 비용
- 기간 한정 성공률
- 보호된 희귀 타워의 자동 소비
- 환생 시 합체 진행 초기화

---

## 10. 미확정 사항

- 합체 해금의 정확한 환생 횟수와 가격
- 모든 단계가 동일 타워 3개를 사용하는지
- 최초 합체 계보
- 합체별 누적 기여량과 상한
- 변종과 기본형의 혼합 합체 여부
- 자동 합체 필터와 최소 보존 수량
