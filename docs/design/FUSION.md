## 요약

합체는 같은 타워의 중복 수량을 고정된 상위 타워로 바꾸는 중후반 **수동 시스템**입니다.

- 플레이어가 인벤토리 합체 탭에서 직접 실행
- 결과 고정
- 성공률 100%
- 추가 코인·정수 비용 없음
- 자동 합체 없음
- 보호·편성 중인 수량 자동 소비 없음

---

## 1. 해금

- 자동 굴리기·자동 편성보다 훨씬 뒤
- 중복 타워가 충분히 쌓인 시점
- 거대 스탯 트리에서 영구 해금
- 환생 횟수 조건 가능
- 환생 후 유지
- 실제 해금 시 지연 튜토리얼

첫 튜토리얼에는 합체를 넣지 않습니다.

---

## 2. 기본 합체

초기 기준:

```text
같은 TowerId 3개
→ 고정된 상위 TowerId 1개
```

단계마다 필요 수량을 다르게 설정할 수 있습니다.

- 실행 전 재료와 결과 표시
- 실패 없음
- 무작위 결과 없음
- 대기시간 없음
- 합체권 없음

---

## 3. 수동 실행만 사용

### FUS-001: 자동 합체 없음

사용하지 않음:

- 타워 획득 직후 자동 소비
- 백그라운드 합체
- 오프라인 합체
- 희귀도 필터 기반 자동 합체
- 최소 보존 수량 자동 규칙
- 스탯 트리 자동 합체 노드
- 유료 자동 합체

플레이어가 결과와 현재 편성을 확인한 뒤 직접 실행합니다.

---

## 4. 재료 가능 수량

```text
AvailableForFusion
= OwnedCount
- ProtectedCount
- EquippedCount
```

- 보호된 수량 제외
- 현재 편성에 필요한 수량 제외
- 부족 이유를 UI에 표시
- 보호 해제 또는 편성 제거 후 사용 가능
- 서버가 실행 순간 다시 검증

합체로 현재 편성이 갑자기 사라지지 않습니다.

---

## 5. 기본형과 변종

초기 규칙:

```text
기본형 + 같은 기본형
→ 가능

같은 변종 + 같은 변종
→ 해당 계보가 있으면 가능

기본형 + 변종
→ 불가능

서로 다른 변종
→ 불가능
```

변종은 별도 TowerId로 취급합니다.

각 타워는 다음 중 하나를 명시합니다.

- 기본형 합체 계보
- 변종 대응 계보
- 변종 전용 계보
- 합체 불가

---

## 6. 계보

```text
기본 타워
→ 상위 타워
→ 더 높은 상위 타워
```

- 계보 사전 확인 가능
- 같은 재료는 항상 같은 결과
- 합체 전용 타워는 일반 굴리기 공식 분모가 없을 수 있음
- 리더보드 기본 희귀 분수에서는 비굴리기 타워 제외

---

## 7. 합체 누적

합체 실행 시 계정의 영구 합체 진행이 증가합니다.

가능한 영향:

- 변종 판정 보너스
- 합체 도감·기록
- 중후반 스탯 조건

환생해도 유지합니다. 정확한 변종 영향은 `RNG_PROBABILITY.md`와 변종 명세에서 정합니다.

---

## 8. 자동 편성과의 관계

합체 결과를 획득하면:

- 자동 편성 ON: 실제 기여도 기준 재평가 가능
- 자동 편성 OFF: 현재 편성 강제 변경 없음

재료 타워가 편성 중이면 합체할 수 없으므로 결과 처리 중 편성 수량이 음수가 되지 않습니다.

---

## 9. 저장과 원자성

수동 합체는 하나의 프로필 변경입니다.

```text
TransactionId 검증
→ 재료·보호·편성 수량 검증
→ 재료 차감
→ 결과 지급
→ 합체 누적·도감 갱신
→ 중요 저장 예약
```

- 버튼 연타로 중복 소비 금지
- 실패 검증 시 재료 차감 없음
- 클라이언트가 결과 ID 결정 불가
- 플레이어 간 재료 거래 없음

세부 계약은 `../technical/STATE_LIFECYCLE.md`를 따릅니다.

---

## 10. UI와 피드백

인벤토리 합체 탭:

- 합체 가능한 목록
- Owned·Protected·Equipped·Available 수량
- 필요한 재료
- 고정 결과
- 계보
- 합체 누적
- 확인 버튼

연출:

```text
재료 카드가 중심으로 모임
→ 짧은 압축·음향
→ 결과 카드와 모델 등장
```

전투와 굴리기를 오래 막지 않습니다.

---

## 11. 환생

유지:

- 합체 해금
- 합체 누적
- 결과 타워
- 계보 도감

환생으로 재료나 결과 타워가 사라지지 않습니다.

---

## 12. 사용하지 않는 구조

- 자동 합체
- 합체 실패
- 재료만 파괴
- 무작위 결과
- 실행 코인·정수 비용
- 합체권·대기시간
- 보호·편성 수량 자동 소비
- 기본형·변종 혼합
- 플레이어 간 재료 거래
- 환생 시 합체 진행 초기화

---

## 13. 미확정 사항

- 정확한 해금 환생 횟수와 가격
- 단계별 필요 수량
- 최초 합체 계보
- 합체 누적 기여량
- 변종 대응 계보
