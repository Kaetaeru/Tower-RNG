# 스테이지 생성·검증 기획

- 계층: 게임 기획
- 상태: **Confirmed (Living Document)**
- 계산 인덱스: `../balance/INDEX.md`
- 마지막 정리: 2026-08-03

## 요약

15개 스테이지를 모두 같은 깊이로 계산하지 않습니다.

```text
완전 검증
1, 3, 6, 9, 12, 15

경량 검증
2, 4, 5, 7, 8, 10, 11, 13, 14
```

스테이지 2는 초기 경제 검증 때문에 예외적으로 완전 검증했습니다. 스테이지 15는 집계 EC 검증을 마쳤지만 실제 몬스터 행동을 포함한 완전 검증이 남아 있습니다.

---

# 1. 완전 검증

완전 검증 대상:

```text
최초 기준: 스테이지 1
지역 최종: 스테이지 3, 6, 9, 12, 15
```

검사 항목:

- 실제 슬롯 수와 역할 상한
- 진입 계정과 안정 파밍 계정
- 가능한 역할 수량 조합 전체 또는 충분한 전수 집합
- 5웨이브 처리시간과 누수
- 보스 시간 비중
- SpawnBudget과 보상 단위
- 분당 코인·Defense XP
- 불리한 역할 조합
- 새 행동의 실제 위협도

기존 장기 프록시와 5% 이상 다르면 환생·행운·문·플레이타임 계산을 다시 실행합니다.

---

# 2. 경량 검증

중간 스테이지는 같은 지역의 완전 검증 기준점에서 통과한 행동을 축소·재조합합니다.

대표 편성:

```text
균형형
광역 화력 부족
단일 화력 부족
제어 부족
지원 부족
대형 사냥 부족
```

검사 항목:

- 진입 프로필이 완전히 막히지 않는가
- 안정 파밍 프로필에 누수가 없는가
- 계획 주기와 보상 효율이 목표 범위인가
- 특정 역할 하나의 부재로 진행이 멈추지 않는가
- 새 행동 없이 기존 SpawnCost로 설명 가능한가

---

# 3. 완전 검증 승격 조건

중간 스테이지라도 다음 조건이면 완전 검증으로 승격합니다.

- 새로운 몬스터 행동 최초 도입
- 회복·보호막 공유·분열·부활
- 순간 가속·도약·경로 변경
- 타워 공격 방해·무적 구간
- 다중 경로
- 일반 적의 체력 구간 변화
- 경량 파밍 편성 누수
- 계획 주기 또는 분당 보상 차이 5% 초과
- 역할 부족 편성이 균형형보다 25% 이상 느림
- Roblox 런타임이 계산보다 10% 이상 느림

이미 완전 검증한 행동은 수치와 발동 방식이 비슷한 다른 스테이지에서 재사용할 수 있습니다.

---

# 4. 공통 수치 공식

```text
StageScale(S)
= 10 ^ ((S - 1) / 3)

StandardHP(S)
= 5 × StageScale(S)

StageRewardScale(S)
= StageScale(S) × 1.08 ^ (S - 1)

CoinValue 또는 DefenseXP
= SpawnCost × StageRewardScale × 개별 보정
```

보상 단위는 일반적으로 한 주기 약 400을 사용합니다.

---

# 7. 검증된 지역 행동

## 지역 1·2

- 군집·고속·보호막
- 체력 구간 보호막
- 짧은 잠복과 경로 전진

## 지역 3 정글

- 처치 시 자식으로 분열
- 경로 중간 1회 도약
- HP 임계점 1회 재생
- 보스의 짧은 타겟 불가 폐합

## 지역 4 설원

- 저체력 이동속도 증가
- 보호막 유지 중 감속, 파괴 후 가속
- HP 구간 추가 보호막
- 보스의 짧은 타워 공격 지연과 경로 전진

스테이지 10·11은 스테이지 12에서 검증한 설원 행동을 축소 재사용해 통과했습니다.

```text
S10 실제 파밍 75.74초, 대표 편성 누수 0
S11 실제 파밍 84.25초, 대표 편성 누수 0
```

## 지역 5 용암

아직 행동형 기준점이 없습니다. 스테이지 13·14를 경량 작성하기 전에 스테이지 15에서 용암 행동을 완전 검증합니다.

---

# 8. 현재 작업 순서

```text
스테이지 15 행동형 완전 검증
→ 용암 행동과 예산 경계 확정
→ 스테이지 13·14 경량 검증
→ Roblox 런타임 검사
```

이는 지역 최종 기준점을 먼저 검증한 뒤 앞의 중간 스테이지에 행동을 축소 적용한다는 현재 제작 방식과 일치합니다.

---

# 9. 사용하지 않는 구조

- 모든 스테이지를 무조건 전체 조합으로 검증
- 중간 스테이지를 수치만 바꾼 복사본으로 제작
- 목표 주기를 강제 대기시간으로 구현
- 플레이어 DPS에 맞춰 적 HP 자동 조정
- 경량 검사 실패를 무시
- 새 행동을 SpawnCost 추정만으로 출시
