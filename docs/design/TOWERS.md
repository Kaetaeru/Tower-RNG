## 요약

타워는 굴리기로 획득하고 종류별 수량으로 보유하는 고정 데이터 개체입니다. 같은 ID의 타워는 모두 같은 능력, 행동과 외형을 가지며 개별 레벨·무작위 능력치·무작위 옵션을 사용하지 않습니다.

새 타워는 계정 공통 성장과 환생 보너스를 즉시 적용받습니다. 자동 편성이 켜져 있다면 새로운 획득으로 더 높은 평가 조합이 가능해졌을 때 편성이 자동으로 갱신될 수 있습니다.

---

## 1. 타워의 고정성

### TWR-001: 동일 타워의 동일 성능

같은 이름과 ID를 가진 타워는 다음이 동일합니다.

- 기본 전투 능력
- 이동과 공격 행동
- 역할
- 타겟 설정 지원 범위
- 고유 효과와 확장
- 외형과 모션 키트
- 합체 계보

### TWR-002: 개별 무작위 성장 미사용

초기 구조에서는 다음을 사용하지 않습니다.

- 개별 타워 레벨과 경험치
- 무작위 능력치
- 접두·접미사와 무작위 옵션
- 같은 타워끼리 다른 품질
- 중복 수량에 따른 직접 공격력 증가

영구 성장은 스탯 트리와 환생이 담당합니다.

---

## 2. 타워 데이터

각 타워 정의는 최소한 다음 개념을 가집니다.

- 고유 ID와 표시 이름
- 획득 확률과 보조 등급
- 전투 역할
- 이동 방식과 행동 루틴
- 공격 전달 방식
- 기본 능력과 행동 주기
- 대상 수와 타겟 정책
- 고유 효과와 선택적 확장 모듈
- 성능 강화와 치명타 적용 대상
- 모델·모션·효과·음향 참조
- 합체 결과와 변종 관계
- 자동 편성 평가에 필요한 정보

정확한 데이터 필드와 형식은 구현 명세에서 정합니다.

---

## 3. 역할

초기 역할:

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

복합 역할 타워는 둘 이상의 역할 슬롯 후보를 가질 수 있지만, 한 번의 편성에서 슬롯 하나만 사용합니다.

전투 역할은 이동 방식과 행동 루틴을 결정하지 않습니다. 검투사와 미니거너처럼 같은 단일 화력 역할도 서로 다른 행동 구조를 사용할 수 있습니다.

---

## 4. 보유와 중복

### TWR-003: 종류별 수량

중복 타워는 개별 품질 목록이 아니라 종류별 수량으로 관리합니다.

```text
견습 궁수 ×17
화염 마법사 ×3
왕실 기사 ×1
```

같은 타워를 여러 개 편성할 수 있으며 실제 편성 수는 보유 수량, 전체 슬롯과 역할 슬롯으로 결정됩니다.

### TWR-004: 보호 상태

희귀하거나 중요한 타워를 의도치 않게 합체 재료로 사용하는 일을 막기 위해 보호 상태를 사용합니다.

- 희귀 결과 자동 보호 가능
- 사용자가 보호 상태 변경 가능
- 보호된 수량은 자동 합체에서 제외
- 보호 해제 전 소비 작업에 사용하지 않음

보호 단위의 최종 데이터 형식은 추후 정합니다.

---

## 5. 획득과 자동 편성

### TWR-005: 획득 처리

타워를 획득하면 다음을 갱신합니다.

- 보유 수량
- 최초 획득 여부와 도감
- 최근 획득 기록
- 희귀 결과 보호 상태
- 자동 편성 재평가 필요 여부

### TWR-006: 자동 편성 OFF

자동 편성이 꺼져 있다면 새 타워를 얻어도 현재 편성을 변경하지 않습니다.

### TWR-007: 자동 편성 ON

자동 편성이 켜져 있다면 다음 조건에서 편성을 재평가할 수 있습니다.

- 새로운 타워 획득
- 합체로 상위 타워 획득
- 편성 슬롯 증가
- 역할 슬롯 증가
- 공통 성장으로 평가 순위 변화

재평가 결과는 현재 역할 성향 프리셋, 전체 슬롯과 역할 슬롯을 지켜야 합니다. 단순 표시 공격력만으로 지원·제어 타워를 항상 제외하지 않습니다.

---

## 6. 공통 성장

새 타워와 변종은 다음 성장 효과를 즉시 받습니다.

- 성능 강화
- 공격속도
- 치명타 확률과 피해
- 편성 슬롯
- 환생 코인·행운 배율 중 해당 효과

특정 역할·원소·타워에만 적용되는 영구 성장축을 핵심으로 사용하지 않습니다.

---

## 7. 외형과 행동

타워는 3D `Model`로 제작하며 `Basic`과 자유 이름의 모션 견본을 사용합니다.

타워 행동은 다음 축을 조합합니다.

```text
역할
+ 타겟 정책
+ 이동 방식
+ 행동 루틴
+ 전달 방식
+ 3D 모션
+ 선택적 고유 확장
```

일반 행동으로 표현하기 어려운 전장 전체 능력과 플레이어 조작은 고유 확장 프레임워크를 사용합니다.

---

## 8. 환생

환생해도 다음을 유지합니다.

- 타워 보유 수량
- 보호 상태
- 도감
- 합체 진행
- 변종 해금
- 자동 편성에서 사용할 수 있는 타워 풀

환생은 타워 수집을 초기화하지 않습니다.

---

## 9. 사용하지 않는 구조

- 같은 타워끼리 다른 무작위 성능
- 개별 타워 레벨
- 중복 보유만으로 직접 공격력 상승
- 자동 편성 OFF 상태에서 새 획득이 강제로 편성을 변경
- 특정 역할 투자 때문에 새 타워를 사용할 수 없는 구조
- 환생 시 타워 소실

---

## 10. 미확정 사항

- 보호 상태의 정확한 데이터 단위
- 보조 등급 체계와 명칭
- 최초 출시 타워 목록
- 역할별 대표 타워와 실제 수치
- 자동 편성 평가용 데이터 필드
- 도감 공개 정보 범위
- 최종 타워 카탈로그 형식
