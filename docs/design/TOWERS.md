## 요약

타워는 굴리기로 획득하고 종류별 수량으로 보유하는 고정 데이터 개체입니다. 같은 이름의 타워는 모두 같은 능력과 행동을 가지며, 개별 레벨·무작위 능력치·무작위 옵션을 사용하지 않습니다.

새로운 좋은 타워를 얻었을 때 기존 성장과 맞지 않아 사용하기 어려운 상황을 피합니다. 공통 성장 스탯은 새 타워에도 그대로 적용됩니다.

---

## 1. 타워의 고정성

### TWR-001: 동일 타워의 동일 성능

같은 이름과 ID를 가진 타워는 모두 동일합니다.

- 기본 전투 능력
- 공격 방식
- 역할
- 타겟 설정 지원 범위
- 고유 효과
- 외형
- 합체 계보

같은 타워끼리 개체별 품질 차이를 만들지 않습니다.

### TWR-002: 사용하지 않는 개별 성장

초기 구조에서는 다음을 사용하지 않습니다.

- 개별 타워 레벨
- 개체별 경험치
- 무작위 능력치
- 무작위 옵션 또는 접두·접미사
- 같은 타워끼리 다른 품질
- 중복 수량에 따른 직접 공격력 증가

타워의 영구적인 전역 성장은 `docs/design/STAT_TREE.md`가 담당합니다.

---

## 2. 타워 데이터

### TWR-003: 기본 정의 항목

각 타워 정의는 최소한 다음 개념을 가집니다.

- 고유 ID
- 표시 이름
- 획득 확률
- 보조 등급
- 전투 역할
- 기본 공격 또는 능력
- 공격·능력 발동 간격
- 공격 대상 수
- 타겟 우선순위 지원 여부
- 고유 효과
- 성능 강화 적용 대상
- 치명타 적용 대상
- 외형과 연출 참조
- 합체 결과 또는 합체 계보
- 변종 관계

정확한 데이터 스키마와 필드명은 구현 명세에서 확정합니다.

### TWR-004: 전투 역할

초기 역할은 다음 여섯 가지입니다.

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

복합 역할 또는 둘 이상의 역할 슬롯 중 하나를 선택할 수 있는 타워는 존재할 수 있습니다. 실제 편성 슬롯 계산은 `docs/design/FORMATION.md`에서 관리합니다.

---

## 3. 타워 보유

### TWR-005: 종류별 수량 보관

중복 타워는 개별 인스턴스 목록보다 종류별 보유 수량으로 관리합니다.

```text
견습 궁수 ×17
화염 마법사 ×3
왕실 기사 ×1
```

같은 타워를 여러 개 편성할 수 있으며, 실제 편성 가능 수는 보유 수량·전체 슬롯·역할 슬롯으로 결정됩니다. 동일 타워만을 위한 별도 편성 상한은 사용하지 않습니다.

### TWR-006: 보호 상태

희귀하거나 중요한 타워를 합체 재료 등으로 의도치 않게 사용하는 일을 막기 위해 보호 상태를 둘 수 있습니다.

- 희귀 결과 자동 보호 가능
- 사용자가 보호 상태를 변경할 수 있음
- 보호된 수량은 자동 합체 재료에서 제외
- 보호 해제 전에는 소비 작업에 사용하지 않음

보호 상태를 개별 수량 단위로 관리할지, 종류 전체 단위로 관리할지는 아직 확정하지 않습니다.

---

## 4. 획득과 도감

### TWR-007: 새 타워 획득

타워를 획득하면 다음 정보가 즉시 갱신됩니다.

- 보유 수량
- 최초 획득 여부
- 도감 발견 상태
- 최근 획득 기록
- 희귀 결과 보호 상태

새 타워를 얻었다고 기존 편성을 자동으로 제거하거나 교체하지 않습니다. 실제 편성 변경은 플레이어가 선택합니다.

### TWR-008: 확률과 등급

타워의 핵심 희귀도 정보는 실제 획득 확률입니다.

- 실제 확률: `1 / N`
- 보조 등급: 색상·필터·정렬·연출에 사용

보조 등급이 실제 확률을 대체하거나 숨기지 않습니다.

---

## 5. 공통 성장과 새 타워

### TWR-009: 신규 타워의 즉시 성장 적용

새로 획득한 타워는 이미 구매한 공통 스탯의 혜택을 즉시 받습니다.

예시:

- 성능 강화
- 공격속도
- 치명타 확률
- 치명타 피해

특정 역할·원소·타워에만 적용되는 영구 스탯을 핵심 성장축으로 사용하지 않습니다. 좋은 새 타워를 얻었을 때 기존 투자 때문에 사용할 수 없는 상황을 피합니다.

### TWR-010: 성능 강화 적용 정의

각 타워는 `성능 강화`가 자신의 어떤 수치에 적용되는지 명시합니다.

예시:

- 직접 공격 타워: 피해량
- 지속 피해 타워: 지속 피해량
- 제어 타워: 지정된 제어 수치 또는 지속시간
- 지원 타워: 지원 효과 수치
- 소환 타워: 소환체의 지정 전투 수치

보스 저항 규칙, 최대 중첩 수와 같은 공통 제한까지 성능 강화로 무한 증가시키지 않습니다.

---

## 6. 타워와 전투 연출

### TWR-011: 판정과 연출 분리

타워의 전투 판정은 시각 연출과 분리할 수 있습니다.

- 근접 돌진
- 투사체 이동
- 마법 효과 생성
- 소환체 연출

연출 때문에 이미 죽은 대상에게 피해가 낭비되거나 실제 공격 판정이 불필요하게 늦어지지 않도록 합니다.

전투 계산은 `docs/design/COMBAT.md`, 타겟 선택은 `docs/design/TARGETING.md`가 담당합니다.

## 8. Open Questions

사용자 승인 전에는 다음을 확정하지 않습니다.

- 보호 상태를 개별 수량 단위로 관리할지 여부
- 보조 등급 체계와 명칭
- 최초 출시 타워 목록
- 역할별 대표 타워와 실제 수치
- 도감에서 공개할 정보 범위
- 타워 카탈로그의 최종 데이터 형식
