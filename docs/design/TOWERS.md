## 요약

타워는 굴리기로 획득하고 종류별 수량으로 보유하는 고정 데이터 개체입니다. 같은 ID의 타워는 모두 같은 능력, 행동과 외형을 가지며 개별 레벨·무작위 능력치·무작위 옵션을 사용하지 않습니다.

첫 출시의 일반 굴리기 타워는 최소 50종을 목표로 합니다. 여섯 역할마다 약 8~10종의 대표 타워를 준비하되, 행동 문법과 실루엣이 반복되지 않도록 구성합니다. 변종과 합체 전용 타워는 기본 50종에 추가되는 콘텐츠입니다.

---

## 1. 타워의 고정성

### TWR-001: 동일 타워의 동일 성능

같은 이름과 ID를 가진 타워는 다음이 동일합니다.

- 기본 전투 능력
- 이동과 공격 행동
- 역할
- 타겟 설정 지원 범위
- 고유 효과와 확장
- 외형과 모션 키트
- 합체 계보

### TWR-002: 개별 무작위 성장 미사용

초기 구조에서는 다음을 사용하지 않습니다.

- 개별 타워 레벨과 경험치
- 무작위 능력치
- 접두·접미사와 무작위 옵션
- 같은 타워끼리 다른 품질
- 중복 수량에 따른 직접 공격력 증가

영구 성장은 스탯 트리와 환생이 담당합니다.

---

## 2. 출시 콘텐츠 목표

### TWR-003: 일반 타워 최소 50종

첫 출시 목표:

```text
일반 굴리기 타워 최소 50종
+ 변종 타워
+ 합체 전용 상위 타워
```

50종은 이름과 수치만 다른 복제 타워 수가 아니라 실제 수집 카탈로그의 최소 목표입니다.

### TWR-004: 역할별 8~10종

초기 역할:

- 단일 화력
- 광역 화력
- 제어
- 마무리
- 지원
- 대형 사냥

각 역할에 8~10종을 목표로 하며 전체 일반 타워가 최소 50종이 되게 조정합니다.

복합 역할 타워는 실제 카탈로그에서 한 종류로만 계산합니다. 한 타워를 두 역할 수량에 중복 계산해 목표를 채우지 않습니다.

### TWR-005: 행동 다양성

같은 역할 안에서도 다음을 분산합니다.

- Formation·Engage·ChargeThrough·Orbit 등 이동 방식
- Impact·Sequence·Burst·Channel·Summon 등 행동 루틴
- Contact·Projectile·Beam·Area 등 전달 방식
- 단순 기본 타워와 고유 확장 타워
- 인간형·기계·생물·추상 오브젝트 등 실루엣

모든 50종을 고유 확장으로 만들 필요는 없지만, 수치와 색만 다른 기본 타워가 대부분이 되지는 않게 합니다.

---

## 3. 타워 데이터

각 타워 정의는 최소한 다음 개념을 가집니다.

- 고유 ID와 표시 이름
- 획득 확률과 보조 등급
- 전투 역할
- 이동 방식과 행동 루틴
- 공격 전달 방식
- 기본 능력과 행동 주기
- 대상 수와 타겟 정책
- 고유 효과와 선택적 확장 모듈
- 성능 강화와 치명타 적용 대상
- 모델·모션·효과·음향 참조
- 합체 결과와 변종 관계
- 자동 편성 평가 정보
- 피드백·연출 등급

실제 목록과 수치는 `docs/reference/TOWER_CATALOG.md`에서 관리합니다.

---

## 4. 보유와 중복

### TWR-006: 종류별 수량

중복 타워는 개별 품질 목록이 아니라 종류별 수량으로 관리합니다.

```text
견습 궁수 ×17
화염 마법사 ×3
왕실 기사 ×1
```

같은 타워를 여러 개 편성할 수 있으며 실제 편성 수는 보유 수량, 전체 슬롯과 역할 슬롯으로 결정됩니다.

### TWR-007: 보호 상태

- 희귀 결과 자동 보호 가능
- 사용자가 보호 상태 변경 가능
- 보호된 수량은 자동 합체에서 제외
- 보호 해제 전 소비 작업에 사용하지 않음

보호 단위의 최종 데이터 형식은 추후 정합니다.

---

## 5. 획득과 자동 편성

### TWR-008: 획득 처리

타워를 획득하면 다음을 갱신합니다.

- 보유 수량
- 최초 획득 여부와 도감
- 최근 획득 기록
- 희귀 결과 보호 상태
- 자동 편성 재평가 필요 여부
- 현재 보유 희귀 타워 리더보드 후보

### TWR-009: 자동 편성 OFF

자동 편성이 꺼져 있다면 새 타워를 얻어도 현재 편성을 변경하지 않습니다.

### TWR-010: 자동 편성 ON

다음 조건에서 편성을 재평가할 수 있습니다.

- 새로운 타워 획득
- 합체로 상위 타워 획득
- 편성 슬롯 증가
- 역할 슬롯 증가
- 공통 성장으로 평가 순위 변화

재평가 결과는 역할 성향, 전체 슬롯과 역할 슬롯을 지켜야 합니다. 지원·제어 타워를 표시 공격력만으로 제외하지 않습니다.

---

## 6. 공통 성장

새 타워와 변종은 다음 성장 효과를 즉시 받습니다.

- 성능 강화
- 공격속도
- 치명타 확률과 피해
- 편성 슬롯
- 해당 환생 보너스

특정 역할·원소·타워에만 적용되는 영구 성장축을 핵심으로 사용하지 않습니다.

---

## 7. 외형·행동·타격감

타워는 3D `Model`과 `Basic + 자유 이름 모션 견본`으로 제작합니다.

```text
역할
+ 타겟 정책
+ 이동 방식
+ 행동 루틴
+ 전달 방식
+ 3D 모션
+ 선택적 고유 확장
```

모든 공격은 공격자의 움직임, 접촉 순간과 대상의 피격 반응을 읽을 수 있어야 합니다. 수치 판정만 발생하고 타워와 대상이 정적으로 남는 공격은 기본 완성 기준을 충족하지 않습니다.

세부 기준은 `FEEL_AND_FEEDBACK.md`를 따릅니다.

---

## 8. 환생

환생해도 다음을 유지합니다.

- 타워 보유 수량
- 보호 상태
- 도감
- 합체 진행
- 변종 해금
- 자동 편성 타워 풀

환생은 타워 수집을 초기화하지 않습니다.

---

## 9. 사용하지 않는 구조

- 같은 타워끼리 다른 무작위 성능
- 개별 타워 레벨
- 중복 보유만으로 직접 공격력 상승
- 자동 편성 OFF 상태에서 강제 편성 변경
- 특정 역할 투자 때문에 새 타워를 사용할 수 없는 구조
- 환생 시 타워 소실
- 역할 수량 목표를 복합 역할 중복 계산으로 채움
- 색과 수치만 바꾼 타워로 일반 50종 대부분을 구성
- 움직임과 피격 반응 없이 피해 숫자만 표시

---

## 10. 미확정 사항

- 일반 50종의 실제 목록
- 역할별 최종 수량
- 보조 등급 체계와 명칭
- 보호 상태 데이터 단위
- 자동 편성 평가용 데이터 필드
- 도감 공개 정보 범위
- 개별 타워의 피드백 등급
