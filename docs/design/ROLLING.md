## 요약

굴리기는 일정한 간격마다 무료로 타워를 획득하는 핵심 시스템입니다. 실제 획득 확률을 `1 / N` 형태로 표시하며, 낮은 결과도 중복 보유·합체·특수 주사위 진행에 기여해야 합니다.

정해진 굴리기 횟수마다 황금 주사위와 다이아몬드 주사위가 확정 적용됩니다. 전체 굴리기 횟수와 특수 주사위 진행도는 영구 저장되며 실패나 접속 종료로 초기화되지 않습니다.

---

## 1. 기본 굴리기

### ROL-001: 무료 주기 굴리기

- 기본 굴리기에는 일반 성장 재화나 연금 정수를 요구하지 않습니다.
- 플레이어는 일정한 굴리기 간격마다 타워를 한 개 획득합니다.
- 전투 중에도 굴리기는 계속 진행됩니다.
- 굴리기와 전투는 서로를 중단시키는 별도 모드가 아닙니다.

굴리기 간격은 스탯 트리와 포션에 의해 단축될 수 있습니다.

### ROL-002: 실제 확률 표시

각 타워는 추상적인 등급명보다 실제 확률을 중심으로 표시합니다.

예시:

```text
견습 궁수      1 / 2
석궁병          1 / 75
화염 마법사    1 / 1,250
왕실 기사      1 / 25,000
```

`Rare`, `Epic`, `Legendary`와 같은 등급은 색상·필터·정렬을 위한 보조 정보로만 사용할 수 있습니다. 실제 획득 가능성은 `1 / N` 표기가 기준입니다.

---

## 2. 특수 주사위

### ROL-003: 황금 주사위

- 매 10번째 굴리기에 확정 적용됩니다.
- 초기 기준 행운 배율은 `×5`입니다.
- 특정 타워를 확정 지급하지 않고 해당 한 번의 굴리기에 행운을 적용합니다.

### ROL-004: 다이아몬드 주사위

- 매 100번째 굴리기에 확정 적용됩니다.
- 황금 주사위보다 높은 행운 배율을 사용합니다.
- 정확한 배율은 아직 확정하지 않습니다.

### ROL-005: 주기 중첩 처리

100번째 굴리기처럼 황금 주사위와 다이아몬드 주사위의 주기가 겹치면 다이아몬드 주사위가 황금 주사위를 대체합니다. 두 효과를 동시에 곱하지 않습니다.

### ROL-006: 진행도 보존

다음 값은 영구 저장됩니다.

- 전체 굴리기 횟수
- 다음 황금 주사위까지 남은 횟수
- 다음 다이아몬드 주사위까지 남은 횟수

카운터는 다음 상황에서 초기화되지 않습니다.

- 낮은 등급 타워 획득
- 서버 이동
- 접속 종료
- 베이스 과부하
- 스테이지 변경

UI에는 다음 특수 주사위까지 남은 횟수를 표시합니다.

## 3. 행운과 굴리기 속도

### ROL-007: 행운

행운은 굴리기 결과의 희귀 타워 획득 가능성을 높이는 성장값입니다.

행운에 영향을 줄 수 있는 요소:

- 영구 행운 스탯
- 행운의 포션
- 황금 주사위
- 다이아몬드 주사위
- 합체 누적에 따른 변종 확률 보너스

일반 희귀도 행운과 변종 확률 보너스의 정확한 계산 순서는 시스템 명세 단계에서 확정합니다.

### ROL-008: 굴리기 속도

굴리기 속도 증가는 굴리기 간격을 단축합니다.

영향:

- 같은 시간 동안의 총 굴리기 횟수 증가
- 황금·다이아몬드 주사위 도달 속도 증가
- 중복 타워 축적 속도 증가
- 합체 재료 축적 속도 증가

굴리기 속도는 영구 스탯과 신속한 굴리기 포션의 영향을 받을 수 있습니다.

---

## 4. 획득 결과 처리

### ROL-009: 모든 굴림의 진행 가치

낮은 확률 결과가 아니더라도 굴림은 다음 진행에 기여합니다.

- 전체 굴리기 횟수 증가
- 특수 주사위 진행
- 중복 타워 수량 증가
- 합체 재료 축적
- 합체를 통한 장기 변종 확률 성장

완전히 무의미한 굴림이 생기지 않도록 합니다.

### ROL-010: 희귀 결과 연출

희귀 타워 획득 연출은 화려하게 만들 수 있지만 다음 원칙을 따릅니다.

- 전투 진행을 막지 않음
- 수동 건너뛰기 가능
- 자동 건너뛰기 설정 가능
- 최근 획득 기록 제공
- 희귀 타워 자동 보호 가능

새 타워의 보유·보호·도감 처리는 `docs/design/TOWERS.md`에서 관리합니다.

---

## 5. 자동 굴리기

### ROL-011: 자동 굴리기 해금

자동 굴리기는 스탯 트리에서 해금하는 편의 기능입니다.

- 자동 굴리기도 일반 굴리기와 같은 확률 및 특수 주사위 규칙을 사용합니다.
- 자동 기능이 수동 굴리기보다 불리하거나 별도의 비용을 요구하지 않습니다.
- 자동 굴리기 중에도 희귀 결과 기록과 보호 규칙이 유지됩니다.

자동 굴리기의 정확한 시작·정지 UI와 접속 종료 시 처리 방식은 아직 확정하지 않습니다.

---

## 6. 사용하지 않는 구조

- 굴리기 1회마다 재화 소비
- 실패 결과 또는 빈 결과
- 특수 주사위 카운터 초기화
- 기간 한정으로만 얻을 수 있는 핵심 전투 타워
- 희귀 연출을 강제로 끝까지 시청해야 하는 구조
- 등급명만 보여주고 실제 확률을 숨기는 구조
- 같은 이름의 타워에 서로 다른 무작위 능력치를 부여하는 구조

## 7. 구현 단계에서 고려할 사항

하위 문서에서는 다음을 반드시 다룹니다.

- 굴리기 결과와 카운터의 서버 권한
- 중복 요청으로 여러 결과를 받는 악용 방지
- 저장 중 종료될 때 굴리기 횟수와 결과의 원자성
- 고정 시드를 이용한 확률 테스트
- 행운 계산 순서
- 특수 주사위 중첩 우선순위
- 자동 굴리기 호출 빈도와 서버 부하
- 희귀 연출과 실제 결과 지급의 분리

- 최종 행운 계산식과 배율 적용 순서
- 자동 굴리기의 정확한 UI 흐름
