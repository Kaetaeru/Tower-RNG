## 요약

굴리기는 일정한 간격마다 무료로 타워를 획득하는 핵심 시스템입니다. 실제 획득 확률을 `1 / N` 형태로 표시하며, 전투와 동시에 계속 진행됩니다.

자동 굴리기는 극초반 튜토리얼에서 매우 저렴한 첫 스탯 노드로 해금합니다. 이후 플레이어는 자동 굴리기를 켜 둔 상태로 전투, 코인 수집과 메뉴 조작을 함께 수행할 수 있습니다.

---

## 1. 기본 굴리기

### ROL-001: 무료 주기 굴리기

- 기본 굴리기에는 코인이나 연금 정수를 요구하지 않습니다.
- 일정한 굴리기 간격마다 타워를 한 개 획득합니다.
- 전투 중에도 굴리기는 계속 진행됩니다.
- 굴리기와 전투는 별도 모드가 아닙니다.
- 굴리기 간격은 스탯 트리와 포션으로 단축할 수 있습니다.

### ROL-002: 실제 확률 표시

각 타워는 실제 획득 확률을 중심으로 표시합니다.

```text
견습 궁수      1 / 2
석궁병          1 / 75
화염 마법사    1 / 1,250
왕실 기사      1 / 25,000
```

등급은 색상·필터·정렬을 위한 보조 정보이며, 실제 가능성은 `1 / N` 표기가 기준입니다.

---

## 2. 자동 굴리기

### ROL-003: 극초반 해금

자동 굴리기는 첫 코인을 획득하고 스탯 트리를 여는 튜토리얼에서 매우 저렴한 첫 노드로 구매합니다.

```text
첫 수동 굴리기
→ 자동 전투 확인
→ 코인 획득
→ 스탯 트리 열기
→ 자동 굴리기 구매
```

- 자동 굴리기는 수동 굴리기와 동일한 확률을 사용합니다.
- 황금·다이아몬드 주사위 진행도도 동일하게 증가합니다.
- 희귀 결과 기록과 보호 규칙을 유지합니다.
- 자동 굴리기 ON/OFF를 지원합니다.
- 환생 후에도 해금 상태와 설정을 유지합니다.

수동 굴리기는 자동 굴리기 해금 후에도 즉시 한 번 굴리거나 자동 기능을 끈 상태에서 사용할 수 있습니다.

---

## 3. 특수 주사위

### ROL-004: 황금 주사위

- 매 10번째 굴리기에 확정 적용됩니다.
- 초기 기준 행운 배율은 `×5`입니다.
- 특정 타워를 확정 지급하지 않고 해당 한 번의 굴리기에 행운을 적용합니다.

### ROL-005: 다이아몬드 주사위

- 매 100번째 굴리기에 확정 적용됩니다.
- 황금 주사위보다 높은 행운 배율을 사용합니다.
- 정확한 배율은 아직 확정하지 않습니다.

### ROL-006: 주기 중첩

100번째 굴리기처럼 주기가 겹치면 다이아몬드 주사위가 황금 주사위를 대체합니다. 두 배율을 동시에 곱하지 않습니다.

### ROL-007: 진행도 보존

다음 값은 영구 저장됩니다.

- 전체 굴리기 횟수
- 다음 황금 주사위까지 남은 횟수
- 다음 다이아몬드 주사위까지 남은 횟수

다음 상황에서도 초기화하지 않습니다.

- 낮은 타워 획득
- 서버 이동과 접속 종료
- 베이스 과부하
- 스테이지 변경
- 환생

---

## 4. 행운

### ROL-008: 행운의 구성

행운은 희귀 타워 획득 가능성을 높이는 계정 성장값입니다.

행운에 영향을 주는 확정 축:

- 스탯 트리의 영구 행운
- 환생 행운 배율
- 현재 입장한 스테이지의 행운
- 행운의 포션
- 황금 주사위
- 다이아몬드 주사위

합체 누적은 일반 희귀도보다 변종 판정에 별도로 영향을 줄 수 있습니다.

정확한 계산 순서와 공식은 시스템 명세에서 정합니다.

### ROL-009: 현재 스테이지 행운

굴리기에는 현재 플레이어가 입장한 스테이지의 행운이 적용됩니다.

- 높은 스테이지일수록 더 높은 행운 제공
- 낮은 스테이지로 이동하면 해당 스테이지 행운으로 변경
- 최고 해금 스테이지가 아니라 현재 입장 스테이지 기준
- 몬스터 처치율과 무관하게 해당 스테이지에 있는 동안 적용
- 너무 어려운 스테이지에서는 행운은 높지만 코인 수입이 낮아질 수 있음

이 선택은 플레이어가 코인 파밍 효율과 굴리기 행운 사이에서 현재 위치를 선택할 수 있게 합니다.

## 5. 굴리기 속도

### ROL-010: 굴리기 간격 감소

굴리기 속도는 굴리기 간격을 단축합니다.

영향:

- 같은 시간의 총 굴리기 횟수
- 황금·다이아몬드 주사위 도달 속도
- 중복 타워 축적 속도
- 합체 재료 축적 속도

굴리기 속도는 영구 스탯과 포션의 영향을 받을 수 있습니다.

---

## 6. 모든 굴림의 진행 가치

### ROL-011: 빈 결과 없음

모든 굴림은 다음 중 하나 이상에 기여합니다.

- 전체 굴리기 횟수
- 특수 주사위 진행
- 타워 보유 수량
- 합체 재료
- 합체 누적과 변종 성장

실패 결과나 아무것도 받지 못하는 결과를 사용하지 않습니다.

### ROL-012: 희귀 결과 연출

희귀 획득 연출은 화려하게 만들 수 있지만 다음을 지킵니다.

- 전투와 코인 수집을 막지 않음
- 수동 건너뛰기 가능
- 자동 건너뛰기 설정 가능
- 최근 획득 기록 제공
- 희귀 타워 자동 보호 가능

---

## 7. 환생과 굴리기

환생하면 현재 코인과 지역·스테이지 진행은 초기화되지만 다음은 유지됩니다.

- 자동 굴리기
- 전체 굴리기 횟수
- 황금·다이아몬드 주사위 진행도
- 보유 타워와 중복 수량

환생 행운 배율은 이후 모든 일반 굴리기에 영구 적용됩니다.

---

## 8. 사용하지 않는 구조

- 굴리기 1회마다 재화 소비
- 실패 또는 빈 결과
- 특수 주사위 카운터 초기화
- 환생 시 굴리기 진행 초기화
- 자동 굴리기를 중후반까지 잠금
- 자동 굴리기에 별도 비용이나 불리한 확률 적용
- 실제 확률을 숨기고 등급명만 표시
- 같은 타워에 서로 다른 무작위 능력치 부여

---

## 9. 미확정 사항

- 기본 굴리기 간격
- 자동 굴리기 노드의 정확한 가격
- 다이아몬드 주사위의 정확한 행운 배율
- 최종 행운 계산식과 배율 순서
- 일반 행운과 변종 판정의 관계
