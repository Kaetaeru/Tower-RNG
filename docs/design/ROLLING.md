## 요약

굴리기는 일정 간격마다 무료로 타워 한 개를 획득하는 핵심 시스템입니다. 전투와 동시에 진행하며 빈 결과가 없습니다.

첫 수직 슬라이스:

```text
기본 굴리기 간격: 4.0초
굴리기 속도 I: 3.6초
자동 굴리기 구매: 약 8초
```

공식 기본 확률만 표시하고 현재 스테이지·환생 행운 토큰·특수 주사위가 적용된 유효 확률은 표시하지 않습니다.

---

## 1. 기본 굴리기

### ROL-001: 무료 주기

- 코인·정수·Robux 소비 없음
- 한 굴림에 정확히 한 타워
- 실패·빈 결과 없음
- 전투와 코인 수집 중 계속 진행
- 기본 간격 4.0초
- 스탯 트리와 포션으로 단축 가능

### ROL-002: 첫 속도 성장

```text
굴리기 속도 I
가격 160코인
4.0초 → 3.6초
```

균형 소비 약 1분 19초에 구매합니다. 후속 단계는 아직 미확정입니다.

### ROL-003: 누적 굴림 기준

현재 속도 노드만 적용한 계획값:

| 활성 플레이 | 누적 굴림 |
|---:|---:|
| 15분 | 246 |
| 30분 | 496 |
| 2시간 | 1,996 |
| 5시간 | 4,996 |
| 12시간 | 11,996 |
| 15시간 | 14,996 |
| 20시간 | 19,996 |
| 25시간 | 24,996 |
| 30시간 | 29,996 |

후속 속도 노드가 정해지면 행운 누적 획득률을 다시 계산합니다.

## 2. 공식 확률과 전역 풀

### ROL-004: 공식 `1 / N`

- `BaseOddsN`은 임의 정밀도 10진수 문자열
- 공식 분모가 도감·획득 연출·리더보드 기준
- V1 일반 최고 타워 `1 / 10^20`
- 보조 등급은 색상·필터용

### ROL-005: 전역 일반 풀

- 첫 스테이지에서도 모든 일반 타워 이론상 등장
- 높은 스테이지는 타워 종류가 아니라 행운 증가
- 낮은 스테이지로 돌아가도 일반 풀 유지
- 환생으로 풀·카운터·타워 초기화 없음

예외:

- 해금 전 변종
- 이벤트·한정 풀
- 합체 전용 타워
- 비굴리기 획득 타워

### ROL-006: 신규 타워

- 기존 중·고희귀 분모 유지
- CommonReserve 우선 사용
- 공식 변경 사전 공개
- 확률표 버전 기록

---

## 3. 자동 굴리기

### ROL-007: 극초반 해금

```text
첫 수동 굴리기
→ 첫 슬라임 처치·코인 10
→ 자동 굴리기 구매
```

- 수동과 같은 확률
- 특수 주사위 진행 동일
- 희귀 기록·보호 규칙 동일
- ON/OFF 지원
- 환생 후 해금·설정 유지

수동 굴리기는 자동 해금 후에도 즉시 한 번 굴리는 입력으로 남길 수 있습니다.

## 4. 특수 주사위

### ROL-008: 황금

- 매 10번째 굴림
- `BaseCompression +0.25`
- 최종 상한 `5.65`
- 특정 타워 확정 지급 아님

### ROL-009: 다이아몬드

- 매 100번째 굴림
- 황금 대신 적용
- `BaseCompression +0.65`
- 최종 상한 `6.05`
- 특정 타워 확정 지급 아님

### ROL-010: 진행 보존

영구 저장:

- TotalRolls
- GoldenProgress
- DiamondProgress

접속 종료, 서버 이동, 스테이지 변경, 과부하와 환생으로 초기화하지 않습니다. 오프라인에는 진행되지 않습니다.

## 5. 행운

### ROL-011: 기본 공식

```text
BaseCompression
= 1
+ 0.245 × (CurrentStage - 1)
+ 0.040 × AllocatedLuckTokens
+ TemporaryCompressionBonus
```

일반 굴림:

```text
clamp(BaseCompression, 1.00, 5.40)
```

- 스테이지 이동 시 즉시 재계산
- 환생 토큰 배분 시 즉시 재계산
- 처치율과 무관하게 현재 입장 스테이지 기준
- 환생 횟수만으로 자동 행운 없음

### ROL-012: 스테이지 기준

토큰 없는 일반 굴림:

```text
스테이지 1  = 1.000
스테이지 3  = 1.490
스테이지 6  = 2.225
스테이지 9  = 2.960
스테이지 12 = 3.695
스테이지 15 = 4.430
```

높은 스테이지에서 행운만 받고 낮은 스테이지로 복귀하는 전략을 허용합니다.

### ROL-013: 토큰 기준

```text
행운 배분 토큰 1개
→ Compression +0.040
```

스테이지 15에서 약 25개면 일반 굴림 상한입니다. 토큰 지급량과 실제 분배는 아직 미확정입니다.

### ROL-014: 순서 보존

행운 적용 후에도:

- 전체 합 100%
- 한 굴림 한 결과
- 희귀 순서 역전 없음
- 흔한 결과 확률 0 금지

## 6. 획득 체감 검증

50자리 사다리와 중앙 V1 진행을 사용한 균형 행운 배분 시나리오:

```text
최초 30분 이후 행운에 평균 1.50토큰/시간 배분
```

`1 / 10^20` 최고 타워 누적 획득률:

| 활성 플레이 | 확률 |
|---:|---:|
| 12시간 | 1.549% |
| 13.5시간 | 3.012% |
| 15시간 | 4.661% |
| 20시간 | 11.007% |
| 25시간 | 17.062% |
| 30시간 | 22.705% |

V1 완주 13.5~15시간의 3~5%, 숙련 25~30시간의 15~25% 목표를 통과합니다.

## 7. 모든 굴림의 진행 가치

모든 결과는 다음에 기여합니다.

- 전체 굴림 횟수
- 황금·다이아몬드 진행
- 타워 보유 수량
- 수동 합체 재료
- 도감·희귀 기록
- 변종 판정 기회

희귀 획득 연출:

- 공식 기본 `1 / N` 표시
- 전투·수집을 장시간 정지시키지 않음
- 건너뛰기·축약 설정
- 공식 분모 기준 자동 보호

---

## 8. 서버 권위와 저장

- 결과는 서버 결정
- 카운터·결과·도감 기록을 같은 프로필 변경으로 처리
- 극희귀는 중요 저장 큐
- 공식 분모 문자열 보존
- 유효 확률표는 파생 캐시이며 저장하지 않음
- 자동 타이머는 서버 권위
- 스테이지·토큰·포션 변경 시 다음 정상 굴림부터 새 캐시 사용

---

## 9. 사용하지 않는 구조

- 굴리기 재화 소비
- 실패·빈 결과
- 지역별 일반 풀
- 환생 시 풀·카운터 초기화
- 자동 굴리기 유료·중후반 잠금
- 현재 유효 확률 표시
- 공식 확률과 다른 숨은 기본 확률
- 일반 number에 거대 분모 저장
- 오프라인 굴리기
- Robux 직접 반복 굴리기
- 특정 타워 확정 황금·다이아몬드

---

## 10. 남은 검증

- 환생당 토큰 수와 실제 평균 배분
- TemporaryCompressionBonus 값
- 후속 굴리기 속도 단계
- 전체 50종 최고 보유·편성 전투력 분포
- 변종 판정과 일반 행운 관계
- 실제 연출 길이와 3.6초 주기 충돌
