## 요약

굴리기는 일정 간격마다 무료로 타워 한 개를 획득하는 핵심 시스템입니다. 전투와 동시에 진행하며 빈 결과가 없습니다.

각 타워는 공식 기본 확률 `1 / N`을 가집니다. 분모는 `999,999`에서 끝나지 않고 수십억·수조·그 이상으로 확장할 수 있습니다. 플레이어에게는 공식 기본 확률만 표시하며 현재 행운이 반영된 실시간 확률은 표시하지 않습니다.

---

## 1. 기본 굴리기

### ROL-001: 무료 주기 굴리기

- 기본 굴리기에 코인·연금 정수·Robux를 요구하지 않음
- 한 굴림에 정확히 타워 한 개 지급
- 실패·빈 결과 없음
- 전투와 코인 수집 중 계속 진행
- 굴리기 간격은 스탯 트리와 포션으로 단축 가능

### ROL-002: 공식 기본 확률

표시 예:

```text
견습 궁수       1 / 10
석궁병           1 / 998
왕실 기사        1 / 999
공허의 성자      1 / 1,000,000,000,000
```

- `N`은 임의 정밀도 10진수 문자열로 저장
- 카탈로그의 공식 기본 확률이 도감·획득 연출·리더보드의 기준
- 보조 등급은 색상·필터용이며 실제 희귀도 기준은 `1 / N`
- 큰 분모는 카드에서 축약 가능하지만 상세 화면에서 전체 값 확인 가능

### ROL-003: 현재 확률 비공개

표시하지 않음:

- 현재 행운 적용 후 `1 / N`
- 실시간 결과별 확률표
- 내부 정규화 가중치

표시 가능:

- 현재 행운 수치 또는 배율
- 행운의 출처
- 황금·다이아몬드 주사위 상태

확률 계산의 전체 계약은 `RNG_PROBABILITY.md`에서 관리합니다.

## 2. 전역 타워 풀

### ROL-004: 일반 타워의 전역 등장

- 첫 스테이지에서도 모든 일반 타워가 이론적으로 등장 가능
- 높은 스테이지는 타워 종류가 아니라 행운을 높임
- 낮은 스테이지로 돌아가도 일반 풀이 축소되지 않음
- 환생으로 일반 풀이 초기화되지 않음

예외:

- 해금 전 변종 계열
- 이벤트·한정 별도 풀
- 합체 전용 상위 타워
- 명시된 비굴리기 획득 타워

### ROL-005: 신규 타워 추가

- 기존 중·고희귀 타워의 공식 분모 유지
- 신규 타워는 공통 저희귀 확률 예비분을 우선 사용
- 공식 확률 변경은 사전에 공개
- 확률표 버전을 기록

## 3. 자동 굴리기

### ROL-006: 극초반 해금

```text
첫 수동 굴리기
→ 자동 전투 확인
→ 코인 획득
→ 스탯 트리 열기
→ 자동 굴리기 구매
```

- 수동 굴리기와 같은 확률
- 황금·다이아몬드 진행 동일 증가
- 희귀 기록과 보호 규칙 동일
- ON/OFF 지원
- 환생 후 해금과 설정 유지

수동 굴리기는 자동 해금 후에도 즉시 한 번 굴리는 입력으로 남길 수 있습니다.

---

## 4. 특수 주사위

### ROL-007: 황금 주사위

- 매 10번째 굴리기에 적용
- 초기 행운 보정 기준은 기존 `×5 LuckScore` 후보
- 특정 타워 확정 지급이 아님

### ROL-008: 다이아몬드 주사위

- 매 100번째 굴리기에 적용
- 황금보다 높은 행운 보정
- 정확한 값은 시뮬레이션 후 확정

### ROL-009: 주기 중첩

100번째처럼 주기가 겹치면 다이아몬드가 황금을 대체합니다. 둘을 동시에 곱하지 않습니다.

### ROL-010: 진행 보존

영구 저장:

- 전체 굴림 횟수
- 황금 진행
- 다이아몬드 진행

서버 이동, 접속 종료, 스테이지 변경, 과부하와 환생으로 초기화하지 않습니다. 오프라인 중에는 진행되지 않습니다.

---

## 5. 행운

### ROL-011: 행운 입력

- 스탯 트리 영구 행운
- 환생 행운
- 현재 스테이지 행운
- 행운 포션
- 허용된 제한적 유료 행운
- 황금·다이아몬드 주사위

서버는 이를 `LuckScore`로 합성해 로그 희귀도 압축 방식으로 전체 확률표에 적용합니다.

### ROL-012: 희귀 순서 유지

행운 적용 후에도 다음을 지킵니다.

- 전체 확률 합 100%
- 한 굴림 한 결과
- 더 희귀한 타워가 더 흔한 타워보다 높은 확률이 되는 역전 없음
- 흔한 결과가 완전히 사라지지 않음

### ROL-013: 현재 스테이지 행운

- 현재 들어간 스테이지 기준
- 높은 스테이지일수록 증가
- 처치율과 무관하게 적용
- 스테이지 이동 시 즉시 변경
- 어려운 높은 스테이지에서 행운만 얻는 전략 허용

---

## 6. 모든 굴림의 진행 가치

### ROL-014: 빈 결과 없음

모든 굴림은 다음에 기여합니다.

- 굴림 카운터
- 특수 주사위 진행
- 타워 보유 수량
- 수동 합체 재료
- 도감과 희귀 기록
- 변종 판정 기회

### ROL-015: 희귀 결과 연출

- 공식 기본 `1 / N` 표시
- 전투와 코인 수집을 장시간 정지시키지 않음
- 건너뛰기·축약 설정 지원
- 최근 획득 기록
- 공식 기본 분모 기준 자동 보호

---

## 7. 저장과 서버 권위

- 굴리기 결과는 서버가 결정
- 카운터 증가·결과 지급·도감 기록을 하나의 프로필 변경으로 처리
- 극희귀 결과는 우선 저장 큐에 등록
- 공식 분모는 문자열로 보존
- 현재 행운 적용 확률표는 파생 캐시이며 저장하지 않음

세부 계약은 `../technical/STATE_LIFECYCLE.md`를 따릅니다.

---

## 8. 사용하지 않는 구조

- 굴리기마다 재화 소비
- 실패·빈 결과
- 지역별 일반 타워 풀
- 환생 시 타워 풀·카운터 초기화
- 자동 굴리기 중후반 잠금
- 자동 굴리기에 불리한 확률
- 현재 행운 적용 확률 표시
- 공식 `1 / N`과 다른 실제 기본 확률
- 일반 숫자형에 거대한 분모 강제 저장
- 오프라인 굴리기
- Robux 직접 반복 굴리기

## 9. 미확정 사항

- 기본 굴리기 간격
- 자동 굴리기 노드 가격
- 최초 50종 공식 분모
- 공통 확률 예비분 크기
- 행운→압축 계수 공식
- 다이아몬드 주사위 보정
- 변종 판정과 일반 행운의 정확한 관계
