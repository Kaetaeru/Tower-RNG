## 요약

일반 월드는 로비에서 스테이지 1~15가 물리적으로 이어지는 선형 구조입니다. 각 문은 코인으로 한 번 구매하며 계정에 영구적으로 개방됩니다.

열린 문은 접속 종료, 서버 이동과 환생 후에도 유지됩니다. 재접속은 항상 로비에서 시작하고 마지막 활동 스테이지가 열려 있으면 빠른 복귀 버튼을 제공합니다.

환생은 월드 진행이나 현재 전투를 초기화하지 않습니다.

---

## 1. 월드 구조

```text
로비
→ 스테이지 1~3: 초원·숲
→ 스테이지 4~6: 사막
→ 스테이지 7~9: 정글
→ 스테이지 10~12: 설원
→ 스테이지 13~15: 용암지대
```

- 지역당 3스테이지
- 물리적 벽·문·장벽
- 열린 구역 왕복 가능
- 일반 스테이지는 독립 매치가 아님
- 라이브 웨이브 입구는 로비

---

## 2. 문 해금

```text
잠긴 문
+ 스테이지 이름
+ 코인 가격
+ 현재 코인
→ 구매
→ 계정 영구 개방
```

- 이전 문 해금 필요
- 반복 입장료 없음
- 플레이어별 진행
- 다른 플레이어의 문은 내 진행에 영향 없음
- 코인 차감과 문 해금을 하나의 프로필 변경으로 처리
- 재접속·서버 이동·환생 후 유지
- 환생 뒤 다시 벽을 열지 않음

---

## 3. 하나의 활성 스테이지

스테이지 경계 또는 텔레포트 시:

```text
이전 전투 컨텍스트 종료
→ 웨이브·보스 초기화
→ 몬스터·미획득 코인 제거
→ 타워 대상·행동·생성물 취소
→ 새 스테이지 데이터 적용
→ 새 1웨이브 시작
→ 새 적 탐색
```

두 스테이지를 동시에 파밍할 수 없습니다. 이전 스테이지로 돌아가도 이전 웨이브를 복원하지 않고 새 1웨이브부터 시작합니다.

이 초기화는 스테이지 이동 규칙입니다. 환생은 스테이지 이동을 발생시키지 않습니다.

---

## 4. 타워 전환

스테이지 이동 시 정리:

- 타겟과 잠금
- Engage 추격·교전 슬롯
- 공격 준비·Burst·Channel
- 투사체·Beam·범위 효과
- 소환체·설치물
- 예약 피해와 이벤트 구독

새 스테이지:

- Formation은 새 편대 위치
- Engage는 새 우선순위 적에게 이동
- 합류 불가 시 플레이어 근처로 보정 후 재교전

이전 전투는 추가 피해·처치·보상을 만들 수 없습니다.

---

## 5. 로비

로비 기능:

- 게임 시작·재접속 위치
- 스테이지 1 입구
- 라이브 웨이브 입구
- 리더보드·상점·주요 시설
- 마지막 스테이지 빠른 복귀

로비 진입 시 개인 스테이지 전투는 종료됩니다.

환생은 로비 진입을 강제하지 않습니다.

---

## 6. 재접속

### NAV-001: 항상 로비 시작

재접속·서버 이동 후 플레이어는 항상 로비에 생성됩니다.

유지:

- 영구적으로 열린 문
- 코인
- Defense XP
- 환생 스탯 토큰과 배분
- 최고 도달 스테이지
- 마지막 활동 스테이지 ID

복구하지 않음:

- 현재 웨이브
- 몬스터·보스 체력
- 베이스 체력
- 바닥 코인
- 타워 전투 상태

### NAV-002: 빠른 복귀

마지막 활동 스테이지가 열려 있으면 로비 HUD에 버튼을 표시합니다.

```text
마지막 스테이지로 복귀
→ 영구 해금 상태 재검증
→ 해당 스테이지 이동
→ 새 1웨이브 시작
```

유효하지 않거나 잠긴 목적지이면 표시하지 않습니다. 빠른 복귀는 문 가격을 우회하지 않습니다.

---

## 7. 텔레포터

중반 이후 스탯 트리에서 영구 해금합니다.

이동 가능:

- 로비
- 영구적으로 문을 연 스테이지

이동 불가:

- 잠긴 스테이지

규칙:

- 반복 비용 없음
- 기본 쿨다운 없음
- 환생 후 기능과 목적지 유지
- 전환 규칙은 걸어서 경계를 넘는 것과 동일

---

## 8. 환생

환생 시:

```text
Defense XP 0
환생 횟수 증가
스탯 토큰 지급
```

월드에서 변경하지 않음:

- 열린 문
- 마지막 활동 스테이지
- 현재 위치
- 현재 웨이브·몬스터·보스·베이스
- 바닥 코인
- 타워 전투 상태
- 텔레포터 목적지

환생 버튼을 전투 중 눌러도 현재 전투를 계속합니다.

---

## 9. 저장 계약

```text
WorldProgress
- OpenStageGates
- LastActiveStageId
```

- 서버 권위
- 접속 종료 시 저장
- 환생으로 초기화하지 않음
- 웨이브 상태와 분리

기존 `CurrentCycle` 필드는 마이그레이션에서 `WorldProgress`로 옮깁니다.

세부 계약은 `../technical/STATE_LIFECYCLE.md`를 따릅니다.

---

## 10. 사용하지 않는 구조

- 메뉴에서만 고르는 비물리적 월드
- 여러 스테이지 병렬 파밍
- 이탈·재접속 후 웨이브·보스 복구
- 재접속 시 마지막 전투 위치 직접 생성
- 다른 플레이어 문으로 내 진행 해금
- 이전 적을 스테이지 밖에서 계속 공격
- 이전 코인·소환체 왕복 수집
- 텔레포터·빠른 복귀로 잠긴 문 우회
- 환생 시 모든 문 재잠금
- 환생 시 로비 강제 이동
