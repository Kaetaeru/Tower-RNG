# 월드·스테이지 이동 기획

- 계층: 게임 기획
- 상태: **Confirmed (Living Document)**
- 필수 참고: `../../AGENTS.md`
- 관련 문서: `LEVEL_DESIGN.md`, `COMBAT.md`, `FORMATION.md`, `CURRENCY.md`, `STAT_TREE.md`, `LIVE_WAVE.md`, `UI_FLOW.md`

- 마지막 정리: 2026-08-02

## 요약

Tower RNG의 일반 진행 월드는 로비에서 시작해 스테이지 1, 스테이지 2, 스테이지 3으로 물리적으로 이어지는 선형 구조입니다. 각 스테이지 사이에는 벽과 잠긴 문이 있으며, 플레이어가 코인을 지불하면 현재 환생 주기 동안 다음 구역으로 이동할 수 있습니다.

플레이어는 처음에는 직접 걸어서 이동합니다. 중반 이후 스탯 트리에서 텔레포터를 영구 해금하면 로비와 현재 환생 주기에서 해금한 스테이지 사이를 빠르게 이동할 수 있습니다.

---

## 1. 월드 구조

### NAV-001: 로비에서 이어지는 선형 월드

첫 출시의 기본 구조:

```text
로비
→ 지역 1 / 스테이지 1
→ 스테이지 2
→ 스테이지 3
→ 지역 2 / 스테이지 4
→ ...
→ 지역 5 / 스테이지 15
```

- 로비와 15개 일반 스테이지가 물리적인 이동 흐름으로 연결됨
- 지역당 3개 스테이지
- 다음 스테이지는 이전 스테이지를 통해 접근
- 플레이어가 앞뒤로 직접 이동 가능
- 일반 스테이지에는 클리어 후 퇴장하는 별도 판 구조를 사용하지 않음

지역 전환은 같은 선형 진행 안에서 시각적 테마와 환경이 크게 바뀌는 경계로 표현합니다.

---

## 2. 잠긴 문과 구매

### NAV-002: 코인으로 문 해금

스테이지 사이에는 벽, 문, 장벽 또는 그에 준하는 물리적 경계가 있습니다.

```text
잠긴 문
+ 해금 가격 표시
+ 현재 보유 코인 표시
→ 코인 지불
→ 현재 환생 주기에서 문 개방
```

- 이전 스테이지가 해금되어 있어야 다음 문 구매 가능
- 문 구매는 현재 환생 주기의 스테이지 해금과 동일한 행동
- 별도 입장료와 재입장 비용 없음
- 열린 문을 통해 이전 스테이지로 자유롭게 돌아갈 수 있음
- 환생하면 모든 일반 스테이지 문이 다시 잠김
- 스탯 트리와 타워 같은 영구 진행은 유지

각 플레이어의 문 해금 상태는 개인 진행입니다. 같은 서버의 다른 플레이어가 문을 열었다고 내 진행이 자동으로 해금되지 않습니다.

---

## 3. 활성 스테이지

### NAV-003: 하나의 활성 개인 스테이지

플레이어는 한 번에 하나의 일반 스테이지만 활성 전투 구역으로 가집니다.

플레이어가 스테이지 경계를 넘어가면:

1. 이전 스테이지 전투 컨텍스트 종료
2. 이전 스테이지 몬스터와 미획득 코인 정리
3. 모든 타워의 이전 대상과 행동 취소
4. 새 스테이지를 현재 활성 스테이지로 설정
5. 스테이지 행운·코인 단가·몬스터 구성을 새 값으로 변경
6. 새 스테이지 몬스터 생성 시작
7. 타워가 새 스테이지의 적을 재탐색

경계를 오가며 두 스테이지의 몬스터와 보상을 동시에 유지할 수 없습니다.

### NAV-004: 이전 스테이지 복귀

이미 열린 문을 통해 이전 스테이지로 돌아가면 그 스테이지가 즉시 새 활성 스테이지가 됩니다.

- 해당 스테이지의 행운 적용
- 해당 스테이지의 코인 단가 적용
- 해당 스테이지의 몬스터 생성 재시작
- 더 높은 스테이지의 몬스터와 코인 정리

플레이어가 코인 효율과 행운을 비교해 원하는 스테이지를 선택할 수 있습니다.

---

## 4. 타워의 스테이지 전환

### NAV-005: 이전 공격의 완전 중단

스테이지가 바뀌면 타워는 이전 스테이지의 적에 대한 행동을 계속하지 않습니다.

정리 대상:

- 현재 타겟과 타겟 잠금
- Engage 추격과 교전 슬롯
- 공격 준비와 Channel
- 이전 전투에 속한 투사체·Beam·범위 효과
- 소환체와 설치물 중 이전 전투 전용 생성물
- 예약 피해와 이전 스테이지 이벤트 구독

이미 판정이 끝난 장식 연출은 짧게 마무리할 수 있지만, 닫힌 이전 전투에 추가 피해나 보상을 만들 수 없습니다.

### NAV-006: Engage 재교전

Engage 타워는 스테이지 전환 시 이전 적을 포기하고 현재 스테이지의 적을 새로 선택해 접근합니다.

```text
이전 적 추격 중단
→ 새 스테이지 귀속
→ 현재 우선순위 적 탐색
→ 새 적에게 이동
→ 교전 거리에서 공격
```

타워가 경계, 벽 또는 플레이어와 지나치게 멀어 정상 이동이 어려운 경우 기존 편대 복귀·추종 보정 규칙으로 플레이어 근처에 합류한 뒤 재교전할 수 있습니다. 정확한 거리와 보정 방식은 기술 설계에서 정합니다.

Formation과 다른 이동 방식도 새 스테이지 전투 컨텍스트에 다시 연결됩니다.

---

## 5. 로비

### NAV-007: 비전투 중심 공간

로비는 기본적인 일반 스테이지 전투 구역이 아닙니다.

주요 기능:

- 게임 시작과 재접속 위치
- 스테이지 1 입구
- 라이브 웨이브 입구
- 주요 시스템 안내와 NPC 또는 장치
- 향후 이벤트·소셜 공간

로비에 들어오면 기존 일반 스테이지 전투는 종료되고 해당 스테이지의 미획득 코인은 정리됩니다.

### NAV-008: 라이브 웨이브 연결

라이브 웨이브는 일반 스테이지 사이에 배치하지 않고 로비에서 진입합니다.

- 일반 진행 동선을 막지 않음
- 참가하지 않아도 스테이지와 환생 진행 가능
- 공동 전투와 개인 전투의 구분을 공간적으로 명확하게 표현

구체적인 참가 방식과 전장 이동은 `LIVE_WAVE.md`에서 정합니다.

---

## 6. 텔레포터

### NAV-009: 스탯 트리 영구 해금

텔레포터는 중반 이후 스탯 트리에서 영구 해금하는 이동 편의 기능입니다.

해금 전:

- 로비와 스테이지를 직접 걸어서 이동
- 잠긴 문을 물리적으로 구매하며 진행

해금 후:

- 로비로 즉시 이동 가능
- 현재 환생 주기에서 해금한 스테이지로 즉시 이동 가능
- 아직 잠긴 스테이지로는 이동 불가
- 환생 후 텔레포터 기능 자체는 유지되지만 목적지는 다시 해금한 스테이지만 제공

텔레포터 사용에 반복 코인 비용이나 쿨다운을 기본으로 요구하지 않습니다.

### NAV-010: 텔레포트도 스테이지 전환

텔레포트로 이동해도 일반 경계를 걸어서 넘은 것과 동일한 전환 규칙을 사용합니다.

- 이전 몬스터와 코인 정리
- 이전 타워 행동 취소
- 새 스테이지 데이터 적용
- 타워 재배치와 새 타겟 탐색

---

## 7. 사용하지 않는 구조

- 메뉴에서만 선택하고 물리적 월드 진행이 없는 초기 구조
- 한 번에 여러 일반 스테이지를 병렬 파밍
- 다른 플레이어가 연 문으로 내 스테이지가 자동 해금
- 스테이지 이동 후 이전 적을 계속 공격
- 이전 스테이지에 코인과 소환체를 남겨 두고 왕복 수집
- 텔레포터로 잠긴 스테이지 우회
- 라이브 웨이브 입구가 일반 스테이지 진행을 막는 구조

---

## 8. 미확정 사항

- 각 문과 장벽의 최종 시각 형식
- 스테이지 경계 판정의 정확한 크기와 위치
- 같은 서버에서 개인별 문 충돌을 표현하는 기술 방식
- 스테이지 전환 시 타워 합류 보정 거리
- 텔레포터의 정확한 해금 가격과 환생 요구 횟수
- 로비의 최종 시설 배치
