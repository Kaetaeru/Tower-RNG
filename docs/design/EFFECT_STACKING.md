# 지원·제어 효과 중첩 기획

- 계층: 게임 기획

- 계산 근거: `../balance/SUPPORT_CONTROL_STACKING_BENCHMARK.md`
- 관련 문서: `FORMATION.md`, `COMBAT.md`, `TOWER_BEHAVIOR.md`, `TOWERS.md`
- 마지막 정리: 2026-08-03

## 요약

지원·제어 타워는 역할 상한 안에서 여러 개 편성할 수 있습니다. 별도의 수동 편성 제한은 추가하지 않으며, 실제 효과 중첩 규칙과 자동 편성의 한계 기여도 평가로 과도한 조합을 제어합니다.

핵심 원칙:

```text
같은 지원 효과
- 한 대상에서 가장 강한 효과만 적용
- 중복 지원은 새로운 대상을 우선

같은 제어 효과
- 한 몬스터에서 강도 중첩 없음
- 재적용은 지속시간 갱신
- 중복 제어는 미제어 대상을 우선

다른 지원·제어 효과
- 정해진 결합식과 대상 등급 상한 사용
```

---

# 1. 공통 식별자

모든 지원·제어 효과는 다음 식별자를 가집니다.

```text
StackGroup
- 같은 효과로 취급할 그룹

StatChannel 또는 ControlType
- 공격력, 공격속도, 치명타, 감속, 기절 등 실제 적용 채널

SourceId
- 효과를 만든 타워 또는 생성물
```

표시 이름이 달라도 같은 `StackGroup`이면 같은 효과로 판정할 수 있습니다. 반대로 같은 타워가 서로 다른 능력을 사용하면 다른 그룹을 사용할 수 있습니다.

---

# 2. 지원 효과

## EFF-SUP-001: 출처 전력 예산

지원 효과는 강화 대상의 전력이 아니라 지원 출처의 전력으로 상한을 가집니다.

기준 지원 타워:

```text
직접 기여: SourceEC × 0.55
지원 기여 예산: SourceEC × 0.45
기준 최대 대상: 3
기준 대상당 표시 비율: +15%
```

대상 하나의 실제 증가:

```text
TargetBonusEC
= min(TargetBaseEC × PercentRate,
      SourceEC × PerTargetSourceCap)
```

기준값:

```text
PercentRate = 0.15
PerTargetSourceCap = 0.15
MaxTargets = 3
```

따라서 낮은 전력 지원 타워가 높은 전력 타워를 강화해도 지원 출처의 총 기여 예산을 초과하지 않습니다.

고희귀 지원 타워는 더 높은 `SourceEC`, 다른 직접·지원 배분, 더 많은 대상 또는 고유 효과를 가질 수 있습니다. 정확한 값은 카탈로그에서 정합니다.

## EFF-SUP-002: 같은 StackGroup

같은 지원 효과가 한 대상에 여러 번 적용되면:

```text
가장 강한 값만 적용
동일 강도면 남은 지속시간이 긴 값 유지
강도 합산 또는 곱연산 없음
```

같은 지원 효과를 가진 타워가 여러 개면 다음 대상 우선순위를 사용합니다.

```text
1. 아직 같은 StackGroup 효과가 없는 유효 대상
2. 효과 증가량이 가장 큰 대상
3. 남은 지속시간이 가장 짧은 대상
```

중복 지원의 주된 가치는 강도 중첩이 아니라 지원 범위와 지속시간 안정성입니다.

## EFF-SUP-003: 다른 StackGroup

서로 다른 지원 효과가 같은 능력치 채널에 적용되면 합산한 뒤 채널 상한을 적용합니다.

```text
동일 StatChannel 최대 증가: +50%
```

공격력·공격속도·치명타처럼 서로 다른 출력 채널이 함께 적용될 때의 최종 예상 출력 배율은 다음 상한을 사용합니다.

```text
지원으로 얻는 최종 출력 배율 최대: ×1.75
```

직접 피해, 대상 특화와 실행 조건처럼 지원 효과가 아닌 타워 자체 능력은 이 상한에 포함하지 않습니다.

## EFF-SUP-004: 자기 자신

기본적으로 지원 타워는 자신의 동일 지원 효과를 받지 않습니다. 다른 `StackGroup`의 외부 지원 효과는 개별 능력 정의가 허용하면 받을 수 있습니다.

# 3. 이동속도 제어

## EFF-CTL-001: 같은 ControlGroup

같은 감속이 한 몬스터에 여러 번 적용되면:

```text
가장 강한 감속만 적용
재적용은 남은 지속시간 갱신
감속률 합산 없음
```

같은 제어 타워를 여러 개 편성하면 자동 타겟 선정은 이미 같은 감속을 가진 대상보다 미제어 대상을 우선합니다.

## EFF-CTL-002: 다른 감속 결합

서로 다른 감속은 남은 이동속도를 곱하는 방식으로 결합합니다.

```text
CombinedSlow
= 1 - Π(1 - Slow_i)
```

예:

```text
15% + 다른 15%
= 1 - 0.85 × 0.85
= 27.75%
```

## EFF-CTL-003: 대상 등급별 감속 상한

```text
일반 몬스터: 최대 60%
정예 몬스터: 최대 45%
보스: 최대 35%
```

상한을 넘는 감속은 추가 강도를 만들지 않지만 지속시간 갱신에는 사용할 수 있습니다.

완전 이동 정지 효과는 일반 감속이 아니라 완전 제어 규칙을 사용합니다.

---

# 4. 기절·빙결·완전 제어

## EFF-CTL-004: 최근 5초 제어 예산

기절, 빙결, 속박형 완전 정지와 타겟 불가를 제외한 강제 행동 중단은 몬스터별 최근 5초 예산을 사용합니다.

| 대상 등급 | 최근 5초 최대 비활성 시간 |
|---|---:|
| 일반 | 3.00초 |
| 정예 | 2.00초 |
| 보스 | 1.25초 |

새 완전 제어가 남은 예산보다 길면 지속시간을 남은 예산만큼 줄입니다. 남은 예산이 없으면 완전 제어 부분은 발동하지 않습니다.

피해, 표식, 약화와 일반 감속처럼 완전 행동 중단이 아닌 부가 효과는 정상 처리합니다.

## EFF-CTL-005: 예산 계산

- 몬스터별로 독립 계산
- 효과 출처가 달라도 같은 예산 사용
- 최근 5초를 벗어난 비활성 시간은 자동 제거
- 베이스 도달 또는 사망 시 상태 제거
- 스테이지 전환 시 이전 전투의 예산 제거

이를 통해 여러 제어 타워가 있어도 보스를 영구적으로 멈출 수 없습니다.

---

# 5. 자동 편성 평가

자동 편성은 지원·제어 타워의 표시 공격력만 비교하지 않습니다.

지원 평가:

```text
직접 기여
+ 새로 강화할 수 있는 대상의 실제 증가량
+ 지속시간 공백 감소 가치
- 이미 덮인 StackGroup 중복 손실
```

제어 평가:

```text
직접 기여
+ 미제어 대상 범위 증가
+ 보스·정예 제어 가치
+ 지속시간 공백 감소
- 감속 상한 초과
- 완전 제어 예산 초과
- 같은 대상 중복 손실
```

자동 편성은 현재 역할 상한을 그대로 지킵니다. 지원과 제어를 합친 별도 수동 상한은 사용하지 않습니다.

초기 4슬롯에서는 같은 지원 또는 같은 제어 두 개보다 서로 다른 역할을 우선합니다. 후반 슬롯에서는 실제 대상 범위와 한계 기여도가 남아 있으면 중복 지원·제어를 선택할 수 있습니다.

---

# 6. 표시와 피드백

플레이어가 효과 적용 상태를 알 수 있어야 합니다.

지원:

- 강화받는 타워에 작은 효과 아이콘
- 같은 효과가 이미 적용돼 중복되지 않는 경우 상세 화면에 표시
- 지원 대상 변경 시 짧은 연결 연출

제어:

- 감속 종류와 강도를 몬스터 상태 아이콘으로 구분
- 감속 상한 도달 시 추가 감속이 강도를 높이지 않는다는 표시
- 보스의 완전 제어 예산이 소진되면 짧은 저항 피드백

숫자와 아이콘이 전투 화면을 가리지 않도록 상세 중첩 정보는 타워·몬스터 상세 패널에서 확인합니다.

---

# 7. 사용하지 않는 구조

- 같은 지원 오라의 무제한 합산
- 같은 감속의 단순 덧셈
- 감속 100%로 영구 이동 정지
- 여러 기절을 이용한 보스 영구 잠금
- 낮은 희귀도 지원이 출처 전력과 무관하게 최고 희귀 타워를 비율 증폭
- 지원·제어라는 이유만으로 별도 수동 편성 금지
- 자동 편성이 중첩 손실을 무시하고 표시 EC만 합산

---

# 8. 남은 세부 명세

- 지원 대상 선택과 재선택 주기
- `SourceEC`를 런타임 `MagnitudeNumber`로 변환하는 방법
- 공격속도·치명타·소환체 지원의 채널별 환산
- 밀치기·경로 후퇴의 제어 예산 환산
- 타겟 불가와 공격 취소가 완전 제어 예산을 사용하는지 여부
- 효과 아이콘과 상세 패널 UI
- 자동 편성 한계 기여도 계산 함수
