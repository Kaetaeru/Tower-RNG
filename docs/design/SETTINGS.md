## 요약

Tower RNG는 과장된 모델 움직임, 피격 반응, 음향과 파티클로 손맛을 만들되 일반 공격에 화면 흔들림을 남발하지 않습니다.

카메라 흔들림은 기본적으로 보스 등장·처치처럼 제한된 대형 사건에만 사용합니다. 파티클, 다른 플레이어 효과, 피해 숫자, UI 움직임과 희귀 연출은 설정 탭에서 줄일 수 있어야 합니다.

설정을 낮춰도 클릭 성공·실패, 공격 명중, 보상 획득과 상태 변화는 분명히 전달합니다.

---

## 1. 설정 메뉴 구조

```text
설정
├─ 화면·효과
├─ 카메라
├─ 음향
├─ UI·접근성
├─ 알림·자동 보호
└─ 성능
```

설정은 전투 중에도 열 수 있으며 자동 전투와 굴리기를 정지하지 않습니다.

---

## 2. 화면·효과

### SET-001: 파티클 밀도

허용값:

```text
Full
Reduced
Minimal
```

- `Full`: 제작자가 의도한 전체 효과
- `Reduced`: 장식 파티클과 잔상 수 감소
- `Minimal`: 명중·상태·보상 확인에 필요한 핵심 효과만 유지

파티클을 낮춰도 공격이 명중했는지와 상태 효과가 적용됐는지는 보여야 합니다.

### SET-002: 다른 플레이어 효과

허용값:

```text
Full
Reduced
Hidden
```

일반 개인 스테이지에서는 다른 플레이어 전투 효과를 기본적으로 표시하지 않습니다. 라이브 웨이브와 로비 전시에서 이 설정을 적용합니다.

### SET-003: 피해 숫자

허용값:

```text
All
ImportantOnly
Hidden
```

- `All`: 개별 피해 표시
- `ImportantOnly`: 치명타·강공격·보스 피해 중심으로 병합 표시
- `Hidden`: 피해 숫자 숨김

숫자를 숨겨도 피격 반응과 체력바는 유지합니다.

### SET-004: 명중 섬광

```text
On | Reduced | Off
```

광과민성을 고려해 강한 전체 화면 섬광은 기본 공격에 사용하지 않습니다.

### SET-005: Trail·잔상

```text
On | Reduced | Off
```

공격 궤적과 이동 잔상을 줄여도 실제 공격 방향과 접촉은 모델 동작으로 읽을 수 있어야 합니다.

### SET-006: 희귀 획득 연출

```text
Full
Short
Minimal
```

공식 기본 확률이 매우 낮은 타워도 연출을 줄일 수 있습니다. 설정과 무관하게 결과 카드, 타워 이름과 공식 `1 / N`은 표시합니다.

---

## 3. 카메라

### SET-007: 일반 전투 화면 흔들림 금지

다음에는 기본 카메라 흔들림을 사용하지 않습니다.

- 일반 공격
- 빠른 연속 공격
- 일반 치명타
- 일반 몬스터 처치
- 코인 획득
- UI 클릭

타격감은 모델 역동작, 반동, 피격 압축, 음향, Trail과 파티클로 만듭니다.

### SET-008: 보스 카메라 흔들림

허용 대상:

- 보스 등장
- 지역 최종 보스 처치
- 매우 제한된 보스 특수 행동
- 환생 또는 극희귀 획득의 선택적 대형 연출

허용값:

```text
Off
Low
Normal
```

기본값은 `Low`입니다. 카메라 흔들림이 없어도 대형 사건의 음향·UI·모델 연출은 유지됩니다.

### SET-009: FOV 연출

```text
On | Off
```

기본값은 `On`이지만 짧고 작은 범위만 사용합니다. 일반 공격마다 FOV를 변경하지 않습니다.

### SET-010: 보스 프레이밍

```text
On | Off
```

- 긴 컷신 사용 금지
- 플레이어 조작을 빼앗는 강제 고정 금지
- 짧은 방향 강조 또는 UI 포인터 중심

---

## 4. 음향

### SET-011: 볼륨 채널

각 채널은 독립 조절합니다.

- 전체
- 배경음악
- 전투 효과음
- UI 효과음
- 환경음
- 희귀 획득·보스 알림

### SET-012: 반복 피격음 제한

설정과 별개로 같은 순간에 너무 많은 피격음이 겹치지 않도록 우선순위와 동시 재생 상한을 둡니다.

- 강공격·치명타 우선
- 같은 대상의 빠른 연속 피격음 병합
- 화면 밖·먼 거리 효과음 감쇠

---

## 5. UI·접근성

### SET-013: UI 크기

```text
Small
Default
Large
```

모바일 안전 영역과 퀵 편성 HUD를 함께 조정합니다.

### SET-014: UI 움직임

```text
Full
Reduced
Minimal
```

- `Full`: 오버슈트·카드 이동·팝 연출
- `Reduced`: 이동 거리와 반복 반동 감소
- `Minimal`: 즉각적인 색·윤곽·음향 중심

클릭 반응 자체는 끌 수 없습니다. 움직임을 줄여도 입력 성공 여부를 즉시 보여 줍니다.

### SET-015: 감소된 움직임 모드

한 번에 다음을 적용하는 접근성 프리셋입니다.

- UI 움직임 Reduced
- 카메라 흔들림 Off
- FOV 연출 Off
- Trail Reduced
- 희귀 연출 Short

개별 설정으로 다시 덮어쓸 수 있습니다.

### SET-016: 툴팁과 도움말

- 상세 툴팁 ON/OFF
- 처음 보는 기능 설명
- 튜토리얼 다시 보기
- 역할과 타겟 정책 설명

### SET-017: 입력 장치

- 모바일 햅틱 ON/OFF
- 게임패드 진동 ON/OFF
- 키 배치 보기
- 게임패드 포커스 강조

---

## 6. 알림과 자동 보호

### SET-018: 굴리기 결과 알림

```text
All
NewOnly
RareOnly
VeryRareOnly
Off
```

알림을 줄여도 타워는 정상 지급되고 최근 획득 기록에 남습니다.

### SET-019: 희귀 자동 보호 기준

공식 기본 분모를 기준으로 설정합니다.

예:

```text
1 / 100,000 이상 희귀한 결과 자동 보호
```

현재 행운 적용 확률은 기준으로 사용하지 않습니다.

### SET-020: 서버 공지

- 극희귀 획득 서버 공지 ON/OFF
- 다른 플레이어 보스·환생 공지 ON/OFF
- 상점·이벤트 공지 수준

필수 시스템 경고는 숨길 수 없습니다.

---

## 7. 성능

### SET-021: 자동 성능 조절

```text
On | Off
```

프레임 저하가 일정 시간 지속되면 장식 파티클, 잔상과 다른 플레이어 표시를 단계적으로 줄입니다. 핵심 명중·UI 피드백은 마지막까지 유지합니다.

### SET-022: 다른 플레이어 타워 표시량

```text
All
Nearby
Reduced
Hidden
```

일반 개인 전투 판정에는 영향을 주지 않습니다.

### SET-023: 조명과 그림자

- 추가 공격 조명 효과
- 동적 그림자
- 환경 장식 밀도

Roblox 기본 그래픽 품질와 충돌하지 않게 상위 제한으로 동작합니다.

### SET-024: 효과 동시성 예산

저사양에서도 다음 우선순위를 사용합니다.

```text
1. 내 UI 입력과 성공·실패
2. 내 타워의 강공격·명중
3. 보스 상태와 경고
4. 일반 공격 장식
5. 다른 플레이어 장식
```

---

## 8. 저장

### SET-025: 계정 설정

다음은 계정 프로필에 저장합니다.

- UI 움직임
- 피해 숫자
- 희귀 알림
- 자동 보호 기준
- 음향 채널
- 보스 카메라 설정
- 접근성 프리셋

### SET-026: 장치 오버라이드

장치 성능에 따라 달라질 수 있는 설정은 로컬 오버라이드를 허용할 수 있습니다.

- 파티클 밀도
- 그림자
- 다른 플레이어 표시량
- 자동 성능 조절

동기화 충돌 시 장치 오버라이드를 우선하되 계정 기본값을 삭제하지 않습니다.

## 9. 초기 기본값

```text
파티클: Full
다른 플레이어 효과: Reduced
피해 숫자: ImportantOnly
명중 섬광: Reduced
Trail: On
희귀 연출: Full
보스 화면 흔들림: Low
FOV 연출: On
보스 프레이밍: On
UI 움직임: Full
자동 성능 조절: On
굴리기 알림: NewOnly
```

실제 모바일 기본값은 성능 테스트 후 Reduced 계열로 조정할 수 있습니다.

---

## 10. 사용하지 않는 구조

- 일반 공격마다 화면 흔들림
- 화면 전체를 반복적으로 덮는 명중 섬광
- 파티클 감소 시 명중 여부까지 사라짐
- 설정을 바꾸려면 재접속 필요
- 피해 숫자 숨김이 전투 판정을 변경
- 현재 행운 적용 확률 표시 옵션
- 접근성 설정을 과금 상품으로 판매
- 설정 변경으로 서버 권위 게임 결과 변경

---

## 11. 미확정 사항

- 각 설정의 실제 UI 배치
- 파티클 단계별 정확한 생성 예산
- 보스 흔들림 강도와 지속시간
- 모바일 기본값
- 장치 오버라이드 저장 방식
- 색각 보조와 고대비 모드 범위
- 피해 숫자 병합 시간창
