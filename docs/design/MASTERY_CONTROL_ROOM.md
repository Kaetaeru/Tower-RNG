## 요약

숙련 제어실은 변종·합체·오프라인 가지를 모두 진행한 플레이어를 위한 후반 편의·수집·표현 가지입니다.

```text
새 전투력 없음
새 행운·확률 없음
새 코인 수익 없음
반복 유지비 없음
```

이미 기획된 월드 이동, 편성 프리셋, 세부 타겟, 퀵 HUD와 수집 표시 기능을 후반 코인 목표로 묶습니다.

메인 콘텐츠 완주와 스테이지 15 최초 클리어에는 필요하지 않습니다.

---

# 1. 해금

다음 가지를 모두 완료한 뒤 공개합니다.

- 변종 가지
- 합체 가지
- 오프라인 가지

구매 결과는 영구 유지하며 환생, 접속 종료와 서버 이동으로 초기화하지 않습니다.

숙련 제어실을 구매하지 않아도 다음 기능은 정상 진행됩니다.

- 스테이지 15 완주
- 12슬롯 편성
- 공통 전투 ×5.00
- 타워·변종 획득
- 합체 실행
- 기본 빠른 복귀

---

# 2. 기능 범위

## 이동

- 영구적으로 연 스테이지를 대상으로 하는 텔레포터
- 자주 쓰는 스테이지 즐겨찾기
- 잠긴 문 우회 금지
- 반복 이동 비용 없음

## 편성

- 추가 편성 프리셋
- 프리셋 빠른 전환 HUD
- 자동 편성 ON/OFF 상태 보존
- 역할 상한과 전체 슬롯 상한은 그대로 유지

## 타겟

- 역할별 타겟 우선순위
- 개별 TowerId별 타겟 우선순위
- 여러 타겟 설정을 프로필로 저장
- 공격력이나 타겟 수를 직접 증가시키지 않음

## 수집·표현

- 바닥 코인의 표시량과 병합 표현 설정
- 총 코인 지급량은 변경하지 않음
- 도감 전시와 희귀 획득 연출 프리셋
- 연출 축약 설정과 충돌하지 않음

## 최종 제어실

최종 노드는 해금된 기능을 하나의 관리 화면에서 편집하게 합니다.

- 추가 전투 배율 없음
- 추가 확률 없음
- 숨은 코인 보너스 없음
- 최종 노드 전용 필수 전투 콘텐츠 없음

---

# 3. 계산용 단계

```text
텔레포터 코어
→ 스테이지 즐겨찾기
→ 역할별 타겟 명령
→ 편성 프리셋 II
→ 개별 타워 타겟 명령
→ 편성 프리셋 III
→ 타겟 프로필 저장
→ 퀵 HUD 확장
→ 코인 표시·병합 제어
→ 도감·획득 연출 프리셋
→ 숙련 제어실 완성
```

계산 총가격은 `25.2B`입니다. 실제 NodeId, 좌표, 아이콘과 표시 문구는 카탈로그에서 확정합니다.

---

# 4. 금지선

사용하지 않는 구조:

- 숙련 제어실 전용 공격력·공격속도·치명타
- 일반 행운·Compression 증가
- 변종 티켓 확률 증가
- 합체 재료 감소
- 코인 드롭량 증가
- 오프라인 효율 40% 상한 초과
- Defense XP 또는 환생 토큰 증가
- 12개를 넘는 V1 편성 슬롯
- Robux로 가지 전체 즉시 완료
- 매 이동·프리셋 사용 시 반복 코인 비용

---

# 5. 구현 원칙

- 서버는 구매 상태와 잠긴 목적지를 검증
- 프리셋은 TowerId와 타겟 규칙을 저장하되 현재 보유 수량 부족 시 안전하게 축소 적용
- 텔레포트는 일반 스테이지 전환 정리 규칙을 그대로 사용
- 코인 표시·병합 옵션은 지급량과 서버 권위 코인 합계를 바꾸지 않음
- 연출 설정은 전투와 자동 굴리기를 중단하지 않음
- 삭제되거나 변경된 카탈로그 ID는 저장 마이그레이션 처리

---

# 6. 남은 작업

- 텔레포터 목적지 UI

- 도감·연출 프리셋의 실제 자산
