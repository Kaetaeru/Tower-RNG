## 요약

오프라인 진행은 접속하지 않은 동안 굴리기나 실제 전투를 진행하지 않고, 스탯 트리에서 해금한 수집 능력에 따라 제한된 양의 코인을 축적하는 보조 성장 시스템입니다.

오프라인 수익은 접속 플레이보다 낮고 저장 시간에 상한이 있습니다. 플레이어가 다시 접속하면 서버가 보상을 즉시 계정에 지급하고 요약 화면을 표시합니다.

---

## 1. 기본 원칙

### OFF-001: 코인만 축적

오프라인 중 다음은 진행하지 않습니다.

- 무료 굴리기와 특수 주사위 카운터
- 타워 획득과 중복 축적
- 실제 몬스터 생성·처치
- 월드 코인 드롭 생성
- 연금 정수 게이지
- 개인 보스와 라이브 웨이브
- 지역·스테이지 해금
- 포션 시간 감소

오프라인 진행은 코인 보조 수익만 제공합니다.

### OFF-002: 스탯 트리 해금

오프라인 코인 축적은 자동 굴리기·자동 편성 이후의 초반 스탯 트리에서 영구 해금합니다.

- 해금 전에는 오프라인 코인 없음
- 해금 후 접속 종료 시간부터 축적
- 환생 후에도 해금과 업그레이드 유지
- 반복 활성화 비용 없음

---

## 2. 계산 기준

### OFF-003: 실제 전투를 시뮬레이션하지 않음

오프라인 동안 몬스터, 타워, Engage 이동, 코인 드롭과 자석을 실제로 재생하지 않습니다.

보상은 저장된 계정 진행과 오프라인 수익 스탯을 사용해 한 번에 계산합니다.

기본 구조:

```text
오프라인 코인
= 적용 오프라인 시간
× 영구 진행 기준 코인율
× 오프라인 효율
× 환생 코인 배율
```

정확한 수식과 반올림은 시스템 명세에서 정합니다.

### OFF-004: 영구 진행 기준

오프라인 기준 코인율은 현재 서 있는 스테이지나 접속 종료 직전 순간 수익을 그대로 복사하지 않습니다.

기준에 포함할 방향:

- 계정의 최고 도달 스테이지 기록
- 오프라인 수익 관련 스탯 트리 단계
- 영구 환생 코인 배율

포함하지 않는 항목:

- 현재 스테이지에 잠시 서 있는 것
- 최근 몇 초간의 일시적인 코인 획득량
- 풍요의 포션과 다른 임시 효과
- 라이브 웨이브 보너스
- 개인 보스의 일회성 보상
- 자석 반경과 코인 드롭 병합

높은 스테이지에 잠시 진입해 처치하지 못한 상태로 종료하는 행동이 오프라인 코인을 비정상적으로 증가시키지 않게 합니다.

---

## 3. 효율과 보관 시간

### OFF-005: 접속 플레이보다 낮은 효율

오프라인 수익은 정상적인 접속 코인 파밍을 대체하지 않습니다.

초기 밸런스 목표:

- 최초 해금 효율: 해당 진행 구간의 기준 온라인 코인 수익 약 25%
- 후속 스탯 성장: 최대 약 40% 범위
- 접속해서 코인을 직접 줍는 플레이가 항상 더 높은 수익

위 수치는 확정 출시값이 아니라 밸런스 기준이며, 실제 경제 시뮬레이션으로 조정합니다.

### OFF-006: 시간 상한

초기 밸런스 목표:

```text
최초 해금: 최대 8시간 축적
중간 업그레이드: 최대 12시간
후반 업그레이드: 최대 24시간
```

상한을 넘긴 시간은 추가 코인을 만들지 않습니다.

- 매일 특정 시각에 초기화하지 않음
- 접속 강제용 짧은 상한을 사용하지 않음
- 후반에도 무제한 축적은 기본으로 제공하지 않음

정확한 노드 수와 가격은 스탯 트리 밸런스에서 정합니다.

---

## 4. 지급과 표시

### OFF-007: 접속 시 안전한 자동 지급

플레이어가 다시 접속하면 서버가 오프라인 시간을 검증하고 코인을 계정에 직접 지급합니다.

- 별도 월드 드롭으로 생성하지 않음
- 수령 버튼을 누르지 못해 보상을 잃지 않음
- 같은 오프라인 구간을 두 번 지급하지 않음
- 서버 이동과 재접속 반복으로 중복 지급하지 않음

### OFF-008: 요약 화면

지급 후 짧은 요약을 표시합니다.

필수 정보:

- 실제 오프라인 시간
- 보상에 적용된 시간
- 현재 시간 상한
- 오프라인 효율
- 획득한 코인
- 다음 효율 또는 시간 업그레이드 안내

요약 화면은 자동 굴리기와 전투를 오래 막지 않으며 즉시 닫을 수 있습니다.

---

## 5. 환생과 오프라인 진행

### OFF-009: 환생 보너스 적용

환생 코인 배율은 오프라인 코인에도 적용합니다.

- 환생 횟수와 오프라인 노드는 영구 유지
- 환생 시 이미 지급된 코인은 일반 코인과 함께 초기화
- 환생 이후 새로 접속 종료한 시점부터 새로운 오프라인 구간 계산

환생 직전 종료하고 다음 접속에서 오프라인 코인을 받은 뒤 환생하는 것은 허용합니다. 이는 저장된 영구 진행에 따른 정상 보상입니다.

---

## 6. 사용하지 않는 구조

- 오프라인 무료 굴리기
- 오프라인 타워 획득
- 실제 전투 전체 시뮬레이션
- 오프라인 코인 드롭을 맵에 쌓아 두기
- 현재 어려운 스테이지에 서 있기만 하면 최대 수익 적용
- 임시 포션을 오프라인 수익에 적용
- 무제한 오프라인 축적
- 광고 시청을 필수로 요구하는 수령
- 수령 버튼을 놓쳐 보상이 사라지는 구조

---

## 7. 미확정 사항

- 최고 도달 스테이지별 기준 코인율
- 최초 해금 가격과 위치
- 효율 업그레이드의 실제 단계 수
- 8·12·24시간 구간의 최종 가격
- 최소 오프라인 시간과 요약 표시 기준
- 최종 수식과 반올림 방식
