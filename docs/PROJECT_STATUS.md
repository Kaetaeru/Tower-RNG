# Tower RNG V1 진행 현황

- 상태: **Active Project Dashboard**
- 마지막 정리: 2026-08-03
- 갱신 규칙: 의미 있는 계산·카탈로그·명세·구현 작업을 완료한 커밋에서 이 문서를 함께 갱신합니다.
- 문서 구조: `INDEX.md`, `catalog/INDEX.md`, `balance/INDEX.md`

## 목적

현재 무엇이 완료됐고 무엇이 남았는지를 한 곳에서 확인합니다.

이 문서의 퍼센트는 출시일까지 남은 실제 시간을 예측하지 않습니다. 저장소에 기록된 V1 작업 항목을 가중치로 환산한 **준비도 지표**입니다.

상태 표기:

```text
[x] 완료: 권위 문서·검증·수용 조건이 존재함
[~] 진행 중: 일부 값이나 범위만 존재함
[ ] 미착수 또는 검증 전
```

| QA·출시 | **0%** | 런타임·플레이테스트·출시 체크 미착수 |

가중치:

```text
게임 규칙·기획 15%
계산·밸런스 25%
콘텐츠 카탈로그 20%
기술 명세 10%
Roblox 구현 25%
QA·출시 5%
```

현재 전체 V1 준비도:

```text
약 32%
```

참고 지표:

```text
기획·밸런스만 보면 약 68%
실제 플레이 가능한 V1 기준으로는 아직 초기 단계
```

Roblox Studio 또는 다른 저장소에 구현이 있다면 해당 경로를 연결한 뒤 구현 준비도를 다시 계산합니다.

## 갱신 규칙

작업을 완료할 때 같은 작업에서 다음을 수행합니다.

1. 해당 체크박스를 갱신합니다.
2. 준비도 퍼센트에 영향을 주면 상단 표를 갱신합니다.
3. 계산 결과는 `balance` 인덱스에 등록합니다.
4. 최종 채택 콘텐츠는 `catalog` 인덱스에 등록합니다.
5. 다음 작업 ID를 하나만 지정합니다.

현재 다음 작업 ID:

```text
BAL-NEXT-002
스테이지 9 지역 3 최종전 완전 검증
```
