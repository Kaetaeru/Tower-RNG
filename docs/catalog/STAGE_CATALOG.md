# 2. 공통 계약

```text
StageScale(S) = 10 ^ ((S - 1) / 3)
StageRewardScale(S) = StageScale(S) × 1.08 ^ (S - 1)
```

- 웨이브는 적을 모두 처치하거나 누수 처리하면 즉시 종료합니다.
- 고정 대기 타이머로 목표시간을 강제하지 않습니다.
- 스테이지 이동·로비 복귀·베이스 과부하 시 웨이브 1로 초기화합니다.
- 일반 스테이지 5웨이브가 한 주기입니다.
- 5웨이브는 보스를 최소 1개 포함합니다.
- 보스 기본 보상 배율은 `1.15`입니다.
- 스테이지 1~14 한 주기 보상은 400 단위입니다.
- 스테이지 15 한 주기 보상은 440 단위입니다.

```text
→ 첫 타워 빈 슬롯 배치
→ 초원 슬라임 1개
→ 10코인 + Defense XP 10
→ 자동 굴리기 구매
→ 4슬롯 완성
→ 정규 웨이브 1
```

재접속 시 완료 상태를 이어서 처리하며 보상을 중복 지급하지 않습니다.

# 10. 맵·모델 교체 경계

다음 항목은 전투 카탈로그를 유지하면서 교체할 수 있습니다.

- 맵 메시와 재질
- 경로의 실제 곡선과 높낮이
- 몬스터 VisualProfile
- 배경 소품과 랜드마크
- 코인 드롭의 시각적 궤적

교체 뒤 반드시 유지할 값:

- 각 프로필의 `TimeToBaseSeconds`
- 스폰 시각과 순서
- 동시 배치 가능한 몬스터 수
- 행동 발동 조건
- 웨이브 예산과 보상

경로 변경으로 실제 이동시간이 5% 이상 달라지거나 몬스터 충돌이 병목을 만들면 해당 스테이지를 다시 검증합니다.
