# Tower RNG 콘텐츠 카탈로그 인덱스

- 상태: **Active Catalog Index**
- 마지막 정리: 2026-08-03
- 프로젝트 현황: `../PROJECT_STATUS.md`
- 계산·검증: `../balance/INDEX.md`
- 최종 계산 권고안: `../balance/FINAL_RECOMMENDATION.md`

## 책임

카탈로그는 게임에 실제로 채택되는 영구 ID, 플레이어 표시 콘텐츠와 최종 수치를 소유합니다.

```text
balance에서 계산
→ 사용자 승인
→ catalog에서 채택
→ spec·implementation에서 같은 값 사용
→ Roblox 런타임 검증
```

계산 문서가 바뀌어도 카탈로그 값은 자동으로 변경되지 않습니다.

# 아직 카탈로그 채택이 필요한 콘텐츠

## 타워

- 일반 굴리기 타워 50종의 최종 이름과 `TowerId`
- 50종 실제 행동과 역할별 희귀도 순서
- 타워별 `AllowedVariantFamilies`
- 개별 변종 `TowerId`, 이름과 행동
- 기본형·변종 합체 계보와 결과 `TowerId`
- 모델·애니메이션·VFX·SFX 요구사항

## 몬스터·스테이지

- 스테이지 2~15 최종 몬스터·보스 이름과 `MonsterId`
- 계산용 웨이브를 최종 스테이지 데이터로 채택
- 맵·경로·랜드마크·코인 수집 동선
- 문의 실제 모델·좌표·해금 연출

## 스탯 트리 표시 콘텐츠

- 전체 X·Y 좌표와 연결선
- 가지 입구의 공통 부모 노드
- 일부 최소 환생 횟수 조건
- 아이콘·분야 색상·구매 연출
- 모바일·PC 트리 조작 UI

# 카탈로그 진행

```text
공식 일반 확률 슬롯: 50 / 50
기준 타워 정체성: 6 / 최소 50
스테이지 수치 검증: 15 / 15
영구 문 가격 채택: 14 / 14
주요 코인 노드 값 채택: 완료
변종·합체 공통 시스템 값 채택: 완료
개별 타워·몬스터 콘텐츠: 대부분 미작성
```

카탈로그 준비도는 약 `26%`로 평가합니다. 수치·시스템 채택은 진행됐지만 실제 타워 50종과 스테이지 2~15 콘텐츠가 가장 큰 잔여 작업입니다.

# 작성 규칙

- 계산 결과 전체나 시뮬레이션 로그를 카탈로그에 복사하지 않습니다.
- 계산용 임시 몬스터 이름을 자동으로 최종 이름으로 승격하지 않습니다.
- 같은 영구 ID를 여러 파일에서 독립 정의하지 않습니다.
- 수치와 표시 콘텐츠의 상태를 분리합니다.
- 구현 데이터는 카탈로그 수치를 복사하지 않고 동일한 단일 데이터 원천을 사용해야 합니다.
- 실제 런타임 효율은 Roblox 측정 전까지 `Confirmed`로 표시하지 않습니다.
