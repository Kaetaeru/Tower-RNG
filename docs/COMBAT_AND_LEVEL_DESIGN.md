# 전투 및 레벨 디자인

이 문서는 Tower RNG의 일반 스테이지 전투, 타워 편성, 몬스터 생성, 경로와 타겟 판정에 관한 상세 설계를 정리합니다.

루트 `README.md`는 프로젝트 전체 개요와 핵심 원칙을 담당하고, 이 문서는 실제 구현과 밸런싱에 필요한 전투 규칙을 담당합니다.

---

## 1. 전투의 기본 방향

Tower RNG는 전통적인 타워 디펜스처럼 타워를 맵 위에 하나씩 설치하지 않습니다.

플레이어가 편성한 타워들은 플레이어 주변과 뒤를 편대 형태로 따라다니며, 현재 스테이지에 존재하는 몬스터를 자동으로 공격합니다.

```text
        플레이어

   타워 1      타워 2

타워 3   타워 4   타워 5

   타워 6      타워 7
```

기본 원칙:

- 타워는 맵에 고정 설치하지 않음
- 타워는 플레이어를 따라다님
- 플레이어의 위치가 공격 가능 여부에 영향을 주지 않음
- 일반 스테이지에서는 타워 사거리를 사용하지 않음
- 플레이어가 움직이지 않아도 전투 효율이 감소하지 않음
- 플레이어는 몬스터에게 직접 공격받지 않음
- 편성과 타겟 설정은 전투 중에도 자유롭게 변경 가능
- 편성 변경에 재화 비용을 요구하지 않음

공격 판정과 시각 효과는 분리합니다. 근접 타워의 돌진, 화살이나 마법 투사체 등은 시각 연출이며 실제 공격 판정이 연출 때문에 지나치게 늦어지지 않도록 합니다.

---

## 2. 타워 역할

타워의 차이는 사거리보다 공격 방식, 특화 대상과 고유 효과에서 발생합니다.

| 역할 | 주요 기능 | 적합한 상황 |
|---|---|---|
| 단일 화력 | 한 대상에게 안정적인 피해 | 일반적인 강적 처리 |
| 광역 화력 | 여러 몬스터를 동시에 공격 | 다수의 약한 몬스터 처리 |
| 제어 | 감속, 기절, 밀치기 등 | 빠른 적과 대규모 전투 안정화 |
| 마무리 | 체력이 낮은 적에게 추가 피해 | 적의 수를 빠르게 감소 |
| 지원 | 다른 타워의 전투 성능 강화 | 전체 편성 효율 증가 |
| 대형 사냥 | 최대 체력이 높은 적에게 추가 피해 | 정예 몬스터와 스테이지 보스 |

모든 역할은 초반에 빠르게 사용할 수 있게 합니다. 역할 자체를 장기간 잠그는 대신 전체 배치 수와 역할별 복수 배치가 성장 요소가 됩니다.

특정 역할이 없으면 전투를 진행할 수 없는 구조는 피합니다. 적합한 역할을 편성하면 처리 속도와 파밍 효율이 높아지지만, 잘못된 편성이 진행을 영구적으로 막아서는 안 됩니다.

### 복합 역할 타워

일부 희귀, 변종 또는 합체 타워는 주 역할 외에 보조 기능을 가질 수 있습니다.

```text
폭풍 마법사
- 주 역할: 광역 화력
- 보조 기능: 짧은 감속
```

일부 특별한 타워는 둘 이상의 역할 슬롯 중 하나를 선택해 편성할 수 있습니다.

```text
서리폭풍 대마법사
배치 가능 역할:
- 광역 화력
- 제어
```

한 번 편성할 때는 하나의 역할 슬롯만 차지합니다.

## 3. 편성 제한과 성장

편성 제한은 다음 두 종류를 사용합니다.

1. 전체 최대 배치 수
2. 역할별 최대 배치 수

동일 타워만을 위한 별도 최대 배치 수는 사용하지 않습니다. 좋은 타워를 여러 개 획득했는데 편성하지 못하는 스트레스를 피하기 위해서입니다.

실제 편성 가능 수량은 다음 조건으로 결정됩니다.

```text
실제 편성 가능 수
= 보유 수량
∩ 해당 역할의 남은 슬롯
∩ 전체 남은 편성 슬롯
```

### 전체 최대 배치 수

프로토타입 기준:

- 시작: 4개
- 최종 상한: 12개

12개는 여섯 역할을 평균 두 개씩 사용할 수 있고, 화면 혼잡도와 공격 효과, Roblox 성능을 관리할 수 있는 상한으로 사용합니다.

| 예상 진행 | 전체 최대 배치 수 | 의도 |
|---|---:|---|
| 시작 / 스테이지 1 | 4 | 기본 조합 시작 |
| 스테이지 2 | 5 | 부족한 역할 보완 |
| 스테이지 3 | 6 | 여섯 역할을 하나씩 사용 가능 |
| 스테이지 5 | 7 | 첫 특화 편성 시작 |
| 스테이지 7 | 8 | 역할 조합이 본격적으로 갈림 |
| 스테이지 10 | 9 | 합체 및 변종 타워 편성 확대 |
| 스테이지 13 | 10 | 보스 대응 편성 구축 |
| 스테이지 16 | 11 | 후반 특화 편성 |
| 스테이지 20 | 12 | 최대 편성 완성 |

스테이지 도달만으로 자동 지급하지 않고, 해당 시점에 구매할 수 있는 스탯 트리 노드로 제공합니다. 초반 슬롯은 저렴하고 빠르게 해금하며, 11번째와 12번째 슬롯은 후반의 큰 성장 목표로 둡니다.

### 역할별 최대 배치 수

각 역할의 첫 슬롯은 초반에 모두 해금합니다.

초기 기본값 예시:

```text
단일 화력 1
광역 화력 1
제어 1
마무리 1
지원 1
대형 사냥 1
```

전체 편성 수가 4라면 여섯 역할 중 네 역할을 선택합니다. 이후 타워 스탯 트리에서 원하는 역할의 슬롯을 늘릴 수 있습니다.

```text
광역 화력 최대 배치 수 +1
지원 최대 배치 수 +1
대형 사냥 최대 배치 수 +1
```

같은 타워도 보유 수량, 역할 슬롯과 전체 슬롯이 허용하는 만큼 편성할 수 있습니다.

```text
화염 마법사 보유: 4
광역 역할 슬롯: 3
전체 남은 슬롯: 3

→ 화염 마법사 3개 편성 가능
```

지원과 제어 타워의 과도한 중첩은 편성 제한이 아니라 효과 규칙으로 조절합니다.

- 동일한 지원 효과는 가장 높은 효과만 적용하거나 효율 감소 적용
- 감속에는 최대 감속 상한 적용
- 기절에는 연속 제어 저항 또는 내부 재사용 대기시간 적용
- 각 타워 정보에 효과 중첩 여부 표시

## 4. 편성 UI

편성 UI에서는 전체 한도와 역할별 한도를 동시에 보여줍니다.

```text
전체 편성 8 / 12

[단일 화력]  2 / 3
왕실 기사       [-] 1 [+]
명사수           [-] 1 [+]

[광역 화력]  2 / 2
화염 마법사      [-] 2 [+]

[제어]       1 / 2
냉기술사         [-] 1 [+]
```

필수 기능:

- `+` 버튼으로 한 개 추가
- `-` 버튼으로 한 개 제거
- 타워 카드를 빈 슬롯 또는 다른 타워 위로 드래그해 추가·교체
- 역할별 필터와 검색
- 현재 편성된 타워를 상단에 표시
- 편성 불가능한 이유를 즉시 표시
- 전투 중 변경 가능
- 변경 즉시 추종 편대와 전투에 반영
- 타겟 우선순위 설정 저장
- 편성 교체로 공격 재사용 대기시간을 초기화하는 악용 방지

예시 안내:

```text
화염 마법사를 더 편성할 수 없습니다.
- 광역 화력 슬롯: 2 / 2
- 전체 편성: 12 / 12
- 보유 수량: 7
```

새 타워를 획득했을 때는 역할과 현재 편성 상태를 즉시 표시합니다. 시스템이 기존 타워를 자동으로 제거하지 않으며 최종 변경은 플레이어가 선택합니다.

## 5. 타겟 우선순위

기본 타겟 방식:

- 균형: 오버킬을 줄이며 적절하게 목표 분산
- 선두: 경로 진행도가 가장 높은 적
- 후미: 경로 진행도가 가장 낮은 적
- 강적: 최대 체력이 가장 높은 적
- 마무리: 현재 체력이 가장 낮은 적
- 변종 우선: 황금, 수정, 공허 등 변종 몬스터 우선

초반에는 전체 편성에 공통 타겟 명령을 적용할 수 있습니다. 이후 관련 기능을 해금하면 역할별 또는 타워별 우선순위를 지정할 수 있습니다.

```text
광역 마법사: 선두 집단
명사수: 선두
처형자: 마무리
용 사냥꾼: 강적
사냥꾼: 변종 우선
```

타겟 변경에는 재화 비용이나 긴 재사용 대기시간을 두지 않습니다.

## 6. 경로 시스템

맵 제작자가 원하는 형태의 경로를 직접 만들 수 있어야 합니다.

초기 버전에서는 하나의 경로를 사용하지만 경로 모양은 자유롭게 구성합니다.

지원 예시:

- S자 경로
- 성벽을 돌아가는 경로
- 다리와 협곡을 지나는 경로
- 마을 골목을 통과하는 경로
- 중앙 광장을 회전하는 경로
- 경사와 높낮이가 있는 입체 경로
- 서로 가까이 스쳐 지나가는 U자 경로

맵 구조 예시:

```text
Stage
├─ Spawn
├─ Base
└─ Path
   ├─ 001
   ├─ 002
   ├─ 003
   ├─ 004
   └─ 005
```

몬스터는 `Spawn → 001 → 002 → ... → Base` 순서로 이동합니다.

구현 원칙:

- Roblox 자동 길찾기에 전적으로 의존하지 않음
- 웨이포인트 순서로 고정 경로 생성
- 경로 편집 중 연결선 미리보기 제공
- 웨이포인트 사이를 부드럽게 보간 가능
- 몬스터는 이동 방향을 향해 자연스럽게 회전
- 몬스터끼리 물리적으로 밀어내지 않음
- 전체 경로 길이 자동 계산
- 맵별 목표 이동 시간 설정 가능

### 경로 길이와 이동 시간

맵마다 경로 길이가 다르기 때문에 경로 길이와 몬스터 이동속도를 분리해서 관리합니다.

```text
실제 이동속도
= 전체 경로 길이 ÷ 목표 이동 시간
```

예시:

```text
경로 길이: 300 studs
목표 이동 시간: 30초
실제 이동속도: 10 studs/s
```

스테이지 특성에 따라 목표 이동 시간을 다르게 설정할 수 있습니다.

- 일반 스테이지: 약 30초
- 군집형 스테이지: 35~40초
- 빠른 적 중심 스테이지: 20~25초
- 강한 소수 몬스터: 약 35초
- 보스: 별도 값

초기에는 갈림길과 복수 경로를 제외합니다. 단일 경로 시스템이 안정된 뒤 복수 생성 지점, 분기, 합류, 보스 전용 경로를 검토합니다.

## 7. 몬스터 위치 데이터의 이중 관리

몬스터는 경로 진행도와 실제 월드 좌표를 동시에 가집니다.

```text
Monster
├─ WorldPosition
├─ PathProgress
├─ SegmentIndex
├─ CurrentHP
├─ MaxHP
├─ ReservedDamage
├─ MoveSpeed
└─ Variant / Tags
```

두 정보는 서로 다른 판정에 사용합니다.

```text
경로 진행도 배열
├─ 선두와 후미 판정
├─ 진행도 순 정렬
├─ 타겟 우선순위
└─ 타워 간 목표 분산

실제 월드 좌표
├─ 광역 공격 반경
├─ 연쇄 공격 거리
├─ 몬스터 밀집도
└─ 범위 상태 효과
```

### 경로 진행도 배열

`PathProgress`는 전체 경로의 시작을 0, 베이스를 1 또는 100%로 표현합니다.

```text
[98%, 91%, 83%, 71%, 46%, 20%, 7%]
```

- 선두: 배열 앞쪽
- 후미: 배열 뒤쪽
- 선두 여러 마리: 앞에서부터 필요한 수만큼
- 후미 여러 마리: 뒤에서부터 필요한 수만큼

맵이 굽어 있거나 높낮이가 있어도 선두와 후미를 정확하게 판정할 수 있습니다.

### 목표 분산과 예정 피해

여러 타워가 같은 약한 적에게 공격을 낭비하지 않도록 `ReservedDamage`를 사용합니다.

```text
몬스터 현재 체력: 100
이미 예약된 피해: 80
판정상 남은 체력: 20
```

다음 타워는 해당 적에게 공격을 더하는 것이 낭비라면 우선순위 배열의 다음 적을 선택합니다.

## 8. 광역 공격 판정

광역 공격은 경로 배열에서 인접한 몬스터를 공격하는 것이 아니라 실제 맵 좌표를 기준으로 계산합니다.

```text
광역 중심: 목표 몬스터의 WorldPosition
폭발 반경: 12 studs

→ 실제 거리 12 studs 안의 몬스터에게 피해
```

경로가 U자 형태로 접혀 있다면 진행도가 크게 다른 적도 실제 위치가 가까울 경우 같은 광역 공격에 맞을 수 있습니다.

이 효과는 허용합니다. 자유로운 경로 모양이 광역 타워 효율에 영향을 주며 맵별 전투 특성을 만들기 때문입니다.

초기 판정은 단순 3D 거리 기준으로 합니다.

나중에 필요한 경우 다음 조건을 추가할 수 있습니다.

- 벽에 막히면 제외
- 높이 차이가 크면 제외
- 특정 경로 구역만 포함

### 광역 타겟 선택 순서

광역 타워는 우선순위와 실제 밀집도를 함께 사용합니다.

```text
1. 설정된 우선순위로 후보 몬스터 선택
2. 각 후보 주변의 실제 월드 좌표 검색
3. 반경 내 몬스터 수와 총 체력 계산
4. 가장 적합한 후보를 광역 중심으로 선택
5. 공격 실행
```

예시:

```text
선두 후보 A 주변: 3마리
선두 후보 B 주변: 7마리
선두 후보 C 주변: 5마리

→ 후보 B 중심으로 공격
```

타워마다 광역 판단 방식을 다르게 만들 수 있습니다.

- 폭탄병: 가장 많은 몬스터를 맞히는 집단
- 화염 마법사: 선두에 가까운 밀집 집단
- 공허 마법사: 총 체력이 가장 높은 집단
- 번개술사: 첫 목표부터 실제 거리순으로 연쇄
- 빙결술사: 빠른 몬스터가 많이 포함된 집단

### 성능 관리

몬스터 수가 적은 초기 버전에서는 단순 거리 비교를 사용할 수 있습니다.

몬스터가 많아지면 공간 그리드 또는 공간 해시를 사용합니다.

```text
맵을 일정한 크기의 셀로 구분
→ 공격 지점 주변 셀만 검색
→ 멀리 있는 몬스터는 검사하지 않음
```

경로 진행도 정렬과 공간 데이터는 매 프레임 갱신하지 않고 약 0.1~0.25초 간격으로 갱신해도 충분합니다.

## 9. 몬스터 생성 시스템

몬스터 생성은 20초 단위 생성 구간을 기준으로 합니다.

```text
20초 생성 구간
→ 다음 생성 구성 계산
→ 반복
```

각 생성 구간에는 생성값 예산이 존재하며, 몬스터는 자신의 생성 비용만큼 예산을 소비합니다.

```text
구간 생성값: 100

일반 몬스터 비용: 5
→ 최대 20마리

강한 몬스터 비용: 20
→ 최대 5마리
```

몬스터를 한 번에 생성하지 않고 20초 동안 분산해서 생성합니다.

높은 스테이지는 무조건 몬스터 수가 많아지는 구조가 아닙니다.

- 낮은 스테이지: 약한 몬스터 다수
- 높은 스테이지: 강한 몬스터 소수
- 혼합 스테이지: 서로 다른 생성 비용의 조합

맵 또는 스테이지 데이터에 필요한 값:

```text
생성 구간 길이
구간 생성값
등장 가능한 몬스터 목록
각 몬스터 생성 비용
몬스터 구성 비율
목표 이동 시간
경로
베이스 위치
```

프로토타입 권장 밀도:

| 스테이지 구간 | 예상 편성 수 | 20초당 권장 몬스터 수 |
|---|---:|---:|
| 1~3 | 4~6 | 16~24 |
| 4~7 | 6~8 | 12~18 |
| 8~12 | 8~9 | 8~14 |
| 13~16 | 10~11 | 5~10 |
| 17~20 | 11~12 | 3~8 |

이는 고정 규칙이 아니라 초기 밸런스 기준입니다. 군집형 스테이지는 더 많은 약한 적을, 강적형 스테이지는 적은 수의 강한 적을 사용합니다.

## 10. 베이스 체력과 회복

몬스터가 경로 끝에 도달하면 베이스에 피해를 주고 사라집니다.

베이스는 체력을 가지며 지속적으로 회복합니다. 한두 마리가 드물게 통과하는 것은 자연스럽게 회복되지만 짧은 시간 안에 많은 몬스터가 통과하면 위험해집니다.

프로토타입 기준:

```text
베이스 최대 체력: 100
초당 회복량: 5
```

몬스터가 주는 피해는 도착 시 남은 체력 비율을 반영합니다.

```text
실제 베이스 피해
= 몬스터 기본 베이스 피해
× 도착 시 현재 체력 / 최대 체력
```

몬스터를 처치하지 못했어도 많은 피해를 줬다면 베이스 피해가 줄어듭니다.

초기 몬스터 피해 예시:

| 몬스터 종류 | 최대 체력 상태로 도착했을 때 피해 |
|---|---:|
| 빠른 소형 몬스터 | 15 |
| 일반 몬스터 | 20 |
| 방어형 몬스터 | 25 |
| 정예 몬스터 | 35 |
| 스테이지 보스 | 50 |

### 베이스 체력이 0이 된 경우

영구적인 패배 대신 베이스 과부하로 처리합니다.

```text
1. 현재 필드 몬스터 정리
2. 몬스터 생성 5초 중단
3. 베이스 체력 완전 회복
4. 같은 스테이지에서 자동 재개
5. 타워, 재화, 굴리기 진행과 스탯은 유지
```

실제 손실은 짧은 재정비 시간 동안 몬스터 보상을 얻지 못하는 정도입니다.

## 11. 상태 효과

상태 효과는 역할 전체에 고정하지 않고 각 타워가 개별적으로 가집니다.

예시:

```text
냉기술사
- 공격 시 3초 동안 25% 감속

천둥술사
- 10% 확률로 0.5초 기절

부패 마법사
- 5초 동안 지속 피해

왕실 사냥꾼
- 대상에게 표식
- 표식 대상이 받는 피해 증가
```

상태 효과 데이터:

```text
효과 종류
발동 확률
효과 수치
지속시간
중첩 방식
최대 중첩 수
보스 적용 규칙
```

## 12. 현재 확정된 전투 규칙

- 타워는 플레이어를 따라다니며 맵에 고정 설치하지 않는다.
- 일반 스테이지에서는 공격 사거리 제한이 없다.
- 타워 역할은 단일 화력, 광역 화력, 제어, 마무리, 지원, 대형 사냥으로 구분한다.
- 모든 역할은 초반에 빠르게 사용할 수 있다.
- 전체 최대 배치 수는 4개로 시작해 12개까지 성장한다.
- 역할별 최대 배치 수는 타워 스탯 트리로 확장한다.
- 동일 타워만을 위한 별도의 편성 제한은 두지 않는다.
- 편성은 전투 중에도 무료로 변경할 수 있다.
- 맵 제작자가 웨이포인트를 사용해 자유로운 단일 경로를 만든다.
- 선두, 후미와 타겟 분산은 경로 진행도 배열을 사용한다.
- 광역 공격, 연쇄 공격과 범위 효과는 실제 월드 좌표를 사용한다.
- 오버킬 방지를 위해 예약 피해를 고려한다.
- 몬스터 생성은 20초 단위 생성값 예산을 기준으로 한다.
- 베이스는 체력을 가지며 지속적으로 회복한다.
- 몬스터의 도착 피해는 남은 체력 비율을 반영한다.
- 베이스가 0이 되어도 영구 손실 없이 짧은 재정비 후 자동 재개한다.
- 상태 효과는 타워마다 개별적으로 정의한다.

- 편성 프리셋과 자동 편성 기능
